A partir daqui, o mesmo JavaScript passa a rodar fora do navegador. O Node.js é o
ambiente que torna isso possível, e o Express é a camada fina que transforma esse
ambiente em um servidor HTTP com rotas, middlewares e respostas em JSON.

Este é o tópico em que o projeto da disciplina deixa de ser um front-end isolado e
passa a ter um back-end de verdade: uma API que recebe requisições, valida dados,
consulta um banco e devolve respostas com o status HTTP correto.

## O que esperar deste tópico

Primeiro o ambiente: rodar arquivos, entender módulos no Node.js e gerenciar
dependências com npm. Depois o servidor: do `hello world` em HTTP puro até uma API
organizada em camadas, com controllers, middlewares, tratamento de erros
padronizado, cadastro de usuário e autenticação.

<Aside type="tip" title="A prática é incremental">
  Os quatro [projetos práticos](../../projects/) acompanham exatamente esta
  sequência: cada um adiciona uma camada ao anterior, e o último já é a base do
  projeto final da disciplina.
</Aside>
