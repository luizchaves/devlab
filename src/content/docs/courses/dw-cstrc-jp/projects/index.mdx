Cada projeto acrescenta poucos conceitos ao anterior. Todos existem como código real
e executável em `examples/` no repositório — clone, instale e rode.

## Progressão

```text
task-api-hello        servidor, rotas, JSON
      │
      ▼
task-api-router       modularização com express.Router()
      │
      ▼
task-api-mvc          models, controllers e middlewares
      │
      ▼
task-api-typescript   as mesmas camadas, tipadas
      │
      ▼
task-api-validation   validação de entrada com Zod
      │
      ▼
task-api-openapi      contrato publicado em OpenAPI
      │
      ▼
task-api-sqlite       persistência com node:sqlite
      │
      ▼
task-api-prisma       persistência com ORM e relações
      │
      ▼
autenticação          tokens e controle de acesso
```

A última etapa fica por conta do projeto final da disciplina.

## Como rodar qualquer projeto?

```bash
git clone https://github.com/luizchaves/devlab.git
cd devlab/examples/courses/expressjs/projects/task-api-mvc
pnpm install
pnpm dev
```

<Aside type="tip" title="Código sempre sincronizado">
  As páginas dos tópicos importam os arquivos diretamente de `examples/`. Se o projeto
  muda, a documentação muda junto — não existe cópia manual para ficar desatualizada.
</Aside>
