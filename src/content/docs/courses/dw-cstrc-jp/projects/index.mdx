Cada projeto acrescenta poucos conceitos ao anterior. Todos existem como código real
e executável em `examples/` no repositório — clone, instale e rode.

## Progressão

```text
express-basic     servidor, rotas, JSON
      │
      ▼
express-router    modularização com express.Router()
      │
      ▼
express-mvc       models, controllers e middlewares
      │
      ▼
express-prisma    persistência com ORM
      │
      ▼
REST API          verbos, status e convenções
      │
      ▼
validation        validação de entrada em middleware
      │
      ▼
authentication    autenticação com tokens
```

As duas últimas etapas ficam por conta do projeto final da disciplina.

## Como rodar qualquer projeto

```bash
git clone https://github.com/luizchaves/devlab.git
cd devlab/examples/express/projects/mvc
pnpm install
pnpm dev
```

<Aside type="tip" title="Código sempre sincronizado">
  As páginas das aulas importam os arquivos diretamente de `examples/`. Se o projeto
  muda, a documentação muda junto — não existe cópia manual para ficar desatualizada.
</Aside>
