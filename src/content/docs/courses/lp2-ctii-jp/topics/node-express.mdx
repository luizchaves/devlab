Aqui a disciplina vira do avesso: em vez de consumir uma API, você passa a
construí-la. Primeiro um servidor HTTP com o módulo nativo do Node.js, para ver o
ciclo requisição-resposta sem intermediários; depois o Express, que organiza esse
ciclo em rotas e middlewares.

## O que esperar deste tópico

Do `hello world` em HTTP puro até a Invest API completa, com as quatro operações de
CRUD, os três tipos de parâmetro de requisição (query, route e body) e os status
codes corretos para cada caso.

<Aside type="note" title="Os três parâmetros">
  Query, route e body param são a fonte mais comum de confusão no início. Cada um tem
  um lugar na URL ou na requisição, e o Express expõe cada um em um objeto diferente:
  `req.query`, `req.params` e `req.body`.
</Aside>
