A disciplina abre revisando a linguagem. O objetivo não é cobrir JavaScript por
inteiro, e sim firmar o subconjunto que o restante do semestre vai exigir: tipos,
variáveis, operadores, decisão, repetição e funções.

Em seguida a linguagem sai do console e vai para a página: manipular o HTML,
responder a eventos de formulário e conversar com uma API.

## O que esperar deste tópico

Uma revisão rápida da sintaxe, seguida do uso prático no navegador — conteúdo
dinâmico, formulários, eventos e um CRUD completo consumindo a API que você mesmo vai
construir na segunda metade da disciplina.

<Aside type="tip" title="Revisão sob demanda">
  Os guias cobrem cada assunto com mais profundidade do que a revisão exige. Use-os
  como consulta: leia a página inteira só quando o assunto ainda estiver frágil.
</Aside>
