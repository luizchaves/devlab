O **Guia de React** cobre a construção de interfaces com componentes: como descrever a
tela em JSX, passar dados por props, derivar a UI do estado e reagir a mudanças com
hooks. Ele pressupõe o [Guia de ECMAScript](../ecmascript/) — sobretudo funções,
desestruturação, módulos e assincronismo — e o [Guia de Web APIs](../web-api/) para o
consumo de dados.
