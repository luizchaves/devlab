O **Guia de React** ensina a construir interfaces por etapas: primeiro a aplicação mínima,
depois componentes e JSX, em seguida props, estado, eventos, ciclo de vida, hooks, requisições
assíncronas, roteamento e gerenciamento de estado. A progressão segue a lógica de roadmaps
atuais de React, como o [roadmap.sh](https://roadmap.sh/react), adaptada ao ritmo do DevLab.

<Aside type="tip" title="Dica de IA: Transforme o guia em plano de estudo">
  Use a IA para transformar esta trilha em um cronograma semanal, mas peça que ela preserve a
  ordem dos conceitos. Pular de hooks avançados para Redux antes de entender props e estado local
  costuma gerar aplicações difíceis de depurar.

  **Prompt:** *"Monte um plano de quatro semanas para estudar este Guia de React na ordem das páginas; inclua um exercício prático por página e um critério de verificação para cada semana."*
</Aside>

## Objetivo

Compreender React como uma forma de descrever interfaces a partir de dados e eventos, evoluindo
de componentes pequenos para aplicações com navegação, estado compartilhado, integração com APIs
e organização de projeto. Ao final do guia, o leitor deve ser capaz de:

- Criar um projeto React com Vite ou Next.js e explicar a diferença entre as duas escolhas.
- Escrever componentes com JSX, composição, props e renderização condicional.
- Controlar estado local, eventos, formulários e listas com chaves estáveis.
- Usar hooks para sincronizar a interface com APIs, timers, armazenamento e outros sistemas externos.
- Escolher entre estado local, Context API, Redux Toolkit e bibliotecas de servidor de dados.
- Implementar roteamento e um projeto prático com fluxo completo de tela, dados e erro.

## Como Estudar

Use cada tópico como uma pequena iteração de produto: leia o conceito, rode o exemplo, modifique
um detalhe e faça o exercício. Quando a página comparar alternativas, como Vite versus Next.js
ou Context API versus Redux, não escolha pela popularidade: escolha pelo problema concreto que
o projeto precisa resolver.

<Aside type="note" title="Conceitos que aparecem ao longo do caminho">
  JSX, Virtual DOM, ciclo de vida, hooks e gerenciamento de estado não são assuntos isolados. Eles
  se conectam em uma cadeia: estado muda, React renderiza novamente, componentes recebem props,
  efeitos sincronizam com sistemas externos e o roteador decide qual parte da árvore aparece.
</Aside>

## Projeto Prático do Guia

Ao final, o guia propõe um projeto autoral. A sugestão-base é um **Painel de Hábitos, Estudos ou
Investimentos**, mas o aluno pode trocar o domínio mantendo os mesmos requisitos técnicos:
componentes reutilizáveis, lista filtrável, formulário controlado, rota de detalhe, consumo de
API externa, tratamento de erro, estado compartilhado e persistência simples.

O objetivo não é decorar uma stack. O objetivo é conseguir explicar por que cada parte existe,
qual problema ela resolve e qual alternativa seria aceitável se o projeto crescesse.
