Express é um framework minimalista para servidores HTTP em Node.js. Ele resolve
justamente o que era trabalhoso no [servidor em Node puro](../../../nodejs/basics/introduction/): roteamento,
leitura do corpo da requisição e escrita da resposta.

## Definição

[Site Express](http://expressjs.com/):

> Express is a minimal and flexible Node.js web application framework that provides a robust set of features for web and mobile applications.

## Características

- Rápido
- Minimalista
- Flexível
- Não opinativo
- Usado para montar APIs
- Alguns frameworks são baseados no Express


## Objetivo

Subir um servidor que responde JSON em algumas rotas, entendendo o ciclo
**requisição → rota → resposta**.

<Aside type="note" title="Por que `express.json()`?">
  Sem esse middleware, `req.body` é `undefined`. Ele lê o corpo da requisição e o
  converte em objeto JavaScript quando o `Content-Type` é `application/json`.
</Aside>

## Anatomia de uma rota

```js
app.get('/hello/:name', (req, res) => {
  res.json({ message: `Hello ${req.params.name}` });
});
//  │    │              │     │
//  │    │              │     └─ resposta
//  │    │              └─────── requisição
//  │    └────────────────────── caminho (com parâmetro)
//  └─────────────────────────── método HTTP
```

Os objetos mais usados:

| Objeto            | Contém                                         |
| ----------------- | ---------------------------------------------- |
| `req.params`      | Parâmetros da rota (`/users/:id`)              |
| `req.query`       | Query string (`?page=1`)                       |
| `req.body`        | Corpo da requisição (requer `express.json()`)  |
| `res.json(dados)` | Envia JSON e define o `Content-Type`           |
| `res.status(201)` | Define o status; encadeia com `.json()`        |

Para executar o projeto use algum destes comandos:

```sh
$ node src/index.js
```

```sh
$ npm start
```

Já a execução no modo watch:

```sh
$ npm run dev
```

Depende da versão do node.js, o modo watch precisa de um pacoto como o [nodemon](https://www.npmjs.com/package/nodemon) para funcionar:

```js
 "scripts": {
    ...
    "dev": "nodemon src/index.js"
  },
```

```sh
$ npm install nodemon -D
$ npx nodemon src/index.js
$ npm run dev
```
