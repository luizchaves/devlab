Nível **Iniciante → Avançado** · Node.js · Express.js · TypeScript · Prisma

O **InvestApp** é a aplicação que atravessa o guia inteiro: um controle de investimentos com
front-end web e API própria. Ele não é um projeto pronto — é a **mesma** aplicação em seis
estados, cada um em uma branch do repositório.

<ProjectLinks repo="luizchaves/lp2-2026" path="classroom/back-end/investment-api" />

## A ideia

Cada etapa resolve exatamente um problema novo e mantém tudo que veio antes. Comparar duas
branches com `git diff` mostra, isolado, o que aquela etapa mudou — e é a melhor forma de ver
o efeito de uma decisão de arquitetura.

## O que muda em cada etapa

| Etapa | Branch        | Persistência   | Linguagem   | Novidade principal                     |
| ----- | ------------- | -------------- | ----------- | -------------------------------------- |
| 1     | `f476d6b`     | array          | JavaScript  | rotas, JSON e o front consumindo a API  |
| 2     | `sqlite`      | `node:sqlite`  | JavaScript  | migration, seeders e model com SQL      |
| 3     | `typescript`  | `node:sqlite`  | TypeScript  | camadas, `HttpError`, tipos do domínio  |
| 4     | `prisma-js`   | Prisma + SQLite| TypeScript  | schema, migrations e relações           |
| 5     | `create-user` | Prisma         | TypeScript  | `User`, Argon2id e cadastro             |
| 6     | `main`        | Prisma         | TypeScript  | login, JWT e autorização por dono       |

<Aside type="tip" title="Compare duas etapas com um comando">
  ```bash title="Terminal"
  git clone https://github.com/luizchaves/lp2-2026
  cd lp2-2026
  git diff sqlite typescript -- classroom/back-end/investment-api/src
  ```

  O diff entre `sqlite` e `typescript` é a migração de linguagem e a separação em camadas,
  sem nenhum ruído de funcionalidade nova.
</Aside>

## Como rodar qualquer etapa

Cada página de etapa traz os botões **Ver no GitHub** e **Abrir no Codespaces** já apontando
para a branch correta. Localmente:

```bash title="Terminal"
git clone https://github.com/luizchaves/lp2-2026
cd lp2-2026/classroom/back-end/investment-api
git switch sqlite          # ou a branch da etapa desejada
npm install
npm run dev
```

<Aside type="caution" title="As dependências mudam entre as branches">
  A etapa 4 em diante instala o Prisma; a etapa 3 acrescenta `typescript` e `@types/*`.
  Rode `npm install` de novo sempre que trocar de branch — o `package.json` é diferente.
</Aside>
