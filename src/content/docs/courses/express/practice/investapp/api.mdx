## Antes: `hello-api`

O repositório traz um projeto ainda menor, útil para conferir se o ambiente está de pé:

```js title="hello-api/src/index.js" showLineNumbers {6,9,12}
import express from 'express';
import morgan from 'morgan';

const app = express();

app.use(morgan('tiny'));

// Arquivos estáticos: public/index.html responde em GET /
app.use(express.static('public'));

// Conteúdo dinâmico: método + caminho
app.get('/api/hello', (req, res) => res.send('Hello, World!'));

app.listen(3000, () => console.log('Server is running on port 3000'));
```

Duas linhas resumem a arquitetura de todas as etapas seguintes: `express.static` serve a
interface e `/api/*` serve os dados — **mesma origem**, sem CORS.

## O contrato

Cinco rotas, o CRUD completo do recurso `investments`:

| Método | Caminho                | Corpo               | Sucesso | Erros        |
| ------ | ---------------------- | ------------------- | ------- | ------------ |
| GET    | `/api/investments`     | —                   | `200`   | —            |
| GET    | `/api/investments?name=`| —                  | `200`   | —            |
| GET    | `/api/investments/:id` | —                   | `200`   | `404`        |
| POST   | `/api/investments`     | `{ name, value }`   | `201`   | `400`        |
| PUT    | `/api/investments/:id` | `{ name, value }`   | `200`   | `400`, `404` |
| DELETE | `/api/investments/:id` | —                   | `204`   | `404`        |

## O front-end

A interface conversa com a API por uma camada fina, e nenhuma tela conhece `fetch`
diretamente:

```js title="public/js/main.js" showLineNumbers {3,8}
async function listar() {
  const response = await fetch('/api/investments');
  const investments = await response.json();

  render(investments);
}

async function criar(dados) {
  await fetch('/api/investments', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(dados),
  });

  listar();
}
```

<Aside type="caution" title="O que se perde ao reiniciar">
  Tudo. O array vive na memória do processo: um `Ctrl+C` apaga os investimentos cadastrados.
  É exatamente o problema que a próxima etapa resolve.
</Aside>

## Conceitos abordados

- Filtro por query string
- Status codes de sucesso e de erro
- `request.http` como contrato executável
