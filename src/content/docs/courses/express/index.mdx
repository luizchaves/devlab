O **Guia de Express.js** cobre a construção de APIs HTTP em Node.js: do primeiro servidor até
uma aplicação em camadas, com banco, autenticação e deploy. Ele pressupõe o
[Guia de Node.js](../nodejs/) e conversa com o [Guia de TypeScript](../typescript/) — os
fundamentos começam em JavaScript e migram para TypeScript logo na quinta aula.

<Aside type="tip" title="Nativo primeiro, pacote depois">
  Sempre que o Node resolve o problema sozinho — hash de senha, JWT, CORS, limite de
  requisições, testes, leitura de `.env` — o guia mostra a versão nativa antes de citar o
  pacote equivalente. Escolher `bcrypt` depois de ter escrito o Argon2id é uma decisão;
  escolher antes é sorte.
</Aside>

## Como o guia está organizado

Cada tópico aparece em **duas** páginas com propósitos diferentes:

| Página                | O que traz                                                                 |
| --------------------- | -------------------------------------------------------------------------- |
| **Aula de conceito**  | a ideia, o diagrama, as armadilhas, trechos mínimos, exercício e revisão     |
| **Página de projeto** | o código completo que roda, a árvore de arquivos, o passo a passo e os botões de acesso |

As aulas de conceito ficam nas categorias temáticas; os projetos, em **Na Prática**. Cada
uma aponta para a outra.

## Por onde começar

Se você nunca subiu um servidor HTTP, comece por
[Fundamentos](basics/introduction/) e siga a ordem da barra lateral. Se já conhece Express e
quer o que costuma faltar, vá direto a [Tratamento de Erros](api/error-handling/),
[Senhas e Hash](auth/passwords/) e [Endurecimento](security/hardening/).
