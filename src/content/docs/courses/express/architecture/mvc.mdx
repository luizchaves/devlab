## Objetivo

Reorganizar a aplicação de usuários seguindo **MVC**, de modo que cada arquivo tenha
uma única responsabilidade — e trocar o armazenamento (memória hoje, banco de dados
na próxima etapa) exija mudar **um** arquivo apenas.

Ao final você terá um CRUD completo de usuários com tratamento de erros centralizado.

## Conceitos

## Arquitetura

```text
    requisição HTTP
          │
          ▼
     app.js  ──────► middlewares  (express.json, logger)
          │
          ▼
     routes/  ─────► define os caminhos
          │
          ▼
  controllers/ ────► valida a entrada e monta a resposta
          │
          ▼
     models/  ─────► lê e grava os dados
          │
          ▼
     resposta JSON        (erros ──► middlewares/error-handler.js)
```

A dependência aponta sempre em uma direção: o router conhece o controller, o
controller conhece o model, e o model não conhece ninguém. É isso que permite trocar
a camada de dados sem tocar nas outras.

<Aside type="caution" title="A ordem é a arquitetura">
  `express.json()` precisa vir antes do router, senão `req.body` chega `undefined`.
  E `errorHandler` precisa vir por último, senão nunca é alcançado.
</Aside>

## Exercício

Adicione o recurso **produtos** ao projeto, seguindo exatamente a mesma estrutura:

1. `src/models/product-model.js` com `findAll`, `findById`, `create` e `remove`;
2. `src/controllers/product-controller.js` com `index`, `show`, `store` e `destroy`;
3. `src/routes/product-router.js` apontando para o controller;
4. registre o router em `app.js` sob o prefixo `/products`.

Um produto tem `id`, `name` e `price`. Rejeite com `400` a criação sem `name` ou com
`price` negativo.

## Desafio

Extraia a validação para um middleware reutilizável:

```js title="src/middlewares/validate.js"
export function validate(camposObrigatorios) {
  return (req, res, next) => {
    // devolve um middleware que valida req.body
  };
}
```

Use-o nas rotas de criação dos dois recursos:

```js title="src/routes/user-router.js" ins={1}
router.post('/', validate(['name', 'email']), userController.store);
```

O controller deve ficar sem nenhum `if` de validação. Pense: onde esse middleware
precisa ser registrado para que o erro chegue ao `errorHandler`?
