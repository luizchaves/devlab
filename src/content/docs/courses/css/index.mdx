O **Guia de CSS** é um material de referência técnica para estilização de páginas Web com CSS3. Ele cobre desde a sintaxe básica, cascata e especificidade até a criação de layouts modernos com Flexbox e CSS Grid, variáveis CSS, tipografia, design responsivo e os frameworks Bootstrap e Tailwind.
