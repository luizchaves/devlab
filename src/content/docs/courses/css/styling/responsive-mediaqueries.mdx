O **Design Responsivo** (*Responsive Web Design*) é a prática de criar páginas Web que se adaptam perfeitamente ao tamanho da tela e às capacidades de qualquer dispositivo (smartphones, tablets, notebooks e monitores ultrawide).

---

## Objetivo

Compreender o conceito de **Mobile-First**, configurar corretamente a viewport HTML, utilizar **Media Queries** com `@media` e utilizar a tecnologia recente de **Container Queries** (`@container`).

---

## O Elemento Essencial: Viewport Meta Tag

Para que qualquer layout responsivo funcione em celulares, o arquivo HTML **deve** incluir a tag de viewport no `<head>`:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Sem essa tag, os navegadores mobile simulam uma tela desktop de 980px e encolhem a página, tornando a leitura impossível.

---

## Estratégia Mobile-First vs. Desktop-First

<Tabs>
  <TabItem label="Mobile-First (Recomendado)">
    Escreva primeiro o CSS para telas pequenas (smartphones). Em seguida, adicione Media Queries usando `min-width` para expandir o layout conforme a tela cresce.

    ```css
    /* Estilos base (Mobile) */
    .card-list {
      display: flex;
      flex-direction: column;
      gap: 1rem;
    }

    /* Tablets e telas maiores (≥ 768px) */
    @media (min-width: 48rem) {
      .card-list {
        flex-direction: row;
      }
    }
    ```

    - **Vantagens**: Carregamento mais leve em redes móveis, código mais limpo e arquitetura progressiva.
  </TabItem>

  <TabItem label="Desktop-First">
    Escreva o CSS para monitores desktop e use `max-width` para desconstruir ou esconder elementos em telas menores.

    ```css
    /* Estilos base (Desktop) */
    .sidebar {
      width: 300px;
      display: block;
    }

    /* Telas pequenas (≤ 768px) */
    @media (max-width: 48rem) {
      .sidebar {
        display: none;
      }
    }
    ```
  </TabItem>
</Tabs>

## Breakpoints Típicos

Breakpoints são os pontos de corte de largura de tela onde o layout muda:

| Categoria | Breakpoint Típico | Dispositivos |
| :--- | :--- | :--- |
| **Mobile** | `< 640px` (`< 40rem`) | Smartphones em retrato. |
| **Tablet** | `≥ 640px` (`≥ 40rem`) | Smartphones grandes e tablets. |
| **Desktop** | `≥ 1024px` (`≥ 64rem`) | Laptops e monitores desktop. |
| **Wide Desktop** | `≥ 1280px` (`≥ 80rem`) | Monitores grandes e ultrawide. |

## Media Queries Avançadas

Media queries não consultam apenas a largura da tela; elas também detectam preferências do usuário e capacidades do hardware:

```css
/* 1. Preferência por Modo Escuro (Dark Mode) */
@media (prefers-color-scheme: dark) {
  body {
    background-color: #0f172a;
    color: white;
  }
}

/* 2. Preferência por Movimento Reduzido (Acessibilidade) */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

/* 3. Dispositivos de Impressão */
@media print {
  .no-print, nav, footer {
    display: none;
  }
}
```

## Recursos Modernos: Container Queries (`@container`)

Diferente das Media Queries (que consultam a largura da janela inteira), as **Container Queries** permitem que um componente se adapte com base na largura do seu **contêiner pai**:

```css
/* 1. Define o pai como um contêiner de tamanho */
.card-wrapper {
  container-type: inline-size;
}

/* 2. O card se adapta ao tamanho do pai, não da janela */
@container (min-width: 400px) {
  .card {
    display: flex;
    flex-direction: row;
  }
}
```

---

## Resumo e Boas Práticas

- Adicione sempre a tag `<meta name="viewport">` no cabeçalho do HTML.
- Adote a abordagem **Mobile-First** usando Media Queries com `min-width`.
- Use unidades relativas (`rem`, `em`, `%`) em Media Queries para responder ao tamanho da fonte do usuário.
