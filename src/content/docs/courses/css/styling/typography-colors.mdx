A **estilização visual** de uma aplicação envolve quatro pilares fundamentais: escolha e hierarquia tipográfica, paleta de cores consistente, carregamento de fontes e ícones (como **Google Fonts**, **Lucide Icons** e **Material Symbols**), e o uso de **variáveis CSS** (*custom properties*).

Uma escolha tipográfica bem estruturada combinada com ícones vetoriais modernos melhora a escaneabilidade do texto e a intuição da interface de usuário (*UI*).

---

## Objetivo

Dominar o carregamento de fontes externas com Google Fonts e `@font-face`, incorporar bibliotecas de ícones modernos (como **Lucide** e **Google Material Symbols**), aplicar formatos de cores modernos (`hex`, `rgb`, `hsl`, `oklch`) e estruturar um design system com variáveis CSS.

## 1. Carregando Web Fonts (Google Fonts e `@font-face`)

Para utilizar fontes que não estão instaladas por padrão no sistema operacional do usuário, devemos importá-las como Web Fonts.

### Método 1: Inclusão via `<link>` no HTML (Recomendado por Performance)

Esta é a abordagem mais rápida porque utiliza `preconnect` para antecipar a conexão com os servidores do Google Fonts:

```html title="index.html"
<!-- 1. Pré-conecta aos domínios de fontes para reduzir latência -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- 2. Carrega a família de fontes Inter com os pesos 400, 600 e 700 -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
```

No seu arquivo CSS, declare a fonte com uma lista de fontes de reserva (*fallbacks*):

```css title="style.css"
body {
  font-family: 'Inter', system-ui, -apple-system, sans-serif;
  font-size: 1rem;
  line-height: 1.5;
  color: #334155;
}
```

### Método 2: Importação com `@import` no CSS

Você também pode importar a fonte no topo do seu arquivo `.css`:

```css title="style.css"
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap');

h1, h2, h3 {
  font-family: 'Inter', sans-serif;
  font-weight: 700;
}
```

### Método 3: Fontes Locais com `@font-face`

Caso possua os arquivos de fonte (`.woff2`) salvos no projeto, declare a regra `@font-face`:

```css title="style.css"
@font-face {
  font-family: 'MinhaFonteCustomizada';
  src: url('/fonts/MinhaFonte.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap; /* Garante exibição de texto imediata com fallback */
}
```

## 2. Inclusão de Ícones (Lucide, Google Material Symbols e SVG)

Ícones acrescentam clareza visual a botões, menus e alertas.

### Método A: Lucide Icons (Biblioteca SVG Moderna)

O **Lucide** é uma das bibliotecas de ícones mais populares e leves do mercado.

Você pode incluir os ícones Lucide via CDN simples em páginas HTML estáticas usando a marcação `<i data-lucide="...">`:

```html title="index.html"
<!-- 1. Inclui o script do Lucide via CDN -->
<script src="https://unpkg.com/lucide@latest"></script>

<!-- 2. Adiciona o elemento i informando o nome do ícone -->
<button class="btn">
  <i data-lucide="shopping-cart"></i> Comprar Agora
</button>

<button class="btn-danger">
  <i data-lucide="trash-2"></i> Excluir
</button>

<!-- 3. Inicializa os ícones no final da página -->
<script>
  lucide.createIcons();
</script>
```

Para estilizar ícones do Lucide no CSS, você pode controlar seu tamanho e cor usando `width`, `height` e `stroke`:

```css title="style.css"
.btn {
  display: inline-flex;
  align-items: center;
  gap: 0.5rem;
  padding: 0.75rem 1.25rem;
  background-color: #2563eb;
  color: #ffffff;
  border: none;
  border-radius: 0.375rem;
  font-weight: 600;
}

/* O script do Lucide gera uma tag <svg class="lucide lucide-name"> */
.btn svg {
  width: 1.25rem;
  height: 1.25rem;
  stroke-width: 2px;
}
```

```txt title="Resultado na tela (Botões com Lucide Icons)"
+------------------------------------+   +---------------------------+
|  [🛒] Comprar Agora                |   |  [🗑️] Excluir             |
+------------------------------------+   +---------------------------+
```

### Método B: Google Material Symbols (Icon Fonts)

O **Google Material Symbols** disponibiliza milhares de ícones mantidos pelo Google que funcionam como uma fonte de caracteres.

Para incluir o Google Material Symbols:

```html title="index.html"
<!-- 1. Importa a folha de estilos do Material Symbols -->
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0,0" />

<!-- 2. Utiliza a tag span com a classe material-symbols-outlined contendo o nome do ícone como texto -->
<button class="icon-button">
  <span class="material-symbols-outlined">search</span> Pesquisar
</button>

<span class="material-symbols-outlined favorite-icon">favorite</span>
```

Estilizando ícones do Material Symbols no CSS como se fossem texto (usando `font-size` e `color`):

```css title="style.css"
.material-symbols-outlined {
  font-size: 1.5rem;
  color: #64748b;
  vertical-align: middle;
}

.favorite-icon {
  color: #ef4444; /* Ícone vermelho */
  font-variation-settings: 'FILL' 1; /* Preenche o coração */
}
```

### Método C: Ícones SVG Inline Direto no HTML

Inserir a tag `<svg>` diretamente no arquivo HTML é a forma mais flexível e de melhor performance, eliminando requisições de rede adicionais:

```html title="index.html"
<button class="btn-search">
  <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <circle cx="11" cy="11" r="8"></circle>
    <line x1="21" y1="21" x2="16.65" y2="16.65"></line>
  </svg>
  <span>Buscar</span>
</button>
```

<Aside type="tip" title="Usando stroke='currentColor'">
  Ao utilizar `stroke="currentColor"` ou `fill="currentColor"` em elementos SVG, o ícone herda automaticamente a cor do texto (`color`) definida no CSS do seu elemento pai!
</Aside>

## 3. Unidades de Medida e Hierarquia Tipográfica

No CSS moderno, evite fixar tamanhos de fontes em pixels (`px`). Prefira a unidade relativa `rem`:

| Unidade | Base de Cálculo | Uso Recomendado |
| :--- | :--- | :--- |
| `rem` | Relativo ao tamanho da fonte do elemento raiz (`<html>`). Padrão: `1rem = 16px`. | **Tamanho de fontes, margens, paddings e layouts.** |
| `em` | Relativo ao tamanho da fonte do **elemento atual ou pai**. | Espaçamentos que devem escalar proporcionalmente com a fonte. |
| `px` | Pixel absoluto estático da tela. | Bordas finas (`1px` ou `2px`). |

```css title="Escala tipográfica com rem"
html {
  font-size: 100%; /* Respeita a preferência de tamanho do navegador do usuário */
}

h1 {
  font-size: 2.25rem; /* 36px */
  line-height: 1.2;
}

p {
  font-size: 1rem;    /* 16px */
  line-height: 1.6;
}
```

## 4. Sistemas de Cores Modernos

O CSS suporta diversos formatos para especificar cores:

```css title="Formatos de cores"
.card {
  /* 1. Hexadecimal (#RRGGBB ou #RRGGBBAA) */
  color: #1e293b;

  /* 2. RGB / RGBA com sintaxe moderna sem vírgulas */
  background-color: rgb(241 245 249 / 90%);

  /* 3. HSL (Hue, Saturation, Lightness) */
  border-color: hsl(221 83% 53%);

  /* 4. OKLCH (Soma estabilidade perceptual perfeita) */
  outline-color: oklch(0.6 0.2 250);
}
```

## 5. Variáveis CSS (`Custom Properties`)

Variáveis CSS armazenam valores reutilizáveis no topo da folha de estilos.

Elas são declaradas com o prefixo `--` e consumidas com a função `var()`:

```css title="design-tokens.css"
:root {
  --font-primary: 'Inter', system-ui, sans-serif;
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-bg: #f8fafc;
  --color-text: #0f172a;
  --radius-md: 0.5rem;
}

/* Aplicando as variáveis */
body {
  font-family: var(--font-primary);
  background-color: var(--color-bg);
  color: var(--color-text);
}

.btn {
  background-color: var(--color-primary);
  border-radius: var(--radius-md);
}

.btn:hover {
  background-color: var(--color-primary-hover);
}
```

## Executando e testando no DevTools

Você pode inspecionar o carregamento de fontes e ícones diretamente no navegador:

<Steps>

1. **Abra o DevTools** (<kbd>F12</kbd>) e selecione a aba **Rede (Network)**.

2. **Filtre por `Font`** para verificar se os arquivos de fonte do Google Fonts foram baixados sem erros.

3. **Inspecione um ícone** com a ferramenta de elementos para ajustar seu `font-size`, `color` ou `stroke` interativamente.

## Perguntas de revisão

### Web Fonts e Tipografia

1. **Qual a vantagem de usar `<link rel="preconnect">` ao importar o Google Fonts no HTML?**
   <details>
     <summary>Possível resposta</summary>

     Ele instrui o navegador a estabelecer conexões antecipadas com os servidores do Google (DNS lookup, TCP handshake, TLS negotiation), reduzindo substancialmente o tempo de carregamento das fontes.
   </details>

2. **Por que a unidade `rem` é mais recomendada que o `px` para tamanhos de fonte?**
   <details>
     <summary>Possível resposta</summary>

     Porque o `rem` é relativo ao tamanho padrão do elemento raiz (`<html>`), o que respeita a configuração de acessibilidade e o zoom de texto configurado pelo usuário no seu próprio sistema ou navegador.
   </details>

3. **Para que serve a propriedade `font-display: swap` no `@font-face`?**
   <details>
     <summary>Possível resposta</summary>

     Ela garante que o texto seja exibido imediatamente usando uma fonte do sistema enquanto a fonte web está sendo baixada, substituindo-a assim que a transferência for concluída (*swap*), evitando o texto invisível (*FOIT*).
   </details>

### Bibliotecas de Ícones

4. **Como funcionam os ícones do Lucide Icons no HTML?**
   <details>
     <summary>Possível resposta</summary>

     Eles usam elementos `<i data-lucide="nome-do-icone">` que são convertidos em elementos `<svg>` leves via JavaScript (`lucide.createIcons()`), permitindo estilizá-los facilmente no CSS.
   </details>

5. **Como funciona a biblioteca Google Material Symbols?**
   <details>
     <summary>Possível resposta</summary>

     Ela funciona como uma fonte de ícones (*icon font*). Você importa a folha de estilos e declara a tag `<span class="material-symbols-outlined">nome_do_icone</span>`, estilizando a cor e o tamanho usando `color` e `font-size`.
   </details>

6. **O que faz a declaração `stroke="currentColor"` ou `fill="currentColor"` em um ícone SVG?**
   <details>
     <summary>Possível resposta</summary>

     Faz com que a cor de preenchimento ou do traço do SVG herde automaticamente o valor da propriedade CSS `color` definida no elemento pai.
   </details>

7. **Qual a diferença entre uma Icon Font (como Material Symbols) e um SVG Inline?**
   <details>
     <summary>Possível resposta</summary>

     Icon Fonts funcionam como texto e dependem de um download de arquivo de fonte completo. O SVG Inline insere o desenho direto na marcação HTML, com melhor performance, sem requisições de rede adicionais e suporte total a animações CSS independentes por traço.
   </details>

8. **Para que serve a propriedade `line-height`?**
   <details>
     <summary>Possível resposta</summary>

     Define a altura da linha de texto, controlando o espaçamento vertical entre linhas em um parágrafo. Recomenda-se usar multiplicadores sem unidade (ex: `1.5` ou `1.6`).
   </details>

### Variáveis e Cores

9. **Como declarar e consumir uma variável CSS?**
   <details>
     <summary>Possível resposta</summary>

     Declara-se com `--nome-da-variavel: valor;` (geralmente no `:root`) e consome-se com `property: var(--nome-da-variavel);`.
   </details>

10. **Quais são os formatos de cor modernos mais indicados em vez das palavras-chave (`red`, `blue`)?**
    <details>
      <summary>Possível resposta</summary>

      Hexadecimal (`#2563eb`), `rgb(37 99 235)`, `hsl(221 83% 53%)` e `oklch()`, pois oferecem milhões de cores e suporte a controle de opacidade.
    </details>
