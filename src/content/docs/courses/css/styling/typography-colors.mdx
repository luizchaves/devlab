A **estilização visual** de uma aplicação envolve três pilares principais: escolha e hierarquia tipográfica, paleta de cores consistente e o uso de **unidades relativas** e **variáveis CSS** para garantir manutenibilidade e flexibilidade.

---

## Objetivo

Dominar o uso de fontes externas e tipografia web, escolher unidades adequadas (`rem` vs `px`), aplicar formatos de cores modernos (`hex`, `rgb`, `hsl`, `oklch`) e estruturar um design system com variáveis CSS (`custom properties`).

## Propriedades e valores

Uma propriedade muda um aspecto específico do elemento. O valor precisa ser válido
para aquela propriedade.

| Grupo       | Propriedades comuns                                      | Exemplo de valor                         |
| ----------- | -------------------------------------------------------- | ---------------------------------------- |
| Texto       | `color`, `font-family`, `font-size`, `font-weight`, `line-height` | `#1d4ed8`, `Arial`, `1rem`, `bold` |
| Espaço      | `margin`, `padding`, `gap`                               | `0`, `1rem`, `2rem`                      |
| Caixa       | `width`, `max-width`, `border`, `border-radius`, `box-sizing` | `48rem`, `1px solid #ccc`, `border-box` |
| Fundo       | `background`, `background-color`                         | `white`, `#dbeafe`, `linear-gradient(...)` |
| Layout      | `display`, `grid-template-columns`, `justify-content`, `align-items` | `grid`, `flex`, `center`       |
| Responsivo  | `@media`, `min-width`, `max-width`                       | `@media (min-width: 48rem)`              |

<Aside type="tip" title="Propriedades abreviadas (Shorthand properties)">
  Propriedades como `margin`, `padding`, `border`, `font` e `background` são
  *shorthands*: elas permitem definir múltiplos valores em uma única declaração.
  Elas deixam o código mais conciso, mas redefinem subpropriedades não especificadas
  para seus valores iniciais.

  ```css title="Exemplo de shorthand font"
  /* Declaração abreviada: */
  font: italic bold 20px Times;

  /* Equivalente a definir individualmente: */
  font-style: italic;
  font-weight: bold;
  font-size: 20px;
  font-family: Times;
  ```
</Aside>

## Unidades de Medida no CSS

No CSS, evite fixar tamanhos em pixels (`px`) para fontes ou contêineres principais. Prefira **unidades relativas**:

| Unidade | Base de Cálculo | Recomendação de Uso |
| :--- | :--- | :--- |
| `px` | Pixel absoluto da tela. | Bordas finas (`1px`), sombras pequenas. |
| `rem` | Relativo ao tamanho da fonte do elemento raiz (`<html>`). Padrão: `1rem = 16px`. | **Fontes, margens, paddings e espaçamentos gerais.** |
| `em` | Relativo ao tamanho da fonte do **próprio elemento ou pai**. | Espaçamentos que devem escalar junto com o tamanho da fonte. |
| `%` | Relativo ao elemento pai. | Largura de contêineres. |
| `vw` / `vh` | 1% da largura / altura da viewport (janela do navegador). | Hero sections, modais e layouts de tela cheia. |

```css
html {
  font-size: 100%; /* Normalmente 16px */
}

h1 {
  font-size: 2.25rem; /* 2.25 * 16px = 36px */
  margin-bottom: 1rem;
}
```

## Sistemas de Cores

O CSS aceita múltiplos formatos para definir cores:

```css
.card {
  /* 1. Hexadecimal (#RRGGBB) */
  color: #1e293b;

  /* 2. RGB / RGBA (Red, Green, Blue, Alpha) */
  background-color: rgb(241 245 249 / 80%);

  /* 3. HSL (Hue, Saturation, Lightness) - Ótimo para criar variações de tema */
  border-color: hsl(221 83% 53%);

  /* 4. OKLCH (Moderno: Perceptual Uniformity) */
  outline-color: oklch(0.6 0.2 250);
}
```

<Aside type="tip" title="Cores Nominais vs Hex/RGB">
  Evite usar cores por palavras-chave (`red`, `blue`, `green`) em produção, pois elas são limitadas a 148 cores e não permitem opacidade. Prefira Hexadecimal ou `hsl()` / `oklch()`.
</Aside>

## Tipografia Web

A hierarquia tipográfica guia a leitura do usuário. Propriedades essenciais:

- `font-family`: Lista de fontes prioritárias com fallback.
- `font-size`: Tamanho da fonte (use `rem`).
- `font-weight`: Peso (`400` normal, `600` semi-bold, `700` bold).
- `line-height`: Altura da linha (use multiplicadores sem unidade, ex: `1.5`).
- `letter-spacing`: Espaçamento entre letras.

```css
/* Carregamento de fonte customizada no CSS */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap');

body {
  font-family: 'Inter', system-ui, -apple-system, sans-serif;
  line-height: 1.5;
  color: #334155;
}
```

## Variáveis CSS (`Custom Properties`)

As variáveis CSS permitem armazenar valores reusáveis em um único local e atualizá-los dinamicamente via CSS ou JavaScript.

Declaram-se variáveis com o prefixo `--` e lêem-se com a função `var()`:

```css
/* 1. Declaração global no pseudo-seletor :root */
:root {
  --primary: #2563eb;
  --primary-hover: #1d4ed8;
  --bg-main: #f8fafc;
  --text-main: #0f172a;
  --radius: 0.5rem;
  --spacing: 1rem;
}

/* 2. Uso das variáveis nos seletores */
.btn-primary {
  background-color: var(--primary);
  color: white;
  border-radius: var(--radius);
  padding: var(--spacing);
}

.btn-primary:hover {
  background-color: var(--primary-hover);
}
```

### Tema Claro / Escuro (Dark Mode) com Variáveis

```css
/* Re-definição de variáveis para Dark Mode */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-main: #0f172a;
    --text-main: #f8fafc;
  }
}
```

### Unidades, cores e funções

Alguns valores são palavras, outros são números com unidade, cores ou funções.

| Tipo de valor | Exemplos                                                       | Uso comum                              |
| ------------- | -------------------------------------------------------------- | -------------------------------------- |
| Comprimento   | `px`, `rem`, `em`, `%`, `vw`, `vh`                             | Tamanho, espaço, largura e altura      |
| Cor           | `red`, `#2563eb`, `rgb(37 99 235)`, `hsl(221 83% 53%)`         | Texto, fundo e borda                   |
| Tempo         | `150ms`, `0.3s`                                                | Transições e animações                 |
| Ângulo        | `45deg`, `0.25turn`                                            | Rotação, gradiente e transformações    |
| Função        | `var(--cor)`, `calc(100% - 2rem)`, `rgb(...)`, `min(...)`      | Reuso, cálculo e valores compostos     |

```css title="Funções CSS"
.card {
  width: calc(100% - 2rem);
  color: rgb(37 99 235);
  padding: var(--espaco);
}
```

<Aside type="tip" title="Por que evitar cores nominais?">
  Cores por palavras-chave (`red`, `blue`, `green`) são práticas para testes rápidos,
  mas possuem limitações: são restritas a um conjunto fixo (~148 cores), não
  permitem definir transparência (canal alfa) e dificultam alinhar a paleta com a
  identidade visual do projeto. Usar **Hexadecimal** (`#2563eb`), **`rgb()`** ou
  **`hsl()`** dá acesso a milhões de cores com controle de opacidade. Formatos
  modernos como **`oklch()`** oferecem ainda brilho perceptualmente uniforme entre
  diferentes matizes.
</Aside>

<details>
  <summary>
    Mais exemplos: <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values">CSS values and units | MDN</a>
  </summary>

| Tipo | Exemplos | Uso comum |
| ---- | -------- | --------- |
| Largura de caractere | `ch` | Campos e blocos de texto com largura aproximada por caracteres |
| Altura dinâmica da viewport | `svh`, `lvh`, `dvh` | Layouts mobile que precisam lidar com barras do navegador |
| Linha do texto | `lh` | Espaçamentos proporcionais à altura da linha |
| Grid | `fr` | Distribuição de espaço em layouts com CSS Grid |
| Cor moderna | `oklch(...)`, `color-mix(...)` | Cores perceptualmente mais consistentes e misturas de cor |
| Função responsiva | `clamp(1rem, 2vw, 2rem)` | Valores com mínimo, valor fluido e máximo |
| Função de imagem | `linear-gradient(...)`, `url(...)` | Fundos, imagens e gradientes |
</details>


### Panorama de variáveis CSS

### Variáveis CSS

Variáveis CSS são chamadas de **custom properties**. O nome começa com `--` e o uso
acontece com `var()`:

```css title="Custom properties"
:root {
  --cor-destaque: #2563eb;
  --espaco: 1rem;
}

.botao {
  color: var(--cor-destaque);
  padding: var(--espaco);
}
```

Elas ajudam a manter cores, espaçamentos e outros valores consistentes em várias
partes da página.

<Aside type="tip" title="Temas claro e escuro (Light e Dark Theme)">
  Um uso muito prático de variáveis CSS é a implementação de temas (*light* e *dark mode*).
  Basta definir variáveis de cores (como `--cor-fundo` e `--cor-texto`) em `:root` e
  redefinir apenas os seus valores dentro de uma media query `@media (prefers-color-scheme: dark)`
  ou de uma classe como `.dark`. Toda a página se adapta automaticamente sem precisar
  sobrescrever as regras de cada elemento individualmente.
</Aside>

Referência completa: [Using CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties)
no MDN.


## Resumo e Boas Práticas

- Use a unidade `rem` para fontes e espaçamentos para respeitar as preferências de acessibilidade do usuário.
- Declare cores principais, fontes e espaçamentos em variáveis CSS no `:root`.
- Mantenha a altura de linha (`line-height`) entre `1.4` e `1.6` para blocos de texto longo.
