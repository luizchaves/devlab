A propriedade de plano de fundo (*background*) no CSS permite aplicar cores sólidas, imagens, padrões repetidos e gradientes em qualquer elemento retangular da página.

Entender como as propriedades de fundo interagem com a camada de `padding` do Box Model é essencial para criar cartões com visual profissional, faixas *hero* de destaque e botões modernos.

---

## Objetivo

Dominar as propriedades individuais de `background`, entender o dimensionamento com `background-size: cover` e `contain`, fixar fundos durante a rolagem com `background-attachment`, e criar gradientes lineares e radiais.

## Detalhamento das Propriedades

### 1. `background-color` e `background-image`

A propriedade `background-color` define a cor sólida de fundo, aceitando nomes de cores, valores hexadecimais, `rgb()`, `hsl()` e `oklch()`.

A propriedade `background-image` insere uma imagem de fundo apontando para uma URL ou definindo um gradiente:

```css title="Definindo imagem de fundo"
.hero-banner {
  background-color: #0f172a; /* Cor de fallback caso a imagem falhe */
  background-image: url('/images/hero-bg.webp');
}
```

### 2. `background-repeat` e `background-position`

Por padrão, imagens de fundo são repetidas em mosaico nos eixos X e Y.

Utilize `background-repeat: no-repeat` para evitar a repetição e `background-position` para ancorar a imagem:

```css title="Alinhando a imagem no centro"
.hero-banner {
  background-repeat: no-repeat;
  background-position: center center; /* Horizontal Vertical */
}
```

### 3. `background-size` (`cover` vs `contain`)

O dimensionamento da imagem de fundo é crucial para páginas responsivas:

| Valor | Comportamento no elemento |
| :--- | :--- |
| **`cover`** | Ajusta a imagem para **cobrir toda a área** do elemento, mesmo que precise cortar parte da imagem. |
| **`contain`** | Ajusta a imagem para que ela fique **totalmente visível** sem cortar nada, mesmo que sobrem espaços vazios. |
| **`auto`** | Mantém as dimensões originais da imagem (padrão). |

```css title="Seção Hero com preenchimento total"
.hero-section {
  min-height: 400px;
  background-image: url('banner.jpeg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

### 4. `background-attachment: fixed` (Efeito Parallax)

Quando definimos `background-attachment: fixed`, a imagem de fundo permanece travada em relação à tela durante a rolagem, criando um efeito sutil de paralaxe:

```css title="Efeito de imagem fixa"
.parallax-section {
  background-image: url('landscape.webp');
  background-attachment: fixed;
  background-size: cover;
  background-position: center;
}
```

## Gradientes no CSS (`linear-gradient` e `radial-gradient`)

Gradientes no CSS são tratados tecnicamente como imagens de fundo geradas por código, dispensando o download de arquivos pesados.

### Gradiente Linear (`linear-gradient`)

Um gradiente linear transita cores ao longo de um ângulo ou direção:

```css title="Gradiente em 135 graus"
.card-gradient {
  /* Sintaxe: linear-gradient(direção, cor1, cor2, ...) */
  background-image: linear-gradient(135deg, #2563eb, #7c3aed);
  color: white;
}
```

### Gradiente Radial (`radial-gradient`)

Um gradiente radial se expande em círculos ou elipses a partir de um ponto central:

```css title="Gradiente radial central"
.glowing-box {
  background-image: radial-gradient(circle, #38bdf8 0%, #0f172a 100%);
}
```

Você pode testar seletores de cores e ajuste de gradientes diretamente nas ferramentas de desenvolvedor:

<Steps>

3. **Alterne `background-size` entre `cover` e `contain`** no painel de estilos para observar a resposta imediata da imagem na tela.

## Exercício

Crie um cartão de cabeçalho de destaque (`.hero-card`):

1. O cartão deve ter altura mínima de `300px` e texto em cor branca `#ffffff`.
2. Aplique um gradiente linear em 90 graus que transite da cor `#1e293b` para a cor `#0f172a`.
3. Adicione cantos arredondados de `12px` e padding de `32px`.

<details>
  <summary>Possível resposta</summary>

  ```css title="solucao.css"
  .hero-card {
    min-height: 300px;
    padding: 32px;
    color: #ffffff;
    background-image: linear-gradient(90deg, #1e293b, #0f172a);
    border-radius: 12px;
  }
  ```
</details>

## Perguntas de revisão

### Propriedades de Fundo

1. **Qual a diferença entre `background-size: cover` e `background-size: contain`?**
   <details>
     <summary>Possível resposta</summary>

     `cover` ajusta a imagem para cobrir toda a área do contêiner sem deixar espaços em branco (podendo cortar partes da imagem). `contain` ajusta para que toda a imagem fique visível sem cortes (podendo deixar áreas em branco no contêiner).
   </details>

2. **Por que é uma boa prática declarar `background-color` ao usar uma `background-image`?**
   <details>
     <summary>Possível resposta</summary>

     Porque a cor serve de alternativa legível caso o download da imagem falhe ou a conexão do usuário esteja lenta.
   </details>

3. **O que faz o valor `background-attachment: fixed`?**
   <details>
     <summary>Possível resposta</summary>

     Fixa a imagem de fundo em relação à janela do navegador (*viewport*), fazendo com que ela permaneça estática enquanto o conteúdo da página rola por cima.
   </details>

### Gradientes

4. **Como os gradientes no CSS são interpretados pelo navegador?**
   <details>
     <summary>Possível resposta</summary>

     São interpretados como tipos de imagem (`background-image`), permitindo aplicar transições de cores por código sem precisar de arquivos externos.
   </details>

5. **Qual é a sintaxe padrão de um gradiente linear?**
   <details>
     <summary>Possível resposta</summary>

     `background-image: linear-gradient(direção/ângulo, cor1, cor2, ...);`
   </details>

6. **Como combinar uma imagem de fundo com uma camada de gradiente semitransparente para melhorar o contraste do texto?**
   <details>
     <summary>Possível resposta</summary>

     Passando duas origens em `background-image`: a primeira sendo o `linear-gradient(rgba(...), rgba(...))` e a segunda sendo `url(...)`.
   </details>

7. **Qual o efeito da propriedade `background-repeat: no-repeat`?**
   <details>
     <summary>Possível resposta</summary>

     Evita que o navegador repita a imagem de fundo em mosaico quando ela for menor que as dimensões do elemento.
   </details>

8. **Como centralizar uma imagem de fundo horizontalmente e verticalmente?**
   <details>
     <summary>Possível resposta</summary>

     Utilizando `background-position: center center;` (ou simplesmente `background-position: center;`).
   </details>

9. **O `background-color` preenche a área de `padding` do elemento?**
   <details>
     <summary>Possível resposta</summary>

     Sim. O plano de fundo se estende por toda a área interna compreendida dentro da borda, incluindo o `padding`.
   </details>

10. **Quais unidades podem ser usadas para definir ângulos em `linear-gradient`?**
    <details>
      <summary>Possível resposta</summary>

      Graus (`deg`, como `90deg`), turnos (`turn`, como `0.25turn`) ou palavras-chave de direção (`to right`, `to bottom right`).
    </details>
