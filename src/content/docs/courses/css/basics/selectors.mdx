Os **seletores CSS** determinam quais elementos do documento HTML serão afetados pelas regras de estilo. O CSS moderno oferece desde seletores básicos por tag ou classe até pseudo-classes avançadas e combinadores lógicos.

---

## Objetivo

Dominar os diferentes tipos de seletores CSS, saber quando utilizar cada tipo para manter o código limpo e reusável, e aplicar **pseudo-classes** de estado e **pseudo-elementos** para estilização semântica e interativa.

---

## Seletores Fundamentais

A tabela a seguir apresenta os seletores fundamentais da linguagem CSS. Cada tipo atua em um nível diferente da árvore do DOM, variando em sintaxe, capacidade de reuso e especificidade:

| Tipo de Seletor | Sintaxe | Exemplo | Descrição |
| :--- | :--- | :--- | :--- |
| **Elemento / Tag** | `tag` | `p { ... }` | Seleciona todos os elementos do tipo especificado. |
| **Classe** | `.nome` | `.card { ... }` | Seleciona todos os elementos com a classe correspondente. Reutilizável. |
| **ID** | `#nome` | `#main-header { ... }` | Seleciona o elemento único com aquele `id`. Alta especificidade. |
| **Universal** | `*` | `* { box-sizing: border-box; }` | Seleciona absolutamente todos os elementos do DOM. |
| **Atributo** | `[attr]` | `input[type="text"]` | Seleciona elementos com base em atributos HTML ou seus valores. |

O código a seguir exemplifica como selecionar elementos especificamente pelo atributo `target="_blank"` em hiperlinks:

```css
/* Exemplo de seletor por atributo */
a[target="_blank"] {
  color: #2563eb;
  font-weight: 600;
}
```

## Combinadores

Os combinadores definem relacionamentos de estrutura espacial ou hierárquica entre elementos no DOM:

```css
/* 1. Descendente: qualquer 'p' dentro de '.article' (mesmo aninhado fundo) */
.article p {
  line-height: 1.6;
}

/* 2. Filho direto (>): apenas 'li' que seja filho imediato de 'ul' */
ul > li {
  list-style: square;
}

/* 3. Irmão adjacente (+): 'p' que vem imediatamente após um 'h2' */
h2 + p {
  font-size: 1.125rem;
  color: #475569;
}

/* 4. Irmão geral (~): todos os 'p' que compartilham o mesmo pai e vêm após 'h2' */
h2 ~ p {
  margin-top: 0.5rem;
}
```

## Pseudo-classes

Pseudo-classes selecionam elementos com base em seu **estado** ou em sua **posição estrutural** na árvore HTML. Elas iniciam com um dois-pontos `:`.

### Pseudo-classes de Estado e Interação

<Tabs>
  <TabItem label="Interação do Usuário">
    ```css
    /* Quando o cursor passa por cima do botão */
    .btn:hover {
      background-color: #1d4ed8;
    }

    /* Quando o elemento recebe foco (via teclado ou clique) */
    .input:focus {
      outline: 2px solid #3b82f6;
    }

    /* Durante o clique ativo */
    .btn:active {
      transform: scale(0.98);
    }
    ```
  </TabItem>

  <TabItem label="Formulários">
    ```css
    /* Campo desabilitado */
    input:disabled {
      opacity: 0.5;
      cursor: not-allowed;
    }

    /* Checkbox ou Radio checado */
    input:checked + label {
      font-weight: bold;
    }

    /* Campo com entrada válida ou inválida */
    input:invalid {
      border-color: #ef4444;
    }
    ```
  </TabItem>
</Tabs>

### Pseudo-classes Estruturais

- `:first-child` / `:last-child`: Seleciona o primeiro ou último filho do pai.
- `:nth-child(n)`: Seleciona pela posição numérica, padrão ímpar/par ou fórmula.

```css
/* Pinta linhas alternadas de uma tabela */
tr:nth-child(even) {
  background-color: #f1f5f9;
}

/* Seleciona o primeiro item de uma lista */
li:first-child {
  border-top: none;
}
```

## Pseudo-elementos

Pseudo-elementos estilizam partes específicas de um elemento ou inserem conteúdo decorativo sem precisar alterar o HTML. Iniciam com dois dois-pontos `::`.

```css
/* Inserção de conteúdo decorativo antes ou depois */
.badge::before {
  content: "★ ";
  color: #f59e0b;
}

/* Estilização da primeira letra de um parágrafo */
.article p::first-letter {
  font-size: 2rem;
  font-weight: bold;
}

/* Estilização da seleção de texto pelo usuário */
::selection {
  background-color: #fef08a;
  color: #000;
}
```

<Aside type="tip" title="Sintaxe de Pseudo-elementos">
  No CSS3, pseudo-elementos usam `::` (ex: `::after`), enquanto pseudo-classes usam `:` (ex: `:hover`). O navegador aceita `:` em pseudo-elementos por compatibilidade, mas o formato `::` é a boa prática moderna.
</Aside>

## Panorama dos tipos de seletores

Seletores são padrões que escolhem quais elementos receberão uma regra. Comece pelos
seletores mais comuns e só avance para combinações complexas quando elas deixarem o
código mais claro.

O exemplo usa estes seletores:

| Seletor          | Tipo                  | O que seleciona                                          |
| ---------------- | --------------------- | -------------------------------------------------------- |
| `body`           | Elemento              | Todos os elementos `<body>`                              |
| `#principal`     | ID                    | O único elemento com `id="principal"`                    |
| `.cartao`        | Classe                | Todo elemento com `class="cartao"`                       |
| `.cartao p`      | Descendente           | Todo `<p>` dentro de um elemento com `class="cartao"`    |
| `.lista li + li` | Irmão adjacente       | Cada `<li>` que vem logo depois de outro `<li>`          |
| `.botao:hover`   | Pseudo classe         | O link quando o ponteiro passa sobre ele                 |

<Aside type="tip" title="Classes utilitárias e reutilização">
  As classes são os seletores mais flexíveis do CSS por poderem ser aplicadas a qualquer
  elemento e repetidas pela página. Além de definir componentes (como `.cartao`),
  é comum criar **classes utilitárias** focadas em uma única regra visual — como
  `.text-center` para centralizar texto. Essa estratégia de pequenas classes reutilizáveis
  é a base de frameworks populares como [Bootstrap](https://getbootstrap.com/) e
  [Tailwind CSS](https://tailwindcss.com/).
</Aside>

## Resumo e Boas Práticas

- Baseie a maior parte dos estilos em **classes** reutilizáveis.
- Use pseudo-classes de foco (`:focus` / `:focus-visible`) para garantir acessibilidade via teclado.
- Utilize `::before` e `::after` para ícones ou efeitos decorativos em vez de criar tags HTML vazias.
