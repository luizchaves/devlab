At-rules são instruções CSS que começam com `@`. Elas não estilizam elementos
diretamente: orientam o comportamento da folha de estilos, carregando fontes,
importando arquivos, definindo animações ou condicionando um bloco inteiro de regras.

## Objetivo

Reconhecer as at-rules mais comuns do CSS, saber quando cada uma se aplica e onde
consultar a lista completa.

## O que são at-rules

At-rules são instruções CSS que começam com `@`. Elas servem para orientar o
comportamento do CSS, como carregar fontes personalizadas, criar animações ou
importar outras folhas de estilo:

```css title="Exemplo de @font-face"
@font-face {
  font-family: "MinhaFonte";
  src: url("fonts/minha-fonte.woff2") format("woff2");
}
```

<Aside type="tip" title="Google Fonts gera @font-face automaticamente">
  Ao usar serviços como o [Google Fonts](https://fonts.google.com/), você inclui uma
  tag `<link>` no HTML ou `@import` no CSS. A folha de estilos externa carregada já
  contém as regras `@font-face` geradas automaticamente para cada peso e formato de
  fonte, dispensando a escrita manual dessas declarações.
</Aside>

Algumas das at-rules mais comuns no CSS:

| At-rule      | Uso comum                                                   |
| ------------ | ----------------------------------------------------------- |
| `@media`     | Adapta estilos por largura de tela, impressão ou preferência |
| `@import`    | Importa outra folha de estilos                              |
| `@font-face` | Declara uma fonte externa                                   |
| `@keyframes` | Define etapas de uma animação                               |
| `@supports`  | Aplica CSS apenas se o navegador suportar um recurso         |
