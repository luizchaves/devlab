O **CSS Grid Layout** é o sistema de layout mais potente e versátil do CSS moderno. 

Enquanto o Flexbox foi projetado para alinhar elementos em uma única dimensão (linha *ou* coluna), o CSS Grid é **bidimensional**, permitindo controlar linhas e colunas simultaneamente com precisão milimétrica.

Com o Grid, você define a estrutura externa do contêiner e o navegador posiciona automaticamente os elementos filhos dentro das células da grade.

---

## Objetivo

Compreender a estrutura de linhas e colunas de um grid, dominar a unidade fracional `fr`, criar layouts responsivos sem necessidade de *media queries* com `repeat(auto-fit, minmax(...))` e desenhar estruturas de páginas completas com `grid-template-areas`.

---

Use **Flexbox** para componentes baseados no conteúdo (menus, botões alinhados, cartões simples).

Use **CSS Grid** para a estrutura principal de páginas, dashboards de várias colunas e galerias de imagens complexas.

## Ativando o CSS Grid

Para iniciar uma grade, aplique `display: grid` ou `display: inline-grid` no contêiner pai e defina as colunas e linhas:

```css title="Definindo um grid de 3 colunas"
.grid-container {
  display: grid;
  grid-template-columns: 200px 1fr 200px; /* 3 colunas */
  grid-template-rows: 80px 1fr 60px;     /* 3 linhas */
  gap: 1.5rem;                           /* Espaçamento entre células */
}
```

### A Unidade Fracional (`fr`)

A unidade `fr` (*fractional unit*) representa uma fração do espaço livre disponível no contêiner.

Ao contrário de porcentagens, a unidade `fr` é calculada após subtrair os espaçamentos (`gap`):

```css title="Uso da unidade fracional"
.gallery {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; 
  /* A coluna central ocupa o dobro do espaço das colunas laterais */
}
```

## Grid Responsivo Sem Media Queries

Uma das técnicas mais elegantes do CSS Grid é a criação de grades responsivas automáticas usando a combinação de `repeat()`, `minmax()` e `auto-fit`.

Esta abordagem calcula dinamicamente a quantidade de colunas que cabem na tela:

```css title="Galeria de cards 100% responsiva"
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 1.5rem;
}
```

Entendendo a fórmula:
- **`repeat()`**: Repete a definição de colunas.
- **`auto-fit`**: Ajusta o número de colunas automaticamente preenchendo toda a largura da tela.
- **`minmax(280px, 1fr)`**: Garante que cada coluna meça no mínimo `280px` e no máximo `1fr`.

<Aside type="tip" title="auto-fit vs auto-fill">
  Com `auto-fit`, se houver poucos itens na tela, eles esticam para ocupar toda a linha. Com `auto-fill`, o navegador mantém o espaço de colunas vazias adicionais na linha.
</Aside>

## Layout de Página com `grid-template-areas`

O CSS Grid permite nomear regiões da grade e organizar o layout de forma extremamente visual:

```css title="Estrutura de aplicação completa"
.app-layout {
  display: grid;
  grid-template-columns: 260px 1fr;
  grid-template-rows: 70px 1fr 50px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
}

header  { grid-area: header; }
aside   { grid-area: sidebar; }
main    { grid-area: main; }
footer  { grid-area: footer; }
```

```txt title="Resultado na tela (Esquema do Grid de Aplicação)"
+-------------------------------------------------------------------------+
|                             HEADER (70px)                               |
+--------------------------+----------------------------------------------+
|                          |                                              |
|     SIDEBAR (260px)      |                MAIN (1fr)                    |
|                          |                                              |
+--------------------------+----------------------------------------------+
|                             FOOTER (50px)                               |
+-------------------------------------------------------------------------+
```

Se precisar alterar a ordem dos blocos em um dispositivo móvel, basta alterar o mapa `grid-template-areas` dentro de uma *media query*.

## Posicionando Itens (`grid-column` e `grid-row`)

Além de usar áreas nomeadas, você pode posicionar itens em linhas de grade específicas:

```css title="Card que ocupa duas colunas"
.featured-card {
  grid-column: 1 / 3; /* Vai da linha vertical 1 até a linha 3 (abrange 2 colunas) */
}

.hero-banner {
  grid-column: span 2; /* Abrange 2 colunas a partir da posição atual */
}
```

## Executando e inspecionando no DevTools

Inspecionar linhas de grid no navegador facilita enormemente o desenvolvimento de layouts bidimensionais:

<Steps>

1. **Abra o DevTools** pressionando <kbd>F12</kbd> e selecione um contêiner com `display: grid`.

2. **Clique no selo `grid`** ao lado da tag na árvore de elementos para visualizar as linhas de grade numeradas na página.

3. **Abra a aba Layout** no painel de ferramentas do DevTools para personalizar as cores das linhas de grid e exibir os nomes das áreas.

</Steps>

## Exercício

Crie um grid de galeria de imagens com 4 colunas de tamanhos iguais e espaçamento de `16px` entre elas:

1. O contêiner `.photo-gallery` deve usar `display: grid`.
2. As 4 colunas devem usar a unidade `fr`.
3. Garanta que o espaço entre cada imagem seja uniforme.

<details>
  <summary>Possível resposta</summary>

  ```css title="solucao.css"
  .photo-gallery {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 16px;
  }
  ```
</details>

## Perguntas de revisão

### Conceitos Fundamentais

1. **Qual a diferença fundamental entre o Flexbox e o CSS Grid?**
   <details>
     <summary>Possível resposta</summary>

     O Flexbox é unidimensional (alinha em linha OU coluna por vez). O CSS Grid é bidimensional (alinha em linhas E colunas simultaneamente).
   </details>

2. **O que representa a unidade fracional `fr` no CSS Grid?**
   <details>
     <summary>Possível resposta</summary>

     Representa uma fração proporcional do espaço livre disponível no contêiner após descontar os espaçamentos (`gap`).
   </details>

3. **Como a propriedade `gap` funciona no CSS Grid?**
   <details>
     <summary>Possível resposta</summary>

     Define o espaçamento entre colunas e linhas sem adicionar margens externas nas bordas do contêiner.
   </details>

### Responsividade e Áreas Nomeadas

4. **Para que serve a combinação `repeat(auto-fit, minmax(250px, 1fr))`?**
   <details>
     <summary>Possível resposta</summary>

     Para criar grades responsivas automáticas que se adaptam à largura da tela criando o máximo de colunas possível (de no mínimo 250px) sem precisar de media queries.
   </details>

5. **Qual é a diferença entre `auto-fit` e `auto-fill`?**
   <details>
     <summary>Possível resposta</summary>

     `auto-fit` estica as colunas existentes para preencher todo o espaço restante da linha. `auto-fill` mantém o espaço reservado para colunas vazias adicionais na linha.
   </details>

6. **Como funciona a propriedade `grid-template-areas`?**
   <details>
     <summary>Possível resposta</summary>

     Permite criar um mapa visual da página nomeando células em texto dentro de aspas e associando elementos HTML usando `grid-area`.
   </details>

7. **Como fazer um item ocupar duas colunas na grade?**
   <details>
     <summary>Possível resposta</summary>

     Utilizando `grid-column: 1 / 3;` ou `grid-column: span 2;`.
   </details>

8. **O que acontece se você não definir `grid-template-rows` em um grid?**
   <details>
     <summary>Possível resposta</summary>

     O navegador cria as linhas automaticamente conforme o conteúdo é inserido (Grid Implícito), ajustando a altura ao conteúdo.
   </details>

9. **Podemos usar Flexbox dentro de uma célula do CSS Grid?**
   <details>
     <summary>Possível resposta</summary>

     Sim! É uma prática muito comum utilizar o CSS Grid para a estrutura macro da página e o Flexbox para alinhar elementos dentro de cartões ou células individuais.
   </details>

10. **Qual a propriedade equivalente ao `justify-content` para alinhar os itens no eixo horizontal de cada célula?**
    <details>
      <summary>Possível resposta</summary>

      A propriedade `justify-items` (para o contêiner) ou `justify-self` (para um item individual).
    </details>
