O **CSS Grid Layout** é o sistema de layout mais poderoso do CSS. Diferente do Flexbox (que é unidimensional), o Grid é **bidimensional**, permitindo controlar linhas e colunas simultaneamente com precisão cirúrgica.

---

## Objetivo

Compreender os conceitos de contêiner e itens de grid, utilizar a unidade fracional `fr`, definir colunas e linhas responsivas sem media queries utilizando `repeat()`, `minmax()` e `auto-fit`, e criar layouts de páginas completas com `grid-template-areas`.

---

## Ativando o CSS Grid

Para iniciar um grid, defina `display: grid` no contêiner e especifique a estrutura de colunas e linhas:

```css
.grid-container {
  display: grid;
  grid-template-columns: 200px 1fr 200px; /* 3 colunas */
  grid-template-rows: auto 1fr auto;      /* 3 linhas */
  gap: 1.5rem;                            /* Espaçamento entre células */
}
```

### A Unidade Fracional (`fr`)

A unidade `fr` (*fractional unit*) representa uma fração do espaço disponível no contêiner do grid:

```css
.grid-columns {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; 
  /* Coluna central ocupa o dobro do espaço das colunas laterais */
}
```

---

## Grid Responsivo sem Media Queries

Combinando a função `repeat()`, a função `minmax()` e a palavra-chave `auto-fit`, é possível criar grides de cards que se adaptam automaticamente ao tamanho da tela:

```css
.card-grid {
  display: grid;
  /* Cria o máximo de colunas possível com no mínimo 250px cada */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 1.5rem;
}
```

<Aside type="tip" title="Como funciona auto-fit + minmax">
  Se a tela tiver 1000px, o navegador cria 4 colunas de 250px. Se a tela encolher para 500px, ele ajusta para 2 colunas. Se tiver 300px, vira 1 coluna única de 1000% da largura. Não é necessária nenhuma media query!
</Aside>

## Layout de Página com `grid-template-areas`

O CSS Grid permite nomear áreas do layout para criar protótipos de páginas inteiras de forma extremamente visual:

```css
.app-layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 60px 1fr 40px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
}

/* Mapeamento dos elementos para cada área */
header  { grid-area: header; }
aside   { grid-area: sidebar; }
main    { grid-area: main; }
footer  { grid-area: footer; }
```

## Flexbox vs. CSS Grid: Quando usar cada um?

A tabela a seguir compara as principais características do Flexbox e do CSS Grid, auxiliando na escolha da ferramenta adequada para cada necessidade de layout:

| Critério | Flexbox | CSS Grid |
| :--- | :--- | :--- |
| **Dimensão** | Unidimensional (Linha **ou** Coluna). | Bidimensional (Linhas **e** Colunas juntas). |
| **Foco** | Conteúdo em primeiro lugar (os itens definem o espaço). | Layout em primeiro lugar (o contêiner define as posições). |
| **Casos ideais** | Navbars, botões alinhados, listas de cards, formulários. | Pág. principal, dashboards complexos, galerias de fotos. |

---

## Resumo e Boas Práticas

- Use **CSS Grid** quando precisar organizar elementos em uma grade bidimensional (linhas e colunas simultâneas).
- Use `repeat(auto-fit, minmax(min, 1fr))` para componentes de galeria ou cards responsivos.
- Combine Flexbox dentro das células de um CSS Grid para um fluxo de trabalho de UI moderno e limpo.
