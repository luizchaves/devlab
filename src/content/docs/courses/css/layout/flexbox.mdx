O **Flexbox** (*Flexible Box Layout*) é um módulo de layout unidimensional projetado para distribuir espaço e alinhar itens em um contêiner ao longo de uma linha ou coluna, mesmo quando as dimensões dos itens são desconhecidas ou dinâmicas.

---

## Objetivo

Compreender o conceito de **Eixo Principal** (*Main Axis*) e **Eixo Cruzado** (*Cross Axis*), alinhar elementos com facilidade e construir componentes dinâmicos (como barras de navegação, cards e formulários).

---

## Os Dois Eixos do Flexbox

Ao aplicar `display: flex` em um contêiner, os elementos filhos tornam-se **flex items**. O comportamento depende da direção do layout:

```txt
flex-direction: row (padrão)
Main Axis (Horizontal) ───►  [ Item 1 ]  [ Item 2 ]  [ Item 3 ]
Cross Axis (Vertical)  │
                       ▼

flex-direction: column
Main Axis (Vertical)   │     [ Item 1 ]
                       │     [ Item 2 ]
                       ▼     [ Item 3 ]
Cross Axis (Horizontal) ───►
```

---

## Propriedades do Contêiner (`Flex Container`)

### 1. Direction & Wrap

- `flex-direction`: Define a orientação do eixo principal (`row`, `row-reverse`, `column`, `column-reverse`).
- `flex-wrap`: Permite que os itens dobrem de linha se o espaço acabar (`nowrap`, `wrap`, `wrap-reverse`).
- `gap`: Define o espaçamento entre itens flexíveis sem usar margens individuais.

```css
.container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  gap: 1.5rem; /* Espaço de 1.5rem entre os itens */
}
```

### 2. Alinhamento no Eixo Principal: `justify-content`

Alinha os itens ao longo do **Main Axis**:

| Valor | Comportamento |
| :--- | :--- |
| `flex-start` | Agrupa os itens no início do eixo (padrão). |
| `flex-end` | Agrupa os itens no final do eixo. |
| `center` | Centraliza os itens no eixo principal. |
| `space-between` | Primeiro item no início, último no fim, espaço igual entre eles. |
| `space-around` | Espaço igual ao redor de cada item. |
| `space-evenly` | Espaço idêntico entre todos os itens e as bordas. |

### 3. Alinhamento no Eixo Cruzado: `align-items`

Alinha os itens ao longo do **Cross Axis**:

| Valor | Comportamento |
| :--- | :--- |
| `stretch` | Estica os itens para ocupar toda a altura/largura do contêiner (padrão). |
| `center` | Centraliza os itens verticalmente (em `row`). |
| `flex-start` | Alinha os itens no topo. |
| `flex-end` | Alinha os itens na base. |

```css
/* Padrão clássico: Centralização Perfeita (horizontal e vertical) */
.modal-overlay {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 100vh;
}
```

---

## Propriedades dos Itens (`Flex Items`)

### Propriedades `flex-grow`, `flex-shrink` e `flex-basis`

- `flex-grow`: Fator de crescimento. Define quanto o item crescerá para ocupar o espaço vago.
- `flex-shrink`: Fator de encolhimento. Define como o item diminui se o contêiner encolher.
- `flex-basis`: Tamanho inicial base antes da distribuição do espaço restante.

```css
/* Atalho recomendado: flex: grow shrink basis */
.sidebar {
  flex: 0 0 250px; /* Não cresce, não encolhe, largura base fixada em 250px */
}

.main-content {
  flex: 1 1 auto; /* Ocupa todo o espaço vago restante */
}
```

---

## Exemplo Prático: Navbar Responsiva

```css
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
  background-color: #0f172a;
  color: white;
}

.nav-links {
  display: flex;
  gap: 1rem;
  list-style: none;
}
```

---

## Resumo e Boas Práticas

- Use **Flexbox** para layouts unidimensionais (linhas **ou** colunas), como menus, listas de cards ou alinhamentos de botões.
- Use a propriedade `gap` no contêiner flex para gerenciar espaçamentos limpos entre itens.
- Lembre-se que `justify-content` atua no Eixo Principal e `align-items` atua no Eixo Cruzado.
