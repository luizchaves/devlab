O **Flexbox** (*Flexible Box Layout*) é um modelo de layout unidimensional projetado para distribuir espaço de maneira inteligente e alinhar elementos dentro de um contêiner.

Ele foi criado para resolver problemas históricos do CSS tradicional (como alinhamento vertical complexo, distribuição proporcional de espaço e elementos de alturas diferentes em uma mesma linha).

A grande força do Flexbox está na sua capacidade de fazer com que os itens se ajustem (encolhendo ou expandindo) dinamicamente ao espaço disponível na tela.

---

## Objetivo

Compreender a diferença entre o **Eixo Principal** (*Main Axis*) e o **Eixo Cruzado** (*Cross Axis*), dominar a manipulação de contêineres e itens flexíveis, e construir componentes responsivos reais (como barras de navegação, cabeçalhos e cartões).

---

## Os Dois Eixos do Flexbox

Para dominar o Flexbox, você deve entender que todo alinhamento é calculado em relação a dois eixos perpendiculares: o **Main Axis** (Eixo Principal) e o **Cross Axis** (Eixo Cruzado).

A orientação desses eixos muda de acordo com a propriedade `flex-direction`:

<Mermaid title="Orientação dos Eixos no Flexbox (Row vs. Column)">
{`

Quando `flex-direction` é `row` (padrão):
- O **Main Axis** corre horizontalmente (da esquerda para a direita).
- O **Cross Axis** corre verticalmente (de cima para baixo).

Quando `flex-direction` é `column`:
- O **Main Axis** corre verticalmente (de cima para baixo).
- O **Cross Axis** corre horizontalmente (da esquerda para a direita).

## Propriedades do Contêiner (`Flex Container`)

Para transformar um elemento em um contêiner flexível, basta aplicar `display: flex` ou `display: inline-flex`. Todos os seus filhos diretos tornam-se automaticamente **Flex Items**.

### 1. `flex-direction` e `flex-wrap`

A propriedade `flex-direction` define a orientação do eixo principal.

Já a propriedade `flex-wrap` controla se os itens devem quebrar para a próxima linha quando o espaço na tela acabar:

```css title="Direção e quebra de linha"
.container {
  display: flex;
  flex-direction: row; /* row | row-reverse | column | column-reverse */
  flex-wrap: wrap;       /* nowrap | wrap | wrap-reverse */
  gap: 1.5rem;           /* Espaçamento entre os itens */
}
```

O atalho `flex-flow` permite combinar ambas as propriedades em uma única declaração: `flex-flow: row wrap;`.

### 2. Alinhamento no Eixo Principal: `justify-content`

A propriedade `justify-content` alinha e distribui os itens ao longo do **Main Axis**:

| Valor | Comportamento no Eixo Principal |
| :--- | :--- |
| `flex-start` | Agrupa os itens no início do eixo (padrão). |
| `flex-end` | Agrupa os itens no final do eixo. |
| `center` | Centraliza os itens no centro do eixo. |
| `space-between` | O primeiro item fica no início, o último no fim, e o espaço vago é dividido igualmente entre eles. |
| `space-around` | Distribui espaço uniforme ao redor de cada item (as pontas recebem metade do espaço interno). |
| `space-evenly` | Distribui espaço rigorosamente idêntico entre todos os itens e as bordas. |

### 3. Alinhamento no Eixo Cruzado: `align-items`

A propriedade `align-items` alinha os itens ao longo do **Cross Axis**:

| Valor | Comportamento no Eixo Cruzado |
| :--- | :--- |
| `stretch` | Estica os itens para preencher toda a altura/largura disponível (padrão). |
| `center` | Centraliza os itens no centro do eixo cruzado. |
| `flex-start` | Alinha os itens no início do eixo cruzado. |
| `flex-end` | Alinha os itens no final do eixo cruzado. |
| `baseline` | Alinha os itens de acordo com a linha base dos seus textos internos. |

O snippet a seguir mostra a combinação de centralização perfeita em ambas as direções:

```css title="Centralização absoluta de um modal"
.overlay {
  display: flex;
  justify-content: center; /* Centraliza no Main Axis */
  align-items: center;     /* Centraliza no Cross Axis */
  min-height: 100vh;
}
```

## Propriedades dos Itens (`Flex Items`)

Além de configurar o contêiner, é possível controlar individualmente como cada item flexível se comporta e redistribui o espaço.

### `flex-grow`, `flex-shrink` e `flex-basis`

Essas três propriedades controlam a flexibilidade de tamanho de cada item:

1. **`flex-grow`**: Define a proporção de crescimento do item caso haja espaço sobrando no contêiner (ex: `1`).
2. **`flex-shrink`**: Define o fator de encolhimento do item se o contêiner for menor que a soma dos itens (padrão: `1`).
3. **`flex-basis`**: Define o tamanho inicial base do item antes de distribuir o espaço restante (ex: `250px` ou `auto`).

Dica: utilize a propriedade atalho `flex: <grow> <shrink> <basis>`:

```css title="Layout de barra lateral e conteúdo principal"
.sidebar {
  /* Não cresce (0), não encolhe (0), tamanho fixo de 280px */
  flex: 0 0 280px;
}

.main-content {
  /* Cresce para ocupar todo o espaço restante (1 1 auto) */
  flex: 1 1 auto;
}
```

### `align-self` e `order`

Com `align-self`, um item individual pode sobresscrever o `align-items` definido pelo contêiner pai.

Já a propriedade `order` permite alterar a ordem visual de exibição dos elementos sem modificar a estrutura HTML original:

```css title="Ajuste individual de um item"
.card-featured {
  align-self: flex-end; /* Alinha este card no final, diferente dos outros */
  order: -1;            /* Move este card para o topo visual da lista */
}
```

## Exemplo Prático: Barra de Navegação Responsiva

Veja como combinar as propriedades do Flexbox para construir um cabeçalho completo:

```css title="navbar.css"
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
  background-color: #0f172a;
  color: #ffffff;
}

.nav-links {
  display: flex;
  gap: 1.5rem;
  list-style: none;
  margin: 0;
  padding: 0;
}

.nav-links a {
  color: #cbd5e1;
  text-decoration: none;
  font-weight: 500;
}

.nav-links a:hover {
  color: #ffffff;
}
```

```txt title="Resultado na tela (Renderização da Navbar)"
+-------------------------------------------------------------------------+
| [DevLab Logo]                             Início   Aulas   Contato      |
+-------------------------------------------------------------------------+
 (Logo alinhado à esquerda; Links agrupados com gap de 1.5rem à direita)
```

## Executando e inspecionando no DevTools

Você pode visualizar a grade flexível e testar o alinhamento interativamente no navegador:

<Steps>

1. **Abra o DevTools** pressionando <kbd>F12</kbd> e inspecione um elemento com `display: flex`.

2. **Clique na insígnia `flex`** ao lado do elemento na árvore HTML para ativar as linhas guias visuais do Flexbox.

3. **Abra o painel Estilos (Styles)** e localize o ícone do editor Flexbox ao lado da propriedade `display: flex`.

4. **Clique nos botões de alinhamento visual** para alternar `justify-content` e `align-items` em tempo real.

</Steps>

## Exercício

Crie um layout flexível com uma lista de 3 cartões (`.card`) organizados lado a lado:

1. O contêiner pai `.card-container` deve usar `display: flex` com espaçamento de `20px` entre os cartões.
2. Cada cartão deve ocupar larguras iguais e preencher uniformemente o espaço disponível na linha.
3. Se a janela for reduzida, os cartões devem quebrar linha automaticamente (`wrap`).

<details>
  <summary>Possível resposta</summary>

  ```css title="solucao.css"
  .card-container {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
  }

  .card {
    flex: 1 1 280px; /* Cresce, encolhe e tem largura base de 280px */
    padding: 20px;
    background-color: #f8fafc;
    border: 1px solid #cbd5e1;
    border-radius: 8px;
  }
  ```

  Ao usar `flex: 1 1 280px`, os cartões dividem o espaço de forma igual e pulam para a próxima linha quando a tela for menor que `280px`.
</details>

## Perguntas de revisão

### Eixos e Alinhamento

1. **O que determina qual é o Eixo Principal (Main Axis) e o Eixo Cruzado (Cross Axis)?**
   <details>
     <summary>Possível resposta</summary>

     A propriedade `flex-direction`. Se for `row`, o Eixo Principal é horizontal e o Eixo Cruzado é vertical. Se for `column`, os eixos se invertem.
   </details>

2. **Qual é a diferença entre `justify-content` e `align-items`?**
   <details>
     <summary>Possível resposta</summary>

     `justify-content` alinha os itens no Eixo Principal (Main Axis). `align-items` alinha os itens no Eixo Cruzado (Cross Axis).
   </details>

3. **Qual é a diferença de comportamento entre `space-between` e `space-around`?**
   <details>
     <summary>Possível resposta</summary>

     `space-between` cola o primeiro item no início e o último no fim. `space-around` coloca espaço igual em volta de cada item, fazendo com que as extremidades fiquem com metade do espaço existente entre dois itens.
   </details>

### Propriedades dos Itens Flexíveis

4. **Para que serve a propriedade `flex-grow`?**
   <details>
     <summary>Possível resposta</summary>

     Ela dita a taxa de crescimento do item para ocupar qualquer espaço livre restante no contêiner.
   </details>

5. **O que representa a propriedade `flex-basis`?**
   <details>
     <summary>Possível resposta</summary>

     Representa o tamanho inicial padrão do item flexível antes de qualquer cálculo de crescimento (`flex-grow`) ou encolhimento (`flex-shrink`).
   </details>

6. **Como funciona a sintaxe atalho `flex: 1 0 200px`?**
   <details>
     <summary>Possível resposta</summary>

     Define `flex-grow: 1` (cresce), `flex-shrink: 0` (não encolhe) e `flex-basis: 200px` (tamanho base inicial).
   </details>

7. **Como alinhar um único item diferente dos demais itens no contêiner?**
   <details>
     <summary>Possível resposta</summary>

     Utilizando a propriedade `align-self` diretamente no item desejado.
   </details>

8. **A propriedade `order` altera a ordem dos elementos no código HTML?**
   <details>
     <summary>Possível resposta</summary>

     Não. A propriedade `order` altera apenas a ordem visual de renderização na tela. A estrutura no DOM HTML permanece inalterada.
   </details>

9. **Qual a vantagem da propriedade `gap` em relação às margens individuais nos itens?**
   <details>
     <summary>Possível resposta</summary>

     O `gap` aplica espaçamento apenas **entre** os itens do contêiner, sem adicionar margens indesejadas nas bordas externas do contêiner.
   </details>

10. **Quando o Flexbox deve ser preferido em relação ao CSS Grid?**
    <details>
      <summary>Possível resposta</summary>

      O Flexbox é ideal para layouts unidimensionais (alinhamento em uma única linha ou coluna, como barras de navegação, botões ou cabeçalhos).
    </details>
