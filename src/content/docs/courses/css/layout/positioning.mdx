No CSS, o **fluxo normal do documento** (*Normal Flow*) dita como os elementos em bloco e inline são organizados naturalmente de cima para baixo e da esquerda para a direita.

A propriedade `position` permite retirar elementos desse fluxo normal ou deslocá-los com precisão matemática em relação à tela, à página ou a um elemento pai.

Dominar o posicionamento é essencial para criar menus fixos, janelas modais, sobreposições de texto em imagens e elementos adesivos (*sticky*).

---

## Objetivo

Compreender a diferença entre os 5 valores da propriedade `position` (`static`, `relative`, `absolute`, `fixed`, `sticky`), controlar o empilhamento com `z-index`, e entender o contexto de posicionamento do elemento pai.

## Valores da Propriedade `position`

### 1. `position: static` (Padrão)

Todo elemento HTML nasce com `position: static`. Ele obedece estritamente ao fluxo normal do documento.

Propriedades de deslocamento (`top`, `right`, `bottom`, `left`) e `z-index` **não têm efeito** em elementos estáticos.

### 2. `position: relative`

O elemento permanece no fluxo normal, mas aceita ser deslocado visualmente.

O espaço original que o elemento ocupava no layout **continua reservado**, evitando que os vizinhos se movam:

```css title="Deslocamento relativo"
.box-relative {
  position: relative;
  top: 20px;  /* Empurra 20px para baixo da sua posição original */
  left: 30px; /* Empurra 30px para a direita */
}
```

### 3. `position: absolute`

O elemento é **completamente removido do fluxo normal**. Ele não ocupa espaço na página e nenhum vizinho reserva espaço para ele.

Seu posicionamento é calculado em relação ao **ancestral posicionado mais próximo** (qualquer ancestral que tenha `position` diferente de `static`). Se nenhum ancestral for posicionado, ele se alinha ao documento inicial (`<html>`):

```css title="Padrão clássico: Pai Relativo + Filho Absoluto"
.card-container {
  position: relative; /* Define o pai como âncora de contexto */
  width: 300px;
  height: 200px;
}

.badge-tag {
  position: absolute;
  top: 10px;
  right: 10px; /* Gruda no canto superior direito do .card-container */
  background-color: #ef4444;
  color: white;
  padding: 4px 8px;
}
```

```txt title="Resultado na tela (Selo Posicionado no Canto do Card)"
+------------------------------------------+
|                            [SELO: NOVO]  |  <- Preso a 10px do topo e direita
|                                          |     do .card-container
|            Conteúdo do Card              |
+------------------------------------------+
```

<Aside type="tip" title="Padrão Pai Relativo, Filho Absoluto">
  Definir `position: relative` no contêiner pai é o padrão mais utilizado para garantir que os filhos com `position: absolute` fiquem presos dentro da caixa pai.
</Aside>

### 4. `position: fixed`

O elemento é removido do fluxo normal e posicionado fixamente em relação à janela do navegador (*viewport*).

Ele permanece na mesma posição visível na tela **mesmo durante a rolagem** da página:

```css title="Barra de navegação fixa no topo"
.header-fixed {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  z-index: 1000;
  background-color: #0f172a;
}
```

### 5. `position: sticky`

Um comportamento híbrido entre `relative` e `fixed`.

O elemento se comporta como `relative` até que a rolagem da página atinja a posição especificada (ex: `top: 0`), momento em que ele "gruda" na tela como `fixed`:

```css title="Cabeçalho de tabela ou menu adesivo"
.sticky-header {
  position: sticky;
  top: 0; /* Gruda no topo assim que a rolagem alcançar a posição 0 */
  background-color: #ffffff;
  z-index: 10;
}
```

## Ordem de Empilhamento (`z-index`)

Quando elementos posicionados se sobrepõem, a propriedade `z-index` controla qual caixa fica na frente ou atrás.

O `z-index` só funciona em elementos que possuem `position` diferente de `static`:

```css title="Controle de sobreposição com z-index"
.modal-backdrop {
  position: fixed;
  top: 0;
  left: 0;
  width: 100vw;
  height: 100vh;
  background-color: rgba(0, 0, 0, 0.5);
  z-index: 100; /* Fica atrás do modal */
}

.modal-content {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  z-index: 200; /* Fica na frente do fundo escuro */
}
```

## Flutuação (`float` e `clear`)

Historicamente, a propriedade `float` era utilizada para criar layouts de colunas antes da existência do Flexbox e Grid.

Hoje, o uso legítimo do `float` restringe-se a envolver texto ao redor de uma imagem:

```css title="Envolvendo texto ao redor de imagem com float"
.article-image {
  float: left;
  margin-right: 16px;
  margin-bottom: 8px;
}
```

Para cancelar a flutuação nos elementos seguintes, utiliza-se `clear: both;` ou um contêiner com `overflow: hidden;`.

## Executando e inspecionando no DevTools

Inspecionar posições no navegador ajuda a identificar o ancestral de referência de um elemento absoluto:

<Steps>

1. **Abra o DevTools** pressionando <kbd>F12</kbd> e inspecione um elemento com `position: absolute`.

2. **Verifique no painel Estilos (Styles)** qual é o ancestral pai que possui `position: relative`.

3. **Altere os valores de `top`, `left` ou `z-index`** no editor do navegador para ver o elemento se mover na tela.

</Steps>

Crie uma imagem de produto com um selo de desconto ("20% OFF") no canto superior direito:

1. O contêiner `.product-card` deve usar `position: relative`.
2. O selo `.badge` deve usar `position: absolute` no canto superior direito (`top: 12px`, `right: 12px`).

  <summary>Possível resposta</summary>

  }

  .badge {
    position: absolute;
    top: 12px;

  }

</details>

## Perguntas de revisão

### Modalidades de Posicionamento

1. **Qual é o comportamento padrão de um elemento com `position: static`?**
   <details>
     <summary>Possível resposta</summary>

     Ele segue estritamente o fluxo normal da página e ignora as propriedades `top`, `right`, `bottom`, `left` e `z-index`.
   </details>

2. **Qual a diferença entre `position: relative` e `position: absolute`?**
   <details>
     <summary>Possível resposta</summary>

     `relative` mantém o elemento no fluxo normal e reserva seu espaço original. `absolute` remove o elemento completamente do fluxo normal e o posiciona em relação ao ancestral posicionado mais próximo.
   </details>

3. **O que acontece com um elemento `position: absolute` se nenhum de seus ancestrais tiver `position` diferente de `static`?**
   <details>
     <summary>Possível resposta</summary>

     Ele se posiciona em relação ao bloco de contenção inicial do documento (a tag `<html>`).
   </details>

4. **Como funciona a propriedade `position: fixed`?**
   <details>
     <summary>Possível resposta</summary>

     Ela fixa o elemento em relação à janela de exibição (*viewport*) do navegador, fazendo com que ele não se mova durante a rolagem.
   </details>

5. **Em qual situação o `position: sticky` alterna seu comportamento?**
   <details>
     <summary>Possível resposta</summary>

     Ele se comporta como `relative` no fluxo normal até que a rolagem atinja o limite informado (ex: `top: 0`), momento em que ele passa a atuar como `fixed`.
   </details>

### Ordem de Empilhamento

6. **Para que serve a propriedade `z-index`?**
   <details>
     <summary>Possível resposta</summary>

     Para controlar a ordem de empilhamento no eixo Z (frente e trás) entre elementos posicionados que se sobrepõem.
   </details>

7. **O `z-index` funciona em elementos com `position: static`?**
   <details>
     <summary>Possível resposta</summary>

     Não. O `z-index` só é aplicado em elementos que possuem `position` diferente de `static`.
   </details>

8. **Qual o uso moderno recomendado para a propriedade `float`?**
   <details>
     <summary>Possível resposta</summary>

     Apenas para envolver trechos de texto ao redor de mídias ou imagens. Para layouts de colunas, deve-se usar Flexbox ou CSS Grid.
   </details>

9. **O que acontece ao aplicar `top: 0` e `bottom: 0` simultaneamente em um elemento com `position: absolute`?**
   <details>
     <summary>Possível resposta</summary>

     Se o elemento não tiver uma altura fixa definida, ele esticará verticalmente para preencher toda a altura do pai posicionado.
   </details>

10. **Por que costumamos colocar `position: relative` no contêiner pai de um item com `position: absolute`?**
    <details>
      <summary>Possível resposta</summary>

      Para definir o contêiner pai como o contexto de ancoragem de coordenadas para o elemento filho absoluto.
    </details>
