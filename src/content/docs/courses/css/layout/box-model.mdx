No CSS, cada elemento renderizado na página é considerado uma **caixa retangular**. O **Modelo de Caixa** (*Box Model*) é o conceito fundamental que dita como o tamanho, o preenchimento, a borda e o espaçamento dessa caixa são calculados.

---

## Objetivo

Entender as quatro camadas que compõem uma caixa CSS (`content`, `padding`, `border`, `margin`), ajustar os tipos de exibição (`display`) e aplicar a propriedade `box-sizing: border-box` para simplificar o cálculo de layouts.

---

## Camadas do Box Model

Cada caixa CSS é formada por quatro áreas concêntricas (de dentro para fora):

```txt
 ┌───────────────────────────────────────────────┐
 │ MARGIN (Espaçamento externo)                 │
 │   ┌───────────────────────────────────────┐   │
 │   │ BORDER (Borda)                        │   │
 │   │   ┌───────────────────────────────┐   │   │
 │   │   │ PADDING (Preenchimento interno)│   │   │
 │   │   │   ┌───────────────────────┐   │   │   │
 │   │   │   │ CONTENT (Conteúdo)    │   │   │   │
 │   │   │   └───────────────────────┘   │   │   │
 │   │   └───────────────────────────────┘   │   │
 │   └───────────────────────────────────────┘   │
 └───────────────────────────────────────────────┘
```

1. **Content (Conteúdo)**: Onde fica o texto, imagem ou filhos. Definido por `width` e `height`.
2. **Padding (Preenchimento)**: Espaço interno entre o conteúdo e a borda. Herda a cor de fundo do elemento.
3. **Border (Borda)**: Linha que envolve o padding e o conteúdo.
4. **Margin (Margem)**: Espaço transparente externo entre este elemento e os elementos vizinhos.

---

## O Problema do `box-sizing: content-box` (Padrão)

Por padrão, a largura total de um elemento na tela é calculada somando a largura do conteúdo + padding + borda:

```css
/* box-sizing: content-box (padrão) */
.box {
  width: 300px;
  padding: 20px;
  border: 5px solid black;
}
/* Largura ocupada na tela = 300 + 20 + 20 + 5 + 5 = 350px! */
```

Isso costuma estourar layouts e criar barras de rolagem indesejadas.

### A Solução: `box-sizing: border-box`

Ao definir `box-sizing: border-box`, o `width` especificado passa a incluir o **conteúdo, o padding e a borda**:

```css
.box {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 5px solid black;
}
/* Largura total na tela = exatamente 300px! O conteúdo se encolhe para acomodar o padding. */
```

<Aside type="tip" title="Reset Global Recomendado">
  A maioria dos projetos modernamente utiliza um reset CSS global para definir `border-box` em todos os elementos:

  ```css
  *, *::before, *::after {
    box-sizing: border-box;
  }
  ```
</Aside>

## Propriedade `display`

A propriedade `display` define como o elemento se comporta no fluxo do documento:

| Valor | Comportamento | Exemplos de Tags |
| :--- | :--- | :--- |
| `block` | Ocupa 100% da largura disponível e quebra linha antes e depois. Aceita `width`, `height`, `margin` e `padding` livremente. | `<div>`, `<h1>`, `<p>`, `<section>` |
| `inline` | Ocupa apenas o tamanho do conteúdo e fica na mesma linha. **Não aceita** `width`/`height`, e margens verticais são ignoradas. | `<span>`, `<a>`, `<strong>`, `<em>` |
| `inline-block` | Fica na mesma linha que outros elementos (como `inline`), mas **aceita** `width`, `height`, `margin` e `padding` (como `block`). | `<button>`, `<input>`, `<img>` |
| `none` | Remove completamente o elemento do fluxo e da tela (não ocupa espaço). | — |

```css
/* Exemplo de botão personalizado com inline-block */
.btn {
  display: inline-block;
  padding: 0.75rem 1.5rem;
  background-color: #2563eb;
  color: white;
  text-decoration: none;
  border-radius: 0.375rem;
}
```

---

## Resumo e Boas Práticas

- Aplique o reset `box-sizing: border-box` no início do projeto.
- Destaque a diferença entre `padding` (espaçamento interno) e `margin` (espaçamento externo).
- Use `display: block` para contêineres e `display: inline-block` quando precisar de dimensões em elementos lado a lado.
