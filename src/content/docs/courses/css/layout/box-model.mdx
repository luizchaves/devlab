No desenvolvimento Web com CSS, absolutamente tudo na tela é interpretado como uma **caixa retangular**. 

O **Modelo de Caixa** (*Box Model*) é o conceito arquitetural mais importante do CSS. Ele dita exatamente como a largura, a altura, o espaçamento interno, as bordas e a margem externa de qualquer elemento são calculados pelo navegador.

Compreender o Box Model evita problemas clássicos de layout, como barras de rolagem indesejadas, elementos desalinhados e quebras inesperadas em telas menores.

---

## Objetivo

Entender detalhadamente as quatro camadas do Box Model (`content`, `padding`, `border` e `margin`), dominar a alteração de modos de exibição (`display`) e aplicar a propriedade `box-sizing: border-box` para criar layouts previsíveis e responsivos.

## As 4 Camadas do Box Model

Cada caixa CSS renderizada no navegador é composta por quatro áreas concêntricas organizadas de fora para dentro.

Cada uma dessas camadas desempenha um papel único na construção visual da página:

### 1. Content (Conteúdo)

O **Content** é o núcleo da caixa. É onde residem os textos, imagens, vídeos ou elementos filhos incorporados.

As dimensões desta área são originalmente controladas pelas propriedades `width` (largura) e `height` (altura).

### 2. Padding (Preenchimento Interno)

O **Padding** é a área de respiro interna situada entre o conteúdo e a borda da caixa.

Esta camada é transparente, porém ela herda a cor ou imagem de fundo (`background`) definida para o elemento.

Usar `padding` é ideal para criar espaço interno em botões, cartões (*cards*) e caixas de texto, evitando que o texto fique colado nas bordas.

### 3. Border (Borda)

A **Border** envolve diretamente o padding e o conteúdo, atuando como o limite visível da caixa.

Sua aparência é controlada por três subpropriedades principais: espessura (`border-width`), estilo (`border-style`) e cor (`border-color`).

A borda delimita até onde o fundo do elemento é desenhado na tela.

### 4. Margin (Margem Externa)

A **Margin** é o espaço transparente localizado do lado de fora da borda.

Ela é utilizada para afastar um elemento de seus vizinhos ao redor no layout, criando áreas em branco na página.

Diferente do padding, a margem nunca herda a cor de fundo do elemento e permanece sempre transparente.

### Resumo das propriedades por camada

Na tabela abaixo, veja como cada camada é mapeada para propriedades CSS específicas:

| Camada | Propriedades comuns | Papel visual no layout |
| :--- | :--- | :--- |
| **Conteúdo** | `width`, `height`, `min-width`, `max-width` | Área que contém o texto ou mídia principal. |
| **Padding** | `padding`, `padding-top`, `padding-right` ... | Espaçamento interno entre conteúdo e a borda. |
| **Border** | `border`, `border-width`, `border-style` ... | Linha de contorno visível da caixa. |
| **Margin** | `margin`, `margin-top`, `margin-left` ... | Espaçamento externo entre a caixa e outros elementos. |

## O Cálculo de Dimensões e o `box-sizing`

Por padrão histórico do CSS, o cálculo da largura total de um elemento na tela pode gerar confusão se você não prestar atenção à propriedade `box-sizing`.

### O Comportamento Padrão (`box-sizing: content-box`)

Por padrão, os navegadores aplicam a propriedade `box-sizing: content-box`.

Neste modo, a largura (`width`) e altura (`height`) declaradas aplicam-se **apenas ao conteúdo**. O padding e a borda são somados por fora.

Exemplo de cálculo com `content-box`:

```css title="Cálculo com content-box (padrão)"
.card {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 5px solid #1e293b;
  margin: 15px;
}
```

Neste cenário, a largura real ocupada na tela será:

```txt title="Cálculo da Largura Total"
Largura Total = 300px (width) + 20px (padding-left) + 20px (padding-right) + 5px (border-left) + 5px (border-right) = 350px
```

A margem de `15px` ainda empurrará os elementos vizinhos, exigindo um espaço livre total de `380px`.

Isso costuma quebrar grids e causar estouro de layout em telas menores.

### A Solução Moderna (`box-sizing: border-box`)

Para solucionar essa complexidade, o CSS moderno introduziu o valor `border-box`.

Com `box-sizing: border-box`, o `width` e o `height` especificados representam a **largura total visível** do elemento (conteúdo + padding + borda).

Veja o mesmo exemplo com `border-box`:

```css title="Cálculo com border-box"
.card {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 5px solid #1e293b;
}
```

Agora, a largura final na tela será **exatamente 300px**. 

O navegador calcula automaticamente a largura do conteúdo interno encolhendo-o para `250px` (`300 - 40 - 10`), garantindo que o cartão nunca ultrapasse o tamanho desejado.

<Aside type="tip" title="Reset Global Recomendado">
  É uma boa prática universal em projetos web adotar o reset global de `box-sizing` no topo da sua folha de estilos:

  ```css title="style.css"
  *, *::before, *::after {
    box-sizing: border-box;
  }
  ```

  Isso garante previsibilidade em todos os elementos da página sem precisar declarar a propriedade repetidamente.
</Aside>

## A Propriedade `display`

A propriedade `display` define como uma caixa se posiciona no fluxo normal da página e como interage com as demais caixas ao seu redor.

Os três modos fundamentais do fluxo tradicional são `block`, `inline` e `inline-block`:

| Valor | Comportamento no fluxo | Aceita `width`/`height`? | Respeita `margin` vertical? | Exemplos comuns |
| :--- | :--- | :--- | :--- | :--- |
| `block` | Ocupa toda a largura da linha (100%) e força quebra de linha. | Sim | Sim | `<div>`, `<h1>`, `<p>`, `<article>` |
| `inline` | Ocupa apenas a largura do próprio texto/conteúdo. Fica na mesma linha. | **Não** | **Não** | `<span>`, `<a>`, `<strong>`, `<em>` |
| `inline-block` | Permanece na mesma linha (como `inline`), mas aceita dimensões e espaçamentos (como `block`). | Sim | Sim | `<button>`, `<input>`, `<img>` |
| `none` | Oculta o elemento e o remove completamente do fluxo de renderização. | N/A | N/A | Elementos escondidos |

O exemplo a seguir ilustra a estilização de um hiperlink (`<a>`), que por padrão é `inline`, transformando-o em um botão com `inline-block`:

```css title="Estilizando um botão"
.btn {
  display: inline-block;
  width: 200px;
  padding: 12px 24px;
  margin-top: 10px;
  background-color: #2563eb;
  color: #ffffff;
  text-decoration: none;
  text-align: center;
  border-radius: 6px;
}
```

## Colapso de Margens (Margin Collapse)

Um comportamento peculiar do Box Model é o **colapso de margens verticais**.

Quando dois elementos em bloco (`display: block`) estão empilhados verticalmente, suas margens top e bottom não se somam. Em vez disso, elas se sobrepõem e apenas a **maior margem prevalece**.

Por exemplo:

```css title="Exemplo de colapso de margens"
.top-box {
  margin-bottom: 30px;
}

.bottom-box {
  margin-top: 20px;
}
```

A distância real entre `.top-box` e `.bottom-box` não será de `50px` (`30 + 20`), mas sim de **`30px`** (a maior entre elas).

<Aside type="note" title="Observação sobre colapso">
  O colapso de margens só ocorre na vertical entre elementos no fluxo normal com `display: block`. Margens horizontais (`left`/`right`) nunca colapsam.
</Aside>

## Executando e inspecionando no DevTools

Você pode visualizar e inspecionar o Box Model de qualquer elemento em tempo real usando as ferramentas de desenvolvedor do navegador.

Siga os passos abaixo para inspecionar o Box Model:

<Steps>

1. **Abra a página no navegador** e pressione <kbd>F12</kbd> (ou clique com o botão direito em um elemento e escolha **Inspecionar**).

2. **Selecione a aba Elementos (Elements)** e escolha a tag que deseja examinar na árvore DOM.

3. **Role até o painel Computado (Computed)** na barra lateral direita do DevTools.

4. **Observe o diagrama interativo do Box Model**, que exibirá exatamente os valores de `margin`, `border`, `padding` e `content` calculados para aquele elemento.

5. **Passe o cursor sobre cada retângulo no diagrama** para ver a área correspondente destacada em cores na tela.

</Steps>

## Exercício

Pratique os conceitos do Box Model resolvendo o exercício a seguir:

1. Crie uma caixa com a classe `.card` com as seguintes especificações:
   - Largura total desejada: `400px`.
   - Preenchimento interno (`padding`): `24px` em todos os lados.
   - Borda (`border`): `4px` sólida na cor `#3b82f6`.
   - Margem externa (`margin`): `20px` na parte inferior.
   - Garanta que a caixa tenha exatamente `400px` de largura visível na tela sem estourar.

<details>
  <summary>Possível resposta</summary>

  ```css title="solucao.css"
  .card {
    box-sizing: border-box;
    width: 400px;
    padding: 24px;
    border: 4px solid #3b82f6;
    margin-bottom: 20px;
  }
  ```

  Com `box-sizing: border-box`, os `24px` de padding e os `4px` de borda ficam contidos dentro dos `400px` declarados.
</details>

## Desafio

Crie um menu de navegação simples com 3 links (`<a class="nav-link">`). 

Cada link deve estar na mesma linha, possuir largura de `120px`, padding vertical de `10px`, fundo `#1e293b` e texto branco centralizado.

<details>
  <summary>Possível resposta</summary>

  ```css title="desafio.css"
  .nav-link {
    display: inline-block;
    width: 120px;
    padding: 10px 0;
    background-color: #1e293b;
    color: #ffffff;
    text-align: center;
    text-decoration: none;
    margin-right: 8px;
  }
  ```

  Como os links `<a>` são por padrão elementos `inline`, foi necessário alterar para `display: inline-block` para que a largura (`width`) e os paddings fossem respeitados.
</details>

## Perguntas de revisão

### Conceitos Fundamentais do Box Model

1. **Quais são as quatro camadas que compõem o Box Model em ordem da mais externa para a mais interna?**
   <details>
     <summary>Possível resposta</summary>

     Margem (`margin`), Borda (`border`), Preenchimento (`padding`) e Conteúdo (`content`).
   </details>

2. **Qual é a principal diferença entre `padding` e `margin`?**
   <details>
     <summary>Possível resposta</summary>

     O `padding` é o espaçamento interno (entre o conteúdo e a borda) e herda o fundo do elemento. A `margin` é o espaçamento externo (entre a borda e elementos vizinhos) e é sempre transparente.
   </details>

3. **O que acontece com a cor de fundo (`background-color`) de um elemento em relação ao `padding` e à `margin`?**
   <details>
     <summary>Possível resposta</summary>

     A cor de fundo preenche a área do conteúdo e do `padding`, mas para na borda. A `margin` nunca recebe a cor de fundo.
   </details>

### Propriedade `box-sizing`

4. **Por que o valor padrão `box-sizing: content-box` pode dificultar o cálculo de layouts?**
   <details>
     <summary>Possível resposta</summary>

     Porque ele soma o `padding` e a `border` por fora da largura declarada (`width`), fazendo com que o elemento ocupe um espaço total maior do que o definido.
   </details>

5. **Como o valor `box-sizing: border-box` simplifica o cálculo de dimensões?**
   <details>
     <summary>Possível resposta</summary>

     Ele faz com que a largura (`width`) inclua o conteúdo, o padding e a borda. O navegador reduz automaticamente o tamanho do conteúdo interno para manter a largura total fixa no valor informado.
   </details>

6. **Qual é a regra CSS recomendada para aplicar `border-box` em todo o projeto?**
   <details>
     <summary>Possível resposta</summary>

     ```css
     *, *::before, *::after {
       box-sizing: border-box;
     }
     ```
   </details>

### Modos de Exibição (`display`)

7. **Qual é a diferença entre os elementos com `display: block` e `display: inline`?**
   <details>
     <summary>Possível resposta</summary>

     Elementos `block` ocupam 100% da largura da linha, forçam quebra de linha e aceitam `width`/`height`. Elementos `inline` ocupam apenas a largura do seu conteúdo, ficam lado a lado e ignoram `width`, `height` e margens verticais.
   </details>

8. **Quando devemos utilizar `display: inline-block`?**
   <details>
     <summary>Possível resposta</summary>

     Quando desejamos manter o elemento na mesma linha que outros elementos (como um item `inline`), mas precisamos definir dimensões (`width`/`height`) e espaçamentos personalizados (como um item `block`).
   </details>

9. **O que ocorre no layout ao aplicar `display: none` a um elemento?**
   <details>
     <summary>Possível resposta</summary>

     O elemento é completamente removido da renderização visual e do fluxo da página, deixando de ocupar qualquer espaço na tela.
   </details>

10. **Como funciona o colapso de margens (*margin collapse*) no CSS?**
    <details>
      <summary>Possível resposta</summary>

      Ocorre quando dois elementos em bloco empilhados na vertical combinam suas margens top/bottom, resultando em um espaço igual à maior margem entre eles, em vez da soma das duas.
    </details>
