Formulários HTML funcionam sem CSS, mas a aparência padrão do navegador costuma ser
limitada para uma interface de aplicação. Nesta página, o foco é comparar diferentes
formas de apresentar o mesmo tipo de tela com CSS próprio, Bootstrap e Tailwind.

<Aside type="tip" title="Estrutura antes da aparência">
  Antes de estilizar, revise os elementos em
  [HTML: Formulários](../../../html/forms/elements-controls/). CSS deve melhorar a experiência visual sem
  substituir rótulos, tipos de campo, agrupamento e semântica correta.
</Aside>

## Formulário com CSS

Com CSS próprio, é possível controlar espaçamento, largura dos campos, bordas, cores,
estados de foco, alinhamento e responsividade sem depender de uma biblioteca externa.

<Aside type="note" title="CSS e interação">
  Quando o formulário tem comportamento dinâmico, como cálculo ou validação no
  navegador, o CSS cuida da apresentação e o JavaScript cuida da interação. As duas
  responsabilidades aparecem juntas no exemplo, mas continuam separadas.
</Aside>

## Formulário com Bootstrap

Bootstrap oferece classes prontas para campos, botões, grid e espaçamento. Ele é útil
quando o projeto precisa de uma interface consistente rapidamente, seguindo um padrão
visual já definido pela biblioteca.

## Comparação

A tabela a seguir compara as três principais abordagens para estilização de formulários em projetos Web:

| Abordagem | Vantagem | Cuidado |
| --------- | -------- | ------- |
| CSS próprio | Dá controle total sobre aparência e responsividade | Exige criar e manter o padrão visual |
| Bootstrap | Acelera a construção com componentes e classes prontas | Pode deixar projetos diferentes com aparência parecida |
| Tailwind | Facilita ajustes finos com classes utilitárias | Pode deixar o HTML longo se não houver organização |
