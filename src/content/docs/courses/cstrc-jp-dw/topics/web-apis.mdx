Aqui a linguagem encontra o navegador. As **Web APIs** não fazem parte do ECMAScript:
são interfaces que o navegador oferece ao JavaScript para ler e alterar a página,
responder a cliques, guardar dados no dispositivo e falar com servidores pela rede.

É neste tópico que a página deixa de ser um documento e vira uma aplicação. Também é
onde entram as primeiras dependências externas do projeto — um servidor de
desenvolvimento, uma API falsa para prototipar e uma biblioteca de gráficos.

## O que esperar deste tópico

Você vai partir dos objetos globais do navegador, aprender a percorrer e modificar a
árvore do DOM, reagir a eventos do usuário, persistir dados com `localStorage` e
consumir APIs HTTP com `fetch` e com Axios.

<Aside type="note" title="Onde termina a linguagem e começa o navegador">
  `Promise` é da linguagem; `fetch` é do navegador. `Array` é da linguagem;
  `document` é do navegador. Essa distinção fica clara aqui e explica por que o
  código do tópico de Node.js não tem `document` — lá o ambiente é outro.
</Aside>
