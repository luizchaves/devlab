Com a estrutura no lugar, o próximo passo é a apresentação. CSS é a linguagem que
separa *o que a página é* de *como ela aparece* — e essa separação é o que permite
mudar todo o visual de um site sem tocar em uma linha de HTML.

O tópico tem duas metades. A primeira é conceitual e não dá para pular: cascata,
especificidade e herança explicam por que uma regra vence a outra, e é onde mora a
maior parte da frustração de quem está começando. A segunda é prática: modelo de
caixa, Flexbox, Grid e media queries, que são as ferramentas com que você monta
qualquer layout moderno.

## O que esperar deste tópico

Você vai escrever CSS do zero, conectar uma folha externa a uma página, selecionar
elementos com precisão e montar layouts que funcionam do celular ao desktop. No
fim, entram Bootstrap e Tailwind — não como substitutos do CSS, mas como duas
respostas diferentes para o mesmo problema de produtividade.

<Aside type="caution" title="Framework não dispensa o fundamento">
  Bootstrap e Tailwind aparecem depois de você já saber escrever o CSS na mão, e é
  intencional. Quem chega ao framework sem entender cascata e box model consegue
  copiar exemplos, mas trava no primeiro ajuste que a documentação não cobre.
</Aside>
