Todo elemento renderizado ocupa uma caixa. Entender essa caixa evita a maior parte dos problemas de espaçamento.

## Estrutura do Box Model

```plaintext title="Modelo de caixa"
┌──────────────────────── margin ────────────────────────┐
│ ┌────────────────────── border ──────────────────────┐ │
│ │ ┌─────────────────── padding ────────────────────┐ │ │
│ │ │                  conteúdo                       │ │ │
│ │ └────────────────────────────────────────────────┘ │ │
│ └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

| Parte     | Propriedade comum | Papel                                      |
| --------- | ----------------- | ------------------------------------------ |
| Conteúdo  | `width`, `height` | Área ocupada pelo conteúdo                 |
| Padding   | `padding`         | Espaço interno entre conteúdo e borda      |
| Borda     | `border`          | Linha ao redor da caixa                    |
| Margin    | `margin`          | Espaço externo entre uma caixa e outra     |

<Aside type="tip" title="Use box-sizing: border-box">
  Com `box-sizing: border-box`, largura e altura passam a incluir padding e borda.
  Isso deixa o cálculo do layout mais previsível.
</Aside>
