CSS (*Cascading Style Sheets*) é uma linguagem de **folha de estilos**. Ela descreve
como um documento HTML deve aparecer na tela, no papel e em outros meios: cores,
fontes, espaçamento, bordas, posicionamento, layout e adaptação a tamanhos de tela.

## Objetivo

Escrever CSS básico do zero, conectar uma folha de estilos a uma página HTML,
selecionar elementos com precisão, trabalhar com variáveis e media queries, e
entender por que a cascata e a especificidade decidem qual regra vence quando estilos
entram em conflito.

## Por que CSS existe

No começo da Web, era comum misturar estrutura e aparência no HTML com tags como
`<center>` e `<font>`. Esses elementos hoje são obsoletos: o HTML deve descrever o
conteúdo, enquanto o CSS deve cuidar da apresentação.

```html title="HTML antigo" del={1-3}
<center>
  <font color="blue" size="6">Bem-vindos</font>
</center>
```

```html title="HTML com significado" ins={1}
<h1>Bem-vindos</h1>
```

```css title="CSS para aparência" ins={1-4}
h1 {
  color: blue;
  text-align: center;
}
```

<Aside type="tip" title="Separe responsabilidade">
  Use HTML para dizer o que cada conteúdo é. Use CSS para definir como esse conteúdo
  deve aparecer. Para observar claramente essa separação, você pode desabilitar os
  estilos CSS da página usando extensões como a
  [Web Developer](https://chrome.google.com/webstore/detail/web-developer/bfbameneiokkgbdmiekhjnmfkcnldffj).
</Aside>

Referências: [`<center>` no MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/center)
e [`<font>` no MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/font).

CSS tem poucas peças de sintaxe, mas elas aparecem combinadas em muitos lugares:
propriedades, seletores, valores, funções, variáveis e regras iniciadas com `@`.
Esta visão geral ajuda a saber onde consultar cada assunto.

  color: #92400e;
}

## Como o CSS entra na página

CSS pode ser escrito diretamente no elemento, dentro do próprio HTML ou em um arquivo
separado. Os três formatos são úteis para entender a linguagem, mas projetos reais
normalmente usam arquivo externo.

| Forma       | Onde fica                               | Quando faz sentido                                  |
| ----------- | --------------------------------------- | --------------------------------------------------- |
| Inline      | Atributo `style` no elemento             | Testes rápidos ou valores calculados por JavaScript |
| Interno     | Tag `<style>` dentro do `<head>`         | Exemplos pequenos e páginas isoladas                |
| Externo     | Arquivo `.css` carregado por `<link>`    | Projetos reais, reaproveitamento e manutenção       |

### CSS inline

O atributo `style` recebe declarações CSS diretamente no elemento. Uma
**declaração** é um par `propriedade: valor`: em `font-size: 20px`, a propriedade é
`font-size` e o valor é `20px`.

```plaintext title="Declaração no atributo style"
            declaração
          ┌──────┴───────┐
<p style="font-size: 20px;">Lorem ipsum dolor</p>
          └───┬───┘  └─┬─┘
          propriedade valor
```

Como o estilo está no próprio elemento, não há seletor: a declaração vale apenas
para aquele elemento.

| Parte       | Papel no CSS                                                   |
| ----------- | -------------------------------------------------------------- |
| Declaração  | Par `propriedade: valor`                                       |
| Propriedade | Nome do aspecto visual que será alterado                       |
| Valor       | Valor aplicado à propriedade                                   |
| `:`         | Separa propriedade e valor                                     |
| `;`         | Encerra uma declaração; é obrigatório quando há mais de uma     |

O exemplo a seguir mostra declarações aplicadas diretamente nos elementos e o
resultado visual produzido por elas.

</Aside>

### CSS interno

A tag `<style>` fica no `<head>` e afeta a página atual. Dentro dela, uma regra CSS
junta um **seletor** e um bloco de **declarações**: o seletor escolhe os elementos,
e cada declaração muda uma propriedade visual.

```plaintext title="Anatomia de uma regra CSS"
seletor       declaração
  ┌┴┐   ┌─────────┴─────────┐
  p  {  color: #1d4ed8;     }
       └──┬──┘  └───┬────┘
       propriedade  valor
```

Nesta forma, aparecem peças que não existem no CSS inline:

| Parte        | Papel no CSS                                                    |
| ------------ | --------------------------------------------------------------- |
| Seletor      | Define quais elementos recebem as declarações                   |
| Bloco        | Agrupa declarações entre `{` e `}`                              |

O exemplo a seguir mostra regras CSS dentro da tag `<style>` e como elas afetam os
elementos da mesma página.

<Aside type="note" title="Prós e contras do CSS interno">
  CSS interno é prático para protótipos e páginas pequenas, porque mantém o
  exemplo completo em um único arquivo HTML. Em projetos maiores, ele dificulta o
  reaproveitamento entre páginas, aumenta o tamanho do HTML e pode deixar a
  manutenção mais trabalhosa. Quando o estilo precisa ser compartilhado, prefira CSS
  externo.
</Aside>

  CSS externo facilita reaproveitamento, organização e manutenção, porque várias

  precisa ser atualizado.
</Aside>

## Cascata, especificidade e herança

A palavra "cascading" no nome CSS importa. Várias regras podem atingir o mesmo
elemento, e o navegador precisa decidir qual valor usar para cada propriedade.

<Tabs syncKey="css-cascata">
  <TabItem label="HTML">
    <SourceCode

        '<p>',
        'class="aviso"',
        'class="aviso destaque"',

    />

  <TabItem label="Resultado">

De forma prática, observe no código quais trechos disputam a mesma propriedade. Em
herança e valor inicial, o ponto principal é o que acontece quando não existe uma
declaração direta no próprio elemento.

| Fator          | Ideia central                                                             | No exemplo                                                                 |
| -------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Ordem          | Se duas regras equivalentes competem, a última no arquivo vence           | Em `<p class="aviso destaque">`, `.aviso` define `color: #2563eb` e `.destaque` define `color: #b45309`. Como as duas classes têm a mesma especificidade, vence `#b45309`, pois `.destaque` aparece depois no CSS |
| Importância    | Uma declaração com `!important` ganha prioridade sobre declarações normais | Em `<p class="prioridade" style="color: #dc2626;">`, o inline tenta usar `#dc2626`, mas `.prioridade` define `color: #be123c !important`. Vence `#be123c`, porque a declaração importante supera a declaração normal |
| Especificidade | ID vence classe, classe vence elemento                                    | Em `<p id="mensagem" class="aviso">`, `p` define `#334155`, `.aviso` define `#2563eb` e `#mensagem` define `#047857`. Vence `#047857`, porque o seletor de ID é mais específico |
| Inline         | O atributo `style` costuma vencer regras do arquivo CSS                   | Em `<p id="urgente" class="aviso" style="color: #dc2626;">`, `#urgente` define `#7c3aed`, mas o inline define `#dc2626`. Vence `#dc2626`, porque o atributo `style` tem prioridade maior que seletores normais |
| Herança        | Algumas propriedades, como `color` e `font-family`, passam para filhos    | `body` define `font-family: Arial, sans-serif`. Como os `<p>` não definem outra `font-family`, eles herdam esse valor do elemento pai |
| Valor inicial  | Quando nada é definido, o navegador usa o valor inicial da propriedade    | Nenhuma regra define `font-weight` para os parágrafos. Por isso, eles usam o valor inicial `normal` |

<Aside type="tip" title="Use o DevTools para investigar conflitos">
  Quando duas regras definem a mesma propriedade, o painel **Styles** do DevTools
  mostra quais declarações foram aplicadas e quais foram descartadas. Essa é uma
  forma prática de enxergar a cascata, a especificidade, a ordem e o efeito de
  `!important` no elemento selecionado.
</Aside>

<Aside type="caution" title="Evite !important como padrão">
  `!important` existe para casos excepcionais, mas não deve virar padrão. Quando ele
  é usado sem necessidade, o código fica mais difícil de sobrescrever e a cascata
  perde previsibilidade.
</Aside>

<Aside type="tip" title="Prefira classes para estilizar componentes">
  IDs são úteis para fragmentos de URL e JavaScript, mas classes costumam ser mais
  flexíveis para CSS. Evite resolver conflitos aumentando especificidade sem motivo.
</Aside>

<Aside type="note" title="Contêineres genéricos: <div> e <span>">
  `<div>` (bloco) e `<span>` (inline) são contêineres genéricos sem estilo visual
  próprio ou valor semântico específico. Eles são muito usados com classes para
  agrupar elementos. Ao aplicar propriedades herdáveis (como `color` e `font-family`)
  em um `<div>`, todos os elementos e `<span>` filhos herdam esses estilos
  automaticamente, a menos que uma regra mais específica os sobrescreva.
</Aside>

Referência completa: [Introduction to the CSS cascade](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Introduction)
no MDN.

## Propriedades e valores

Uma propriedade muda um aspecto específico do elemento. O valor precisa ser válido
para aquela propriedade.

| Grupo       | Propriedades comuns                                      | Exemplo de valor                         |
| ----------- | -------------------------------------------------------- | ---------------------------------------- |
| Texto       | `color`, `font-family`, `font-size`, `font-weight`, `line-height` | `#1d4ed8`, `Arial`, `1rem`, `bold` |
| Espaço      | `margin`, `padding`, `gap`                               | `0`, `1rem`, `2rem`                      |
| Caixa       | `width`, `max-width`, `border`, `border-radius`, `box-sizing` | `48rem`, `1px solid #ccc`, `border-box` |
| Fundo       | `background`, `background-color`                         | `white`, `#dbeafe`, `linear-gradient(...)` |
| Layout      | `display`, `grid-template-columns`, `justify-content`, `align-items` | `grid`, `flex`, `center`       |
| Responsivo  | `@media`, `min-width`, `max-width`                       | `@media (min-width: 48rem)`              |

<Aside type="tip" title="Propriedades abreviadas (Shorthand properties)">
  Propriedades como `margin`, `padding`, `border`, `font` e `background` são
  *shorthands*: elas permitem definir múltiplos valores em uma única declaração.
  Elas deixam o código mais conciso, mas redefinem subpropriedades não especificadas
  para seus valores iniciais.

  ```css title="Exemplo de shorthand font"
  /* Declaração abreviada: */
  font: italic bold 20px Times;

  /* Equivalente a definir individualmente: */
  font-style: italic;
  font-weight: bold;
  font-size: 20px;
  font-family: Times;
  ```
</Aside>

Referência completa: [CSS properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties)
no MDN.

### Unidades, cores e funções

Alguns valores são palavras, outros são números com unidade, cores ou funções.

| Tipo de valor | Exemplos                                                       | Uso comum                              |
| ------------- | -------------------------------------------------------------- | -------------------------------------- |
| Comprimento   | `px`, `rem`, `em`, `%`, `vw`, `vh`                             | Tamanho, espaço, largura e altura      |
| Cor           | `red`, `#2563eb`, `rgb(37 99 235)`, `hsl(221 83% 53%)`         | Texto, fundo e borda                   |
| Tempo         | `150ms`, `0.3s`                                                | Transições e animações                 |
| Ângulo        | `45deg`, `0.25turn`                                            | Rotação, gradiente e transformações    |
| Função        | `var(--cor)`, `calc(100% - 2rem)`, `rgb(...)`, `min(...)`      | Reuso, cálculo e valores compostos     |

```css title="Funções CSS"
.card {
  width: calc(100% - 2rem);
  color: rgb(37 99 235);
  padding: var(--espaco);
}
```

<Aside type="tip" title="Por que evitar cores nominais?">
  Cores por palavras-chave (`red`, `blue`, `green`) são práticas para testes rápidos,
  mas possuem limitações: são restritas a um conjunto fixo (~148 cores), não
  permitem definir transparência (canal alfa) e dificultam alinhar a paleta com a
  identidade visual do projeto. Usar **Hexadecimal** (`#2563eb`), **`rgb()`** ou
  **`hsl()`** dá acesso a milhões de cores com controle de opacidade. Formatos
  modernos como **`oklch()`** oferecem ainda brilho perceptualmente uniforme entre
  diferentes matizes.
</Aside>

| Tipo | Exemplos | Uso comum |
| ---- | -------- | --------- |
| Largura de caractere | `ch` | Campos e blocos de texto com largura aproximada por caracteres |
| Altura dinâmica da viewport | `svh`, `lvh`, `dvh` | Layouts mobile que precisam lidar com barras do navegador |

| Função de imagem | `linear-gradient(...)`, `url(...)` | Fundos, imagens e gradientes |
</details>

### Variáveis CSS

Variáveis CSS são chamadas de **custom properties**. O nome começa com `--` e o uso
acontece com `var()`:

```css title="Custom properties"
:root {
  --cor-destaque: #2563eb;
  --espaco: 1rem;
}

.botao {
  color: var(--cor-destaque);
  padding: var(--espaco);
}
```

Elas ajudam a manter cores, espaçamentos e outros valores consistentes em várias
partes da página.

<Aside type="tip" title="Temas claro e escuro (Light e Dark Theme)">
  Um uso muito prático de variáveis CSS é a implementação de temas (*light* e *dark mode*).
  Basta definir variáveis de cores (como `--cor-fundo` e `--cor-texto`) em `:root` e
  redefinir apenas os seus valores dentro de uma media query `@media (prefers-color-scheme: dark)`
  ou de uma classe como `.dark`. Toda a página se adapta automaticamente sem precisar
  sobrescrever as regras de cada elemento individualmente.
</Aside>

Referência completa: [Using CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties)
no MDN.

## Tipos de seletores

Seletores são padrões que escolhem quais elementos receberão uma regra. Comece pelos
seletores mais comuns e só avance para combinações complexas quando elas deixarem o

<Aside type="tip" title="Classes utilitárias e reutilização">

  é a base de frameworks populares como [Bootstrap](https://getbootstrap.com/) e
  [Tailwind CSS](https://tailwindcss.com/).
</Aside>

## At-rules

At-rules são instruções CSS que começam com `@`. Elas servem para orientar o
comportamento do CSS, como carregar fontes personalizadas, criar animações ou
importar outras folhas de estilo:

```css title="Exemplo de @font-face"
@font-face {
  font-family: "MinhaFonte";
  src: url("fonts/minha-fonte.woff2") format("woff2");
}
```

<Aside type="tip" title="Google Fonts gera @font-face automaticamente">
  Ao usar serviços como o [Google Fonts](https://fonts.google.com/), você inclui uma
  tag `<link>` no HTML ou `@import` no CSS. A folha de estilos externa carregada já
  contém as regras `@font-face` geradas automaticamente para cada peso e formato de
  fonte, dispensando a escrita manual dessas declarações.
</Aside>

Algumas das at-rules mais comuns no CSS:

| At-rule      | Uso comum                                                   |
| ------------ | ----------------------------------------------------------- |
| `@media`     | Adapta estilos por largura de tela, impressão ou preferência |
| `@import`    | Importa outra folha de estilos                              |
| `@font-face` | Declara uma fonte externa                                   |
| `@keyframes` | Define etapas de uma animação                               |
| `@supports`  | Aplica CSS apenas se o navegador suportar um recurso         |

## Media queries

Media queries permitem aplicar CSS apenas quando o dispositivo, a tela ou a
preferência do usuário atende a uma condição. Segundo o MDN, uma media query combina
um tipo de mídia opcional com uma ou mais expressões de recursos de mídia.

```plaintext title="Anatomia de uma media query"
@media screen and (min-width: 48rem) {
       └─┬──┘ └┬┘ └──────┬───────┘
   media type operador  media feature
}
```

Cada parte da estrutura de uma media query tem um papel específico:

| Parte | Papel | Exemplo |
| ----- | ----- | ------- |
| `@media` | At-rule que inicia a condição | `@media (...)` |
| Media type | Indica o meio onde a regra vale | `screen`, `print`, `all` |
| Operador lógico | Combina ou modifica condições | `and`, `not`, `only` |
| Media feature | Recurso consultado no ambiente | `width`, `hover`, `orientation`, `prefers-color-scheme` |
| Operador de comparação | Compara uma feature com um valor | `>=`, `<=`, `=`, ou prefixos como `min-width` |
| Valor | Medida, palavra chave ou preferência testada | `48rem`, `landscape`, `dark` |
| Lista de queries | Separa alternativas com vírgula | `screen and (min-width: 48rem), print` |

O exemplo a seguir mostra regras CSS que alteram o alinhamento e a cor de um título quando a página é enviada para impressão:

Outros exemplos comuns de media query no CSS:

```css title="Exemplos de media query"
@media print {
  body {
    font-size: 12pt;
  }
}

@media screen and (min-width: 48rem) {
  .conteudo {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (prefers-color-scheme: dark) {
  body {
    background-color: #0f172a;
    color: white;
  }
}
```

<Aside type="note" title="Media query também aparece fora de @media">
  `@media` não é a única forma de declarar uma media query. Em HTML,
  `<link rel="stylesheet" href="print.css" media="print" />` carrega uma folha
  voltada para impressão. Em CSS, `@import url("wide.css") screen and (min-width:
  64rem);` importa outra folha apenas quando a condição combina com o ambiente. Para
  folhas principais, prefira `<link>`; use `@media` quando as regras ficam no próprio
  arquivo.
</Aside>

<Aside type="tip" title="Comece por features, não por aparelhos">
  Prefira testar características da tela ou do usuário, como `width`, `hover` e
  `prefers-color-scheme`, em vez de tentar adivinhar modelos de aparelhos. Isso
  deixa o CSS mais flexível para telas atuais e futuras.
</Aside>

## Exercício

Use a página pessoal criada na aula de HTML e acrescente CSS externo:

1. Crie a pasta `css/` e o arquivo `css/style.css`;
2. Carregue o arquivo com `<link rel="stylesheet" href="css/style.css" />`;
3. Defina cores, fonte, largura máxima e espaçamento geral;
4. Transforme o menu em uma lista horizontal;
5. Crie ao menos duas classes reutilizáveis, como `.card` e `.destaque`;
6. Use `:hover` em links ou botões;
7. Crie uma `@media` query para telas maiores ou impressão;
8. Inspecione uma regra no DevTools e identifique propriedade, valor e seletor.

## Desafio

Crie variáveis em `:root` para cor principal, cor de fundo, cor do texto e espaço
padrão. Em seguida, implemente um tema escuro alterando os valores dessas variáveis
dentro de uma media query `@media (prefers-color-scheme: dark)` ou de uma classe `.dark`.

## Perguntas de revisão

**1. Qual é a responsabilidade do CSS em uma página?**

<details>
  <summary>Possível resposta</summary>

  CSS descreve a apresentação visual do documento: cores, fontes, espaçamentos,
  bordas, layout, responsividade e outros aspectos de renderização.
</details>

**2. Qual é a diferença entre CSS inline, interno e externo?**

<details>
  <summary>Possível resposta</summary>

  Inline fica no atributo `style` de um elemento. Interno fica na tag `<style>` da
  página. Externo fica em um arquivo `.css` carregado com `<link>`, que é a opção
  mais comum para projetos.
</details>

**3. O que um seletor faz?**

<details>
  <summary>Possível resposta</summary>

  Um seletor escolhe quais elementos do HTML receberão as declarações de uma regra
  CSS.
</details>

**4. Por que uma regra pode vencer outra?**

<details>
  <summary>Possível resposta</summary>

  Porque a cascata considera fatores como origem, importância, especificidade,
  ordem de leitura e herança. De forma prática, ID costuma vencer classe, classe
  costuma vencer elemento, e regras equivalentes obedecem à última declaração.
</details>

**5. Para que servem variáveis CSS?**

<details>
  <summary>Possível resposta</summary>

  Elas guardam valores reutilizáveis, como cores e espaçamentos, e permitem manter a
  página consistente com menos repetição.
</details>

**6. Para que servem as *media queries*?**

<details>
  <summary>Possível resposta</summary>

  Elas permitem aplicar regras CSS apenas quando o ambiente do dispositivo atende a
  determinadas condições, como largura de tela, orientação ou preferência do usuário
  (ex.: modo escuro ou impressão).
</details>
