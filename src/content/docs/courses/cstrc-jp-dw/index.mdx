A disciplina de [Desenvolvimento para Web](../../dw/docs/plano-de-ensino.pdf) (DW)
faz parte do Curso Superior de Tecnologia em Redes de Computadores do IFPB. Ela
possui carga horária de 120 horas-aula e será ministrada pelo professor Luiz Carlos
Chaves.

O foco da disciplina é construir uma base prática para o desenvolvimento de sistemas
Web. Ao longo do semestre, estudamos a Web como plataforma, a estrutura de páginas
com HTML, a apresentação visual com CSS, a programação no navegador com JavaScript
e a construção de servidores HTTP com Node.js e Express.

A trilha principal evolui um projeto em etapas. Começamos com páginas e interações
simples, avançamos para consumo de APIs e, depois, construímos uma **API REST** com
organização em MVC e persistência em banco de dados.

As aulas combinam exposição, leitura de código, exercícios e atividades práticas.
As avaliações podem envolver entregas individuais e em grupo, com ênfase na
capacidade de implementar, explicar e evoluir uma aplicação Web.

Como pré-requisito, espera-se conhecimento prévio de Algoritmos e Programação de
Script.

## Como a disciplina está organizada

<Steps>

1. **Fundamentos da Web** — [Importância da Web](html/web-importance/), origem,
   arquitetura e papel da Web como plataforma aberta.

2. **Estrutura do conteúdo** — [HTML](html/), a marcação que descreve a página.

3. **Apresentação visual** — [CSS](css/), para definir cores, fontes, espaçamento e
   layout.

4. **Fundamentos da linguagem** — [JavaScript](javascript/ecmascript/), para nivelar
   a sintaxe moderna usada na disciplina.

5. **Ambiente de execução** — [Node.js](node/), para rodar JavaScript no servidor e
   instalar dependências.

6. **Servidor HTTP** — [Express.js](express/), do primeiro servidor até uma API
   organizada em MVC.

7. **Persistência** — [Banco de Dados](database/sql/), com SQL e Prisma ORM.

8. **Projeto final** — [Especificação do Projeto](project/), atividade obrigatória da
   disciplina.

</Steps>

<Aside type="note" title="Código das aulas">
  O código produzido durante as aulas será publicado no repositório da turma:
  [luizchaves/dw-2026-2](https://github.com/luizchaves/dw-2026-2). Use esse

</Aside>

## Avaliações

A nota final será calculada a partir de 3 avaliações principais ao longo do semestre. As **Avaliações I, II e III serão pontuadas em parte pela realização dos Quizzes** aplicados na plataforma BrainCheck, combinadas com as entregas de exercícios práticos e etapas do projeto.

Para mais detalhes sobre cada modalidade de avaliação, acesse as páginas dedicadas:

- 📋 [**Especificação do Projeto**](project/): diretrizes e critérios da proposta, entrega de Front-end e aplicação Full-stack;
- 📝 [**Exercícios Práticos**](extra/exercises/): listas de problemas individuais práticos coletados do [ifpb/exercises](https://ifpb.github.io/exercises/);
- 🧠 [**Quizzes no BrainCheck**](extra/quizzes/): questionários objetivos continuados para avaliação e fixação teórica dos conteúdos.

A composição de cada uma das 3 avaliações ao longo do curso é estruturada da seguinte forma:

<Steps>

1. **Avaliação I — Exercícios**

   Pontuada com base na resolução das listas de [Exercícios Práticos](extra/exercises/) (Exercícios 1.1, 1.2 e 1.3) desenvolvidas individualmente e pelos [Quizzes](extra/quizzes/) correspondentes na plataforma BrainCheck.

2. **Avaliação II — Projeto: Etapa I (Front-end com API Simulada)**

   Pontuada pela entrega da etapa de Front-end do [projeto da disciplina](project/) (interface dinâmica consumindo `json-server`) e pelos [Quizzes](extra/quizzes/) da unidade.

3. **Avaliação III — Projeto: Etapa II (Back-end & Aplicação Full-stack)**

   Pontuada pela entrega final da aplicação Full-stack do [projeto da disciplina](project/) (Express.js, Banco de Dados, JWT) e pelos [Quizzes](extra/quizzes/) da etapa final.

</Steps>

## Ferramentas

Estas ferramentas serão usadas com frequência durante a disciplina. Outras opções
podem funcionar, mas os exemplos e orientações em aula partem deste conjunto.

| Categoria | Ferramenta | Uso principal |
| --------- | ---------- | ------------- |
| Ambiente de execução | [Node.js](https://nodejs.org/en/) | Executar JavaScript no servidor e instalar dependências |
| Editor | [Visual Studio Code](http://code.visualstudio.com) | Escrever, organizar e testar o código dos projetos |
| Design e prototipação | [Figma](https://www.figma.com/) | Planejar telas, fluxos e referências visuais |
| Navegador | [Chrome](https://www.google.com/chrome/browser/index.html) | Testar páginas, usar DevTools e depurar comportamento |
| Versionamento | [Git](https://git-scm.com/) | Controlar histórico, publicar código e acompanhar entregas |

<Aside type="tip" title="Todo código é executável">
  Os exemplos das aulas vivem em projetos reais dentro de `examples/` no repositório
  e são importados pela documentação. Você pode clonar, instalar e rodar qualquer um
  deles.
</Aside>
