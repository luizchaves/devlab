introduz poucos conceitos novos e evolui o mesmo projeto, até chegarmos a uma
aplicação organizada em MVC e persistindo dados em banco.

## Como a disciplina está organizada

<Steps>

1. **Estrutura do conteúdo** — [HTML](html/), a marcação que descreve a página.

2. **Apresentação visual** — [CSS](css/), para definir cores, fontes, espaçamento e layout.

3. **Fundamentos da linguagem** — [JavaScript](javascript/), para nivelar a sintaxe
   moderna que usaremos o tempo todo.

4. **Ambiente de execução** — [Node.js](node/), para rodar JavaScript no servidor e
   instalar dependências.

5. **Servidor HTTP** — [Express.js](express/), do primeiro `Hello World` até uma API
   organizada em MVC.

6. **Persistência** — [Banco de Dados](database/sql/), com SQL e Prisma ORM.

7. **Projetos** — [quatro projetos](projects/) incrementais que consolidam tudo.

</Steps>

## Pré-requisitos

- Lógica de programação e estruturas de dados básicas.
- [Node.js](https://nodejs.org) 22 ou superior instalado.
- Um editor de código (recomendamos o VS Code) e um cliente HTTP como
  [Bruno](https://www.usebruno.com), Insomnia ou a extensão REST Client.

<Aside type="tip" title="Todo código é executável">
  Os exemplos das aulas não são trechos soltos: eles vivem em projetos reais dentro
  de `examples/` no repositório e são importados pela documentação. Você pode clonar,
  instalar e rodar qualquer um deles.
</Aside>
