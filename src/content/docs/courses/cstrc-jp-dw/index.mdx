Nesta disciplina construímos, do zero, uma **API REST** em Node.js. Cada aula
introduz poucos conceitos novos e evolui o mesmo projeto, até chegarmos a uma
aplicação organizada em MVC e persistindo dados em banco.

## O que você vai aprender

<CardGrid>
  <Card title="JavaScript moderno" icon="seti:javascript">
    Modules ESM, funções assíncronas e consumo de APIs com Fetch.
  </Card>

  <Card title="Node.js" icon="node">
    O runtime, o ecossistema npm e a organização de um projeto em módulos.
  </Card>

  <Card title="Express.js" icon="rocket">
    Rotas, middlewares, controllers e a arquitetura MVC.
  </Card>

  <Card title="Banco de dados" icon="seti:db">
    SQL, modelagem com Prisma e operações de CRUD.
  </Card>
</CardGrid>

## Como a disciplina está organizada

<Steps>

1. **Fundamentos da linguagem** — [JavaScript](javascript/), para nivelar a sintaxe
   moderna que usaremos o tempo todo.

2. **Ambiente de execução** — [Node.js](node/), para rodar JavaScript no servidor e
   instalar dependências.

3. **Servidor HTTP** — [Express.js](express/), do primeiro `Hello World` até uma API
   organizada em MVC.

4. **Persistência** — [Banco de Dados](database/sql/), com SQL e Prisma ORM.

5. **Projetos** — [quatro projetos](projects/) incrementais que consolidam tudo.

</Steps>

## Pré-requisitos

- Lógica de programação e estruturas de dados básicas.
- [Node.js](https://nodejs.org) 22 ou superior instalado.
- Um editor de código (recomendamos o VS Code) e um cliente HTTP como
  [Bruno](https://www.usebruno.com), Insomnia ou a extensão REST Client.

<Aside type="tip" title="Todo código é executável">
  Os exemplos das aulas não são trechos soltos: eles vivem em projetos reais dentro
  de `examples/` no repositório e são importados pela documentação. Você pode clonar,
  instalar e rodar qualquer um deles.
</Aside>
