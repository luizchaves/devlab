As atividades de exercícios práticos somam a pontuação das avaliações da disciplina. Os problemas listados abaixo foram selecionados e coletados do repositório oficial de exercícios do IFPB ([ifpb/exercises](https://ifpb.github.io/exercises/)).

<Aside type="note" title="Acervo do ifpb/exercises para Prática">
  Além dos problemas selecionados nesta página para avaliação, o portal [ifpb/exercises](https://ifpb.github.io/exercises/) conta com **diversas outras opções de exercícios práticos** abrangendo HTML, CSS, JavaScript (funções, objetos, arrays), DOM API e serviços Back-end. Recomenda-se explorar o acervo para praticar e aprofundar os conteúdos da disciplina.
</Aside>

<Aside type="caution" title="Atividades Estritamente Individuais">
  Todos os exercícios listados nesta página devem ser **desenvolvidos e submetidos individualmente por cada estudante**. Cada solução deve ser mantida em repositório pessoal próprio no GitHub.
</Aside>

---

## Exercício 1.1 — Introdução ao JavaScript (30 pontos)

Faça os seguintes exercícios de introdução à sintaxe e funções em JavaScript:

- [function-sum](https://ifpb.github.io/exercises/problems/function-sum/)
- [function-calc](https://ifpb.github.io/exercises/problems/function-calc/)
- [function-triangle-checker](https://ifpb.github.io/exercises/problems/function-triangle-checker/)

<Aside type="tip" title="Instruções de Submissão">
  Para submeter os exercícios, utilize o **GitHub** para armazenar o código em seu repositório e gerar a URL do seu código.
</Aside>
