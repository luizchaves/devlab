## Desenvolvimento Web

O curso está organizado para construir repertório de forma progressiva. Primeiro
vem a estrutura da página, depois a linguagem usada no navegador e no servidor,
então o projeto evolui para rotas HTTP, MVC, persistência e APIs.

  </Card>

  <Card title="Banco de dados" icon="database">

  </Card>
