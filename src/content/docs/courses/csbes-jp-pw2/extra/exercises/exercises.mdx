As atividades de exercícios práticos somam a pontuação das avaliações da disciplina. Os problemas listados abaixo foram selecionados e coletados do repositório oficial de exercícios do IFPB ([ifpb/exercises](https://ifpb.github.io/exercises/)).

<Aside type="note" title="Acervo do ifpb/exercises para Prática">
  Além dos problemas selecionados nesta página para avaliação, o portal [ifpb/exercises](https://ifpb.github.io/exercises/) conta com **diversas outras opções de exercícios práticos** abrangendo JavaScript (funções, arrays, strings, objetos) e DOM API. Consulte o [acervo complementar](#acervo-complementar-para-prática) no final desta página para praticar e aprofundar os conteúdos da disciplina.
</Aside>

<Aside type="caution" title="Atividades Estritamente Individuais">
  Todos os exercícios listados nesta página devem ser **desenvolvidos e submetidos individualmente por cada estudante**. Cada solução deve ser mantida em repositório pessoal próprio no GitHub.
</Aside>

---

## Exercício 1.1 — Programação Funcional e Objetos (30 pontos)

Resolva os seguintes exercícios de manipulação de arrays com programação funcional e de estruturação de dados com objetos:

- [array-operations](https://ifpb.github.io/exercises/problems/array-operations/) — uso de programação funcional
- [object-exam](https://ifpb.github.io/exercises/problems/object-exam/) — uso de objetos

<Aside type="tip" title="Instruções de Submissão">
  Para entregar as respostas, envie o código em algum repositório do **GitHub** e gere a URL do seu código.
</Aside>

---

## Exercício 1.2 — Conteúdo Dinâmico (30 pontos)

Faça o seguinte exercício de manipulação do DOM e criação dinâmica de elementos:

- [web-script-country-flags](https://ifpb.github.io/exercises/problems/web-script-country-flags/)

<Aside type="tip" title="Instruções de Submissão">
  Para submeter os exercícios, utilize o **GitHub Pages** para gerar a URL pública de execução do seu código.
</Aside>

## Exercício 1.3 — Requisição Assíncrona (40 pontos)
