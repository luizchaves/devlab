## Criação de Objetos e Notação Literal

Em JavaScript, um **Objeto** é uma coleção dinâmica de propriedades, onde cada propriedade é uma associação entre uma **chave** (*key* ou nome) e um **valor** (*value*). O valor de uma propriedade pode ser de qualquer tipo: primitivos, arrays, outros objetos ou funções (que recebem o nome de **métodos**).

| Elemento | Descrição | Exemplo |
| -------- | --------- | ------- |
| **Notação Literal** | Forma mais comum e legível de criar objetos com `{}` | `const user = { name: "Ana" };` |
| **Chave (Key)** | Identificador da propriedade (string ou Symbol) | `name`, `age`, `"end-point"` |
| **Valor (Value)** | Qualquer dado associado à chave | `"Ana"`, `28`, `true`, `[1, 2]` |
| **Método** | Uma função armazenada como valor de uma propriedade | `sayHello() { return "Olá!"; }` |
| **Tipo de Dado** | Tipo de dado não primitivo em JavaScript | `typeof {}` // `"object"` |

```js title="Formas de criação de objetos"
// 1. Literal de Objeto (Recomendado)
const student = {
  id: 2026101,
  name: "Fulano de Tal",
  email: "fulano@ifpb.edu.br",
  active: true,
  courses: ["DW", "Redes"],
  // Método do objeto (sintaxe abreviada do ES6)
  getSummary() {
    return `${this.name} (${this.email})`;
  },
};

// 2. Construtor new Object() (Evitar)
const server = new Object();
server.ip = "192.168.0.1";
server.port = 8080;

console.log(student.name);        // "Fulano de Tal"
console.log(student.getSummary());// "Fulano de Tal (fulano@ifpb.edu.br)"
console.log(server.ip);           // "192.168.0.1"
```

### Property Shorthand (Sintaxe Abreviada de Propriedades)

Quando o nome da variável local é idêntico ao nome da chave do objeto que se deseja criar, o JavaScript permite omitir a repetição do nome.

```js title="Uso de Property Shorthand"
const name = "Alice";
const email = "alice@gmail.com";
const role = "admin";

// Forma tradicional (verbosa)
const userOld = { name: name, email: email, role: role };

// Forma moderna com Property Shorthand
const user = { name, email, role };

console.log(user); // { name: 'Alice', email: 'alice@gmail.com', role: 'admin' }
```

<Aside type="tip" title="Notação de Propriedades Abreviada">
  A sintaxe abreviada `{ name, email }` é amplamente utilizada em código moderno para construir objetos de forma limpa a partir de variáveis locais existentes.
</Aside>

Referência: [Working with objects | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Working_with_objects).

## Acesso, Modificação e Remoção de Propriedades

O acesso às propriedades de um objeto pode ser feito por **Notação de Ponto** (`obj.prop`) ou por **Notação de Colchetes** (`obj["prop"]`).

### Notação de Ponto vs Notação de Colchetes

```js title="Acessando e alterando propriedades"
const host = {
  hostname: "web-server-01",
  ip: "192.168.1.10",
  "content-type": "application/json", // Chave com hífen precisa de aspas!
  200: "OK",                         // Chave numérica
};

// 1. Notação de Ponto (mais comum)
console.log(host.hostname); // "web-server-01"
console.log(host.ip);       // "192.168.1.10"

// 2. Notação de Colchetes (obrigatória para chaves com hífens, espaços ou números)
console.log(host["content-type"]); // "application/json"
console.log(host[200]);            // "OK"

// 3. Notação de Colchetes com Chaves Dinâmicas (variáveis)
const targetKey = "ip";
console.log(host[targetKey]); // "192.168.1.10" (equivale a host.ip)
```

### Adição, Alteração e Remoção

Objetos em JavaScript são mutáveis por padrão. Propriedades podem ser atribuídas ou removidas a qualquer momento.

```js title="Alterando a estrutura de um objeto"
const config = {
  theme: "dark",
  timeout: 5000,
};

// Adicionando nova propriedade
config.retries = 3;

// Alterando valor de propriedade existente
config.timeout = 10000;

console.log(config); // { theme: 'dark', timeout: 10000, retries: 3 }

// Removendo propriedade com o operador delete
delete config.retries;
console.log(config); // { theme: 'dark', timeout: 10000 }
console.log(config.retries); // undefined
```

### Verificação de Existência de Propriedades

Para testar se uma chave existe em um objeto, podemos usar o operador `in` ou a função estática `Object.hasOwn()`.

```js title="Verificando se uma chave existe"
const user = { name: "Bruno", age: 25 };

console.log("name" in user);        // true
console.log("email" in user);       // false

console.log(Object.hasOwn(user, "name"));  // true
console.log(Object.hasOwn(user, "email")); // false
```

### Encadear Opcional (Optional Chaining: `?.`)

Ao acessar propriedades encadeadas em objetos aninhados, tentar ler um atributo de um valor `null` ou `undefined` causa um erro de execução (`TypeError`). O operador de **Encadear Opcional** (`?.`) permite acessar propriedades com segurança: caso o alvo seja `null` ou `undefined`, a expressão interrompe a avaliação (*short-circuiting*) e retorna `undefined` sem lançar exceções.

```js title="Acesso seguro com Optional Chaining"
const user = {
  id: 1,
  name: "Carlos",
  profile: {
    address: {
      city: "João Pessoa"
    }
  }
};

// ❌ Sem Optional Chaining: se 'settings' for undefined, aceso gera TypeError
// const theme = user.settings.theme; // TypeError: Cannot read properties of undefined

// ✅ Com Optional Chaining (?.): retorna undefined de forma segura
const city = user?.profile?.address?.city;   // "João Pessoa"
const zipCode = user?.profile?.address?.zip;  // undefined (propriedade não existe)
const theme = user?.settings?.theme;          // undefined (objeto 'settings' não existe)

// 💡 Combinando com Coalescência Nula (??) para definir valor padrão
const userCity = user?.profile?.address?.city ?? "Cidade não cadastrada";
const userTheme = user?.settings?.theme ?? "light";
```

<Aside type="caution" title="Variáveis const e Mutabilidade de Objetos">
  Declarar um objeto com `const` impede que a variável seja reassociada a um novo objeto na memória. No entanto, as **propriedades internas** do objeto continuam mutáveis — elas podem ser alteradas, adicionadas ou deletadas normalmente.
  
  ```js
  const server = { port: 8080 };
  server.port = 9090; // PERMITIDO (altera propriedade interna)
  
  // server = { port: 3000 }; // ERRO: TypeError (Assignment to constant variable)
  ```
</Aside>

## Desestruturação de Objetos (Destructuring)

A desestruturação de objetos permite extrair propriedades de um objeto e atribuí-las diretamente a variáveis locais com uma sintaxe concisa.

```js title="Desestruturação básica de Objetos"
const person = {
  firstName: "Maria",
  lastName: "Silva",
  age: 30,
  city: "João Pessoa",
};

// Extraindo propriedades com os mesmos nomes das chaves
const { firstName, age } = person;
console.log(firstName); // "Maria"
console.log(age);       // 30

// Extraindo com renomeação de variáveis (chave: novoNome)
const { city: location } = person;
console.log(location); // "João Pessoa"

// Extraindo com valor padrão caso a propriedade não exista
const { role = "visitante" } = person;
console.log(role); // "visitante"
```

### Desestruturação em Parâmetros de Funções

A desestruturação é extremamente útil em parâmetros de funções, permitindo receber objetos de opção com clareza.

```js title="Desestruturação no parâmetro da função"
function displayServerInfo({ hostname, ip, port = 80 }) {
  console.log(`Servidor ${hostname} rodando em http://${ip}:${port}`);
}

const webServer = {
  hostname: "api-server",
  ip: "10.0.0.15",
  port: 3000,
};

displayServerInfo(webServer); // "Servidor api-server rodando em http://10.0.0.15:3000"
```

Referência: [Destructuring assignment | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment).

## Operador Spread e Imutabilidade em Objetos

O operador de espalhamento (`...`) permite copiar e mesclar propriedades de objetos de forma rasa (*shallow copy*).

```js title="Operador Spread em Objetos"
const baseConfig = {
  env: "development",
  debug: true,
  port: 3000,
};

// Criando uma cópia e sobrescrevendo a propriedade 'env' e 'port'
const prodConfig = {
  ...baseConfig,
  env: "production",
  port: 8080,
};

console.log(baseConfig); // { env: 'development', debug: true, port: 3000 }
console.log(prodConfig); // { env: 'production', debug: true, port: 8080 }
```

### Congelando Objetos com Object.freeze()

Se você precisa impedir que um objeto tenha suas propriedades alteradas, adicionadas ou deletadas, pode utilizar `Object.freeze()`.

```js title="Imutabilidade com Object.freeze()"
const immutableConfig = Object.freeze({
  apiUrl: "https://api.devlab.org",
  version: "v1",
});

// Tentativa de alteração é ignorada em modo padrão (ou lança erro em strict mode)
immutableConfig.version = "v2";
immutableConfig.timeout = 5000;

console.log(immutableConfig); // { apiUrl: 'https://api.devlab.org', version: 'v1' }
```

## Iteração sobre Objetos

Diferente de arrays, objetos comuns não são diretamente iteráveis com `for...of`. JavaScript oferece o laço `for...in` e métodos estáticos auxiliares no objeto `Object` para inspecionar chaves e valores.

| Método / Estrutura | Retorno | Descrição |
| ------------------ | ------- | --------- |
| `for...in` | Chaves (`string`) | Laço que percorre as chaves enumeráveis do objeto |
| `Object.keys(obj)` | `Array<string>` | Retorna um array com os nomes das chaves do objeto |
| `Object.values(obj)` | `Array<any>` | Retorna um array com os valores de todas as propriedades |
| `Object.entries(obj)` | `Array<[string, any]>` | Retorna um array de pares `[chave, valor]` |

```js title="Iterando sobre objetos com Object.keys, values e entries"
const scores = {
  Alice: 95,
  Bruno: 80,
  Carla: 90,
};

// 1. Object.keys() - Obtendo lista de chaves
const names = Object.keys(scores);
console.log(names); // [ 'Alice', 'Bruno', 'Carla' ]

// 2. Object.values() - Obtendo lista de valores
const points = Object.values(scores);
console.log(points); // [ 95, 80, 90 ]

// 3. Object.entries() - Obtendo pares [chave, valor]
const entries = Object.entries(scores);
console.log(entries);
// [ [ 'Alice', 95 ], [ 'Bruno', 80 ], [ 'Carla', 90 ] ]

// Iterando com for...of sobre Object.entries() usando desestruturação
for (const [student, score] of Object.entries(scores)) {
  console.log(`Estudante: ${student} | Nota: ${score}`);
}
```

Referência: [Object.entries() | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/entries).

## O Formato e Objeto JSON

**JSON** (*JavaScript Object Notation*) é um formato leve e estritamente textual para troca de dados entre sistemas (por exemplo, no envio e recebimento de dados em APIs REST).

Apesar de derivar da sintaxe de objetos do JavaScript, o formato JSON possui **regras estritas**:

| Característica | Objeto JavaScript | Formato JSON |
| -------------- | ----------------- | ------------ |
| **Nomes de Chaves** | Podem ser sem aspas (`name: "Ana"`) | **Devem** estar entre aspas duplas (`"name": "Ana"`) |
| **Strings** | Aspas simples, duplas ou crases | **Devem** usar apenas aspas duplas (`"..."`) |
| **Tipos de Dados Aceitos** | Primitivos, arrays, objetos e **funções** | Apenas primitivos (número, string, boolean, null), arrays e objetos |
| **Vírgula Final (Trailing Comma)** | Permitida (`{ a: 1, }`) | **Proibida** (`{ "a": 1 }`) |

```json title="Exemplo de arquivo ou payload JSON válido"
{
  "id": 101,
  "name": "Servidor Principal",
  "active": true,
  "tags": ["web", "production"],
  "specs": {
    "cpu": 4,
    "ram": "16GB"
  }
}
```

### O Objeto Global JSON (stringify e parse)

Em JavaScript, o objeto global `JSON` oferece dois métodos essenciais para conversão:

- `JSON.stringify(obj)`: Converte um objeto/valor JavaScript em uma **string no formato JSON**.
- `JSON.parse(jsonString)`: Converte uma **string JSON** em um **objeto/valor JavaScript**.

```js title="Uso de JSON.stringify() e JSON.parse()"
const userObject = {
  id: 1,
  name: "Carlos",
  email: "carlos@gmail.com",
};

// 1. Serialização (Objeto JS -> String JSON)
const jsonString = JSON.stringify(userObject);
console.log(typeof jsonString); // "string"
console.log(jsonString);        // '{"id":1,"name":"Carlos","email":"carlos@gmail.com"}'

// 2. Deserialização (String JSON -> Objeto JS)
const parsedObject = JSON.parse(jsonString);
console.log(typeof parsedObject); // "object"
console.log(parsedObject.name);   // "Carlos"
```

<Aside type="caution" title="O que acontece com funções e undefined no JSON.stringify()?">
  Propriedades cujo valor seja `undefined`, uma `function` ou um `Symbol` são **omitidas** durante a execução do `JSON.stringify()` em um objeto.
</Aside>

Referência: [JSON | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON).

  console.log(jsonOutput);

## Perguntas de revisão

### Criação e Acesso

**1. Qual é a diferença entre Notação de Ponto (`obj.prop`) e Notação de Colchetes (`obj["prop"]`)?**

<details>
  <summary>Possível resposta</summary>

  A notação de ponto é mais simples e legível, mas exige que a chave seja um identificador válido sem espaços ou hifens. A notação de colchetes permite usar chaves arbitrárias (com hífens, espaços ou números) e utilizar variáveis dinâmicas para acessar o nome da propriedade (`obj[variable]`).
</details>

**2. O que acontece ao tentar acessar uma propriedade que não existe em um objeto?**

<details>
  <summary>Possível resposta</summary>

  O JavaScript retorna o valor `undefined` (não lança erro, a menos que você tente acessar uma propriedade encadeada a partir desse `undefined`).
</details>

**3. O que é Property Shorthand e quando podemos utilizá-lo?**

<details>
  <summary>Possível resposta</summary>

  É a sintaxe abreviada do ES6 que permite criar propriedades de objetos omitindo o valor quando o nome da chave é idêntico ao nome da variável local (ex: `{ name, age }` em vez de `{ name: name, age: age }`).
</details>

### Desestruturação e Imutabilidade

**4. Como funciona a atribuição por desestruturação em objetos e como renomear uma variável durante a extração?**

<details>
  <summary>Possível resposta</summary>

  A desestruturação extrai valores de chaves de um objeto para variáveis com o mesmo nome (`const { name } = user`). Para renomear a variável extraída, utiliza-se a sintaxe `chave: novoNome` (ex: `const { name: fullName } = user`).
</details>

**5. Declarar um objeto com `const` impede a alteração de suas propriedades internas?**

<details>
  <summary>Possível resposta</summary>

  Não. A palavra-chave `const` impede apenas a reassociação da variável a outro objeto na memória. As propriedades internas do objeto continuam podendo ser alteradas, adicionadas ou excluídas. Para tornar o objeto imutável, deve-se usar `Object.freeze()`.
</details>

**6. Como o operador Spread (`...`) auxilia na atualização imutável de um objeto?**

<details>
  <summary>Possível resposta</summary>

  O operador spread permite copiar todas as propriedades de um objeto existente para um novo objeto `{ ...oldObj, newProp: value }`, permitindo adicionar ou sobrescrever propriedades sem modificar o objeto original.
</details>

### Métodos do Object e JSON

**7. Quais são as diferenças entre os métodos `Object.keys()`, `Object.values()` e `Object.entries()`?**

<details>
  <summary>Possível resposta</summary>

  `Object.keys()` retorna um array com os nomes das chaves. `Object.values()` retorna um array com os valores das propriedades. `Object.entries()` retorna um array de pares `[chave, valor]`.
</details>

**8. Quais são as principais diferenças entre um Objeto JavaScript e uma string no formato JSON?**

<details>
  <summary>Possível resposta</summary>

  No formato JSON, todas as chaves DEVEM estar obrigatoriamente entre aspas duplas, strings devem usar aspas duplas, vírgulas no último elemento (*trailing commas*) são proibidas e métodos/funções ou `undefined` não são permitidos.
</details>

**9. Para que servem os métodos `JSON.stringify()` e `JSON.parse()`?**

<details>
  <summary>Possível resposta</summary>

  `JSON.stringify(obj)` converte um objeto JavaScript em uma string codificada em JSON (serialização). `JSON.parse(jsonString)` converte uma string formatada em JSON de volta para um objeto JavaScript (deserialização).
</details>

**10. O que acontece com propriedades de valor `undefined` ou funções ao executar `JSON.stringify()`?**

<details>
  <summary>Possível resposta</summary>

  Propriedades cujo valor seja uma função, `undefined` ou `Symbol` são omitidas da string JSON resultante.
</details>
