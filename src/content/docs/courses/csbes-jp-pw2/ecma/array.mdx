## Criação e Estrutura de Arrays

Em JavaScript, um **Array** é uma lista ordenada de valores. Ao contrário de linguagens estaticamente tipadas, os arrays em JavaScript são **dinâmicos** (seu tamanho pode mudar automaticamente) e **heterogêneos** (podem armazenar valores de diferentes tipos na mesma estrutura).

| Característica | Descrição | Exemplo |
| -------------- | --------- | ------- |
| **Notação Literal** | Forma mais comum e recomendada de criar arrays | `const items = [1, 2, 3];` |
| **Indexação** | Elementos são acessados por índices inteiros a partir de 0 | `items[0]` // `1` |
| **Heterogeneidade** | Pode armazenar primitivos, objetos e até outros arrays | `[42, "texto", true, { id: 1 }]` |
| **Tipo de Dado** | Internamente é um objeto especial | `typeof []` // `"object"` |
| **Verificação** | Teste oficial para checar se um valor é array | `Array.isArray([])` // `true` |

```js title="Formas de criação de Arrays"
// 1. Literal de Array (forma recomendada)
const numbers = [10, 20, 30, 40];
const empty = [];

// 2. Arrays com múltiplos tipos de dados
const mixed = [42, "JavaScript", true, null, { role: "admin" }, [1, 2]];

// 3. Construtor Array
const items = new Array(10, 20, 30); // [10, 20, 30]
const fixedLength = new Array(5);    // Cria um array com 5 posições vazias (<5 empty items>)

// 4. Array.from() - Cria array a partir de iteráveis ou coleções
const digits = Array.from("12345"); // ["1", "2", "3", "4", "5"]

console.log(numbers); // [ 10, 20, 30, 40 ]
console.log(mixed[1]); // "JavaScript"
console.log(mixed[5][0]); // 1 (acessando elemento do array aninhado)
```

<Aside type="tip" title="Verificando se um valor é Array">
  Como `typeof []` retorna `"object"`, a maneira correta e segura de verificar se um valor é um array em JavaScript é utilizando a função estática `Array.isArray(valor)`.
</Aside>

```js title="Testando o tipo de Array"
console.log(typeof [1, 2, 3]);        // "object"
console.log(Array.isArray([1, 2, 3])); // true
console.log(Array.isArray({}));        // false
```

Referência: [Array | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array).

## Acesso, Modificação e Propriedade length

Os elementos de um array são acessados e modificados usando colchetes e índices numéricos inteiros. O primeiro elemento fica no índice `0` e o último no índice `array.length - 1`.

### Notação de Colchetes e .at()

```js title="Acessando e alterando elementos"
const colors = ["vermelho", "verde", "azul"];

// Leitura por índice
console.log(colors[0]); // "vermelho"
console.log(colors[2]); // "azul"
console.log(colors[3]); // undefined (índice inexistente)

// Novo método .at() (aceita índices negativos a partir do final)
console.log(colors.at(0));  // "vermelho"
console.log(colors.at(-1)); // "azul" (último elemento)
console.log(colors.at(-2)); // "verde" (penúltimo elemento)

// Alterando valor existente
colors[1] = "amarelo";
console.log(colors); // [ "vermelho", "amarelo", "azul" ]

// Adicionando novo elemento em índice futuro
colors[3] = "roxo";
console.log(colors); // [ "vermelho", "amarelo", "azul", "roxo" ]
```

### A Propriedade length e Arrays Esparsos

A propriedade `length` indica o número de posições do array. Em JavaScript, a propriedade `length` é **mutável** — alterar seu valor diretamente pode truncar o array ou criar posições vazias (*empty slots*).

```js title="Comportamento da propriedade length"
const fruits = ["maçã", "banana", "laranja"];
console.log(fruits.length); // 3

// Atribuindo valor a um índice distante cria posições vazias (array esparso)
fruits[5] = "uva";
console.log(fruits);        // [ 'maçã', 'banana', 'laranja', <2 empty items>, 'uva' ]
console.log(fruits.length); // 6
console.log(fruits[3]);     // undefined

// Reduzindo o length diretamente altera/trunca o array!
fruits.length = 2;
console.log(fruits); // [ 'maçã', 'banana' ] (elementos excedentes foram descartados)
```

### O Operador delete

O operador `delete` pode ser usado em arrays, mas deve ser evitado na maioria dos cenários.

```js title="Uso do operador delete"
const numbers = [10, 20, 30, 40];
delete numbers[2];

console.log(numbers);        // [ 10, 20, <1 empty item>, 40 ]
console.log(numbers.length); // 4 (o tamanho NÃO diminuiu)
console.log(numbers[2]);     // undefined
```

<Aside type="caution" title="Evite usar delete em Arrays">
  O operador `delete` remove o valor mas mantém a chave/posição como um slot vazio (*empty*), criando um array esparso sem alterar a propriedade `length`. Para remover elementos reajustando o tamanho do array, utilize métodos como `.splice()`, `.pop()`, `.shift()` ou `.filter()`.
</Aside>

## Operador Spread e Desestruturação (Destructuring)

Com os recursos modernos do ES6+, trabalhar com arrays tornou-se mais expressivo através da sintaxe de espalhamento (*spread operator*) e da atribuição por desestruturação (*destructuring assignment*).

### Operador Spread (`...`)

O operador `...` permite espalhar os elementos de um array dentro de outro array ou como argumentos de uma função, facilitando cópias superficiais (*shallow copies*) e concatenações.

```js title="Operador Spread em Arrays"
const original = [1, 2, 3];

// Cópia superficial (novo array na memória)
const copy = [...original];
copy.push(4);
console.log(original); // [ 1, 2, 3 ] (permanece inalterado)
console.log(copy);     // [ 1, 2, 3, 4 ]

// Concatenação de múltiplos arrays
const front = ["HTML", "CSS"];
const back = ["Node.js", "SQL"];
const fullstack = [...front, "JavaScript", ...back];

console.log(fullstack); // [ 'HTML', 'CSS', 'JavaScript', 'Node.js', 'SQL' ]
```

### Desestruturação de Arrays

A desestruturação permite extrair valores de um array diretamente para variáveis de forma posicional.

```js title="Desestruturação de Arrays"
const coords = [10, 20, 30];

// Extraindo posições por ordem
const [x, y] = coords;
console.log(x); // 10
console.log(y); // 20

// Pulando posições e definindo valor padrão
const [first, , third, fourth = 0] = [100, 200, 300];
console.log(first);  // 100
console.log(third);  // 300
console.log(fourth); // 0 (assumiu valor padrão por falta de elemento)

// Coletando o restante com o operador Rest (...)
const [leader, vice, ...others] = ["Ana", "Bruno", "Carlos", "Daniela", "Eduardo"];
console.log(leader); // "Ana"
console.log(vice);   // "Bruno"
console.log(others); // [ 'Carlos', 'Daniela', 'Eduardo' ]
```

Referência: [Destructuring assignment | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment).

## Iteração em Arrays

Iterar sobre os elementos de um array é uma das operações mais frequentes em programação Web. JavaScript oferece diversas formas de percorrer arrays.

| Estrutura | Sintaxe | Uso Principal |
| --------- | ------- | ------------- |
| `for` tradicional | `for (let i = 0; i < arr.length; i++)` | Controle total sobre índices e passos |
| `for...of` | `for (const item of arr)` | Percorrer valores de forma simples e legível |
| `forEach()` | `arr.forEach((item, index) => ...)` | Executar uma função para cada elemento |

```js title="Diferentes formas de iterar um array"
const languages = ["JavaScript", "Python", "Java", "C#"];

// 1. Laço for tradicional
console.log("--- Laço for ---");
for (let i = 0; i < languages.length; i++) {
  console.log(`Índice ${i}: ${languages[i]}`);
}

// 2. Laço for...of (Recomendado para iterar valores)
console.log("--- Laço for...of ---");
for (const lang of languages) {
  console.log(lang);
}

// 3. Método .forEach()
console.log("--- Método forEach ---");
languages.forEach((lang, index) => {
  console.log(`${index + 1}. ${lang}`);
});
```

<Aside type="caution" title="Evite usar for...in para iterar sobre Arrays">
  O laço `for...in` foi projetado para iterar sobre as **chaves de propriedades enumeráveis** de um objeto. Ao usar `for...in` em um array:
  - Os índices são convertidos para `string` (ex: `"0"`, `"1"`).
  - A ordem de iteração não é garantidamente numérico-sequencial.
  - Propriedades adicionais ou herdadas do protótipo também serão percorridas.
  
  Para arrays, utilize sempre `for...of`, `for` tradicional ou métodos como `.forEach()`.
</Aside>

## Métodos do Objeto Array

O protótipo `Array.prototype` possui dezenas de métodos utilitários. Para facilitar a compreensão, estes métodos são classificados em três categorias principais:

1. **Mutadores**: Alteram o array original (*in-place*).
2. **Acessores / Consulta**: Não alteram o array original e retornam um novo valor ou array.
3. **Iteradores / Funcionais (Higher-Order Functions)**: Recebem uma função de *callback* para processar os elementos.

### 1. Métodos Mutadores (Modificam o Array Original)

Estes métodos alteram diretamente o array sobre o qual foram chamados.

| Método | Ação | Retorno |
| ------ | ---- | ------- |
| `push(...items)` | Adiciona um ou mais elementos ao **final** | Novo `length` |
| `pop()` | Remove e retorna o **último** elemento | O elemento removido |
| `unshift(...items)` | Adiciona um ou mais elementos no **início** | Novo `length` |
| `shift()` | Remove e retorna o **primeiro** elemento | O elemento removido |
| `splice(start, deleteCount, ...items)` | Adiciona/remove elementos em qualquer posição | Array com elementos removidos |
| `reverse()` | Inverte a ordem dos elementos *in-place* | O próprio array modificado |
| `sort(compareFn)` | Ordena os elementos *in-place* | O próprio array modificado |

```js title="Exemplo de métodos mutadores"
const stack = [10, 20];

// Inserção e remoção nas extremidades
stack.push(30);       // Adiciona 30 no final -> [10, 20, 30]
stack.unshift(5);     // Adiciona 5 no início -> [5, 10, 20, 30]
const last = stack.pop();   // Remove 30 -> stack fica [5, 10, 20]
const first = stack.shift(); // Remove 5  -> stack fica [10, 20]

console.log(last, first); // 30 5
console.log(stack);       // [ 10, 20 ]

// Uso do splice() para alterar elementos no meio do array
const months = ["Jan", "Mar", "Abr", "Jun"];
months.splice(1, 0, "Fev"); // No índice 1, remove 0 e insere "Fev"
console.log(months); // [ 'Jan', 'Fev', 'Mar', 'Abr', 'Jun' ]

months.splice(4, 1, "Maio"); // No índice 4, remove 1 e insere "Maio"
console.log(months); // [ 'Jan', 'Fev', 'Mar', 'Abr', 'Maio' ]
```

<Aside type="tip" title="Cuidado ao ordenar números com .sort()">
  Por padrão, o método `.sort()` converte todos os elementos em `string` e os ordena em ordem lexicográfica (alfabética).
  
  ```js
  const numbers = [10, 2, 5, 1, 20];
  numbers.sort();
  console.log(numbers); // [ 1, 10, 2, 20, 5 ] (Incorreto para números!)
  
  // Forma correta para números: fornecer função de comparação
  numbers.sort((a, b) => a - b);
  console.log(numbers); // [ 1, 2, 5, 10, 20 ] (Ordenação numérica crescente)
  ```
</Aside>

### 2. Métodos Acessores e de Consulta (Preservam o Array Original)

Estes métodos não modificam o array original. Em vez disso, calculam e retornam um novo valor ou uma nova cópia de parte do array.

| Método | Descrição | Retorno |
| ------ | --------- | ------- |
| `includes(value)` | Verifica se um valor existe no array | `boolean` |
| `indexOf(value)` | Procura o primeiro índice do valor | Índice ou `-1` se não achar |
| `lastIndexOf(value)` | Procura o último índice do valor | Índice ou `-1` se não achar |
| `join(separator)` | Concatena todos os elementos em uma string | `string` |
| `slice(start, end)` | Extrai uma fatia do array sem alterar o original | Novo `Array` |
| `concat(...arrays)` | Une dois ou mais arrays em um novo array | Novo `Array` |
| `flat(depth)` | Aplatana arrays aninhados até a profundidade informada | Novo `Array` |

```js title="Exemplo de métodos acessores"
const letters = ["a", "b", "c", "d", "b"];

// Busca de valores e índices
console.log(letters.includes("c"));   // true
console.log(letters.includes("z"));   // false
console.log(letters.indexOf("b"));    // 1
console.log(letters.lastIndexOf("b"));// 4

// Conversão para string com join()
const tags = ["web", "javascript", "frontend"];
console.log(tags.join(" - ")); // "web - javascript - frontend"

// Fatiamento com slice(start, end) -> end não é incluído
const numbers = [10, 20, 30, 40, 50];
const subArray = numbers.slice(1, 4);

console.log(subArray); // [ 20, 30, 40 ]
console.log(numbers);  // [ 10, 20, 30, 40, 50 ] (Original preservado)
```

### 3. Métodos de Iteração e Programação Funcional (Higher-Order Functions)

Estes métodos recebem uma função de *callback* como argumento para processar cada elemento do array. São a forma padrão e mais legível de transformar, filtrar e agregar coleções em JavaScript moderno.

| Método | O que a função callback deve retornar | Retorno do método |
| ------ | ------------------------------------- | ----------------- |
| `map(fn)` | O novo valor transformado | Novo array com valores transformados |
| `filter(fn)` | `true` para manter o item, `false` para descartar | Novo array com itens filtrados |
| `reduce(fn, init)` | O acumulador atualizado a cada iteração | Valor único acumulado |
| `every(fn)` | `true` se o item atende à condição | `true` se **todos** atenderem |
| `some(fn)` | `true` se o item atende à condição | `true` se **ao menos um** atender |
| `find(fn)` | `true` no item buscado | O **primeiro elemento** encontrado ou `undefined` |
| `findIndex(fn)` | `true` no item buscado | O **índice** do elemento encontrado ou `-1` |

```js title="Transformação e Filtragem com map() e filter()"
const numbers = [1, 2, 3, 4, 5, 6];

// map(): Cria um novo array dobrando os valores
const doubled = numbers.map((n) => n * 2);
console.log(doubled); // [ 2, 4, 6, 8, 10, 12 ]

// filter(): Cria um novo array contendo apenas os números pares
const evens = numbers.filter((n) => n % 2 === 0);
console.log(evens); // [ 2, 4, 6 ]

// Encadeamento (Chaining) de métodos funcionais
const result = numbers
  .filter((n) => n > 2)
  .map((n) => n * 10);

console.log(result); // [ 30, 40, 50 ]
```

```js title="Acumulação com reduce()"
const cart = [
  { product: "Teclado", price: 150 },
  { product: "Mouse", price: 80 },
  { product: "Monitor", price: 900 },
];

// Somando o preço total do carrinho
const total = cart.reduce((accumulator, item) => accumulator + item.price, 0);
console.log(`Total: R$ ${total}`); // "Total: R$ 1130"
```

```js title="Busca e testes de validação"
const users = [
  { id: 1, name: "Alice", age: 25, active: true },
  { id: 2, name: "Bruno", age: 17, active: true },
  { id: 3, name: "Carla", age: 30, active: false },
];

// find(): Encontra o primeiro usuário menor de idade
const underage = users.find((user) => user.age < 18);
console.log(underage); // { id: 2, name: "Bruno", age: 17, active: true }

// findIndex(): Encontra o índice da posição da Carla
const carlaIndex = users.findIndex((user) => user.name === "Carla");
console.log(carlaIndex); // 2

// some(): Verifica se existe algum usuário inativo
const hasInactive = users.some((user) => !user.active);
console.log(hasInactive); // true

// every(): Verifica se todos os usuários são maiores de 18 anos
const allAdults = users.every((user) => user.age >= 18);
console.log(allAdults); // false
```

Referência: [Array.prototype | MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#instance_methods).

## Resumo e Boas Práticas

<CardGrid>
  <Card title="Criação e Verificação" icon="pencil">
    - Use a notação literal `[]` para criar arrays.
    - Teste se um valor é um array com `Array.isArray(valor)`.
    - Evite o operador `delete`; prefira métodos mutadores ou imutáveis.
  </Card>

  <Card title="Imutabilidade e Paradigma Funcional" icon="star">
    - Em aplicações modernas, dê preferência a métodos que não alteram o original (`map`, `filter`, `reduce`, `concat`, `slice`, `...spread`).
    - Para ordenação sem alterar o original, utilize os métodos imutáveis modernos como `.toSorted()`, `.toReversed()` e `.toSpliced()` (ES2023).
  </Card>
</CardGrid>

- Preferencialmente, declare referências de arrays com `const`. Isso impede a reassociação da variável, embora os elementos do array continuem mutáveis.
- Use `for...of` ou métodos como `.forEach()` e `.map()` para iterar sobre arrays, evitando a armadilha do `for...in`.
- Para ordenação de números com `.sort()`, forneça sempre uma função comparadora `(a, b) => a - b`.

1. Crie um array `inventory` contendo objetos com as propriedades `id`, `name`, `price` e `stock`;
2. Utilize `filter` para selecionar apenas os produtos que possuem estoque disponível (`stock > 0`);
3. Utilize `map` para criar um novo array de produtos aplicando um desconto de `10%` no preço de cada item;
4. Utilize `reduce` para calcular o valor total investido no estoque atual (soma de `price * stock` de todos os produtos);

<details>

  ```js title="inventory-report.js"
  const inventory = [

    { id: 3, name: "Monitor 24'", price: 900, stock: 5 },

  ```

## Perguntas de revisão

### Criação e Acesso

**1. Qual é a diferença entre acessar um índice inexistente em um Array e tentar acessar uma propriedade em um valor `undefined`?**

<details>
  <summary>Possível resposta</summary>

  Acessar um índice inexistente em um array (ex: `arr[99]`) retorna `undefined`. Tentar acessar uma propriedade ou índice de algo que já é `undefined` (ex: `undefined[0]`) lança um erro `TypeError`.
</details>

**2. Por que o operador `typeof` não é suficiente para confirmar se um valor é um Array?**

<details>
  <summary>Possível resposta</summary>

  Porque em JavaScript arrays são objetos, logo `typeof []` retorna `"object"`. Para verificar com segurança se um valor é um array, deve-se usar `Array.isArray(valor)`.
</details>

**3. O que acontece quando o operador `delete` é utilizado em um elemento de um Array?**

<details>
  <summary>Possível resposta</summary>

  O operador `delete` apaga o valor no índice especificado mas deixa a posição como um elemento vazio (*empty slot*), mantendo a propriedade `length` inalterada e criando um array esparso.
</details>

### Métodos e Mutabilidade

**4. Qual é a diferença essencial entre métodos Mutadores e Acessores?**

<details>
  <summary>Possível resposta</summary>

  Métodos mutadores (como `push`, `pop`, `splice`, `sort`) alteram o array original na memória. Métodos acessores (como `slice`, `concat`, `includes`, `join`) não modificam o array original e retornam um novo array ou valor.
</details>

**5. Por que `[10, 2, 5].sort()` não ordena os números em ordem crescente por padrão?**

<details>
  <summary>Possível resposta</summary>

  Porque o método `.sort()` sem parâmetros converte os elementos em strings e compara seus caracteres lexicograficamente. Para ordenação numérica, deve-se passar uma função comparadora como `(a, b) => a - b`.
</details>

**6. Como o método `splice()` difere do método `slice()`?**

<details>
  <summary>Possível resposta</summary>

  `splice()` é um método mutador que remove, substitui ou adiciona elementos diretamente no array original. `slice()` é um método acessor que extrai uma fatia de um array e retorna um novo array sem modificar o original.
</details>

### Programação Funcional e HOFs

**7. Qual é a principal diferença entre os métodos `.forEach()` e `.map()`?**

<details>
  <summary>Possível resposta</summary>

  `.forEach()` apenas executa uma função de callback para cada elemento para produzir efeitos colaterais e retorna `undefined`. `.map()` executa o callback e constrói um **novo array** com os valores retornados por cada execução.
</details>

**8. Quando se deve usar `.find()` em vez de `.filter()`?**

<details>
  <summary>Possível resposta</summary>

  Use `.find()` quando desejar obter apenas o **primeiro elemento** que satisfaça a condição (ou `undefined`). Use `.filter()` quando precisar de **todos os elementos** que satisfaçam a condição retornados em um novo array.
</details>

**9. O que faz o argumento `initialValue` no método `.reduce()` e por que ele é recomendado?**

<details>
  <summary>Possível resposta</summary>

  O `initialValue` define o valor inicial do acumulador no primeiro passo da iteração. Ele é recomendado para evitar erros `TypeError` ao executar `reduce` em arrays vazios e garantir o tipo de dado correto do resultado (ex: número `0` ou objeto `{}`).
</details>

**10. Por que o laço `for...in` deve ser evitado ao iterar sobre Arrays?**

<details>
  <summary>Possível resposta</summary>

  Porque `for...in` itera sobre as chaves de propriedades enumeráveis do objeto, convertendo os índices para `string`, sem garantir a ordem sequencial numérica e podendo incluir propriedades personalizadas ou herdadas no protótipo.
</details>
