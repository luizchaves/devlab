```bash
  create-vite@4.4.1
Ok to proceed? (y)

Scaffolding project in /home/.../invest-app...

Done. Now run:

  cd invest-app
  npm install
  npm run dev
```

[Build Options](https://vitejs.dev/config/build-options.html)
- build.target (default: 'modules')
  - [Browser Compatibility](https://vitejs.dev/guide/build.html#browser-compatibility): 'esnext' | 'modules' | 'es2015' | 'es2019' | 'chrome58' | 'firefox57' | 'safari11' | 'edge16' | 'node12' | 'node10'
  - [@vitejs/plugin-legacy](https://github.com/vitejs/vite/tree/main/packages/plugin-legacy) ([Browserslist](https://browsersl.ist/))
- build.outDir (default: 'dist')
- build.minify (default: 'terser')
