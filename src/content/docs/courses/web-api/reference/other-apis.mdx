Este tópico apresenta um panorama exaustivo das Web APIs avançadas e especializadas que compõem o ecossistema moderno dos navegadores. Ele cataloga interfaces de alto desempenho, computação gráfica, multimídia, autenticação biométrica, fluxos em tempo real, armazenamento estruturado e integração com dispositivos periféricos que complementam os tópicos fundamentais do guia.

Materiais: [slides do tópico](../../../../slides/courses/web-api/reference/other-apis/) e [mapa mental](../../../../mindmaps/courses/web-api/reference/other-apis/).

## Objetivo

Compreender o alcance estendido da plataforma web, identificando as Web APIs especializadas para computação gráfica, multimídia, segurança, armazenamento avançado, conectividade P2P e integração de hardware. Ao final do tópico, o leitor deve ser capaz de:

- Categorizar as principais Web APIs avançadas por domínio de aplicação (gráficos, persistência, rede, mídia, segurança e periféricos).
- Diferenciar os casos de uso de APIs básicas e suas contrapartes avançadas (ex: Canvas 2D vs WebGL/WebGPU, Web Storage vs IndexedDB).
- Avaliar requisitos de segurança, permissões e suporte entre navegadores para recursos experimentais ou de baixo nível.
- Selecionar a especificação adequada para cenários de aplicações web progressivas (PWA), processamento de mídia, autenticação moderna e integração com hardware.

## Gráficos 3D e Computação Acelerada por GPU

Para renderização gráfica tridimensional, sombreamento de shaders e processamento massivo paralelo, o navegador oferece interfaces de acesso direto à placa de vídeo (GPU):

| Web API | Finalidade Principal | Tecnologias Subjacentes | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **WebGL / WebGL 2** | Renderização 2D e 3D acelerada por hardware no `<canvas>` | Baseado em OpenGL ES (GLSL) | Visualizações 3D, mapas interativos, jogos de navegador (via Three.js, Babylon.js). |
| **WebGPU** | Sucessor moderno do WebGL com baixa sobrecarga e computação geral (*compute shaders*) | Vulkan, Metal, Direct3D 12 (WGSL) | Modelos de IA e redes neurais no cliente (Transformers.js), renderizadores 3D de última geração, simulações físicas. |

<Aside type="tip" title="Canvas 2D vs WebGL vs WebGPU">
Use a **Canvas API 2D** para desenhos simples, diagramas, gráficos de pizza e pequenos jogos casuais. Adote **WebGL** quando precisar de modelos 3D com texturas e iluminação complexa. Prefira **WebGPU** para tarefas que exigem alto paralelismo, aprendizado de máquina no cliente e shaders modernos sem a sobrecarga do OpenGL.
</Aside>

## Armazenamento Estruturado e Aplicações Offline (PWA)

Aplicações que operam sem conexão de rede (*offline-first*) ou que lidam com grandes volumes de dados no cliente utilizam interfaces além do `localStorage`:

| Web API | Finalidade Principal | Características | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **IndexedDB API** | Banco de dados orientado a objetos no cliente | Transacional, assíncrono, índices múltiplos, suporta blobs e objetos complexos | Cache offline de grandes coleções de registros, editores de texto com histórico local, clientes de e-mail offline. |
| **Service Workers API** | Proxy de rede programável em segundo plano | Roda fora da thread da UI, intercepta requisições HTTP, gerencia cache e notificações push | Progressive Web Apps (PWAs), funcionamento offline completo, sincronização em segundo plano. |
| **Cache API** | Armazenamento persistente de pares de `Request`/`Response` | Acessível por scripts da página e por Service Workers | Cache de assets estáticos (HTML, CSS, JS, imagens) e respostas da API para navegação instantânea. |
| **Storage Manager API** | Estimativa de uso de disco e persistência garantida | `navigator.storage.estimate()` e `navigator.storage.persist()` | Verificar quota de armazenamento disponível e evitar que o navegador limpe o cache automaticamente. |

## Autenticação, Criptografia e Pagamentos

Para substituir senhas inseguras por autenticação biométrica nativa e realizar operações criptográficas de ponta a ponta:

| Web API | Finalidade Principal | Interfaces Chave | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **Web Authentication API (WebAuthn / Passkeys)** | Autenticação forte e sem senha baseada em criptografia assimétrica | `navigator.credentials.create()`, `get()` | Login com biometria (Touch ID, Face ID, Windows Hello) ou chaves físicas de segurança (FIDO2 / YubiKey). |
| **Web Cryptography API** | Primitivas criptográficas nativas e seguras de hardware | `crypto.subtle` (`encrypt`, `decrypt`, `sign`, `digest`) | Geração de assinaturas digitais, hash SHA-256 no cliente, criptografia ponta a ponta (E2EE) em chats. |
| **Payment Request API** | Interface padronizada de checkout nativo | `new PaymentRequest()` | Formulários de pagamento simplificados integrados a Apple Pay, Google Pay e cartões salvos no navegador. |
| **Credential Management API** | Armazenamento e preenchimento federado de credenciais | `navigator.credentials.store()` | Login automático com 1 clique e sincronização de credenciais de login entre dispositivos do usuário. |

## Áudio Avançado, Câmera e Comunicação em Tempo Real

A manipulação de áudio em nível de nó e a comunicação ponto a ponto dispensam plugins externos:

| Web API | Finalidade Principal | Interfaces Chave | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **Web Audio API** | Processamento, síntese e efeitos de áudio em tempo real | `AudioContext`, `GainNode`, `AnalyserNode`, `OscillatorNode` | Sintetizadores musicais, equalizadores, jogos com áudio espacial 3D, analisadores de espectro sonoro. |
| **MediaStreams / getUserMedia** | Captura de vídeo e áudio do microfone e webcam | `navigator.mediaDevices.getUserMedia()`, `MediaRecorder` | Gravação de voz, leitura de QR Codes por câmera, captura de tela para streaming. |
| **WebRTC API** | Comunicação multimídia ponto a ponto (P2P) de baixa latência | `RTCPeerConnection`, `RTCDataChannel` | Videoconferências em tempo real (como Google Meet e Discord Web), compartilhamento P2P de arquivos. |
| **WebCodecs API** | Acesso de baixo nível a decodificadores e codificadores de mídia | `VideoEncoder`, `VideoDecoder`, `AudioDecoder` | Edição de vídeo no navegador com aceleração de hardware, streaming de jogos e renderização personalizada. |

## Interface Moderna, Animações e Compartilhamento

Interfaces modernas que aproximam a experiência de aplicações web da experiência de aplicativos móveis nativos:

| Web API | Finalidade Principal | Interfaces Chave | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **View Transitions API** | Transições de tela animadas e suaves entre estados e páginas | `document.startViewTransition()` | Navegação cinematográfica com animação contínua de elementos compartilhados (SPA e MPA nativo). |
| **Web Animations API (WAAPI)** | Controle imperativo e programático do motor de animação CSS | `element.animate()`, `Animation` | Animações dinâmicas dirigidas por código JS, controle de reprodução (`pause`, `reverse`, `playbackRate`). |
| **Web Share API** | Compartilhamento de conteúdo com outros apps instalados no SO | `navigator.share()`, `navigator.canShare()` | Botão de "Compartilhar" que abre a folha nativa do celular/desktop para WhatsApp, Telegram ou e-mail. |
| **Badging API** | Notificação visual de contadores no ícone do aplicativo | `navigator.setAppBadge()`, `clearAppBadge()` | Exibir a contagem de mensagens não lidas no ícone do PWA na barra de tarefas ou na tela inicial do celular. |

## Streams e Manipulação de Arquivos

Para processamento eficiente de fluxos contínuos de dados sem carregar arquivos gigantescos inteiramente na memória RAM:

| Web API | Finalidade Principal | Interfaces Chave | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **Streams API** | Criação, encadeamento e consumo de fluxos de dados | `ReadableStream`, `WritableStream`, `TransformStream` | Descompactação em tempo real de downloads, processamento de vídeo em streaming, parsing incremental de JSON grande. |
| **File System Access API** | Leitura e gravação direta em arquivos do sistema operacional | `window.showOpenFilePicker()`, `FileSystemFileHandle` | IDEs web (como VS Code for Web), editores de imagem, ferramentas de edição de código local no navegador. |

## Redes de Próxima Geração e Métricas de Performance

Ferramentas para transporte de dados em alta velocidade e monitoramento de desempenho da aplicação em produção:

| Web API | Finalidade Principal | Interfaces Chave | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **WebTransport API** | Transporte bidirecional cliente-servidor sobre HTTP/3 (QUIC) | `WebTransport`, `datagrams`, `incomingUnidirectionalStreams` | Jogos multiplayer online em tempo real, streaming de baixa latência e alternativas flexíveis a WebSockets. |
| **Performance Timeline API** | Coleta precisa de métricas de temporização e Core Web Vitals | `PerformanceObserver`, `performance.now()` | Medição em tempo real de LCP (*Largest Contentful Paint*), FID/INP e requisições lentas de rede. |
| **Network Information API** | Consulta do status da rede e modo de economia de dados | `navigator.connection` (`effectiveType`, `saveData`) | Adaptar a qualidade das imagens e vídeos automaticamente quando o usuário estiver em redes 3G ou modo de economia. |

## Hardware, Periféricos e Conectividade Local

Ambientes restritos e sistemas operacionais desktop/mobile permitem conectar dispositivos físicos via navegador sob permissões explícitas:

| Web API | Finalidade Principal | Protocolo / Transporte | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **Web Bluetooth API** | Comunicação com dispositivos Bluetooth Low Energy (BLE) | GATT (Generic Attribute Profile) | Monitoramento de frequência cardíaca, leitura de sensores IoT, controle de drones e robôs educacionais. |
| **Web USB API** | Acesso seguro e direto a dispositivos USB | USB standard transfers | Configuração de teclados customizados, placas microcontroladoras (Arduino, ESP32) e leitores fiscais. |
| **Web Serial API** | Comunicação com portas seriais e adaptadores USB-to-Serial | Porta COM / UART serial | Gravação de firmware em microcontroladores, conexão com impressoras térmicas e equipamentos industriais. |
| **WebHID API** | Integração com dispositivos de interface humana não padrão | Protocolo HID | Gamepads especiais, pedais de controle, mesas de som e controladores de voo. |

<Aside type="caution" title="Compatibilidade e Contexto de Execução">
As APIs de acesso a hardware (Web Bluetooth, Web USB, Web Serial, WebHID) são padronizadas principalmente para o ecossistema Chromium e exigem estritamente **Contexto Seguro (HTTPS)** e **Gesto Explícito do Usuário**. Elas possuem suporte restrito ou ausente em navegadores como Mozilla Firefox e Apple Safari por políticas de privacidade e segurança do sistema.
</Aside>

## Sensores, Janelas e Controle do Sistema

Interfaces que controlam o comportamento da aba e reagem ao estado físico do dispositivo:

| Web API | Finalidade Principal | Interfaces Chave | Casos de Uso Típicos |
| --- | --- | --- | --- |
| **Screen Wake Lock API** | Impede que a tela do dispositivo escureça ou bloqueie | `navigator.wakeLock.request('screen')` | Receitas culinárias na tela, aplicativos de apresentação de slides, teleprompters. |
| **Picture-in-Picture API** | Exibe vídeos ou elementos HTML em uma janela flutuante sobreposta | `videoElement.requestPictureInPicture()` | Reprodutores de vídeo e chamadas de videoconferência enquanto o usuário navega em outras abas. |
| **Web Locks API** | Coordena acesso concorrente a recursos entre abas e workers da mesma origem | `navigator.locks.request()` | Evitar que duas abas abertas sincronizem ou gravem dados conflitantes no IndexedDB simultaneamente. |
| **Broadcast Channel API** | Comunicação simples por broadcast entre diferentes abas, janelas e iframes da mesma origem | `new BroadcastChannel('app_channel')` | Deslogar o usuário em todas as abas abertas quando ele clicar em "Sair" em uma delas. |
| **Sensor APIs** | Acesso a sensores inerciais e de ambiente do aparelho | `Accelerometer`, `Gyroscope`, `AmbientLightSensor` | Jogos baseados em inclinação do celular, ajuste dinâmico de brilho e bússolas digitais. |

## Perguntas de revisão

Teste seus conhecimentos sobre o panorama estendido de Web APIs do navegador:

### Escolha e Cenários de Aplicação

1. **Qual a diferença fundamental de aplicação entre Local Storage e IndexedDB?**

<details>
  <summary>Possível resposta</summary>

  O `localStorage` é síncrono, armazena apenas pares simples de chave-valor como strings e possui limite pequeno (aproximadamente 5 MB). O `IndexedDB` é um banco de dados relacional/orientado a objetos transacional, totalmente assíncrono, indexável e projetado para suportar gigabytes de dados estruturados e arquivos binários (blobs).
</details>

2. **Por que WebGL e WebGPU operam de forma diferente da Canvas 2D API?**

<details>
  <summary>Possível resposta</summary>

  A Canvas 2D API fornece métodos imperativos simples de desenho raster direto em duas dimensões pela CPU/GPU integrada. WebGL e WebGPU expõem pipelines gráficos completos programáveis via shaders (GLSL e WGSL), comunicando-se diretamente com o hardware gráfico da GPU para renderização de geometrias 3D complexas e computação paralela.
</details>

3. **Qual é a vantagem da View Transitions API em relação a bibliotecas JS de animação?**

<details>
  <summary>Possível resposta</summary>

  A View Transitions API opera diretamente no motor de renderização do navegador, capturando instantâneos visuais do estado anterior e do novo estado do DOM. Isso permite criar transições contínuas e fluidas a 60/120 fps sem recalcular posições ou criar árvores virtuais pesadas em JavaScript.
</details>

4. **Como o WebAuthn melhora a segurança em relação a senhas tradicionais?**

<details>
  <summary>Possível resposta</summary>

  O WebAuthn utiliza pares de chaves criptográficas assimétricas criadas diretamente no enclave seguro do hardware do usuário (Touch ID, Face ID, YubiKey). A chave privada nunca sai do dispositivo e o desafio de assinatura é vinculado à origem (domínio), tornando o login imune a ataques de phishing e vazamentos de banco de dados.
</details>

### Requisitos e Segurança

5. **Por que APIs como Web Bluetooth e Web USB exigem gesto do usuário e HTTPS?**

<details>
  <summary>Possível resposta</summary>

  Por segurança e proteção à privacidade do usuário. Comunicar-se com dispositivos físicos locais sem criptografia ou sem o consentimento intencional do usuário poderia permitir que scripts maliciosos invadam periféricos, capturem dados de sensores ou gravem dados não autorizados no hardware da máquina.
</details>

6. **Como a Screen Wake Lock API melhora a experiência do usuário em aplicações específicas?**

<details>
  <summary>Possível resposta</summary>

  Ela evita que a tela entre em modo de descanso ou bloqueie automaticamente enquanto o usuário está acompanhando uma atividade passiva, como ler uma receita na cozinha, acompanhar um cronômetro ou ler um roteiro durante uma apresentação.
</details>
