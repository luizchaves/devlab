## 📌 Legenda e Convenções

- **`param?`**: parâmetro opcional.
- **`options`**: objeto de configuração opcional passado como argumento.
- **`Promise<T>`**: método assíncrono que retorna uma promessa com o tipo `T`.
- **`void`**: método sem retorno útil (`undefined`).
- **`Síncrono`**: executa imediatamente e bloqueia a thread principal até concluir.
- **`Assíncrono`**: executa em segundo plano sem travar a renderização da interface.
- **`DOMString` / `string`**: texto UTF-16 padrão do JavaScript.

A consulta rápida a esta referência previne o uso de assinaturas incorretas sugeridas por assistentes de IA:

<Aside type="tip" title="Dica de IA: Confirme a assinatura aqui antes de usar a sugerida">
  Assinaturas de Web APIs e métodos do DOM frequentemente têm variações sutis entre versões de especificação e navegadores: parâmetros de `addEventListener(type, listener, options?)`, os métodos de `fetch(input, init?)` e `Response`, assinaturas de `IntersectionObserver`, `URLSearchParams`, `localStorage` e eventos. Esta página serve como conferência rápida de métodos, propriedades e retornos das APIs nativas do navegador.

</Aside>

## Browser Object Model (BOM) e Objetos Globais

As interfaces do BOM conectam o código JavaScript à janela do navegador, à URL, ao histórico de navegação, ao hardware do dispositivo e às ferramentas de depuração.

**Objeto Window e Janela**

<details>
  <summary>`window.innerWidth: number`, `window.innerHeight: number`</summary>

  Retornam a largura e a altura da área de exibição da página (*viewport*), em pixels, excluindo barras de navegação e ferramentas do navegador.
</details>

<details>
  <summary>`window.open(url?, target?, features?): WindowProxy | null`</summary>

  Abre uma nova janela ou aba no navegador. `target` aceita `_blank`, `_self`, `_parent` ou nomes customizados. Retorna a referência da nova janela (se permitida pelo bloqueador de pop-ups).
</details>

<details>
  <summary>`window.close(): void`</summary>

  Fecha a janela atual (apenas permitido para janelas que foram abertas programaticamente via script com `window.open()`).
</details>

<details>
  <summary>`window.alert(message?): void`, `window.confirm(message?): boolean`, `window.prompt(message?, default?): string | null`</summary>

  Diálogos nativos do sistema. Bloqueiam síncronamente a execução do JavaScript e a renderização da página até que o usuário responda ou feche o diálogo.
</details>

<details>
  <summary>`window.requestAnimationFrame(callback): number`, `window.cancelAnimationFrame(handle): void`</summary>

  Agenda uma função de repintura para ser executada antes do próximo quadro de animação da tela (normalmente a 60Hz ou 120Hz). `callback` recebe o carimbo de tempo `DOMHighResTimeStamp`.
</details>

<details>
  <summary>`window.setTimeout(fn, delay?, ...args): number`, `window.clearTimeout(id): void`</summary>

  Agenda a execução de uma função após um intervalo mínimo em milissegundos. Retorna um identificador numérico para cancelamento.
</details>

<details>
  <summary>`window.setInterval(fn, delay?, ...args): number`, `window.clearInterval(id): void`</summary>

  Executa periodicamente uma função a cada intervalo de milissegundos especificado até ser cancelada com `clearInterval()`.
</details>

<details>
  <summary>`window.getComputedStyle(element, pseudoElement?): CSSStyleDeclaration`</summary>

  Retorna o objeto com todos os valores CSS finais calculados e aplicados pelo navegador ao elemento após a resolução de cascata e herança.
</details>

<details>
  <summary>`window.matchMedia(mediaQueryString): MediaQueryList`</summary>

  Avalia uma Media Query CSS no JavaScript (ex: `window.matchMedia('(prefers-color-scheme: dark)')`). Retorna um objeto com a propriedade `matches` e suporte ao evento `change`.
</details>

<details>
  <summary>`window.scrollTo(options | x, y): void`, `window.scrollBy(options | x, y): void`</summary>

  Rola a janela até coordenadas absolutas (`scrollTo`) ou relativas (`scrollBy`). Aceita o objeto `{ top, left, behavior: 'smooth' | 'instant' | 'auto' }`.
</details>

**Objeto Location (URL)**

<details>
  <summary>`location.href: string`</summary>

  Lê ou define a URL completa da página atual. Atribuir um novo valor navega para a URL informada gravando uma nova entrada no histórico.
</details>

<details>
  <summary>`location.protocol: string`, `location.host: string`, `location.hostname: string`, `location.port: string`</summary>

  Propriedades decompostas da URL: esquema (`http:`, `https:`), domínio com porta (`localhost:3000`), domínio sem porta (`localhost`) e porta (`3000`).
</details>

<details>
  <summary>`location.pathname: string`, `location.search: string`, `location.hash: string`, `location.origin: string`</summary>

  Caminho do recurso (`/produtos`), query string (`?id=10&cat=livros`), âncora (`#topo`) e origem completa (`https://exemplo.com:8080`).
</details>

<details>
  <summary>`location.assign(url): void`</summary>

  Carrega a página na URL informada, gravando uma nova entrada no histórico de navegação (permite clicar em "Voltar").
</details>

<details>
  <summary>`location.replace(url): void`</summary>

  Navega para a URL informada substituindo o registro atual no histórico (o usuário não consegue voltar para a página anterior com o botão do navegador).
</details>

<details>
  <summary>`location.reload(): void`</summary>

  Recarrega a página atual a partir do cache do navegador ou da rede.
</details>

**Objeto History (Histórico da Sessão)**

<details>
  <summary>`history.length: number`, `history.state: any`</summary>

  Retorna a quantidade de entradas no histórico da aba e o estado serializável associado à entrada atual via `pushState` ou `replaceState`.
</details>

<details>
  <summary>`history.back(): void`, `history.forward(): void`, `history.go(delta?): void`</summary>

  Navega pelo histórico da aba: `back()` volta 1 página, `forward()` avança 1 página, e `go(delta)` desloca N páginas (positivo para frente, negativo para trás).
</details>

<details>
  <summary>`history.pushState(state, unused, url?): void`</summary>

  Adiciona uma nova entrada no histórico de navegação e altera a URL visível na barra de endereços **sem recarregar a página**. Base para roteadores SPA.
</details>

<details>
  <summary>`history.replaceState(state, unused, url?): void`</summary>

  Substitui o estado e a URL da entrada atual no histórico sem recarregar a página e sem criar nova entrada.
</details>

**Objeto Navigator (Dispositivo e Plataforma)**

<details>
  <summary>`navigator.userAgent: string`, `navigator.language: string`, `navigator.languages: readonly string[]`</summary>

  Identificador do navegador (*User-Agent*), idioma preferencial do usuário (ex: `"pt-BR"`) e lista completa de idiomas aceitos em ordem de prioridade.
</details>

<details>
  <summary>`navigator.onLine: boolean`</summary>

  Retorna `true` se o navegador possui conectividade com a rede local/internet e `false` caso esteja off-line.
</details>

<details>
  <summary>`navigator.cookieEnabled: boolean`</summary>

  Informa se o suporte a cookies está habilitado nas configurações do navegador.
</details>

<details>
  <summary>`navigator.clipboard: Clipboard`, `navigator.geolocation: Geolocation`, `navigator.mediaDevices: MediaDevices`</summary>

  Pontos de entrada para as APIs de área de transferência, geolocalização e captura de mídia (câmera/microfone).
</details>

<details>
  <summary>`navigator.vibrate(pattern): boolean`</summary>

  Emite vibração no dispositivo móvel. `pattern` pode ser uma duração em ms (ex: `200`) ou um array de tempos alternados de vibração e pausa (`[100, 50, 100]`).
</details>

<details>
  <summary>`navigator.share(data): Promise<void>`, `navigator.canShare(data?): boolean`</summary>

  Aciona o diálogo nativo de compartilhamento do sistema operacional (Web Share API) com `{ title?, text?, url?, files? }`.
</details>

**Objeto Screen (Monitor e Resolução)**

<details>
  <summary>`screen.width: number`, `screen.height: number`, `screen.availWidth: number`, `screen.availHeight: number`</summary>

  Dimensões totais da tela do monitor e dimensões úteis disponíveis excluindo barras fixas do sistema operacional (como a barra de tarefas).
</details>

<details>
  <summary>`screen.orientation: ScreenOrientation`</summary>

  Retorna o tipo de orientação atual da tela (`portrait-primary`, `landscape-primary`, etc.) e permite monitorar o evento `change`.
</details>

**Objeto Console (Depuração)**

<details>
  <summary>`console.log(...data): void`, `console.info(...data): void`, `console.warn(...data): void`, `console.error(...data): void`, `console.debug(...data): void`</summary>

  Imprime mensagens no console do navegador categorizadas por nível de severidade (informativo, aviso, erro, depuração).
</details>

<details>
  <summary>`console.dir(item, options?): void`</summary>

  Exibe uma listagem interativa em árvore de todas as propriedades e protótipos (`[[Prototype]]`) de um objeto JavaScript ou elemento do DOM.
</details>

<details>
  <summary>`console.table(tabularData, properties?): void`</summary>

  Renderiza arrays de objetos ou dicionários em formato de tabela bidimensional com cabeçalhos e ordenação visual por coluna.
</details>

<details>
  <summary>`console.time(label?): void`, `console.timeEnd(label?): void`, `console.timeLog(label?, ...data): void`</summary>

  Inicia e finaliza um cronômetro de alta precisão com o rótulo informado, imprimindo no console a duração exata da execução em milissegundos.
</details>

<details>
  <summary>`console.group(label?): void`, `console.groupCollapsed(label?): void`, `console.groupEnd(): void`</summary>

  Cria blocos indentados e recolhíveis de logs para agrupar mensagens relacionadas.
</details>

<details>
  <summary>`console.count(label?): void`, `console.countReset(label?): void`</summary>

  Registra e incrementa quantas vezes uma determinada linha ou rótulo foi executado.
</details>

<details>
  <summary>`console.assert(condition, ...data): void`</summary>

  Escreve uma mensagem de erro no console apenas se a condição fornecida for avaliada como falsa (`false`).
</details>

<details>
  <summary>`console.trace(...data): void`</summary>

  Exibe no console a pilha de chamadas (*stack trace*) completa até o ponto onde o método foi invocado.
</details>

<details>
  <summary>`console.clear(): void`</summary>

  Limpa todas as mensagens da aba Console das ferramentas do desenvolvedor.
</details>

## DOM: Seleção, Criação e Manipulação

O Document Object Model (DOM) representa o documento HTML como uma árvore hierárquica de nós interativos (`Node` e `Element`).

**Seleção de Elementos**

<details>
  <summary>`document.getElementById(id): HTMLElement | null`</summary>

  Busca e retorna o elemento único que possui o atributo `id` correspondente, ou `null` se não encontrado.
</details>

<details>
  <summary>`document.querySelector(selectors): Element | null`, `element.querySelector(selectors): Element | null`</summary>

  Retorna o **primeiro** elemento dentro do escopo que corresponde ao seletor CSS informado, ou `null`.
</details>

<details>
  <summary>`document.querySelectorAll(selectors): NodeList`, `element.querySelectorAll(selectors): NodeList`</summary>

  Retorna uma `NodeList` estática contendo todos os elementos que correspondem ao seletor CSS fornecido.
</details>

<details>
  <summary>`document.getElementsByClassName(names): HTMLCollection`, `document.getElementsByTagName(name): HTMLCollection`</summary>

  Retornam coleções vivas (*live collections*) atualizadas automaticamente quando o DOM sofre mutações.
</details>

<details>
  <summary>`element.closest(selectors): Element | null`</summary>

  Percorre os ancestrais do elemento (começando por ele mesmo) e retorna o ancestral mais próximo que atende ao seletor CSS informado.
</details>

<details>
  <summary>`element.matches(selectors): boolean`</summary>

  Verifica se o elemento atual seria selecionado pelo seletor CSS especificado.
</details>

**Criação, Inserção e Remoção**

<details>
  <summary>`document.createElement(tagName, options?): HTMLElement`</summary>

  Cria um novo nó de elemento HTML na memória com o nome da tag especificado (ex: `'div'`, `'button'`).
</details>

<details>
  <summary>`document.createTextNode(data): Text`</summary>

  Cria um nó de texto puro contendo os caracteres fornecidos.
</details>

<details>
  <summary>`document.createDocumentFragment(): DocumentFragment`</summary>

  Cria um contêiner virtual leve na memória. Ao inserir o fragmento no DOM, apenas seus nós filhos são anexados, evitando múltiplos recálculos de layout (*reflows*).
</details>

<details>
  <summary>`node.appendChild(childNode): Node`</summary>

  Insere o nó como o último filho de `node` e o retorna.
</details>

<details>
  <summary>`node.insertBefore(newNode, referenceNode): Node`</summary>

  Insere `newNode` antes de `referenceNode` como filho do nó pai atual. Se `referenceNode` for `null`, insere ao final.
</details>

<details>
  <summary>`node.removeChild(childNode): Node`</summary>

  Remove o filho informado da árvore do DOM e retorna a referência do nó removido.
</details>

<details>
  <summary>`node.replaceChild(newChild, oldChild): Node`</summary>

  Substitui o nó filho `oldChild` por `newChild` e devolve o nó antigo.
</details>

<details>
  <summary>`element.append(...nodesOrDOMStrings): void`, `element.prepend(...nodesOrDOMStrings): void`</summary>

  Métodos modernos que inserem múltiplos nós ou strings de texto diretamente no final (`append`) ou no início (`prepend`) dos filhos do elemento.
</details>

<details>
  <summary>`element.before(...nodesOrDOMStrings): void`, `element.after(...nodesOrDOMStrings): void`</summary>

  Insere nós ou strings imediatamente antes ou após o elemento atual como nós irmãos.
</details>

<details>
  <summary>`element.replaceWith(...nodesOrDOMStrings): void`</summary>

  Substitui o elemento atual pelos nós ou strings informados.
</details>

<details>
  <summary>`element.remove(): void`</summary>

  Remove o elemento atual diretamente do DOM.
</details>

<details>
  <summary>`element.insertAdjacentHTML(position, htmlString): void`</summary>

  Analisa a string HTML e a insere na posição relativa: `'beforebegin'`, `'afterbegin'`, `'beforeend'` ou `'afterend'`.
</details>

<details>
  <summary>`element.insertAdjacentElement(position, element): Element | null`</summary>

  Insere o nó de elemento na posição relativa informada (`'beforebegin'`, `'afterbegin'`, `'beforeend'`, `'afterend'`).
</details>

<details>
  <summary>`node.cloneNode(deep?): Node`</summary>

  Clona o nó. Se `deep` for `true`, clona recursivamente toda a subárvore e atributos filhos.
</details>

**Conteúdo, Atributos e Classes**

<details>
  <summary>`element.innerHTML: string`</summary>

  Lê ou substitui o conteúdo HTML interno do elemento. Atenção a riscos de segurança (XSS) com dados de fontes não confiáveis.
</details>

<details>
  <summary>`element.textContent: string`</summary>

  Lê ou substitui todo o texto puro contido no elemento e em seus descendentes, sem interpretar tags HTML.
</details>

<details>
  <summary>`element.innerText: string`</summary>

  Lê ou define o texto visível renderizado pelo navegador, levando em conta regras de estilo CSS (como `display: none`).
</details>

<details>
  <summary>`element.getAttribute(name): string | null`, `element.setAttribute(name, value): void`</summary>

  Lê ou define o valor textual exato de um atributo HTML especificado.
</details>

<details>
  <summary>`element.removeAttribute(name): void`, `element.hasAttribute(name): boolean`, `element.toggleAttribute(name, force?): boolean`</summary>

  Remove, verifica existência ou alterna a presença de atributos booleanos no elemento (como `disabled`, `readonly`, `hidden`).
</details>

<details>
  <summary>`element.dataset: DOMStringMap`</summary>

  Objeto que dá acesso aos atributos customizados `data-*` em formato camelCase (ex: `data-user-id` vira `element.dataset.userId`).
</details>

<details>
  <summary>`element.classList.add(...tokens): void`, `element.classList.remove(...tokens): void`</summary>

  Adiciona ou remove uma ou mais classes CSS do elemento sem alterar as classes existentes.
</details>

<details>
  <summary>`element.classList.toggle(token, force?): boolean`</summary>

  Alterna a presença da classe informada. Se `force` for booleano, força inclusão (`true`) ou remoção (`false`).
</details>

<details>
  <summary>`element.classList.contains(token): boolean`, `element.classList.replace(oldToken, newToken): boolean`</summary>

  Verifica se a classe existe no elemento ou substitui uma classe existente por outra.
</details>

**Navegação na Árvore e Geometria**

<details>
  <summary>`node.parentNode: Node | null`, `node.parentElement: HTMLElement | null`</summary>

  Retorna o nó pai ou o elemento pai do nó atual.
</details>

<details>
  <summary>`element.children: HTMLCollection`, `node.childNodes: NodeList`</summary>

  `children` retorna apenas nós de elementos filhos; `childNodes` inclui também nós de texto, comentários e espaços em branco.
</details>

<details>
  <summary>`element.firstElementChild: Element | null`, `element.lastElementChild: Element | null`</summary>

  Retornam o primeiro e o último elemento filho ignorando nós de texto.
</details>

<details>
  <summary>`element.nextElementSibling: Element | null`, `element.previousElementSibling: Element | null`</summary>

  Retornam os elementos irmãos adjacentes posterior e anterior.
</details>

<details>
  <summary>`element.getBoundingClientRect(): DOMRect`</summary>

  Retorna a posição e o tamanho do elemento relativo ao viewport visível com `{ top, right, bottom, left, width, height, x, y }`.
</details>

<details>
  <summary>`element.clientWidth: number`, `element.clientHeight: number`</summary>

  Retornam a largura e altura internas do elemento em pixels, incluindo *padding*, mas excluindo *border*, *margin* e barras de rolagem.
</details>

<details>
  <summary>`element.offsetWidth: number`, `element.offsetHeight: number`</summary>

  Retornam as dimensões visuais completas do elemento incluindo *content*, *padding*, *border* e barras de rolagem.
</details>

<details>
  <summary>`element.scrollWidth: number`, `element.scrollHeight: number`, `element.scrollTop: number`, `element.scrollLeft: number`</summary>

  Dimensões totais roláveis do conteúdo e a posição atual do deslocamento de rolagem do elemento.
</details>

<details>
  <summary>`element.scrollIntoView(alignToTop | options?): void`</summary>

  Rola a página até que o elemento fique visível na área de exibição. Aceita `{ behavior: 'smooth' | 'instant', block: 'start' | 'center' | 'end' | 'nearest', inline: 'start' | 'center' | 'end' | 'nearest' }`.
</details>

## Eventos e EventTarget

O modelo de eventos do navegador segue o padrão *Observer* via interface `EventTarget`, com fases de captura (*capturing*), alvo (*target*) e borbulhamento (*bubbling*).

**Interface EventTarget**

<details>
  <summary>`target.addEventListener(type, listener, options?): void`</summary>

  Registra uma função ou objeto ouvinte para o tipo de evento especificado. `options` pode ser um booleano (`useCapture`) ou o objeto `{ capture?: boolean, once?: boolean, passive?: boolean, signal?: AbortSignal }`.
</details>

<details>
  <summary>`target.removeEventListener(type, listener, options?): void`</summary>

  Remove o ouvinte previamente registrado. Requer a mesma referência de função e as mesmas configurações de `capture`.
</details>

<details>
  <summary>`target.dispatchEvent(event): boolean`</summary>

  Dispara síncronamente um evento sintético contra o alvo. Retorna `false` se algum ouvinte chamou `preventDefault()`.
</details>

**Interface Event e CustomEvent**

<details>
  <summary>`event.type: string`, `event.target: EventTarget | null`, `event.currentTarget: EventTarget | null`</summary>

  Tipo do evento disparado (`'click'`), o elemento original que causou o evento (`target`) e o elemento ao qual o ouvinte está anexado no momento (`currentTarget`).
</details>

<details>
  <summary>`event.preventDefault(): void`</summary>

  Cancela o comportamento padrão associado ao evento pelo navegador (ex: previne o envio de um formulário ou a navegação de um link).
</details>

<details>
  <summary>`event.stopPropagation(): void`, `event.stopImmediatePropagation(): void`</summary>

  `stopPropagation()` impede que o evento continue borbulhando pela árvore do DOM. `stopImmediatePropagation()` além disso impede a execução de outros ouvintes do mesmo tipo anexados ao próprio elemento.
</details>

<details>
  <summary>`event.bubbles: boolean`, `event.cancelable: boolean`, `event.defaultPrevented: boolean`</summary>

  Informa se o evento borbulha pela hierarquia do DOM, se permite cancelamento com `preventDefault()` e se foi efetivamente cancelado.
</details>

<details>
  <summary>`new CustomEvent(type, options?): CustomEvent`</summary>

  Cria um evento customizado. Aceita `{ detail?: any, bubbles?: boolean, cancelable?: boolean }` para transportar dados na propriedade `event.detail`.
</details>

**Eventos Fundamentais do Navegador**

<details>
  <summary>`DOMContentLoaded`, `load`, `beforeunload`, `visibilitychange` (Ciclo de Vida)</summary>

  - `DOMContentLoaded`: disparado no `document` quando a árvore HTML está pronta (sem esperar imagens/folhas de estilo).
  - `load`: disparado em `window` após o carregamento completo de todos os recursos (imagens, estilos, scripts).
  - `beforeunload`: disparado antes do usuário sair da página (permite exibir confirmação de saída).
  - `visibilitychange`: disparado no `document` quando a aba fica oculta ou visível (`document.visibilityState === 'visible' | 'hidden'`).
</details>

<details>
  <summary>`click`, `dblclick`, `pointerdown`, `pointermove`, `pointerup`, `contextmenu` (Ponteiro e Mouse)</summary>

  Eventos de interação do mouse e ponteiro unificado (*Pointer Events*). Acessam propriedades como `clientX`, `clientY`, `pageX`, `pageY`, `button` e `pointerType`.
</details>

<details>
  <summary>`keydown`, `keyup`, `input`, `change` (Teclado e Entrada)</summary>

  - `keydown` / `keyup`: acessam `event.key` (valor lógico ex: `'Enter'`, `'a'`) e `event.code` (código físico da tecla ex: `'KeyA'`).
  - `input`: disparado a cada caractere digitado ou alteração de valor em campos de texto.
  - `change`: disparado quando o valor é confirmado (após perda de foco em inputs ou seleção em `<select>`).
</details>

## Formulários e Validação

O gerenciamento de dados de formulários e a validação declarativa nativa são operados pela Constraint Validation API e por `FormData`.

**FormData**

<details>
  <summary>`new FormData(form?, submitter?): FormData`</summary>

  Cria um conjunto de pares chave/valor a partir dos campos com atributo `name` contidos no formulário `<form>`.
</details>

<details>
  <summary>`formData.get(name): FormDataEntryValue | null`, `formData.getAll(name): FormDataEntryValue[]`</summary>

  Retorna o primeiro valor ou todos os valores associados à chave fornecida.
</details>

<details>
  <summary>`formData.set(name, value, filename?): void`, `formData.append(name, value, filename?): void`</summary>

  Define ou anexa um novo campo. Suporta valores de texto e instâncias de `File` / `Blob`.
</details>

<details>

<details>

<details>

<details>

<details>

<details>

<details>

**WebSockets e Server-Sent Events (SSE)**

<details>

<details>

<details>

</details>

<details>
  <summary>`worker.postMessage(message, transfer?): void`, `worker.terminate(): void`</summary>

  Envia uma mensagem (clonada estruturalmente) para a thread do worker ou encerra imediatamente a execução da thread externa.
</details>

<details>
  <summary>`self.postMessage(message, transfer?): void`, `self.onmessage`, `self.close(): void`</summary>

  Dentro do arquivo do worker: envia mensagens de volta para a thread principal, escuta mensagens recebidas e encerra a si próprio.
</details>

## Segurança e Criptografia

Interfaces criptográficas nativas para geração de números aleatórios seguros, identificadores únicos e operações de chave pública.

**Web Cryptography API**

<details>
  <summary>`crypto.randomUUID(): string`</summary>

  Gera uma string contendo um identificador único universal (UUID) versão 4 criptograficamente seguro (ex: `"36b8f84d-df4e-4d49-b662-bcde71a8764f"`).
</details>

<details>
  <summary>`crypto.getRandomValues(typedArray): ArrayBufferView`</summary>

  Preenche o array tipado fornecido (ex: `Uint8Array`, `Uint32Array`) com valores aleatórios gerados por um gerador criptográfico de alta entropia.
</details>

<details>
  <summary>`crypto.subtle.digest(algorithm, data): Promise<ArrayBuffer>`</summary>

  Calcula o hash criptográfico seguro dos dados informados utilizando algoritmos padronizados como `'SHA-256'`, `'SHA-384'` ou `'SHA-512'`.
</details>

<details>
  <summary>`crypto.subtle.generateKey(algorithm, extractable, keyUsages): Promise<CryptoKey | CryptoKeyPair>`</summary>

  Gera chaves criptográficas simétricas (AES-GCM, HMAC) ou pares de chaves assimétricas (RSA-OAEP, ECDSA).
</details>

<details>
  <summary>`crypto.subtle.encrypt(algorithm, key, data): Promise<ArrayBuffer>`, `crypto.subtle.decrypt(algorithm, key, data): Promise<ArrayBuffer>`</summary>

  Criptografa ou descriptografa dados binários utilizando a chave e os parâmetros de algoritmo fornecidos.
</details>

<details>
  <summary>`crypto.subtle.sign(algorithm, key, data): Promise<ArrayBuffer>`, `crypto.subtle.verify(algorithm, key, signature, data): Promise<boolean>`</summary>

  Assina digitalmente dados ou verifica a validade de uma assinatura digital existente utilizando chaves públicas/privadas.
</details>
