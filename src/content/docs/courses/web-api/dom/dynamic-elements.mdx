Em aplicações Web interativas, as interfaces não são estáticas: cartões de produtos, linhas de tabelas, comentários e notificações são construídos e renderizados dinamicamente a partir de dados recebidos de APIs ou entradas do usuário.

## Objetivo

Aprender as técnicas de criação, manipulação e remoção dinâmica de nós no DOM, dominando o uso de `DocumentFragment` e da tag `<template>` para otimizar o desempenho da renderização e evitar recálculos desnecessários de layout (*reflows*).

---

## Criação e Inserção Básica de Nós

Para construir elementos via JavaScript, o navegador oferece a API de criação de nós do objeto `document`.

### Métodos `createElement` e `appendChild`

```js title="Construindo um nó de elemento"
// 1. Cria o nó de elemento na memória (desconectado do DOM)
const novoCard = document.createElement('div');
novoCard.classList.add('card-produto');

// 2. Cria o conteúdo interno
const titulo = document.createElement('h3');
titulo.textContent = 'Notebook Gamer';

const preco = document.createElement('p');
preco.textContent = 'R$ 4.500,00';

// 3. Monta a hierarquia na memória
novoCard.appendChild(titulo);
novoCard.appendChild(preco);

// 4. Insere o elemento montado na árvore DOM visível
const container = document.querySelector('#lista-produtos');
container.appendChild(novoCard);
```

### Inserção com `insertAdjacentHTML`

O método `insertAdjacentHTML()` permite inserir uma string de marcação HTML em uma posição específica em relação ao elemento de referência:

```js title="Posições do insertAdjacentHTML"
const container = document.querySelector('#container');

// Insere a marcação HTML antes do final do container
container.insertAdjacentHTML('beforeend', '<div class="item">Novo Item</div>');
```

## Otimização de Performance com `DocumentFragment`

Quando manipulamos o DOM, cada chamada direta como `container.appendChild(el)` faz o navegador recalcular os estilos e a geometria da página (**Reflow**) e redesenhar a tela (**Repaint**).

Inserir 100 itens diretamente no DOM em um laço de repetição causará 100 recálculos de layout, desacelerando a aplicação.

### O Nó `DocumentFragment`

O `DocumentFragment` é uma versão leve do objeto `Document` que existe **apenas em memória**. Quando inserimos elementos no fragmento, nenhum reflow ocorre. Quando o fragmento é inserido no DOM, todos os seus filhos são transferidos de uma só vez em uma única operação de renderização.

<Mermaid title="Renderização com DocumentFragment (1 Único Reflow)">
{`
flowchart LR
  subgraph Memoria["Em Memória (Sem Reflow)"]
    DF["DocumentFragment"] --> Item1["div.item 1"]
    DF --> Item2["div.item 2"]
    DF --> Item3["div.item N"]
  end

  Memoria -- "appendChild (1 Único Reflow)" --> DOMTree["Árvore DOM Principal"]
`}
</Mermaid>

```js title="Renderização performática com DocumentFragment"
const produtos = [
  { id: 1, nome: 'Teclado Mecânico' },
  { id: 2, nome: 'Mouse Óptico' },
  { id: 3, nome: 'Monitor 4K' }
];

const container = document.querySelector('#lista');

// 1. Cria o fragmento em memória
const fragmento = document.createDocumentFragment();

produtos.forEach(prod => {
  const item = document.createElement('li');
  item.textContent = prod.nome;
  // Adiciona ao fragmento na memória (zero impacto na tela)
  fragmento.appendChild(item);
});

// 2. Insere todo o bloco de uma só vez na árvore DOM
container.appendChild(fragmento);
```

## O Elemento `<Template>`

A tag `<template>` do HTML5 permite declarar blocos de marcação que permanecem completamente **inertes** (invisíveis, sem carregar imagens ou executar scripts) até serem clonados e ativados via JavaScript.

```html title="Declaração do template no HTML"
<template id="card-template">
  <div class="card">
    <h3 class="card-title"></h3>
    <button class="btn-detalhes">Ver detalhes</button>
  </div>
</template>

<div id="container-cards"></div>
```

```js title="Clonando e populando o template no JavaScript"
const template = document.querySelector('#card-template');
const container = document.querySelector('#container-cards');

function criarCard(tituloText) {
  // Clona a estrutura interna do template (true indica clone profundo)
  const clone = template.content.cloneNode(true);

  // Popula os elementos do clone
  clone.querySelector('.card-title').textContent = tituloText;

  // Insere o clone na tela
  container.appendChild(clone);
}

criarCard('Projeto Alpha');
criarCard('Projeto Beta');
```

## Exercício

1. Qual a diferença de performance entre fazer `container.appendChild(el)` 50 vezes dentro de um laço vs adicionar os 50 elementos em um `DocumentFragment` e fazer uma única chamada?
2. Por que a tag `<template>` é considerada inerte antes de ser clonada?
3. Escreva um trecho de código que crie uma tag `<a>` com o texto "Ir para o topo" e a insira no início do `<body>` usando `insertAdjacentElement`.

<details>
  <summary>Possível resposta</summary>

  1. Fazer 50 inserções diretas no DOM causa 50 recálculos de layout (*reflows*) e renderizações (*repaints*), desacelerando a aplicação. O `DocumentFragment` armazena todos os elementos na memória e realiza apenas 1 reflow quando o fragmento é adicionado ao DOM.

  2. Porque o navegador lê a marcação do `<template>`, mas não a renderiza na tela, não carrega imagens nem executa scripts contidos nela até que o conteúdo seja clonado via `template.content.cloneNode(true)`.

  3. Inserindo no início do body:
     ```js
     const link = document.createElement('a');
     link.textContent = 'Ir para o topo';
     link.href = '#topo';
     document.body.insertAdjacentElement('afterbegin', link);
     ```
</details>

## Desafio

Crie uma função `renderizarTabela(dados)` que receba um array de objetos `{ id, produto, preco }` e utilize um `DocumentFragment` para construir e inserir as linhas `<tr>` em uma `<table>` existente no DOM.

<details>
  <summary>Possível resposta</summary>

  ```js
  function renderizarTabela(dados) {
    const tbody = document.querySelector('#tabela-produtos tbody');
    const fragmento = document.createDocumentFragment();

    dados.forEach(item => {
      const tr = document.createElement('tr');

      const tdId = document.createElement('td');
      tdId.textContent = item.id;

      const tdNome = document.createElement('td');
      tdNome.textContent = item.produto;

      const tdPreco = document.createElement('td');
      tdPreco.textContent = `R$ ${item.preco.toFixed(2)}`;

      tr.appendChild(tdId);
      tr.appendChild(tdNome);
      tr.appendChild(tdPreco);

      fragmento.appendChild(tr);
    });

    tbody.innerHTML = ''; // Limpa tabela anterior
    tbody.appendChild(fragmento); // Insere tudo com 1 único reflow
  }
  ```
</details>

## Perguntas de revisão

### Renderização e Fragmentos

1. **O que acontece com os nós filhos contidos em um `DocumentFragment` após ele ser adicionado a um nó do DOM com `appendChild(fragmento)`?**
   <details>
     <summary>Possível resposta</summary>
     Os nós filhos são movidos do fragmento para o nó destino no DOM. O `DocumentFragment` fica vazio.
   </details>

2. **Como remover um elemento do DOM utilizando a API moderna?**
   <details>
     <summary>Possível resposta</summary>
     Chamando diretamente o método `elemento.remove()`.
   </details>
