Quando o JavaScript é executado dentro de um navegador web, ele ganha acesso a um conjunto de interfaces nativas chamadas **Web APIs**. O ponto central dessa infraestrutura é o **Browser Object Model (BOM)**, que expõe o controle da janela, da URL, do histórico de navegação e do próprio documento HTML.

## Objetivo

Compreender a hierarquia do modelo de objetos do navegador, dominando as propriedades e métodos dos objetos globais `window`, `location`, `history`, `navigator` e `console` para manipular o comportamento da janela e obter informações do ambiente de execução.

---

## O Browser Object Model (BOM)

O **Browser Object Model** representa o ambiente fornecido pelo navegador. Ao contrário do ECMAScript puro (que trata apenas da linguagem), o BOM conecta o código JavaScript com a aba, a janela e o sistema do usuário.

No topo dessa hierarquia está o objeto global `window`. Tudo o que existe no escopo global do navegador — variáveis globais, funções nativas e outras Web APIs — é propriedade de `window`.

Como `window` é o objeto global implícito, você pode acessar suas propriedades diretamente sem digitar o prefixo `window.`. Por exemplo, `window.alert()` e `alert()` são idênticos.

## Objeto Window

O objeto `window` representa a janela ou aba aberta no navegador. Ele fornece dimensões de tela, controles de abertura de abas e diálogos nativos de interação.

### Dimensões da Janela

As propriedades `innerWidth` e `innerHeight` retornam a largura e a altura da área útil de exibição da página (viewport), em pixels, excluindo barras de ferramentas do navegador:

```js title="Obtendo dimensões do viewport"
const largura = window.innerWidth;
const altura = window.innerHeight;

console.log(`Viewport atual: ${largura}px x ${altura}px`);
```

### Diálogos Nativos

O navegador oferece três métodos síncronos para interagir diretamente com o usuário por meio de caixas de diálogo do sistema operacional:

```js title="Diálogos nativos do navegador"
// 1. Alerta simples de mensagem
window.alert("Operação realizada com sucesso!");

// 2. Confirmação booleana (retorna true ou false)
const confirmou = window.confirm("Deseja realmente excluir este registro?");
if (confirmou) {
  console.log("Usuário confirmou a exclusão.");
}

// 3. Entrada de texto (retorna a string digitada ou null se cancelado)
const nome = window.prompt("Qual é o seu nome?");
if (nome) {
  console.log(`Olá, ${nome}!`);
}
```

<Aside type="caution" title="Boas práticas com diálogos nativos">
Diálogos nativos como `alert()`, `confirm()` e `prompt()` bloqueiam a execução de todo o código JavaScript e a renderização da página até que o usuário responda. Em aplicações modernas, prefira modais construídos em HTML/CSS (ou o elemento `<dialog>`).
</Aside>

### Abertura e Fechamento de Janelas

Você pode abrir novas abas ou janelas através do método `open()`:

```js title="Navegação em nova janela"
// Abre a URL especificada em uma nova aba
const novaAba = window.open("https://developer.mozilla.org", "_blank");

// Fecha a aba que foi aberta via script (se permitido pelo navegador)
if (novaAba) {
  // novaAba.close();
}
```

## Objeto Location

O objeto `location` (ou `window.location`) contém informações detalhadas sobre a URL da página atual e permite realizar redirecionamentos e recarregamentos.

### Propriedades da URL

Considere a URL `https://exemplo.com:8080/produtos?categoria=livros#topo`:

| Propriedade | Valor Exemplo | Descrição |
| --- | --- | --- |
| `href` | `https://exemplo.com:8080/produtos?categoria=livros#topo` | URL completa |
| `protocol` | `https:` | Protocolo da requisição |
| `host` | `exemplo.com:8080` | Domínio e porta |
| `hostname` | `exemplo.com` | Nome do domínio sem a porta |
| `pathname` | `/produtos` | Caminho do recurso na servidor |
| `search` | `?categoria=livros` | Query string (parâmetros de busca) |
| `hash` | `#topo` | Âncora da página |

### Redirecionamento e Recarregamento

Para navegar programaticamente para uma nova página ou recarregar a página atual:

```js title="Redirecionando e recarregando"
// Redirecionamento direto modificando o href
location.href = "https://developer.mozilla.org";

// Redirecionamento gravando no histórico de navegação
location.assign("/nova-pagina");

// Redirecionamento substituindo a página atual (não permite voltar)
location.replace("/login");

// Recarrega a página atual
location.reload();
```

## Objeto History

O objeto `history` permite interagir com o histórico da aba atual, simulando os botões de avançar e voltar do navegador.

```js title="Navegação pelo histórico"
// Volta para a página anterior no histórico
history.back();

// Avança para a próxima página no histórico
history.forward();

// Desloca N páginas no histórico (negativo para voltar, positivo para avançar)
history.go(-2); // Volta duas páginas
```

<Aside type="tip" title="Single Page Applications (SPAs)">
A History API moderna também fornece os métodos `history.pushState()` e `history.replaceState()`, que alteram a URL exibida no navegador sem causar o recarregamento da página. Esse é o fundamento dos roteadores de bibliotecas como React Router.
</Aside>

## Objeto Navigator

O objeto `navigator` fornece informações sobre o navegador, a plataforma, o estado de conectividade e as permissões do dispositivo do usuário.

```js title="Consultando dados do navegador"
// String de identificação do navegador (User-Agent)
console.log(navigator.userAgent);

// Idioma preferencial do usuário
console.log(navigator.language); // ex: "pt-BR"

// Estado da conexão de rede (true se online)
if (navigator.onLine) {
  console.log("Conectado à internet");
} else {
  console.log("Sem conexão de rede");
}
```

## Objeto Console

O objeto `console` fornece acesso ao console de depuração do navegador. Além do conhecido `console.log()`, ele possui métodos valiosos para organização de logs:

```js title="Métodos avançados do console"
// Logs por nível de severidade
console.log("Mensagem informativa");
console.warn("Aviso: esta funcionalidade será descontinuada");
console.error("Erro ao processar a requisição");

// Exibição de arrays ou objetos em formato de tabela
const usuarios = [
  { id: 1, nome: "Ana", papel: "Admin" },
  { id: 2, nome: "Carlos", papel: "Editor" }
];
console.table(usuarios);

// Medição de tempo de execução
console.time("Processamento");
// ... código sendo medido ...
console.timeEnd("Processamento"); // Imprime: Processamento: X ms
```

## Exercício

Responda aos itens a seguir aplicando os conceitos dos objetos do BOM:

1. Qual a diferença prática entre redirecionar um usuário via `location.href = url` e via `location.replace(url)`?
2. Como obter os parâmetros de busca (`search`) de uma URL e ler o valor do parâmetro `categoria`?
3. Escreva um trecho de código que exiba um alerta caso o usuário esteja sem conexão com a internet (`navigator.onLine`).

<details>
  <summary>Possível resposta</summary>

  1. O `location.href` (ou `location.assign`) adiciona a nova página no histórico da aba, permitindo que o usuário clique no botão "Voltar". O `location.replace` substitui a página atual no histórico, impedindo que o usuário volte para a página anterior.

  2. Utilizando o construtor `URLSearchParams`:
     ```js
     const params = new URLSearchParams(window.location.search);
     const categoria = params.get('categoria');
     console.log(categoria);
     ```

  3. Verificação de status online/offline:
     ```js
     if (!navigator.onLine) {
       alert("Você está off-line! Verifique sua conexão de rede.");
     }
     ```
</details>

## Desafio

Crie uma função `medirTempoDeExecucao(fn)` que receba uma função qualquer como parâmetro, execute essa função e utilize os métodos `console.time()` e `console.timeEnd()` para imprimir no console quanto tempo em milissegundos a função levou para ser concluída.

<details>

  ```js
  function medirTempoDeExecucao(fn) {
    const label = `Execução de ${fn.name || 'função anônima'}`;

    fn();
    console.timeEnd(label);
  }

  // Exemplo de uso:
  medirTempoDeExecucao(function simularCarga() {
    let soma = 0;
    for (let i = 0; i < 1_000_000; i++) {
      soma += i;
    }
  });
  ```
</details>

## Cuidados com Server-Side Rendering (SSR)

Em frameworks modernos de renderização no servidor (*Server-Side Rendering*) como Next.js, Nuxt, SvelteKit e Astro, o código JavaScript da página executa primeiro no ambiente Node.js do servidor para gerar a estrutura HTML inicial.

<Aside type="caution" title="ReferenceError: window is not defined">
Como o ambiente Node.js no servidor não possui janela ou aba de navegador, o objeto `window` e seus filhos (`document`, `location`, `history`, `navigator`, `localStorage`) **não existem no servidor**.
</Aside>

Para evitar que o código quebre com `ReferenceError: window is not defined`, proteja o acesso a objetos do BOM verificando a existência de `window`:

```js title="Protegendo o acesso ao BOM em SSR"
// Forma 1: Guard condicional simples
if (typeof window !== 'undefined') {
  console.log('Largura da tela:', window.innerWidth);
  const userAgent = navigator.userAgent;
}

// Forma 2: Execução em Hooks no Cliente (ex: React / Next.js)
import { useEffect, useState } from 'react';

export function MeuComponente() {
  const [largura, setLargura] = useState(0);

  useEffect(() => {
    // useEffect roda estritamente no navegador após a hidratação (hydration)
    setLargura(window.innerWidth);
  }, []);

  return <div>Largura da tela: {largura}px</div>;
}
```

## Perguntas de revisão

### Objeto Window e BOM

1. **Por que variáveis declaradas com `var` no escopo global viram propriedades de `window`, mas variáveis declaradas com `let` ou `const` não?**
   <details>
     <summary>Possível resposta</summary>
     Declarações com `var` criam propriedades no objeto global (`window`). Já `let` e `const` criam variáveis no escopo de bloco global, pertencendo ao ambiente de declaração global, mas sem poluir as propriedades do objeto `window`.
   </details>

2. **Qual é o risco de utilizar diálogos nativos como `window.alert()` em aplicações em produção?**
   <details>
     <summary>Possível resposta</summary>
     Diálogos nativos bloqueiam a thread principal do navegador. Enquanto a caixa de diálogo estiver aberta, nenhum evento de cliques, timers ou animações será executado na página.
   </details>

### Objeto Location e History

3. **Qual propriedade do objeto `location` retorna apenas o caminho da URL após o nome do domínio?**
   <details>
     <summary>Possível resposta</summary>
     A propriedade `location.pathname`.
   </details>

4. **Como funciona o método `history.go(-1)`?**
   <details>
     <summary>Possível resposta</summary>
     O método `history.go(-1)` equivale a `history.back()`, fazendo o navegador voltar exatamente uma página no histórico da aba.
   </details>
