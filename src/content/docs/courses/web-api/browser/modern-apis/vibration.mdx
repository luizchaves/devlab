A **Vibration API** permite que aplicações Web forneçam feedback tátil (*haptic feedback*) ativando o motor de vibração físico de dispositivos móveis (smartphones e tablets). Ela é amplamente utilizada em jogos web, confirmações de ações importantes ou alertas de erro.

## Objetivo

Compreender o uso da Vibration API no navegador, dominando o disparo de pulsos simples, a definição de padrões complexos de vibração e pausa com arrays, e o tratamento de compatibilidade e restrições de permissão.

---

## O Método `navigator.vibrate`

O acesso à Vibration API é feito diretamente através do método `navigator.vibrate()`. Ele aceita um único valor numérico (duração em milissegundos) ou um array de números alternando durações de vibração e pausas.

| Sintaxe | Comportamento |
| --- | --- |
| `navigator.vibrate(200)` | Vibra continuamente por 200 milissegundos |
| `navigator.vibrate([100, 50, 200])` | Vibra por 100ms, pausa por 50ms e vibra por 200ms |
| `navigator.vibrate(0)` ou `navigator.vibrate([])` | Cancela imediatamente qualquer vibração em andamento |

## Exemplos Práticos

### 1. Feedback ao Clicar em um Botão (Pulso Curto)

```js title="Feedback de confirmação de toque"
const botaoConfirmar = document.querySelector('#btn-confirmar');

botaoConfirmar.addEventListener('click', () => {
  // Verifica se o dispositivo suporta a API
  if ('vibrate' in navigator) {
    // Pulso rápido de 50ms para simular sensação de clique físico
    navigator.vibrate(50);
  }
  console.log('Ação confirmada!');
});
```

### 2. Padrão de Erro ou Alerta (Múltiplos Pulsos)

```js title="Padrão de alerta de erro (3 pulsos rápidos)"
function notificarErro() {
  if ('vibrate' in navigator) {
    // Vibra 100ms, pausa 50ms, vibra 100ms, pausa 50ms, vibra 100ms
    navigator.vibrate([100, 50, 100, 50, 100]);
  }
}
```

<Aside type="caution" title="Gesto do Usuário e Dispositivos Desktop">
1. Por motivos de segurança e prevenção de abusos, os navegadores modernos só permitem acionar `navigator.vibrate()` como resposta a um **gesto explícito do usuário** (ex: clique ou toque).
2. Computadores de mesa (desktops) sem motor de vibração ignoram a chamada silenciosamente retornando `false`.
</Aside>

## Executando

Siga os passos abaixo para testar a Vibration API em um smartphone ou emulando no navegador:

<Steps>
1. Acesse sua página web a partir de um smartphone com suporte a vibração.
2. Abra o console das ferramentas de desenvolvedor (<kbd>F12</kbd>).
3. Execute o comando: `document.body.addEventListener('click', () => navigator.vibrate([200, 100, 200]));`.
4. Toque em qualquer lugar da tela e sinta os dois pulsos de vibração.
</Steps>

## Exercício

1. Escreva uma função `cancelarVibracao()` que interrompa imediatamente qualquer padrão de vibração em andamento no dispositivo.
2. Como verificar se o navegador do usuário possui suporte nativo à Vibration API antes de chamá-la?
3. O que acontece ao passar o array `[500, 200, 500]` para `navigator.vibrate()`?

<details>
  <summary>Possível resposta</summary>

  1. Função de cancelamento:
     ```js
     function cancelarVibracao() {
       if ('vibrate' in navigator) {
         navigator.vibrate(0); // ou navigator.vibrate([])
       }
     }
     ```

  2. Verificando a presença da propriedade na interface `navigator`:
     ```js
     if ('vibrate' in navigator) {
       // API suportada
     }
     ```

  3. O dispositivo vibrará por 500 milissegundos, fará uma pausa silenciosa por 200 milissegundos e vibrará novamente por mais 500 milissegundos.
</details>

## Desafio

Crie uma função `vibrarCodigoMorse(texto)` que converta a letra "S" (`...` três pulsos curtos de 50ms) e a letra "O" (`---` três pulsos longos de 200ms) em um array de vibrações executáveis pelo `navigator.vibrate()`.

<details>
  <summary>Possível resposta</summary>

  ```js
  function emitirSOS() {
    if (!('vibrate' in navigator)) return;

    // S: 3 curtos (50ms), O: 3 longos (200ms), S: 3 curtos (50ms)
    const padraoSOS = [
      // S (...)
      50, 50, 50, 50, 50, 200,
      // O (---)
      200, 50, 200, 50, 200, 200,
      // S (...)
      50, 50, 50, 50, 50
    ];

    navigator.vibrate(padraoSOS);
  }
  ```
</details>

## Perguntas de revisão

### Compatibilidade e Permissões

1. **O método `navigator.vibrate()` exige HTTPS ou contexto seguro?**
   <details>
     <summary>Possível resposta</summary>
     Embora funcione em HTTP para testes locais, navegadores modernos exigem que a vibração seja disparada exclusivamente após interação direta do usuário (eventos de clique/toque) e recomendam HTTPS para evitar rastreamento de hardware.
   </details>
