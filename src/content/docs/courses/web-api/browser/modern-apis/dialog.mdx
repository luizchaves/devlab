A **Dialog API** usa o elemento HTML `<dialog>` e a interface `HTMLDialogElement` para criar
diálogos controlados pelo navegador. Ela evita boa parte do modal artesanal porque o navegador já
cuida de foco, camada de fundo, fechamento e estado de abertura.

## Objetivo

Entender quando usar `<dialog>`, como abrir e fechar um diálogo modal, como recuperar o
`returnValue` e quais cuidados de acessibilidade e foco entram nesse tipo de interface.

## Modelo da API

O diálogo faz parte do HTML, mas ganha comportamento por JavaScript. Em vez de esconder e mostrar uma
`div`, o código chama métodos próprios do elemento.

| Recurso | Papel |
| --- | --- |
| `<dialog>` | Elemento HTML que representa a janela de diálogo |
| `dialog.show()` | Abre sem bloquear interação com o restante da página |
| `dialog.showModal()` | Abre como modal e torna o restante da página inerte |
| `dialog.close(valor)` | Fecha o diálogo e pode registrar um valor de retorno |
| `method="dialog"` | Permite fechar o diálogo pelo envio de um formulário interno |
| `cancel` e `close` | Eventos para interceptar cancelamento e reagir ao fechamento |

<Aside type="tip" title="Quando usar">
Use `<dialog>` para confirmação, edição curta, escolha rápida ou fluxo modal pequeno. Para uma página
inteira de cadastro, navegação normal costuma ser mais simples e acessível.
</Aside>

## Cuidados práticos

Nem todo modal precisa ser modal de verdade. Se o usuário precisa consultar o resto da página para
preencher algo, `show()` ou uma tela comum podem ser melhores do que `showModal()`.

| Situação | Cuidado |
| --- | --- |
| Confirmação destrutiva | Texto claro, botão de cancelar visível e foco previsível |
| Formulário dentro do diálogo | Use `method="dialog"` quando o envio não depende de servidor |
| Fechar com teclado | Trate o evento `cancel` se `Esc` não puder fechar naquele caso |
| Valor escolhido | Leia `dialog.returnValue` no evento `close` |

## Exercício

1. Adicione um segundo botão que abra o mesmo diálogo com uma mensagem diferente.
2. Registre no console o valor final de `dialog.returnValue`.
3. Crie uma validação que impeça o fechamento quando uma escolha obrigatória estiver vazia.

<details>
  <summary>Possível resposta</summary>

  O botão pode alterar o texto do diálogo antes de chamar `showModal()`. O evento `close` pode ler
  `dialog.returnValue`, e o evento `cancel` pode chamar `event.preventDefault()` quando o fechamento
  pelo teclado não for permitido naquele estado.
</details>
