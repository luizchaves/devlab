A **Canvas API** fornece uma área de desenho em bitmap. O HTML cria a superfície com `<canvas>`, e o
JavaScript desenha pixels usando um contexto, como `2d`.

## Objetivo

Compreender o canvas como superfície de pixels, usar o contexto 2D para desenhar formas e texto, e
diferenciar desenho imperativo em bitmap de elementos HTML comuns na árvore DOM.

## Modelo da API

Canvas não cria botões, parágrafos ou elementos clicáveis por desenho. Depois que uma linha é
desenhada, ela vira pixel; se o estado mudar, o programa precisa redesenhar.

| Recurso | Papel |
| --- | --- |
| `<canvas width height>` | Define a resolução interna do bitmap |
| `canvas.getContext('2d')` | Retorna a API de desenho 2D |
| `fillRect()` e `strokeRect()` | Desenham retângulos preenchidos ou contornados |
| `beginPath()`, `moveTo()`, `lineTo()` | Constroem caminhos e linhas |
| `arc()` | Desenha círculos e arcos |
| `fillText()` | Desenha texto como pixels |
| `requestAnimationFrame()` | Agenda animações sincronizadas com o navegador |

<Aside type="caution" title="Canvas não é DOM">
Um círculo desenhado no canvas não é um elemento selecionável por `querySelector`. Para detectar
cliques, você calcula coordenadas do mouse e compara com a geometria que seu código desenhou.
</Aside>

## Cuidados práticos

O tamanho visual do canvas em CSS pode ser diferente da resolução do bitmap. Quando isso acontece, o
desenho pode ficar esticado ou borrado.

| Situação | Cuidado |
| --- | --- |
| Canvas responsivo | Ajuste `width` e `height` internos, não apenas CSS |
| Tela de alta densidade | Considere `devicePixelRatio` para evitar desenho borrado |
| Animação | Limpe e redesenhe a cena a cada quadro |
| Acessibilidade | Forneça texto alternativo fora do canvas quando houver informação importante |

## Executando

<Steps>
1. Abra o preview e observe que a imagem não é composta por elementos HTML separados.
2. Altere uma cor ou coordenada no arquivo `canva.html`.
3. Recarregue a página e veja como o desenho muda.
4. Inspecione o DOM e confirme que as formas não aparecem como nós individuais.
</Steps>

## Exercício

1. Desenhe um retângulo adicional com cor diferente.
2. Adicione um texto no canto inferior do canvas.
3. Crie uma função `desenharCena()` que agrupe todos os comandos de desenho.

<details>
  <summary>Possível resposta</summary>

  A função `desenharCena()` deve receber o contexto 2D ou acessá-lo no escopo externo. Dentro dela,
  os comandos podem configurar `fillStyle`, chamar `fillRect()` e depois chamar `fillText()` para
  desenhar a legenda.
</details>
