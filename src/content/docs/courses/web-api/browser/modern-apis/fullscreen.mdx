A **Fullscreen API** permite apresentar um elemento ocupando a tela inteira. Ela é comum em vídeos,
jogos, apresentações e ferramentas visuais que precisam reduzir distrações da interface do navegador.

## Objetivo

Usar `requestFullscreen()` e `exitFullscreen()`, verificar `document.fullscreenElement` e entender
por que a entrada em tela cheia precisa estar ligada a uma ação explícita do usuário.

## Modelo da API

A API não cria uma nova janela. Ela muda o modo de apresentação de um elemento existente da página.

| Recurso | Papel |
| --- | --- |
| `element.requestFullscreen()` | Solicita tela cheia para um elemento |
| `document.exitFullscreen()` | Solicita saída da tela cheia |
| `document.fullscreenElement` | Indica qual elemento está em tela cheia |
| `document.fullscreenEnabled` | Indica se a funcionalidade está disponível |
| `fullscreenchange` | Evento disparado na entrada ou saída |
| `fullscreenerror` | Evento disparado quando a solicitação falha |

<Aside type="caution" title="Controle do usuário">
O usuário sempre pode sair da tela cheia pelo teclado ou pelo sistema. A interface deve continuar
fazendo sentido mesmo quando a página perde esse modo.
</Aside>

## Cuidados práticos

Fullscreen pode ser bloqueado por política de iframe ou por ausência de gesto do usuário.

| Situação | Cuidado |
| --- | --- |
| Preview em iframe | Abra em aba própria se o navegador bloquear |
| Botão de alternância | Leia `document.fullscreenElement` antes de decidir |
| Erro de solicitação | Trate a Promise rejeitada por `requestFullscreen()` |
| Layout em tela cheia | Use CSS para adaptar controles e tamanhos |

## Executando

<Steps>
1. Abra o exemplo `fullscreen.html`.
2. Clique no botão de tela cheia.
3. Saia com o botão da página ou com <kbd>Esc</kbd>.
4. Observe como o código usa `fullscreenElement` para saber o estado atual.
</Steps>

## Exercício

1. Adicione um contador visual que indique se a página está em tela cheia.
2. Registre `fullscreenchange` no console.
3. Mostre uma mensagem quando `fullscreenEnabled` for falso.

<details>
  <summary>Possível resposta</summary>

  O listener de `fullscreenchange` pode atualizar um texto com base em
  `document.fullscreenElement ? 'Tela cheia ativa' : 'Tela cheia inativa'`. A disponibilidade pode
  ser checada antes de habilitar o botão.
</details>
