O **Guia de Web APIs** cobre o que existe além da linguagem: as interfaces que o navegador
expõe para o JavaScript. Enquanto o [Guia de ECMAScript](../ecmascript/) trata da linguagem
em si, aqui o foco é o ambiente — `window`, `document`, o DOM, eventos, `localStorage` e as
APIs de rede.
