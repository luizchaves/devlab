O **Guia de Web APIs** estuda as interfaces nativas que o navegador disponibiliza para que o JavaScript interaja com a página, a rede, o armazenamento e os recursos do sistema operacional.

O [Guia de ECMAScript](../ecmascript/) ensina a sintaxe e a lógica da linguagem. Este guia explica o **ambiente de execução do navegador**. Uma aplicação web moderna nasce do encontro entre os dois: ECMAScript fornece a sintaxe, objetos e Promises; as Web APIs fornecem `window`, `document`, `fetch`, `localStorage`, `WebSocket`, eventos e sensores do dispositivo.

<Aside type="tip" title="Modelo Mental">
A linguagem JavaScript define *como* escrever a lógica; o navegador define *quais recursos do sistema* essa lógica pode acessar.
</Aside>

## Roteiro Sugerido de Estudos

<Steps>
1. **Fundamentos do Ambiente**: Comece por [Ciclo de Vida da Página](browser/lifecycle/) e [Objetos do Navegador](browser/objects/) para entender quando o código é executado e quais objetos globais existem.
2. **Navegação e Interface**: Explore a [History API](browser/history/) para navegação SPA e a [Dialog API](browser/modern-apis/dialog/) para modais nativos.
3. **DOM e Interatividade**: Domine a [Manipulação do DOM](dom/manipulation/), [Eventos](dom/events/) e [Elementos Dinâmicos](dom/dynamic-elements/).
4. **Armazenamento de Dados**: Estude [Local Storage](storage/local-storage/) e [Cookies](storage/cookies/) para gerenciar estados e sessões no cliente.
5. **Rede e Comunicação**: Consuma dados assíncronos com a [Fetch API](http/fetch/), comunique-se em tempo real com a [WebSockets API](http/websockets/) e aprenda sobre [CORS](http/cors/) e [REST API](http/rest/).
6. **Recursos do Dispositivo e Desempenho**: Experimente [Geolocation](browser/modern-apis/geolocation/), [Notifications](browser/modern-apis/notification/), [Vibration](browser/modern-apis/vibration/), [Observadores](browser/observers/) e [Web Workers](browser/workers/) para tarefas pesadas.
</Steps>

## Decisões Frequentes de Arquitetura

| Problema / Necessidade | API Indicada | Cuidados Principais |
| --- | --- | --- |
| Executar código após carregamento do HTML | `DOMContentLoaded`, `defer`, `type="module"` | Garantir que a árvore DOM já foi construída antes da consulta. |
| Alterar conteúdo, atributos e estilos | `document.querySelector`, `classList` | Verificar se o elemento consultado existe antes da manipulação. |
| Reagir a cliques, teclas e formulários | `addEventListener` | Tratar `preventDefault()` e vazamento de memória em listeners. |
| Navegação SPA sem recarregar a página | `history.pushState()`, `popstate` | Configurar o servidor para fallback de rotas (404/index.html). |
| Guardar preferências locais do usuário | `localStorage` | Serializar com `JSON.stringify()` e limitar dados não sensíveis. |
| Comunicação em tempo real full-duplex | `WebSocket` (`wss://`) | Gerenciar reconexões automáticas e serialização de mensagens. |
| Requisitar dados de um servidor HTTP | `fetch()` | `fetch()` não rejeita Promises para erros HTTP 404/500 (checar `res.ok`). |
| Notificar o usuário fora da aba | `Notification` | Requer protocolo `https://` e permissão prévia do usuário. |
| Feedback tátil em dispositivos móveis | `navigator.vibrate()` | Requer ação/gesto prévio do usuário e suporte do hardware. |
| Tratar cálculos pesados sem travar a UI | `Web Worker` | Código roda em thread separada; comunicação via `postMessage()`. |
