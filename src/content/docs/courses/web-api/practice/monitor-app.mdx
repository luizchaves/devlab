O **MonitorApp** é um projeto prático que demonstra a integração de múltiplas Web APIs: manipulação dinâmica do DOM, captura de eventos em formulários e modais, e persistência de dados no cliente utilizando a `localStorage` API.

Materiais: [slides do tópico](../../../../slides/courses/web-api/practice/monitor-app/) e [mapa mental](../../../../mindmaps/courses/web-api/practice/monitor-app/).

## Objetivo do Projeto

Analisar a arquitetura de uma aplicação JavaScript moderna desacoplada em módulos (serviços de armazenamento, utilitários DOM e componentes visuais de interface), praticando as quatro operações de um CRUD completo sem dependência de servidor back-end.

Ao estender componentes com auxílio de ferramentas de IA, preserve as boas práticas de manipulação segura de nós:

<Aside type="tip" title="Dica de IA: Mantenha a renderização de linhas com textContent ou nós seguros">
Ao pedir novas colunas ou ações para o `HostTableRow.js`, assistentes frequentemente voltam a concatenar strings diretamente com `innerHTML`. Prefira criar nós com `document.createElement('td')` e atribuir valores com `textContent` para proteger o DOM contra injeções.

**Prompt:** *"Adicione uma coluna de tempo de resposta à tabela gerando as células com `document.createElement()` e preenchendo os valores formatados com `textContent`."*
</Aside>

## Como Executar o Projeto?

<Steps>
1. Acesse o diretório do exemplo em `examples/courses/web-api/local-storage/monitor-app/`.
2. Instale as dependências executando no terminal:

   <PackageManagerTabs />
3. Inicie o servidor de desenvolvimento: `npm run dev`.
4. Abra o endereço `http://localhost:5173` no seu navegador.
5. Cadastre novos hosts, atualize seus dados e verifique os dados persistidos na aba **Application -> Local Storage** das ferramentas do desenvolvedor (<kbd>F12</kbd>).
</Steps>
