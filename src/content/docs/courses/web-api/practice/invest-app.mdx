O **InvestApp** é um projeto prático de nível intermediário que demonstra como construir uma aplicação front-end completa conectada a um serviço de back-end remoto via **Fetch API** assíncrona.

## Objetivo do Projeto

Estudar o isolamento do acesso à rede em um módulo de serviço (`storage.js`), consumindo endpoints RESTful para realizar operações de cadastro, listagem, edição e exclusão de investimentos em tempo real.

## Configuração de Variáveis de Ambiente

As credenciais do serviço de API são isoladas em um arquivo `.env`:

```ini title=".env.example"
VITE_APP_SUPABASE_URL=https://xyz.supabase.co/rest/v1
VITE_APP_SUPABASE_KEY=seu_token_anonimo_aqui
```

## Como Executar o Projeto?

<Steps>
1. Navegue até a pasta do exemplo em `examples/courses/web-api/fetch-api/invest-app/`.
2. Instale as dependências:

   <PackageManagerTabs />
3. Duplique o arquivo `.env.example` para `.env` e configure sua URL de API.
4. Inicie o servidor de desenvolvimento Vite: `npm run dev`.
5. Abra a aplicação no navegador e teste o envio e exclusão de investimentos contra a API.
</Steps>
