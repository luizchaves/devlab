O **Guia de Banco de Dados** cobre os fundamentos: o que é um SGBD, o modelo relacional e a
linguagem SQL. O acesso a esses dados **a partir de uma aplicação** — `node:sqlite`, Prisma,
migrations e relações — vive na trilha de persistência do
[Guia de Express.js](../express/), onde ele é aplicado a uma API real.
