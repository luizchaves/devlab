O **Guia de Banco de Dados** oferece uma formação completa nos fundamentos de persistência e gerenciamento de dados: desde o que é um SGBD, arquitetura e propriedades ACID, até o projeto conceitual e lógico (MER/DER), normalização até a 3FN e domínio da linguagem SQL (DDL, DML, JOINs e Agregações).

O acesso a esses dados **a partir de uma aplicação backend** — `node:sqlite`, Prisma ORM, migrations e relações — é detalhado na trilha de persistência do [Guia de Express.js](../expressjs/), onde os conceitos são integrados a uma API RESTful real.
