Este tópico apresenta os fundamentos da linguagem **SQL** (Structured Query Language). Você aprenderá a criar e alterar a estrutura de tabelas usando comandos **DDL** (*Data Definition Language*), aplicar restrições de integridade relacional e manipular os dados com os comandos **DML** (*Data Manipulation Language*) do CRUD.

---

## Objetivo

Dominar a sintaxe dos comandos DDL (`CREATE`, `ALTER`, `DROP`) e DML (`INSERT`, `SELECT`, `UPDATE`, `DELETE`), aplicando restrições de chave primária, chave estrangeira, valores únicos e paginação de consultas.

---

## Subdivisões da Linguagem SQL

A linguagem SQL é dividida em subconjuntos especializados de acordo com a finalidade de cada comando:

| Subconjunto | Sigla | Comandos Principais | Descrição Didática |
| :--- | :--- | :--- | :--- |
| **Data Definition Language** | DDL | `CREATE`, `ALTER`, `DROP` | Define e modifica a estrutura das tabelas e esquemas. |
| **Data Manipulation Language** | DML | `INSERT`, `UPDATE`, `DELETE` | Insere, altera e remove dados dentro das tabelas. |
| **Data Query Language** | DQL | `SELECT` | Consulta e recupera dados armazenados. |
| **Data Control Language** | DCL | `GRANT`, `REVOKE` | Administra permissões de acesso dos usuários. |
| **Transaction Control Language** | TCL | `COMMIT`, `ROLLBACK` | Gerencia a confirmação e cancelamento de transações. |

## DDL: Definindo Estruturas de Tabelas

Os comandos DDL operam sobre os metadados do banco. Usaremos o **SQLite** como motor relacional leve de referência.

### Criando Tabelas (`CREATE TABLE`)

Uma tabela representa uma entidade ou recurso da aplicação. A instrução a seguir especifica colunas, tipos e restrições de integridade:

```sql title="schema.sql" showLineNumbers {2,5}
CREATE TABLE User (
  id        INTEGER PRIMARY KEY AUTOINCREMENT,
  name      TEXT    NOT NULL,
  email     TEXT    NOT NULL UNIQUE,
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### Restrições de Integridade Relacional

As restrições (*constraints*) garantem a validade dos dados no próprio SGBD:

- `PRIMARY KEY`: Identifica unicamente cada linha de forma exclusiva.
- `NOT NULL`: Impede que a coluna receba valores nulos ou vazios.
- `UNIQUE`: Garante que não existam dois registros com o mesmo valor (ex: e-mail duplicado).
- `DEFAULT`: Atribui um valor padrão automático caso nenhum seja informado na inserção.
- `CHECK`: Valida se o valor atende a uma condição (ex: `age >= 18`).

### Relacionamentos e Chaves Estrangeiras

No modelo relacional, associamos duas tabelas através de uma **Chave Estrangeira (Foreign Key)**. No caso de um relacionamento 1:N entre `User` e `Post`:

```sql title="schema.sql" {6-7}
CREATE TABLE Post (
  id        INTEGER PRIMARY KEY AUTOINCREMENT,
  title     TEXT    NOT NULL,
  content   TEXT,
  published BOOLEAN DEFAULT 0,
  authorId  INTEGER NOT NULL,
  FOREIGN KEY (authorId) REFERENCES User(id) ON DELETE CASCADE
);
```

<Aside type="tip" title="Efeito do ON DELETE CASCADE">
  O parâmetro `ON DELETE CASCADE` garante que, ao excluir um registro pai na tabela `User`, todos os posts associados a esse autor sejam automaticamente apagados, prevenindo registros órfãos no banco.
</Aside>

### Alterando e Excluindo Tabelas (`ALTER` e `DROP`)

Para adicionar novas colunas a uma tabela existente ou excluí-la completamente:

```sql title="alter-drop.sql"
-- Adicionar uma nova coluna
ALTER TABLE User ADD COLUMN bio TEXT;

-- Excluir uma tabela permanentemente
DROP TABLE IF EXISTS Post;
```

## DML: Manipulando Dados (CRUD)

As quatro operações fundamentais do CRUD são mapeadas diretamente para comandos SQL:

```sql title="crud.sql"
-- 1. CREATE (Inserção de dados)
INSERT INTO User (name, email) VALUES ('Ana Silva', 'ana@example.com');

-- 2. READ (Consulta de dados)
SELECT * FROM User;
SELECT id, name FROM User WHERE id = 1;

-- 3. UPDATE (Atualização de dados)
UPDATE User SET name = 'Ana Maria Silva' WHERE id = 1;

-- 4. DELETE (Exclusão de dados)
DELETE FROM User WHERE id = 1;
```

<Aside type="caution" title="Cuidado: A Cláusula WHERE não é opcional">
  Executar `UPDATE User SET name = 'X';` ou `DELETE FROM User;` sem a cláusula `WHERE` alterará ou apagará **todas as linhas** da tabela sem confirmação prévia!
</Aside>

## Operadores de Filtragem no `WHERE`

Para realizar buscas precisas, a cláusula `WHERE` aceita diversos operadores lógicos e de comparação:

```sql title="filtros.sql"
-- Busca por padrão de texto (% representa qualquer sequência de caracteres)
SELECT * FROM User WHERE name LIKE 'Ana%';

-- Busca em uma lista de valores
SELECT * FROM User WHERE id IN (1, 3, 5);

-- Busca por intervalo numérico ou de datas
SELECT * FROM User WHERE id BETWEEN 10 AND 20;

-- Busca por valores nulos ou existentes
SELECT * FROM Post WHERE content IS NOT NULL;

-- Combinação de condições lógicas
SELECT * FROM Post WHERE published = 1 AND authorId = 2;
```

## Ordenação e Paginação

Em APIs RESTful, é essencial ordenar e paginar grandes volumes de dados antes de enviá-los ao cliente:

```sql title="ordenacao-paginacao.sql"
-- Ordenar resultados (ASC = Ascendente, DESC = Descendente)
SELECT * FROM User ORDER BY name ASC;

-- Paginação: Pular 20 registros e trazer os próximos 10
SELECT * FROM User ORDER BY createdAt DESC LIMIT 10 OFFSET 20;
```

- `LIMIT`: Define o número máximo de linhas retornadas.
- `OFFSET`: Especifica quantas linhas devem ser ignoradas antes de começar a retornar.

## Exercício

Considere a criação de um sistema de inventário de produtos.

1. Escreva o comando DDL para criar a tabela `Product` com colunas `id`, `name` (obrigatório), `price` (decimal positivo), e `categoryId` (chave estrangeira).
2. Escreva o comando DML para atualizar o preço em 10% de todos os produtos da categoria 2.

<details>
  <summary>Possível resposta</summary>

  1. **Comando DDL**:
     ```sql
     CREATE TABLE Product (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       name TEXT NOT NULL,
       price DECIMAL(10,2) CHECK (price >= 0),
       categoryId INTEGER NOT NULL,
       FOREIGN KEY (categoryId) REFERENCES Category(id)
     );
     ```

  2. **Comando DML**:
     ```sql
     UPDATE Product 
     SET price = price * 1.10 
     WHERE categoryId = 2;
     ```
</details>

## Perguntas de revisão

1. **Quais são os 5 subconjuntos da linguagem SQL?**
   <details><summary>Possível resposta</summary>DDL (Data Definition), DML (Data Manipulation), DQL (Data Query), DCL (Data Control) e TCL (Transaction Control).</details>

2. **Qual é a diferença entre os comandos `DROP` e `DELETE`?**
   <details><summary>Possível resposta</summary>`DROP` (DDL) remove a própria tabela e sua estrutura do banco. `DELETE` (DML) apaga apenas as linhas de dados mantendo a estrutura da tabela intacta.</details>

3. **O que garante a restrição `UNIQUE` em uma coluna?**
   <details><summary>Possível resposta</summary>Garante que nenhum valor seja duplicado naquela coluna entre as linhas da tabela.</details>

4. **Para que serve o operador `LIKE` em uma consulta SQL?**
   <details><summary>Possível resposta</summary>Para realizar buscas textuais por padrões flexíveis utilizando os caracteres curinga `%` e `_`.</details>

5. **Como funciona a paginação usando `LIMIT` e `OFFSET`?**
   <details><summary>Possível resposta</summary>`LIMIT` define a quantidade de registros a retornar e `OFFSET` indica quantos registros devem ser pulados do início.</details>

6. **O que acontece ao deletar um registro pai com a opção `ON DELETE CASCADE` configurada na chave estrangeira?**
   <details><summary>Possível resposta</summary>Todos os registros filhos vinculados àquele pai na tabela dependente serão automaticamente excluídos.</details>

7. **Qual é o operador SQL usado para verificar se um campo não possui valor atribuído?**
   <details><summary>Possível resposta</summary>O operador `IS NULL` (ou `IS NOT NULL`).</details>

8. **Qual comando DDL é utilizado para adicionar uma nova coluna em uma tabela existente?**
   <details><summary>Possível resposta</summary>O comando `ALTER TABLE nome_tabela ADD COLUMN nome_coluna tipo;`.</details>
