A primeira etapa de desenvolvimento do InvestBaaS concentra-se na construção da interface visual e no fluxo de navegação do usuário através de páginas HTML5 estáticas estilizadas com Tailwind CSS.

Essa abordagem permite prototipar rapidamente a experiência do usuário antes de acoplar as chamadas de API e os serviços BaaS do Supabase.

## Objetivo

Construir a camada de apresentação do InvestBaaS com layout moderno, componentes reutilizáveis e páginas especializadas para landing page, carteira, analytics, autenticação e administração.

## Dicas de IA

## Visão Geral da Carteira

A tela de carteira (`dashboard.html`) consolida o patrimônio total, o valor investido, os rendimentos acumulados e a lista de posições ativas.

A tabela de ativos categorizados exibe quantidade, preço médio, cotação atual e percentual de lucro de cada papel:

## Executando o Frontend

Para visualizar as telas do frontend estático em execução local, inicie o servidor de desenvolvimento.

Execute o comando a seguir:

```bash
cd examples/courses/npm/projects/investbaas-static
pnpm dev
```

Abra o navegador no endereço informado e navegue entre a landing page (`index.html`), carteira (`dashboard.html`) e tela de analytics (`analytics.html`).

## Exercício

Abra o arquivo `dashboard.html` e adicione uma nova linha na tabela de posições para representar uma cota de investimento em Fundo Imobiliário com badge `badge-fiis`.
