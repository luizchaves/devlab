O **Chart.js** é uma das bibliotecas JavaScript open-source mais populares e flexíveis para visualização de dados em aplicações web. Utilizando o elemento nativo `<canvas>` do HTML5 por baixo dos panos, o Chart.js renderiza gráficos responsivos, animados e altamente personalizáveis (linhas, barras, pizza, radar, entre outros).

## Objetivo

Aprender a instalar o Chart.js em uma aplicação web, integrar a renderização de gráficos com elementos `<canvas>`, formatar dados recebidos de APIs em tempo real e organizar componentes gráficos reutilizáveis em projetos de monitoramento.

---

## Arquitetura de Integração do Chart.js

O Chart.js consome dados do JavaScript e desenha o gráfico diretamente em um contexto 2D de Canvas no DOM:

<Mermaid title="Fluxo de Renderização de Gráficos com Chart.js">
{`
flowchart TD
  API["API / JSON Server (db.json)"] -- "Dados de Métricas (HTTP GET)" --> Fetch["JavaScript (main.js)"]
  Fetch -- "Formata Labels e Datasets" --> Config["Objeto de Configuração Chart.js"]
  Config -- "instancia new Chart(canvas, config)" --> Canvas["<canvas id='myChart'></canvas>"]
  Canvas -- "Desenha Gráfico Animado 2D" --> DOM["Tela do Usuário"]
`}
</Mermaid>

<Aside type="tip" title="Desempenho com HTML5 Canvas">
Como o Chart.js utiliza o elemento `<canvas>`, ele consegue renderizar milhares de pontos de dados com animações suaves de 60fps sem sobrecarregar a árvore DOM com centenas de nós HTML.
</Aside>

## Executando

Siga os passos para rodar a aplicação `Monitor-app` com gráficos:

<Steps>
1. Abra um terminal na pasta `monitor-app/back` e inicie o JSON Server: `npm run dev`.
2. Em outro terminal, abra a pasta `monitor-app/front` e inicie o Vite: `npm run dev`.
3. Acesse `http://localhost:5173/` para ver os gráficos de linha renderizados pelo Chart.js com os dados do banco.

## Exercício

1. Qual elemento HTML é necessário no DOM para que o Chart.js desenhe um gráfico?
2. Como podemos atualizar os dados de um gráfico Chart.js já existente na tela sem recriar a instância do zero?

<details>
  <summary>Possível resposta</summary>

  1. O elemento `<canvas>`.

  2. Alterando as propriedades de `chart.data.labels` ou `chart.data.datasets` e chamando o método `chart.update()`.
</details>

## Perguntas de revisão

1. **Quais são os dois pilares principais do objeto de configuração passado ao instanciar um `new Chart()`?**
   <details>
     <summary>Possível resposta</summary>
     O tipo do gráfico (`type: 'line'`, `'bar'`, `'pie'`, etc.) e o objeto `data` (contendo os rótulos do eixo X e o array de `datasets` com valores e cores).
   </details>

2. **Qual a importância de chamar `chart.destroy()` ao remover um gráfico da tela em aplicações monopágina (SPA)?**
   <details>
     <summary>Possível resposta</summary>
     Destruir a instância anterior evita vazamentos de memória (*memory leaks*) e impede que instâncias antigas continuem escutando eventos de redimensionamento na janela.
   </details>
