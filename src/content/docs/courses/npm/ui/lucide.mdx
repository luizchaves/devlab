Este tópico apresenta o **Lucide Icons**, uma biblioteca moderna e comunitária de ícones vetoriais SVG (evolução direta do Feather Icons) projetada para interfaces front-end limpas, escaláveis e acessíveis.

Ícones são elementos centrais na navegação e no feedback de qualquer aplicação web. No passado, interfaces dependiam de fontes de ícones (*icon fonts* como FontAwesome) ou sprites gigantescos de imagens, que sofriam com problemas de acessibilidade, renderização borrada e carregamento de centenas de glifos não utilizados. O Lucide resolve esses desafios entregando nós SVG nativos com suporte completo a *tree-shaking* e customização via CSS.

## Objetivo

Dominar o uso do pacote Lucide Icons no desenvolvimento front-end com JavaScript moderno, compreendendo as diferentes estratégias de importação e renderização de ícones SVG. Ao final do tópico, o leitor deve ser capaz de:

- Explicar as vantagens do SVG inline sobre fontes de ícones tradicionais (*icon fonts*).
- Instalar e configurar o pacote `lucide` em projetos front-end com Vite ou Vanilla JS.
- Utilizar a função `createIcons()` e atributos `data-lucide` para renderização dinâmica no DOM.
- Personalizar propriedades visuais dos ícones como dimensões, espessura de traço (*stroke width*) e cores.
- Aplicar padrões de acessibilidade (ARIA) para ícones informativos e puramente decorativos.

## O que é o Lucide?

O Lucide é um conjunto de mais de 1.400 ícones vetoriais desenhados sob uma grade consistente de 24x24 pixels, com traços limpos e geometria padronizada. Ele é distribuído em múltiplos pacotes para atender desde projetos em Vanilla JavaScript até frameworks como React, Vue e Svelte.

A tabela a seguir compara o Lucide com outras abordagens clássicas de iconografia no front-end:

| Estratégia | Formato final | Tamanho de carregamento | Acessibilidade | Customização CSS |
| :--- | :--- | :--- | :--- | :--- |
| **Lucide (SVG)** | Nós `<svg>` inline | Apenas os ícones usados | Excelente (`aria-hidden`, `<title>`) | Total (cor, traço, animação) |
| **Fontes de Ícones** | Fonte web (.woff2) | Pacote com todos os glifos | Frágil para leitores de tela | Limitada à cor do texto |
| **Imagens estáticas** | `<img>` (.png / .svg) | Múltiplas requisições HTTP | Média (depende do `alt`) | Não permite alterar cor do traço |

A adoção do Lucide garante que a aplicação carregue apenas os bytes dos ícones realmente utilizados na tela, mantendo a nitidez visual independente da densidade de pixels do monitor do usuário.

## Fundamentos e Modelo Mental

No Vanilla JavaScript e em aplicações SPA com empacotadores modernos, o Lucide opera substituindo marcadores de posição no HTML por árvores de elementos SVG completas.

O diagrama a seguir representa o ciclo de vida da renderização de ícones em uma página:

Ao delegar a renderização para nós SVG vetoriais, o navegador renderiza as formas geométricas com aceleração de hardware e permite transições suaves de cor e escala via CSS.

## Como Usar: Instalação e Configuração

O Lucide é distribuído no registro npm sob o pacote oficial `lucide`. Em projetos que utilizam Vite ou outro empacotador ESM, a instalação é direta.

Execute o comando no terminal do seu projeto:

```bash title="Terminal"
npm install lucide
```

Após a instalação, existem duas formas principais de importar e utilizar os ícones no seu código:

### Método 1: Importação Seletiva e `createIcons` (Recomendado)

A importação seletiva aproveita o mecanismo de *tree-shaking*, garantindo que apenas os ícones importados façam parte do pacote final distribuído para produção:

```js title="src/main.js"
import { createIcons, CheckCircle2, AlertTriangle, Trash2 } from 'lucide';

// Inicializa os ícones no documento
createIcons({
  icons: {
    CheckCircle2,
    AlertTriangle,
    Trash2,
  },
  attrs: {
    'stroke-width': 2,
    width: 20,
    height: 20,
  },
});
```

### Método 2: Obtenção de String SVG ou Nós Nativos

Quando você precisa criar um elemento dinamicamente em uma função de renderização ou template literal, o Lucide disponibiliza funções que geram o SVG diretamente:

```js title="src/components/button.js"
import { createElement, Plus } from 'lucide';

export function createAddButton(label) {
  const button = document.createElement('button');
  button.className = 'btn-primary';
  
  // Cria o elemento SVG nativo do ícone Plus
  const iconElement = createElement(Plus);
  
  button.appendChild(iconElement);
  button.appendChild(document.createTextNode(` ${label}`));
  return button;
}
```

## Sintaxe e Principais Recursos

O Lucide permite customizar globalmente ou individualmente as propriedades visuais de cada ícone através de atributos HTML ou opções no JavaScript.

A tabela a seguir descreve os principais atributos de customização aceitos:

| Atributo / Propriedade | Valor padrão | Descrição |
| :--- | :--- | :--- |
| `data-lucide` | Nome do ícone | Nome do ícone em kebab-case (ex: `shopping-cart`, `bell`). |
| `stroke-width` | `2` | Espessura da linha do traço (ex: `1.5`, `2`, `2.5`). |
| `color` | `currentColor` | Cor do traço. Por padrão, herda a cor do texto do elemento pai. |
| `width` e `height` | `24` | Dimensões em pixels do elemento SVG gerado. |
| `stroke-linecap` | `round` | Formato das extremidades dos traços. |
| `stroke-linejoin` | `round` | Formato dos cantos onde duas linhas se encontram. |

O exemplo a seguir ilustra a declaração de ícones no HTML com diferentes níveis de customização:

```html title="index.html"
<!-- Ícone padrão herdando tamanho e cor -->
<i data-lucide="bell"></i>

<!-- Ícone customizado com atributos locais -->
<i data-lucide="trash-2" stroke-width="1.5" color="#e11d48" width="28" height="28"></i>

<!-- Ícone com classe CSS para estilização externa -->
<i data-lucide="check-circle" class="icon-success"></i>
```

## Exemplo Prático no Front-end

O exemplo a seguir implementa uma barra de navegação responsiva com botões de ação e estados interativos (como alternar entre modo claro e escuro ou visualizar itens no carrinho).

O arquivo HTML define os botões e marcadores de ícones com rótulos acessíveis:

```html title="index.html"
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8" />
    <title>Barra de Ações com Lucide Icons</title>
    <link rel="stylesheet" href="./style.css" />
  </head>
  <body>
    <header class="app-header">
      <div class="logo">
        <i data-lucide="box" class="brand-icon"></i>
        <span>DevLab Store</span>
      </div>

      <nav class="actions-nav">
        <button id="btn-theme" class="icon-btn" aria-label="Alternar tema">
          <i data-lucide="sun"></i>
        </button>
        <button id="btn-notifications" class="icon-btn" aria-label="Ver notificações">
          <i data-lucide="bell"></i>
          <span class="badge">3</span>
        </button>
        <button id="btn-cart" class="btn-primary">
          <i data-lucide="shopping-bag"></i>
          <span>Carrinho</span>
        </button>
      </nav>
    </header>

    <script type="module" src="./main.js"></script>
  </body>
</html>
```

O arquivo JavaScript importa os ícones específicos, inicializa o Lucide e adiciona interatividade para re-renderizar ícones dinamicamente ao alternar o tema:

```js title="src/main.js"
import { createIcons, Box, Sun, Moon, Bell, ShoppingBag } from 'lucide';

// Lista de ícones permitidos para a aplicação
const availableIcons = {
  Box,
  Sun,
  Moon,
  Bell,
  ShoppingBag,
};

function renderAppIcons() {
  createIcons({
    icons: availableIcons,
    attrs: {
      'stroke-width': 2,
    },
  });
}

// Inicializa na carga da página
renderAppIcons();

// Alternância dinâmica de ícone ao clicar no tema
const themeButton = document.getElementById('btn-theme');
let isDarkMode = false;

themeButton.addEventListener('click', () => {
  isDarkMode = !isDarkMode;
  const iconContainer = themeButton.querySelector('i');
  
  // Atualiza o atributo data-lucide e regenera os nós SVG
  iconContainer.setAttribute('data-lucide', isDarkMode ? 'moon' : 'sun');
  renderAppIcons();
});
```

## Boas Práticas e Acessibilidade

O uso de ícones exige atenção para não comprometer a experiência de usuários que utilizam tecnologias assistivas como leitores de tela.

A tabela abaixo resume as regras indispensáveis de acessibilidade e desempenho:

| Prática | Como implementar | Motivo |
| :--- | :--- | :--- |
| **Ícones puramente decorativos** | Adicione `aria-hidden="true"` no elemento do ícone. | Evita que leitores de tela tentem vocalizar caracteres desconhecidos. |
| **Botões compostos apenas por ícone** | Forneça `aria-label="Descrição da ação"` no elemento `<button>`. | Permite que usuários com deficiência visual saibam a função do botão. |
| **Importação pontual (*Tree-shaking*)** | Importe `{ Home, User } from 'lucide'` em vez do pacote inteiro. | Mantém o *bundle* leve e exclui mais de 1.300 ícones não utilizados. |
| **Herança de cor (`currentColor`)** | Use `color="currentColor"` e defina a cor via propriedade CSS `color`. | Garante consistência visual e facilita transições de hover e foco. |

<Aside type="caution" title="Dica de IA: Cuidado com re-renderização em loops">
  Assistentes costumam sugerir invocar `createIcons()` dentro de loops intensos de renderização de listas no DOM. Como o `createIcons()` varre todo o documento, isso causa quedas de performance.

  **Prompt:** *"Refatore a renderização dinâmica abaixo para gerar os ícones com `createElement(IconName)` individualmente por item, em vez de re-executar `createIcons()` em todo o documento."*
</Aside>

## Exercício

Crie um componente de lista de tarefas (*Todo List*) no qual cada item possua um ícone de status dinâmico:

1. Se a tarefa estiver pendente, exiba o ícone `circle`.
2. Se a tarefa estiver concluída, exiba o ícone `check-circle-2` com cor verde.
3. Cada item deve conter um botão de exclusão com o ícone `trash-2` e atributo `aria-label="Excluir tarefa"`.

<details>
  <summary>Possível resposta</summary>

  ```js title="Solução do exercício"
  import { createIcons, Circle, CheckCircle2, Trash2 } from 'lucide';

  const icons = { Circle, CheckCircle2, Trash2 };

  export function renderTasks(tasks, container) {
    container.innerHTML = tasks
      .map(
        (task) => `
      <li class="task-item ${task.completed ? 'is-done' : ''}">
        <span class="status-icon">
          <i data-lucide="${task.completed ? 'check-circle-2' : 'circle'}" 
             color="${task.completed ? '#16a34a' : 'currentColor'}"></i>
        </span>
        <span class="title">${task.title}</span>
        <button class="delete-btn" aria-label="Excluir tarefa ${task.title}">
          <i data-lucide="trash-2"></i>
        </button>
      </li>
    `
      )
      .join('');

    createIcons({ icons });
  }
  ```
</details>

## Desafio

Construa um componente de acordeão (*Accordion*) com seções expansíveis. Ao clicar no cabeçalho de uma seção, ela se expande e o ícone de chevron deve girar 180 graus suavemente utilizando transições CSS sobre o elemento SVG gerado pelo Lucide.

<details>
  <summary>Possível resposta</summary>

  ```html title="Solução do desafio (HTML + CSS + JS)"
  <style>
    .accordion-header {
      display: flex;
      justify-content: space-between;
      align-items: center;
      width: 100%;
      padding: 12px 16px;
      cursor: pointer;
    }
    .accordion-header svg {
      transition: transform 0.3s ease;
    }
    .accordion-item.open .accordion-header svg {
      transform: rotate(180deg);
    }
    .accordion-content {
      display: none;
      padding: 16px;
    }
    .accordion-item.open .accordion-content {
      display: block;
    }
  </style>

  <div class="accordion-item" id="item-1">
    <button class="accordion-header" aria-expanded="false">
      <span>O que é o Lucide Icons?</span>
      <i data-lucide="chevron-down"></i>
    </button>
    <div class="accordion-content">
      <p>O Lucide é uma biblioteca moderna de ícones vetoriais SVG para front-end.</p>
    </div>
  </div>

  <script type="module">
    import { createIcons, ChevronDown } from 'lucide';
    createIcons({ icons: { ChevronDown } });

    document.querySelectorAll('.accordion-header').forEach((btn) => {
      btn.addEventListener('click', () => {
        const item = btn.closest('.accordion-item');
        const isOpen = item.classList.toggle('open');
        btn.setAttribute('aria-expanded', String(isOpen));
      });
    });
  </script>
  ```
</details>

## Perguntas de revisão

Responda às questões abaixo para verificar a fixação dos conceitos:

1. **Por que ícones em SVG inline são superiores a fontes de ícones (*icon fonts*)?**
   <details>
     <summary>Possível resposta</summary>
     Porque suportam *tree-shaking* (carregando apenas os ícones usados), oferecem controle total de estilo via CSS (traço, preenchimento), garantem nitidez perfeita em qualquer resolução e proporcionam acessibilidade robusta.
   </details>

2. **Como o atributo `currentColor` facilita a estilização de ícones?**
   <details>
     <summary>Possível resposta</summary>
     Ele faz com que o ícone herde automaticamente a cor do texto definida no elemento pai (`color`), simplificando estados de hover, foco e temas claro/escuro sem necessidade de classes SVG específicas.
   </details>

3. **Qual atributo deve ser inserido em botões que contêm apenas um ícone visual sem texto?**
   <details>
     <summary>Possível resposta</summary>
     O atributo `aria-label="..."` no botão, fornecendo a descrição textual da ação para leitores de tela.
   </details>

4. **Qual é o papel da função `createIcons()` do Lucide?**
   <details>
     <summary>Possível resposta</summary>
     Varrer o DOM em busca de elementos marcadores (como `<i data-lucide="..."></i>`) e substituí-los pelos respectivos elementos `<svg>` vetoriais configurados.
   </details>
