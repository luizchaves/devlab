O **Guia de Pacotes npm** cobre o ecossistema de pacotes do JavaScript em duas camadas: o **gerenciador** em si, com `package.json`, versionamento, *lockfile*, scripts e `npx`, e os **pacotes de apoio** que ampliam uma aplicação web moderna, como ferramentas de compilação (*build tools*), APIs falsas para prototipagem (*mock APIs*), clientes HTTP, bibliotecas de gráficos e serviços de *Backend as a Service* (BaaS).

O recorte é deliberado: cada linguagem tem o seu gerenciador e o seu registro de pacotes, e misturá-los em um guia único apagaria as diferenças que importam. Aqui o assunto é o **npm**, o registro `npmjs.com` e o que se instala a partir dele. Em Python, o assunto equivalente é tratado na aula de [uv](../python/tools/uv/), do Guia de Python.

Enquanto o [Guia de ECMAScript](../ecmascript/) cobre a linguagem e o [Guia de Web APIs](../web-api/) trata do navegador nativo, este guia ensina a gerenciar dependências e a integrar ferramentas do registro npm em projetos reais.

<Aside type="tip" title="Modelo Mental">
Pacotes e bibliotecas não substituem o conhecimento fundamental da linguagem; eles abstraem tarefas complexas (como bundling, serialização, autenticação e gráficos) para que você foque nas regras de negócio da aplicação.
</Aside>

## Roteiro Sugerido de Estudos

<Steps>
1. **Ambiente de Build**: Comece por [Vite](build/vite/) para aprender a estruturar um projeto com servidor local e minificação.
2. **Prototipagem de Backend**: Use o [JSON Server](mock/json-server/) para simular um banco de dados e rotas REST sem escrever código no servidor.
3. **Consumo de APIs**: Domine o [Axios](http/axios/) para realizar chamadas assíncronas com tratamento global de erros e interceptores.
4. **Visualização de Dados**: Integre o [Chart.js](ui/chartjs/) para exibir relatórios e dashboards com gráficos interativos.
5. **Aplicações na Nuvem (BaaS)**: Explore [Supabase Client](baas/supabase-client/) e [Cloud Firestore](baas/firebase-firestore/) para persistência real de dados e autenticação de usuários sem gerenciar servidores.
</Steps>

## Decisões Frequentes de Pacotes

| Necessidade do Projeto | Pacote Recomendado | Vantagem Principal |
| --- | --- | --- |
| Criar projeto front-end moderno rápido | **Vite** | HMR instantâneo usando módulos ES nativos (*ESM*). |
| Testar front-end sem API pronta no backend | **JSON Server** | Transforma um arquivo `db.json` em rotas REST completas. |
| Fazer chamadas HTTP com interceptores | **Axios** | Trata exceções HTTP 4xx/5xx e permite injetar Tokens JWT via interceptores. |
| Exibir relatórios gráficos na tela | **Chart.js** | Gráficos responsivos renderizados em HTML5 Canvas. |
| Banco de dados Postgres e Auth serverless | **Supabase** | Backend open-source com PostgreSQL e cliente JS reativo. |
| Banco NoSQL em tempo real e Auth | **Firebase** | Firestore com sincronização em tempo real e SDK de autenticação. |
