Este tópico apresenta os fundamentos da sintaxe em HTML: como funcionam elementos, tags, atributos, entidades de caracteres e a estrutura padrão de um documento HTML5.

## Objetivo

Dominar as regras de sintaxe do HTML, reconhecer a diferença entre elementos normais e vazios (autofechados), utilizar atributos e entidades, e estruturar um documento completo com `<!DOCTYPE html>`, `<html>`, `<head>` e `<body>`.

## Sintaxe do HTML

HTML (*HyperText Markup Language*) utiliza etiquetas chamadas **tags** para marcar o conteúdo e indicar ao navegador como ele deve ser estruturado.

A sintaxe é pequena: praticamente tudo que você vai escrever se resume a elementos,
atributos e entidades. Vale conhecer bem essas três peças antes de sair decorando nomes
de tags. Com elas, qualquer elemento novo que aparecer já faz sentido à primeira vista.

### Elementos e tags

Um elemento é a unidade básica da marcação: ele envolve um trecho de conteúdo e declara o
que aquele trecho significa. As tags são as marcas que delimitam esse envelope no arquivo
de texto.

```plaintext title="Anatomia de um elemento"
 tag de                    tag de
abertura     conteúdo    fechamento
   ┌┴┐┌────────────────┐┌─┴─┐
   <p>Lorem ipsum dolor.</p>
   └────────────────────────┘
           elemento
```

- **Tag de abertura** (`<p>`): Indica o início do elemento.
- **Conteúdo**: O texto ou outros elementos aninhados.
- **Tag de fechamento** (`</p>`): Indica o término do elemento (contém a barra `/`).

Alguns elementos não têm conteúdo e por isso não têm tag de fechamento. São os
**elementos vazios** (*void elements*):

```html title="Elementos vazios"
<meta charset="utf-8" />
<img src="logo.svg" alt="Logotipo" />
<br />
<hr />
```

Elementos se aninham, e a ordem de fechamento importa:

```html title="Aninhamento" del={2} ins={5}
<!-- errado: as tags se cruzam -->
<p>Um texto <strong>importante</p></strong>

<!-- certo: o que abre por último fecha primeiro -->
<p>Um texto <strong>importante</strong></p>
```

<Aside type="tip" title="Escolha pelo significado, não pela aparência">
  `<strong>` e `<b>` deixam o texto em negrito, mas só `<strong>` comunica
  *importância* para o leitor de tela, para o buscador e para quem lê o código.
  A aparência é responsabilidade do CSS.
</Aside>

### Atributos

Se o elemento diz *o que* o conteúdo é, os atributos ajustam *como* ele se comporta: o
destino de um link, o arquivo de uma imagem, o idioma de um trecho. Eles são escritos
dentro da tag de abertura, sempre em pares de nome e valor.

```plaintext title="Formato de um atributo"
        atributo (nome="valor")
      ┌──────────┴──────────┐
<img src="logo.svg" alt="Logotipo" />
```

```html title="Elemento com atributos"
<a href="https://devlab.ifpb.edu.br" target="_blank" rel="noopener">Acessar DevLab</a>
```

- **`href`**: Especifica o destino do hiperlink.
- **`target="_blank"`**: Solicita a abertura da página em uma nova aba.
- **`rel="noopener"`**: Boas práticas de segurança ao abrir novos contextos.

Alguns atributos valem para qualquer elemento (**globais**), outros são específicos:

| Tipo         | Exemplos                                                  |
| ------------ | --------------------------------------------------------- |
| Globais      | `id`, `class`, `lang`, `title`, `style`, `hidden`, `data-*` |
| `<a>`        | `href`, `target`, `rel`, `download`                        |
| `<img>`      | `src`, `alt`, `width`, `height`, `loading`                 |
| `<meta>`     | `name`, `content`, `charset`                               |
| `<ol>`       | `start`, `type`, `reversed`                                |
| `<th>`       | `scope`, `colspan`, `rowspan`                              |

<Aside type="tip" title="Atributos Globais">
  Alguns atributos podem ser aplicados em praticamente qualquer elemento HTML, como `id` (identificador único), `class` (classe CSS para estilização/seleção), `style` (estilos inline) e `title` (dica de ferramenta ao passar o mouse).
</Aside>

### Entidades HTML

Alguns caracteres são reservados pela própria sintaxe do HTML (como `<` e `>`). Para
exibi-los como texto puro, utilizamos **entidades de caracteres**, que podem ser escritas
pelo nome ou pelo número:

| Caractere | Descrição                             | Nome      | Número     |
| --------- | ------------------------------------- | --------- | ---------- |
| `<`       | menor que (*less-than*)               | `&lt;`    | `&#60;`    |
| `>`       | maior que (*greater-than*)            | `&gt;`    | `&#62;`    |
| `&`       | e comercial (*ampersand*)             | `&amp;`   | `&#38;`    |
| `"`       | aspas duplas                          | `&quot;`  | `&#34;`    |
| `'`       | apóstrofo                             | `&apos;`  | `&#39;`    |
| `©`       | copyright                             | `&copy;`  | `&#169;`   |
| Espaço    | espaço inquebrável (*non-breaking*)   | `&nbsp;`  | `&#160;`   |

Lista completa: [Named character references | WHATWG](https://html.spec.whatwg.org/multipage/named-characters.html).

### Comentários

Comentários em HTML são escritos entre `<!--` e `-->`. O navegador não renderiza esse
texto na página; ele serve para deixar notas no código ou explicar uma parte da marcação.
Como comentários continuam visíveis no código fonte e no DevTools, não coloque senhas,
tokens ou dados sensíveis neles.

```html title="Comentário em HTML"
<!-- Conteúdo principal da página -->
<main>
  <h1>Olá, turma!</h1>
</main>
```

## Estrutura de um Documento HTML

Todo documento HTML5 deve seguir uma estrutura hierárquica padronizada.

O diagrama a seguir ilustra a árvore de elementos (*DOM Tree*) gerada a partir da estrutura base de um documento HTML:

<Mermaid title="Árvore Hierárquica de um Documento HTML (DOM Base)">
{`
flowchart TD
  DOC["<!DOCTYPE html>"] --> HTML["html (lang='pt-BR')"]
  HTML --> HEAD["head"]
  HTML --> BODY["body"]
  HEAD --> META["meta (charset='UTF-8')"]
  HEAD --> TITLE["title (Título da Aba)"]
  BODY --> MAIN["main (Conteúdo Principal)"]
`}
</Mermaid>

```html title="Estrutura mínima de um documento HTML5"
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha Página - DevLab</title>
  </head>
  <body>
    <h1>Primeiro Título</h1>
    <p>Bem-vindo ao estudo de HTML!</p>
  </body>
</html>
```

- **`<!DOCTYPE html>`**: Declaração obrigatória na primeira linha para informar ao navegador que o documento utiliza a especificação HTML5.
- **`<html lang="pt-BR">`**: Elemento raiz que envolve todo o documento. O atributo `lang` indica o idioma principal da página (essencial para leitores de tela e SEO).
- **`<head>`**: Contém metadados não exibidos diretamente no corpo da página (como charset, título da aba e links para folhas de estilo CSS).
- **`<body>`**: Contém todo o conteúdo visível da aplicação (títulos, parágrafos, imagens, formulários).

Linha a linha, o que a parte marcada faz:

| Linha                  | Papel                                                         |
| ---------------------- | ------------------------------------------------------------- |
| `<!DOCTYPE html>`      | Declara HTML5 e evita o modo de compatibilidade do navegador   |
| `<html lang="pt-BR">`  | Idioma do documento, usado por leitores de tela e tradutores   |
| `<head>`               | Metadados sobre a página, que não aparecem no corpo renderizado |
| `<meta charset="UTF-8" />` | Codificação; sem ela, acentos podem quebrar                |
| `<title>`              | Nome da aba do navegador                                      |
| `<body>`               | Conteúdo que aparece na página                                |
| `<h1>`                 | Título principal do documento                                 |
| `<p>`                  | Parágrafo de texto                                            |
| `&copy;`               | Entidade HTML que mostra o símbolo ©                          |

<Aside type="caution" title="`<head>` e `<body>` têm papéis distintos">
  O `<head>` guarda **metadados**: informação sobre a página, que não aparece nela.
  Só o que está no `<body>` é renderizado.
</Aside>

## Executando

<Steps>

1. Crie um arquivo chamado `index.html` em seu computador:

   ```html title="index.html"
   <!DOCTYPE html>
   <html lang="pt-BR">
     <head>
       <meta charset="UTF-8">
       <title>Página de Teste</title>
     </head>
     <body>
       <h1>Minha Primeira Página</h1>
       <p>Estrutura criada com HTML5 puro.</p>
     </body>
   </html>
   ```

2. Abra o arquivo diretamente em seu navegador (clique duplo no arquivo ou aperte <kbd>Ctrl</kbd> + <kbd>O</kbd> no navegador).

3. Inspecione os elementos abrindo o **DevTools** do navegador com a tecla <kbd>F12</kbd>.

</Steps>

## Perguntas de revisão

**1. Qual é a função da instrução `<!DOCTYPE html>` no início do arquivo?**

<details>
  <summary>Possível resposta</summary>

  Instruir o navegador a renderizar o documento no modo padrão de conformidade da especificação HTML5 (*standards mode*).
</details>

**2. Qual é a diferença entre os elementos `<head>` e `<body>`?**

<details>
  <summary>Possível resposta</summary>

  O `<head>` guarda metadados, títulos de aba, links para CSS e scripts de configuração. O `<body>` guarda todo o conteúdo visível para o usuário na janela do navegador.
</details>

**3. O que são elementos vazios (*void elements*) e quais são seus exemplos?**

<details>
  <summary>Possível resposta</summary>

  São elementos que não contêm conteúdo de texto nem tag de fechamento. Exemplos: `<img>`, `<input>`, `<br>`, `<hr>`, `<meta>`.
</details>

**4. Por que HTML é uma linguagem de marcação e não uma linguagem de programação?**

<details>
  <summary>Possível resposta</summary>

  HTML não executa lógica nem toma decisões. Ele marca o conteúdo e informa ao
  navegador o papel de cada parte da página, como título, parágrafo, lista, link,
  imagem ou tabela.
</details>
