Esta aula apresenta os elementos essenciais para estruturar conteúdos de texto em HTML: a hierarquia de cabeçalhos (`<h1>` a `<h6>`), marcação de parágrafos, ênfases semânticas, listas (ordenadas, não-ordenadas e de definição) e hiperlinks com o elemento `<a>`.

## Objetivo

Compreender e aplicar a hierarquia correta de títulos, utilizar marcações de ênfase semântica (`<strong>` e `<em>`), construir listas de itens e criar conexões de hipertexto entre páginas com o elemento `<a>`.

## Conteúdo de Texto

O HTML oferece tags para categorizar a importância e o significado de cada trecho de texto.

### Cabeçalhos (`<h1>` a `<h6>`)

Os cabeçalhos definem a hierarquia de tópicos da página. `<h1>` representa o título mais importante (geralmente único por página) e `<h6>` o de menor nível.

```html title="Hierarquia de cabeçalhos"
<h1>Título Principal da Página (H1)</h1>
<h2>Seção Secundária (H2)</h2>
<h3>Subseção do Tópico (H3)</h3>
```

<Aside type="caution" title="Não Escolha Cabeçalhos pelo Tamanho Visual">
  Não escolha uma tag `<h3>` apenas porque ela tem um tamanho de fonte menor. Use CSS para alterar o tamanho das letras e mantenha os cabeçalhos fiéis à hierarquia do documento (`h1` -> `h2` -> `h3`).
</Aside>

### Parágrafos e Formatação de Texto

- **`<p>`**: Define um parágrafo de texto corrido.
- **`<strong>`**: Indica alta importância ou urgência (exibido em negrito por padrão).
- **`<em>`**: Indica ênfase no significado do texto (exibido em itálico por padrão).
- **`<mark>`**: Destaca um trecho relevante para o contexto atual.
- **`<code>`**: Representa um trecho de código de computador em fonte monoespaçada.

```html title="Exemplo de marcação de texto"
<p>
  O estudo de <strong>HTML5</strong> é <em>essencial</em> para quem deseja desenvolver para a Web.
</p>
<p>
  Para instalar o projeto, execute o comando <code>pnpm install</code> no terminal.
</p>
```

## Listas em HTML

HTML suporta três tipos de listas estruturadas:

### 1. Listas Não-Ordenadas (`<ul>`)

Utilizadas quando a ordem dos itens não altera o significado (exibidas com marcadores de ponto):

```html title="Lista de compras (Não-ordenada)"
<ul>
  <li>Café</li>
  <li>Leite</li>
  <li>Pão de queijo</li>
</ul>
```

### 2. Listas Ordenadas (`<ol>`)

Utilizadas quando a sequência dos passos importa (exibidas com numeração sequencial):

```html title="Passo a passo (Ordenada)"
<ol>
  <li>Escreva o arquivo HTML.</li>
  <li>Salve com a extensão .html.</li>
  <li>Abra no navegador.</li>
</ol>
```

### 3. Listas de Definição (`<dl>`)

Utilizadas para dicionários, termos e conceitos (combinação de `<dt>` para o termo e `<dd>` para a descrição):

```html title="Lista de termos"
<dl>
  <dt>HTML</dt>
  <dd>Linguagem de marcação para estrutura de páginas Web.</dd>
  <dt>CSS</dt>
  <dd>Folhas de estilo para apresentação e layout visual.</dd>
</dl>
```

## Hiperlinks (`<a>`)

O hiperlink é o elemento fundador da Web (*HyperText*). Ele conecta documentos através do elemento `<a>` (*anchor*) e do atributo `href`.

```html title="Exemplos de hiperlinks"
<!-- Link externo -->
<a href="https://developer.mozilla.org" target="_blank" rel="noopener">Documentação MDN</a>

<!-- Link interno relativo -->
<a href="../semantic-structure/">Ver Aula de Semântica</a>

<!-- Link de e-mail -->
<a href="mailto:contato@ifpb.edu.br">Enviar E-mail</a>
```

## Executando

<Steps>

1. Crie um arquivo `content.html`:

   ```html title="content.html"
   <!DOCTYPE html>
   <html lang="pt-BR">
     <head>
       <meta charset="UTF-8">
       <title>Texto e Links</title>
     </head>
     <body>
       <h1>Guia DevLab</h1>
       <p>Confira os recursos <strong>gratuitos</strong>:</p>
       <ul>
         <li><a href="https://devlab.ifpb.edu.br">DevLab Portal</a></li>
       </ul>
     </body>
   </html>
   ```

2. Abra o arquivo no navegador e teste o clique no link.

</Steps>

3. No outro tópico, insira um hiperlink abrindo o site do W3C em uma nova aba (`target="_blank"`).

  ```html title="exercise_text.html"
      </p>
    </body>
  </html>
  ```
</details>

## Perguntas de revisão

**1. Qual é a diferença semântica entre `<b>` e `<strong>`?**

<details>
  <summary>Possível resposta</summary>

  `<b>` aplica apenas estilo visual negrito sem adicionar importância extra. `<strong>` indica alta importância semântica no texto, lida com ênfase por leitores de tela.
</details>

**2. Quando devemos usar `<ol>` em vez de `<ul>`?**

<details>
  <summary>Possível resposta</summary>

  Usamos `<ol>` quando a sequência dos itens possui ordem lógica relevante (como em um algoritmo ou receita). Usamos `<ul>` quando a ordem não altera o sentido.
</details>
