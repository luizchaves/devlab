Este tópico apresenta os elementos de mídia visual e exibição de dados tabulares em HTML: o elemento `<img>`, o atributo de acessibilidade `alt`, o agrupamento de figuras com `<figure>` e a criação de tabelas estruturadas.

## Objetivo

Inserir imagens de forma acessível e responsiva, utilizar `<figure>` e `<figcaption>` para associar legendas, e construir tabelas organizadas com `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`.

## Imagens em HTML (`<img>`)

O elemento `<img>` é um elemento vazio (*void element*) utilizado para incorporar imagens em uma página Web.

```html title="Inclusão de Imagem Acessível"
<img src="logo.png" alt="Logotipo do projeto DevLab em azul e branco" width="300" height="100">
```

### Principais Atributos de `<img>`

- **`src`** (*source*): Caminho relativo ou URL absoluta para o arquivo de imagem (`.jpg`, `.png`, `.svg`, `.webp`).
- **`alt`** (*alternative text*): Descrição em texto da imagem. **Obrigatório para acessibilidade** e SEO (lido por leitores de tela quando a imagem não pode ser carregada).
- **`width` e `height`**: Dimensões da imagem em pixels. Definir estes atributos previne *Cumulative Layout Shift* (CLS) durante o carregamento.

<Aside type="caution" title="Nunca Omita o Atributo `alt`">
  Se uma imagem for puramente decorativa e não agregar conteúdo ao texto, mantenha o atributo `alt=""` vazio (`alt=""`). Omitir o atributo totalmente faz com que leitores de tela leiam o caminho do arquivo de imagem (`src`), prejudicando a experiência do usuário.
</Aside>

### Agrupando Figuras com Legendas (`<figure>` e `<figcaption>`)

Para associar uma legenda explicativa a uma imagem ou diagrama, utilizamos a combinação dos elementos `<figure>` e `<figcaption>`:

```html title="Imagem com Legenda Semântica"
<figure>
  <img src="arch.png" alt="Diagrama da arquitetura MVC mostrando Model, View e Controller">
  <figcaption>Figura 1: Arquitetura em camadas do padrão MVC.</figcaption>
</figure>
```

### Exemplo completo

```html title="Sintaxe"
<img src="url" alt="texto alternativo" />
```

O `alt` não é opcional:

- descreva **a função** da imagem, não o arquivo (`"Logotipo do IFPB"`, não `"logo.png"`);
- se a imagem é puramente decorativa, use `alt=""`, assim o leitor de tela a ignora;
- omitir o atributo faz o leitor narrar o nome do arquivo, que raramente ajuda.

O exemplo usa estas tags de imagem:

| Tag            | Papel no conteúdo                                                     |
| -------------- | --------------------------------------------------------------------- |
| `<img>`        | Insere uma imagem no documento. Precisa de `src` e `alt`              |
| `<figure>`     | Agrupa uma imagem com conteúdo relacionado, como uma legenda          |
| `<figcaption>` | Escreve a legenda da figura. Deve ficar dentro de um `<figure>`       |

Declarar `width` e `height` reserva o espaço antes de a imagem carregar e evita que o
texto "pule" durante o carregamento.

Também escolha arquivos com tamanho próximo ao tamanho exibido na página. Se a
imagem aparece com `160` por `90` pixels, carregar uma foto de `4000` por `2250`
pixels desperdiça dados, memória e tempo de carregamento. O CSS pode reduzir a
imagem visualmente, mas o navegador ainda precisa baixar o arquivo original.

Imagens podem ser vetoriais ou matriciais:

| Tipo       | Como funciona                                                         | Extensões comuns          | Uso comum                                      |
| ---------- | --------------------------------------------------------------------- | ------------------------- | ---------------------------------------------- |
| Vetorial   | Descreve formas, linhas e cores. Pode aumentar sem perder nitidez     | `.svg`                    | Logotipos, ícones, diagramas e ilustrações     |
| Matricial  | Guarda uma grade de pixels. Perde nitidez quando aumenta demais       | `.jpg`, `.png`, `.webp`   | Fotos, capturas de tela e imagens com textura  |

<Aside type="tip" title="SVG também pode ser HTML">
  SVG também pode ser escrito diretamente no HTML, usando a tag `<svg>`. Nesse caso,
  ele deixa de ser apenas um arquivo carregado por `<img>` e passa a fazer parte da
  estrutura da página.
</Aside>

O `src` também pode receber uma imagem embutida em uma **Data URI**, também chamada
de **data URL**. Em SVG, os caracteres costumam aparecer codificados por URL:

```html title="Imagem vetorial codificada"
<img
  src="data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20160%2090'%3E%3Crect%20width='160'%20height='90'%20fill='%230ea5e9'/%3E%3Ctext%20x='80'%20y='52'%20text-anchor='middle'%20font-size='24'%20fill='white'%3EHTML%3C/text%3E%3C/svg%3E"
  alt="Retângulo azul com o texto HTML"
  width="160"
  height="90"
/>
```

Uma imagem matricial também pode ser embutida em uma **Data URI**, normalmente com
PNG em base64:

```html title="Imagem matricial codificada"
<img
  src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAQAAAAECAYAAACp8Z5+AAAACXBIWXMAAAPoAAAD6AG1e1JrAAAAEklEQVQImWPgW/ryPzJmIF0AAHE3KbGj+UTXAAAAAElFTkSuQmCC"
  alt="Quadrado azul"
  width="16"
  height="16"
/>
```

Nos dois casos, os dados da imagem ficam escritos dentro do próprio atributo `src`.
Os termos mais comuns para isso são **Data URI**, **data URL**, **URL encoded**
quando os caracteres são codificados por URL, e **base64** quando os bytes do
arquivo são transformados em texto. Isso é útil para exemplos pequenos, mas não
substitui arquivos reais em imagens maiores.

<Aside type="tip" title="Geradores de Data URI">
  Existem ferramentas, inclusive online, que convertem arquivos de imagem para
  Data URI automaticamente. Elas ajudam em testes e exemplos pequenos, mas use com
  cuidado em páginas reais para não deixar o HTML pesado demais.
</Aside>

## Tabelas Estruturadas (`<table>`)

Tabelas são utilizadas exclusivamente para exibir dados bidimensionais organizados em linhas e colunas (como planilhas, relatórios ou dados financeiros).

<Aside type="caution" title="Não Use Tabelas para Criar Layouts de Páginas">
  No passado, tabelas eram usadas para posicionar colunas e menus em sites. Hoje, o layout visual deve ser feito exclusivamente com CSS (Flexbox / Grid). Tabelas em HTML servem apenas para dados tabulares.
</Aside>

### Estrutura Semântica de uma Tabela

```html title="Tabela Estruturada Completa"
<table>
  <caption>Tabela 1: Desempenho dos Alunos no Módulo de HTML</caption>
  <thead>
    <tr>
      <th>Matrícula</th>
      <th>Nome</th>
      <th>Nota</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>202601</td>
      <td>Ana Souza</td>
      <td>9.5</td>
    </tr>
    <tr>
      <td>202602</td>
      <td>Carlos Lima</td>
      <td>8.0</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">Média da Turma</td>
      <td>8.75</td>
    </tr>
  </tfoot>
</table>
```

| Elemento | Descrição e Papel Semântico |
| :--- | :--- |
| **`<table>`** | Contêiner principal da tabela. |
| **`<caption>`** | Título acessível que descreve o conteúdo da tabela. |
| **`<thead>`** | Bloco do cabeçalho da tabela. |
| **`<tbody>`** | Bloco do corpo da tabela contendo os dados. |
| **`<tfoot>`** | Bloco de rodapé (usado para totais ou somatórios). |
| **`<tr>`** | Linha da tabela (*table row*). |
| **`<th>`** | Célula de cabeçalho (*table header*), exibida em negrito por padrão. |
| **`<td>`** | Célula de dado (*table data*). |

`<th scope="col">` e `<th scope="row">` dizem qual célula é cabeçalho de qual eixo.
É assim que um leitor de tela consegue anunciar "Linguagem: Python, Utilização: 51%"
ao navegar pela tabela. O exemplo usa estas tags de tabela:

| Tag         | Papel no conteúdo                                                     |
| ----------- | --------------------------------------------------------------------- |
| `<table>`   | Define a tabela                                                        |
| `<caption>` | Dá um título ou resumo curto para a tabela                             |
| `<thead>`   | Agrupa as linhas de cabeçalho                                          |
| `<tbody>`   | Agrupa as linhas principais de dados                                   |
| `<tr>`      | Cria uma linha                                                         |
| `<th>`      | Cria uma célula de cabeçalho, para coluna ou linha                     |
| `<td>`      | Cria uma célula comum de dados                                         |

<Aside type="caution" title="Aparência da tabela">
  Neste exemplo, `border="1"` deixa a tabela visível enquanto ainda não usamos CSS.
  Você ainda pode encontrar HTML antigo com atributos como `border`, `width`,
  `cellpadding`, `cellspacing` e `bgcolor`. Em projetos atuais, largura, borda,
  colapso de bordas e cor de fundo devem ir para o CSS, com propriedades como
  `width`, `border`, `border-collapse` e `background-color`.
</Aside>

## Perguntas de revisão

**1. Para que serve o atributo `alt` em uma imagem?**

<details>
  <summary>Possível resposta</summary>

  Fornecer um texto alternativo descritivo para leitores de tela (acessibilidade) e ser exibido caso a imagem falhe ao carregar ou o usuário esteja em uma conexão lenta.
</details>

**2. Qual é a função dos elementos `<thead>` e `<tbody>` em uma tabela?**

<details>
  <summary>Possível resposta</summary>

  Dividir semanticamente o cabeçalho de títulos da tabela (`<thead>`) das linhas de dados do conteúdo (`<tbody>`), permitindo melhor acessibilidade e estilização independente.
</details>

**3. Por que `alt`, `width` e `height` são importantes em imagens?**

<details>
  <summary>Possível resposta</summary>

  `alt` descreve a função da imagem quando ela não pode ser vista ou carregada.
  `width` e `height` reservam o espaço antes do carregamento e evitam que o layout
  pule. Usar arquivos com tamanho próximo ao exibido também melhora a performance.
</details>

**4. Para que servem `<th scope="col">` e `<th scope="row">` em tabelas?**

<details>
  <summary>Possível resposta</summary>

  Eles indicam se uma célula de cabeçalho vale para uma coluna ou para uma linha.
  Isso ajuda leitores de tela a relacionar cada dado com o cabeçalho correto.
</details>
