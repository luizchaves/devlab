O **Guia de HTML** é um material de referência técnica para a linguagem de marcação fundamental da Web (HTML5). Ele cobre desde as origens da Web e sintaxe básica de marcação até a construção de documentos estruturados, elementos semânticos para acessibilidade (a11y) e formulários completos.
