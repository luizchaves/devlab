O **Guia de Node.js** trata do ambiente que executa JavaScript fora do navegador: como rodar
arquivos, organizar módulos, gerenciar dependências com npm e subir um servidor HTTP sem
framework. A linguagem em si está no [Guia de ECMAScript](../ecmascript/); aqui o foco é o
runtime e suas APIs.
