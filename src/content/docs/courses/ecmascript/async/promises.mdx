O JavaScript possui modelo assíncrono baseado em Event Loop e Promises.

## Sintaxe Async/Await (ES2017)

Permite escrever código assíncrono com aparência síncrona:

```javascript
async function buscarDados() {
  try {
    const resposta = await fetch("https://api.example.com/data");
    const dados = await resposta.json();
    return dados;
  } catch (erro) {
    console.error("Erro ao buscar:", erro);
  }
}
```

## Resumo e Boas Práticas

- Use `async/await` com blocos `try/catch` para legibilidade.
- Utilize `Promise.all()` para operações assíncronas paralelas independentes.
