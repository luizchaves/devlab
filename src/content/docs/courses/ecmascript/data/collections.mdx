O ES6 introduziu coleções especializadas para dicionários (`Map`) e conjuntos (`Set`).

## Set (Conjunto de Valores Únicos)

```javascript
const tags = new Set(["JS", "HTML", "JS", "CSS"]);
console.log(tags.size); // 3 (Removeu duplicatas!)

// Remoção rápida de duplicatas em um Array
const arraySemDuplicatas = [...new Set([1, 2, 2, 3])]; // [1, 2, 3]
```

## Map vs Object

- `Map` aceita qualquer tipo de chave (objetos, funções, números).
- `Map` mantém a ordem exata de inserção e possui a propriedade `.size`.

## Resumo e Boas Práticas

- Use `Set` quando precisar armazenar elementos únicos.
- Use `Map` quando precisar de chaves complexas (não-string).
