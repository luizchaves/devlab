Objetos são coleções de pares chave-valor. No ECMAScript, a herança é baseada em **Protótipos**.

## Desestruturação e Spread (ES6)

```javascript
const usuario = { id: 1, nome: "Ana", funcao: "Dev" };

// Desestruturação
const { nome, funcao } = usuario;
console.log(nome, funcao); // Ana Dev

// Clone com Spread
const usuarioAtualizado = { ...usuario, ativo: true };
```

## Resumo e Boas Práticas

- Use a sintaxe de desestruturação para extrair propriedades de forma limpa.
- Entenda que métodos nativos de objetos vêm de `Object.prototype`.
