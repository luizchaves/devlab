Arrays são listas ordenadas de valores. No JavaScript moderno, métodos funcionais imutáveis são a abordagem recomendada para transformação de dados.

## Principais Métodos de Iteração

- **`map()`**: Transforma cada elemento e retorna um novo array do mesmo tamanho.
- **`filter()`**: Filtra os elementos mantendo apenas os que satisfazem a condição.
- **`reduce()`**: Reduz o array a um único valor acumulado.
- **`find()`**: Retorna o primeiro elemento que satisfaz a condição.

```javascript
const numeros = [1, 2, 3, 4, 5];

// Encadeamento funcional imutável
const resultado = numeros
  .filter(n => n % 2 !== 0) // [1, 3, 5]
  .map(n => n * 10)         // [10, 30, 50]
  .reduce((acc, n) => acc + n, 0); // 90

console.log("Resultado final:", resultado);
```

## Resumo e Boas Práticas

- Prefira métodos que não mutam o array original (`map`, `filter`, `concat`).
- Utilize a sintaxe Spread (`[...array]`) para criar cópias de arrays.
