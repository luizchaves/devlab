Strings representam sequências de caracteres de texto imutáveis no ECMAScript.

## Template Literals (ES6)

Utilizam crases (`` ` ``) para permitir interpolação de expressões `${expressao}` e strings multilinha sem concatenação manual:

```javascript
const produto = "Notebook";
const preco = 4500;

// Interpolação limpa
const resumo = `Produto: ${produto} | Preço com imposto: R$ ${(preco * 1.1).toFixed(2)}`;
console.log(resumo);
```

## Métodos Úteis de String

- **Busca**: `includes()`, `startsWith()`, `endsWith()`.
- **Fatiamento**: `slice(inicio, fim)`, `substring()`.
- **Transformação**: `toLowerCase()`, `toUpperCase()`, `trim()`, `replace()`, `replaceAll()`.

## Resumo e Boas Práticas

- Strings são **imutáveis**: métodos sempre retornam uma nova string.
- Use Template Literals para formar textos complexos e interpolar variáveis.
