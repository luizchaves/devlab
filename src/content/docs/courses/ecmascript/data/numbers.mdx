No JavaScript, o tipo `number` é representado pelo padrão IEEE 754 de precisão dupla (64-bit float).

## Imprecisão de Ponto Flutuante

```javascript
console.log(0.1 + 0.2); // 0.30000000000000004!

// Solução para formatação financeira
const total = (0.1 + 0.2).toFixed(2); // "0.30"
```

## BigInt (ES2020)

Para números inteiros maiores que `Number.MAX_SAFE_INTEGER` ($2^{53} - 1$), utiliza-se o sufixo `n`:

```javascript
const inteiroGigante = 9007199254740991n + 2n;
console.log(typeof inteiroGigante, inteiroGigante); // bigint 9007199254740993n
```

## Resumo e Boas Práticas

- Use `toFixed()` ou converta para centavos inteiros ao lidar com moedas.
- Use `BigInt` quando precisar ultrapassar $9 	imes 10^{15}$.
