Módulos organizam o código em arquivos isolados com escopo próprio.

## Export & Import

```javascript
// math.js (Exportação Nomeada)
export const SOMAR = (a, b) => a + b;

// app.js (Importação)
import { SOMAR } from "./math.js";
console.log(SOMAR(10, 20));
```

## Resumo e Boas Práticas

- Prefira exportações nomeadas para facilitar o autocomplete na IDE.
- Use Módulos ES (`type: "module"`) como padrão moderno.
