Funções no ECMAScript são cidadãs de primeira classe (*first-class citizens*).

## Arrow Functions (ES6)

Possuem sintaxe concisa e não possuem seu próprio binding para a palavra-chave `this` ( herdam o `this` lexical):

```javascript
// Arrow Function concisa
const somar = (a, b = 0) => a + b;

// Closures (Função que lembra de seu escopo lexical)
function criarContador() {
  let contador = 0;
  return () => ++contador;
}

const incrementar = criarContador();
console.log(incrementar()); // 1
console.log(incrementar()); // 2
```

## Resumo e Boas Práticas

- Use Arrow Functions para callbacks e funções curtas.
- Entenda que **Closures** permitem manter estado privado.
