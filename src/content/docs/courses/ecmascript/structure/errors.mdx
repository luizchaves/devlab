Tratamento de erros previne a interrupção abrupta da execução da aplicação.

## Bloco `try...catch...finally`

```javascript
function validarIdade(idade) {
  if (idade < 0) {
    throw new Error("A idade não pode ser negativa.");
  }
  return true;
}

try {
  validarIdade(-5);
} catch (erro) {
  console.error("Capturado:", erro.message);
} finally {
  console.log("Executado sempre.");
}
```

## Resumo e Boas Práticas

- Lance erros explicativos utilizando `throw new Error()`.
- Trate exceções na camada correta para dar feedback ao usuário.
