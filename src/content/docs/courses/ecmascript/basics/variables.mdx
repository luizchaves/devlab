Variáveis são identificadores associados a locais de memória. No ES6+, a declaração de variáveis ganhou regras estritas de escopo de bloco e controle de mutabilidade através das palavras-chave `let` e `const`.

## Objetivo

Dominar o gerenciamento de identificadores no JavaScript:

- Diferenciar o comportamento de `var`, `let` e `const`.
- Compreender os níveis de escopo: **Global**, **Função** e **Bloco (`{}`)**.
- Entender o fenômeno do **Hoisting** (elevação de declarações).
- Identificar o funcionamento da **Temporal Dead Zone (TDZ)**.

## Comparativo de Palavras-Chave

| Característica | `var` | `let` | `const` |
| :--- | :--- | :--- | :--- |
| **Escopo** | Função / Global | Bloco (`{}`) | Bloco (`{}`) |
| **Hoisting** | Sim (`undefined`) | Sim (fica na TDZ) | Sim (fica na TDZ) |
| **Reatribuição** | Permitida | Permitida | Erro de Tipo (`TypeError`) |
| **Redeclaração** | Permitida | Erro de Sintaxe | Erro de Sintaxe |

<Aside type="caution" title="Regra de Ouro do ES6+">
  Por padrão, declare todas as variáveis com **`const`**. Se for necessário reatribuir o valor posteriormente (como contadores em laços), utilize **`let`**. Não utilize `var` em código moderno.
</Aside>

## Exemplo Prático Completo

```javascript
const TAXA = 0.1; // Reatribuição bloqueada

function calcularDesconto(valor) {
  let resultado = 0; // Escopo de função
  
  if (valor > 100) {
    const desconto = 20; // Válido apenas dentro do bloco IF
    resultado = (valor - desconto) * (1 - TAXA);
  } else {
    resultado = valor * (1 - TAXA);
  }
  
  return resultado;
}

console.log("Resultado:", calcularDesconto(150));
```

## Resumo e Boas Práticas

- `const` impede a reatribuição do identificador.
- `let` possui escopo de bloco e não permite redeclaração.
- Respeite o isolamento de escopo para evitar vazamentos de memória e colisão de nomes.
