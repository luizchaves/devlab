Operadores realizam comparações, operações matemáticas e decisões lógicas no código.

## Comparação Estrita (`===`)

- **`==` (Igualdade Solta)**: Realiza conversão implícita de tipo. Ex: `0 == ""` é `true`. (Evitar!)
- **`===` (Igualdade Estrita)**: Compara valor e tipo sem conversões. Ex: `0 === ""` é `false`. (Usar sempre!)

## Operadores Modernos ES2020+

<Tabs>
  <TabItem label="Nullish Coalescing (??)">
    Retorna o valor da direita APENAS se a esquerda for `null` ou `undefined`.
    ```javascript
    const estoque = 0;
    const qtd1 = estoque || 10; // 10 (0 é falsy)
    const qtd2 = estoque ?? 10; // 0 (Preserva o 0!)
    ```
  </TabItem>
  <TabItem label="Optional Chaining (?.)">
    Acessa propriedades encadeadas com segurança contra `null` ou `undefined`.
    ```javascript
    const cliente = { endereco: null };
    console.log(cliente.endereco?.rua); // undefined (sem TypeError)
    ```
  </TabItem>
</Tabs>

## Resumo e Boas Práticas

- Use sempre `===` e `!==`.
- Use `??` para valores padrões que aceitem `0` ou `""`.
- Use `?.` para navegação segura em objetos.
