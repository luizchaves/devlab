Estruturas de controle direcionam o fluxo de execução de um programa.

## Laços de Repetição Modernos

- **`for...of`** (ES6): Percorre os **valores** de elementos iteráveis (Arrays, Strings, Maps, Sets).
- **`for...in`**: Percorre as **chaves/propriedades** de um objeto.

```javascript
const frutas = ["Maçã", "Banana", "Uva"];

// Iterando sobre VALORES
for (const fruta of frutas) {
  console.log("Fruta:", fruta);
}

// Iterando sobre PROPRIEDADES de objeto
const config = { tema: "dark", porta: 3000 };
for (const chave in config) {
  console.log(`${chave}: ${config[chave]}`);
}
```

## Resumo e Boas Práticas

- Prefira `for...of` para Arrays.
- Evite laços infinitos garantindo a atualização das condições de saída.
