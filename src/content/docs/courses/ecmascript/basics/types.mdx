O ECMAScript possui 7 tipos primitivos imutáveis e 1 tipo complexo de referência (Objeto).

## Os 7 Tipos Primitivos

1. **`string`**: Texto.
2. **`number`**: Números inteiros e decimais (IEEE 754).
3. **`boolean`**: `true` ou `false`.
4. **`undefined`**: Ausência de valor atribuído.
5. **`null`**: Ausência intencional de valor de objeto.
6. **`symbol`**: Identificador único imutável.
7. **`bigint`**: Números inteiros de precisão arbitrária.

## Operador `typeof` e Coerção

| Expressão | Retorno | Categoria |
| :--- | :--- | :--- |
| `typeof "Texto"` | `"string"` | Primitivo |
| `typeof 42` | `"number"` | Primitivo |
| `typeof true` | `"boolean"` | Primitivo |
| `typeof undefined` | `"undefined"` | Primitivo |
| `typeof null` | `"object"` | Bug histórico do JS |
| `typeof {}` | `"object"` | Objeto |
| `typeof []` | `"object"` | Array (Objeto) |

<Aside type="caution" title="Coerção Implícita">
  O operador `+` com string realiza **concatenação**: `"5" + 2` resulta em `"52"`. Já a subtração `-` realiza **conversão numérica**: `"5" - 2` resulta em `3`.
</Aside>

## Exemplo Prático Completo

```javascript
// Conversões Explícitas (Recomendado)
const inputTexto = "123.45";
const numero = Number(inputTexto);
const texto = String(numero);
const estaAtivo = Boolean(numero);

console.log(typeof numero, numero); // number 123.45
console.log(Boolean(""));          // false (Falsy)
console.log(Boolean("DevLab"));    // true (Truthy)
```

## Resumo e Boas Práticas

- Primitivos são comparados por **valor**; objetos por **referência**.
- Converta tipos sempre de forma explícita (`Number()`, `String()`, `Boolean()`).
