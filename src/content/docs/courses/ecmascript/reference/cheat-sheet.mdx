Esta página é um **guia completo de referência rápida** contendo todas as assinaturas, parâmetros, tipos de retorno, exemplos e descrições dos métodos, funções nativas e operadores do **ECMAScript (JavaScript)**, da especificação base até as novidades do **ES2024**.

## 📌 Legenda e Convenções

- **`param?`**: parâmetro opcional.
- **`...args`**: operador *rest* (aceita múltiplos argumentos).
- **`Mutador`**: altera o objeto/array original diretamente (*in-place*).
- **`Acessor`**: não altera o original (retorna uma cópia ou novo valor).
- **`HOF`**: *Higher-Order Function* (função que recebe outra callback como parâmetro).

## Operadores, Estruturas e Sintaxe Base

### Operadores Especiais e Atribuição Lógica

| Operador / Sintaxe | Assinatura / Exemplo | Descrição |
| :--- | :--- | :--- |
| `typeof` | `typeof operand: string` | Retorna o nome do tipo primitivo ou `"object"` / `"function"`. |
| `instanceof` | `obj instanceof Constructor: boolean` | Testa se `Constructor.prototype` está na cadeia de protótipos de `obj`. |
| `in` | `'prop' in obj: boolean` | Verifica se a propriedade existe no objeto ou em sua cadeia de protótipos. |
| `delete` | `delete obj.prop: boolean` | Remove uma propriedade de um objeto. |
| `void` | `void expression: undefined` | Avalia a expressão e retorna `undefined`. |
| Encadear Opcional | `obj?.prop`, `arr?.[0]`, `fn?.(): any \| undefined` | Acessa propriedades de forma segura sem lançar erro caso o alvo seja `null` ou `undefined`. |
| Coalescência Nula | `left ?? right: any` | Retorna `right` apenas se `left` for `null` ou `undefined`. |
| Atribuição Lógica `??=` | `target ??= value: any` | Atribui `value` a `target` somente se `target` for `null` ou `undefined`. |
| Atribuição Lógica `\|\|=` | `target \|\|= value: any` | Atribui `value` a `target` se `target` for um valor *falsy*. |
| Atribuição Lógica `&&=` | `target &&= value: any` | Atribui `value` a `target` se `target` for um valor *truthy*. |
| Spread / Rest | `...iterable` / `...args`: varia | Espalha elementos de um iterável ou agrupa argumentos restantes. |

```js title="Exemplo: Operadores Modernos"
const user = null;
const name = user?.profile?.name ?? "Visitante"; // "Visitante"

let config = {};
config.theme ||= "dark"; // config.theme vira "dark"
```

| `arr.concat(...valueN): Array` | Retorna um novo array combinando o original com os valores/arrays fornecidos. |
| `arr.slice(start?, end?): Array` | Retorna uma cópia de uma fatia do array (índice `start` até `end` exclusive). |

| Assinatura Callback | Descrição |
| :--- | :--- |
| `arr.forEach(fn(element, index?, array?), thisArg?): undefined` | Executa a função `fn` para cada elemento. |
| `arr.map(fn(element, index?, array?), thisArg?): Array` | Retorna novo array contendo o resultado da aplicação de `fn` em cada item. |
| `arr.filter(fn(element, index?, array?), thisArg?): Array` | Retorna novo array com elementos que passaram no teste lógico da `fn`. |

| `arr.reduceRight(fn(acc, val, index?, array?), initialVal?): any` | Reduz o array a um único valor acumulado (da direita para a esquerda). |
| `arr.find(fn(element, index?, array?), thisArg?): element \| undefined` | Retorna o **primeiro elemento** que satisfaz a condição da `fn`. |
| `arr.findIndex(fn(element, index?, array?), thisArg?): number` | Retorna o **índice do primeiro elemento** que satisfaz a condição (ou `-1`). |
| `arr.findLast(fn(element, index?, array?), thisArg?): element \| undefined` | Retorna o **último elemento** que satisfaz a condição da `fn`. |
| `arr.findLastIndex(fn(element, index?, array?), thisArg?): number` | Retorna o **índice do último elemento** que satisfaz a condição (ou `-1`). |
| `arr.some(fn(element, index?, array?), thisArg?): boolean` | Retorna `true` se **pelo menos um** elemento satisfazer a condição da `fn`. |
| `arr.every(fn(element, index?, array?), thisArg?): boolean` | Retorna `true` se **todos** os elementos satisfizerem a condição da `fn`. |
| `arr.keys(): Iterator` | Retorna um iterador com os índices do array. |
| `arr.values(): Iterator` | Retorna um iterador com os valores do array. |
| `arr.entries(): Iterator` | Retorna um iterador com pares `[índice, valor]`. |

### Métodos Imutáveis de Alteração (ES2023) e Agrupamento (ES2024)

| Assinatura | Descrição |
| :--- | :--- |
| `arr.toSorted(compareFn?): Array` | Retorna nova cópia do array ordenada sem modificar o original. |
| `arr.toReversed(): Array` | Retorna nova cópia do array invertida sem modificar o original. |
| `arr.toSpliced(start, deleteCount?, ...items): Array` | Retorna nova cópia do array modificada por corte/inserção sem alterar o original. |
| `arr.with(index, value): Array` | Retorna novo array substituindo o elemento no `index` especificado por `value`. |
| `Object.groupBy(iterable, callbackFn(element, index)): Object` | (ES2024) Agrupa elementos de um iterável em um objeto baseado nas chaves retornadas pela callback. |
| `Map.groupBy(iterable, callbackFn(element, index)): Map` | (ES2024) Agrupa elementos de um iterável em um `Map` chaveado por qualquer tipo. |

```js title="Exemplo: ES2023 (Cópia Imutável) & ES2024 (Object.groupBy)"
const items = [{ name: "Maçã", category: "fruta" }, { name: "Cenoura", category: "legume" }];

// ES2024 Object.groupBy
const grouped = Object.groupBy(items, (item) => item.category);
// { fruta: [{ name: "Maçã", ... }], legume: [{ name: "Cenoura", ... }] }
```

## Function & Contexto (`Function.prototype`)

### Sintaxes de Declaração de Funções

```js title="Formas de declaração de funções"
// Declaração tradicional (com hoisting)
function add(a, b = 0) { return a + b; }

// Expressão de função
const multiply = function(a, b) { return a * b; };

// Arrow Function (sem 'this' ou 'arguments' próprios)
const subtract = (a, b) => a - b;

// Parâmetro Rest (...args)
const sumAll = (...numbers) => numbers.reduce((acc, n) => acc + n, 0);

// Função Geradora (Generator Function)
function* idGenerator() {
  let id = 1;
  while (true) yield id++;
}
```

### Métodos de Instância de Function

| Assinatura | Descrição |
| :--- | :--- |
| `fn.call(thisArg, arg1, arg2, ...): any` | Invoca a função configurando explicitamente `thisArg` e passando os argumentos individualmente. |
| `fn.apply(thisArg, argsArray): any` | Invoca a função configurando `thisArg` e passando os argumentos em uma estrutura de array. |
| `fn.bind(thisArg, arg1, arg2, ...): Function` | Retorna uma **nova função** vinculada permanentemente ao `thisArg` e aos argumentos pré-fixados. |

## Iteradores, Geradores e Iteráveis Assíncronos

### Protocolo de Iteração e Sintaxes

| Recurso / Sintaxe | Exemplo de Sintaxe | Descrição |
| :--- | :--- | :--- |
| `for...of` | `for (const item of iterable) { ... }` | Itera sobre os valores de um objeto iterável (`Array`, `Set`, `Map`, `String`). |
| `for await...of` | `for await (const item of asyncIterable) { ... }` | Itera sobre os valores de um iterável assíncrono ou promessas. |
| Gerador (`function*`) | `function* gen() { yield 1; yield 2; }` | Cria uma função geradora que pode ser pausada (`yield`) e retomada. |
| Métodos de Generator | `gen.next(value?)`, `gen.return(val)`, `gen.throw(err)` | Controla a execução da função geradora e consome seus valores. |

```js title="Exemplo: Generator Function e Iterador Customizado"
function* countUp(max) {
  for (let i = 1; i <= max; i++) {
    yield i;
  }
}

const counter = countUp(3);
console.log(counter.next()); // { value: 1, done: false }
console.log(counter.next()); // { value: 2, done: false }
console.log(counter.next()); // { value: 3, done: false }
console.log(counter.next()); // { value: undefined, done: true }
```
