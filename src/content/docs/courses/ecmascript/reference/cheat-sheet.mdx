Esta página é um **guia completo de referência rápida** contendo todas as assinaturas, parâmetros, tipos de retorno, exemplos e descrições dos métodos, funções nativas e operadores do **ECMAScript (JavaScript)**, da especificação base até as novidades do **ES2024**.

## 📌 Legenda e Convenções

- **`param?`**: parâmetro opcional.
- **`...args`**: operador *rest* (aceita múltiplos argumentos).
- **`Mutador`**: altera o objeto/array original diretamente (*in-place*).
- **`Acessor`**: não altera o original (retorna uma cópia ou novo valor).
- **`HOF`**: *Higher-Order Function* (função que recebe outra callback como parâmetro).

## Operadores e Sintaxe

<details>
  <summary>`typeof operand: string`</summary>

  Retorna o nome do tipo primitivo ou `"object"` / `"function"`.
</details>

<details>
  <summary>`obj instanceof Constructor: boolean`</summary>

  Testa se `Constructor.prototype` está na cadeia de protótipos de `obj`.
</details>

<details>
  <summary>`'prop' in obj: boolean`</summary>

  Verifica se a propriedade existe no objeto ou em sua cadeia de protótipos.
</details>

<details>
  <summary>`delete obj.prop: boolean`</summary>

  Remove uma propriedade de um objeto.
</details>

<details>
  <summary>`void expression: undefined`</summary>

  Avalia a expressão e retorna `undefined`.
</details>

<details>
  <summary>`obj?.prop: any | undefined` (Encadear Opcional)</summary>

  Acessa propriedades de forma segura sem lançar erro caso o alvo seja `null` ou `undefined`. Vale também para índices (`arr?.[0]`) e chamadas (`fn?.()`).
</details>

<details>
  <summary>`left ?? right: any` (Coalescência Nula)</summary>

  Retorna `right` apenas se `left` for `null` ou `undefined`.
</details>

<details>
  <summary>`target ??= value: any` (Atribuição Lógica ??=)</summary>

  Atribui `value` a `target` somente se `target` for `null` ou `undefined`.
</details>

<details>
  <summary>`target ||= value: any` (Atribuição Lógica \|\|=)</summary>

  Atribui `value` a `target` se `target` for um valor *falsy*.
</details>

<details>
  <summary>`target &&= value: any` (Atribuição Lógica &&=)</summary>

  Atribui `value` a `target` se `target` for um valor *truthy*.
</details>

<details>
  <summary>`...iterable` / `...args` (Spread / Rest)</summary>

  Espalha os elementos de um iterável na chamada ou agrupa os argumentos restantes em um `Array`.
</details>

<details>
  <summary>Exemplo: Operadores Modernos</summary>

  ```js title="Exemplo: Operadores Modernos"
  const user = null;
  const name = user?.profile?.name ?? "Visitante"; // "Visitante"

  let config = {};
  config.theme ||= "dark"; // config.theme vira "dark"
  ```
</details>

## Funções Globais e Utilitários de Tipo

<details>
  <summary>`Array.isArray(value): boolean`</summary>

  Verifica se `value` é uma instância de `Array`.
</details>

<details>

<details>
  <summary>`Number.isFinite(value): boolean`</summary>

<details>
  <summary>`Number.isInteger(value): boolean`</summary>

</details>

<details>
  <summary>`parseInt(string, radix?): number`</summary>

  Converte string para número inteiro na base `radix` (2 a 36).
</details>

<details>
  <summary>`parseFloat(string): number`</summary>

  Converte string para número de ponto flutuante.
</details>

<details>
  <summary>`encodeURI(uri): string`</summary>

  Codifica uma URI substituindo caracteres especiais.
</details>

<details>
  <summary>`decodeURI(encodedURI): string`</summary>

  Decodifica uma URI previamente codificada.
</details>

<details>
  <summary>`encodeURIComponent(str): string`</summary>

  Codifica componentes de URI (incluindo `/`, `?`, `:`, `#`).
</details>

<details>
  <summary>`decodeURIComponent(encodedStr): string`</summary>

  Decodifica componentes de URI.
</details>

<details>
  <summary>`structuredClone(value, options?): any`</summary>

</details>

## Array

**Métodos Estáticos de Array**

<details>
  <summary>`Array.isArray(value): boolean`</summary>

  Testa se o valor fornecido é um `Array`.
</details>

<details>
  <summary>`Array.from(arrayLike, mapFn?, thisArg?): Array`</summary>

  Cria um `Array` a partir de um objeto iterável ou array-like.
</details>

<details>
  <summary>`Array.fromAsync(asyncIterable, mapFn?, thisArg?): Promise<Array>`</summary>

</details>

<details>
  <summary>`Array.of(...elementN): Array`</summary>

  Cria um novo `Array` contendo todos os argumentos fornecidos.
</details>


**Métodos Mutadores (Alteram o Array Original)**

<details>
  <summary>`arr.push(...elementN): number`</summary>

  Adiciona elementos ao **final**. Retorna o novo `length`.
</details>

<details>
  <summary>`arr.pop(): element | undefined`</summary>

  Remove e retorna o **último** elemento.
</details>

<details>
  <summary>`arr.unshift(...elementN): number`</summary>

  Adiciona elementos ao **início**. Retorna o novo `length`.
</details>

<details>
  <summary>`arr.shift(): element | undefined`</summary>

  Remove e retorna o **primeiro** elemento.
</details>

<details>
  <summary>`arr.splice(start, deleteCount?, ...items): Array`</summary>

  Remove, substitui ou adiciona elementos em qualquer posição. Retorna removidos.
</details>

<details>
  <summary>`arr.sort(compareFn?): Array`</summary>

  Ordena os elementos *in-place*.
</details>

<details>
  <summary>`arr.reverse(): Array`</summary>

  Inverte a ordem dos elementos *in-place*.
</details>

<details>
  <summary>`arr.fill(value, start?, end?): Array`</summary>

  Preenche os elementos do array com um valor estático do índice `start` ao `end`.
</details>

<details>
  <summary>`arr.copyWithin(target, start, end?): Array`</summary>

  Copia uma sequência de elementos dentro do próprio array.
</details>

**Métodos Acessores (Não Mutadores)**

<details>
  <summary>`arr.at(index): element | undefined`</summary>

  Retorna o elemento na posição `index` (aceita índices negativos).
</details>

<details>
  <summary>`arr.concat(...valueN): Array`</summary>

  Retorna um novo array combinando o original com os valores/arrays fornecidos.
</details>

<details>
  <summary>`arr.slice(start?, end?): Array`</summary>

  Retorna uma cópia de uma fatia do array (índice `start` até `end` exclusive).
</details>

<details>
  <summary>`arr.includes(searchElement, fromIndex?): boolean`</summary>

  Verifica se o array contém determinado elemento.
</details>

<details>
  <summary>`arr.indexOf(searchElement, fromIndex?): number`</summary>

  Retorna o primeiro índice do elemento ou `-1`.
</details>

<details>
  <summary>`arr.lastIndexOf(searchElement, fromIndex?): number`</summary>

  Retorna o último índice do elemento ou `-1`.
</details>

<details>
  <summary>`arr.join(separator?): string`</summary>

  Junta os elementos em uma string separada por `separator` (padrão `","`).
</details>

<details>
  <summary>`arr.flat(depth?): Array`</summary>

  Achata sub-arrays aninhados até a profundidade `depth` (padrão `1`).
</details>

<details>
  <summary>`arr.flatMap(fn, thisArg?): Array`</summary>

  Mapeia cada elemento usando a `fn` e achata o resultado em 1 nível.
</details>

**Iteradores e HOFs (Higher-Order Functions)**

<details>
  <summary>`arr.forEach(fn(element, index?, array?), thisArg?): undefined`</summary>

  Executa a função `fn` para cada elemento.
</details>

<details>
  <summary>`arr.map(fn(element, index?, array?), thisArg?): Array`</summary>

  Retorna novo array contendo o resultado da aplicação de `fn` em cada item.
</details>

<details>
  <summary>`arr.filter(fn(element, index?, array?), thisArg?): Array`</summary>

  Retorna novo array com elementos que passaram no teste lógico da `fn`.
</details>

<details>
  <summary>`arr.reduce(fn(acc, val, index?, array?), initialVal?): any`</summary>

  Reduz o array a um único valor acumulado (da esquerda para a direita).
</details>

<details>
  <summary>`arr.reduceRight(fn(acc, val, index?, array?), initialVal?): any`</summary>

  Reduz o array a um único valor acumulado (da direita para a esquerda).
</details>

<details>
  <summary>`arr.find(fn(element, index?, array?), thisArg?): element | undefined`</summary>

  Retorna o **primeiro elemento** que satisfaz a condição da `fn`.
</details>

<details>
  <summary>`arr.findIndex(fn(element, index?, array?), thisArg?): number`</summary>

  Retorna o **índice do primeiro elemento** que satisfaz a condição (ou `-1`).
</details>

<details>
  <summary>`arr.findLast(fn(element, index?, array?), thisArg?): element | undefined`</summary>

  Retorna o **último elemento** que satisfaz a condição da `fn`.
</details>

<details>
  <summary>`arr.findLastIndex(fn(element, index?, array?), thisArg?): number`</summary>

  Retorna o **índice do último elemento** que satisfaz a condição (ou `-1`).
</details>

<details>
  <summary>`arr.some(fn(element, index?, array?), thisArg?): boolean`</summary>

  Retorna `true` se **pelo menos um** elemento satisfazer a condição da `fn`.
</details>

<details>
  <summary>`arr.every(fn(element, index?, array?), thisArg?): boolean`</summary>

  Retorna `true` se **todos** os elementos satisfizerem a condição da `fn`.
</details>

<details>
  <summary>`arr.keys(): Iterator`</summary>

  Retorna um iterador com os índices do array.
</details>

<details>
  <summary>`arr.values(): Iterator`</summary>

  Retorna um iterador com os valores do array.
</details>

<details>
  <summary>`arr.entries(): Iterator`</summary>

  Retorna um iterador com pares `[índice, valor]`.
</details>

**Métodos Imutáveis de Alteração (ES2023) e Agrupamento (ES2024)**

<details>
  <summary>`arr.toSorted(compareFn?): Array`</summary>

  Retorna nova cópia do array ordenada sem modificar o original.
</details>

<details>
  <summary>`arr.toReversed(): Array`</summary>

  Retorna nova cópia do array invertida sem modificar o original.
</details>

<details>
  <summary>`arr.toSpliced(start, deleteCount?, ...items): Array`</summary>

  Retorna nova cópia do array modificada por corte/inserção sem alterar o original.
</details>

<details>
  <summary>`arr.with(index, value): Array`</summary>

  Retorna novo array substituindo o elemento no `index` especificado por `value`.
</details>

<details>
  <summary>`Object.groupBy(iterable, callbackFn(element, index)): Object`</summary>

  (ES2024) Agrupa elementos de um iterável em um objeto baseado nas chaves retornadas pela callback.
</details>

<details>
  <summary>`Map.groupBy(iterable, callbackFn(element, index)): Map`</summary>

  (ES2024) Agrupa elementos de um iterável em um `Map` chaveado por qualquer tipo.
</details>

<details>
  <summary>Exemplo: ES2023 (Cópia Imutável) & ES2024 (Object.groupBy)</summary>

  ```js title="Exemplo: ES2023 (Cópia Imutável) & ES2024 (Object.groupBy)"
  const items = [{ name: "Maçã", category: "fruta" }, { name: "Cenoura", category: "legume" }];

  // ES2024 Object.groupBy
  const grouped = Object.groupBy(items, (item) => item.category);
  // { fruta: [{ name: "Maçã", ... }], legume: [{ name: "Cenoura", ... }] }
  ```
</details>

<details>
  <summary>Exemplo: Formas de declaração de funções</summary>

  ```js title="Formas de declaração de funções"
  // Declaração tradicional (com hoisting)
  function add(a, b = 0) { return a + b; }

  // Expressão de função
  const multiply = function(a, b) { return a * b; };

  // Arrow Function (sem 'this' ou 'arguments' próprios)
  const subtract = (a, b) => a - b;

  // Parâmetro Rest (...args)
  const sumAll = (...numbers) => numbers.reduce((acc, n) => acc + n, 0);

  // Função Geradora (Generator Function)
  function* idGenerator() {
    let id = 1;
    while (true) yield id++;
  }
  ```

## Iteradores e Geradores

<details>
  <summary>`for (const item of iterable) { ... }` (for...of)</summary>

  Itera sobre os valores de um objeto iterável (`Array`, `Set`, `Map`, `String`).
</details>

<details>
  <summary>`for await (const item of asyncIterable) { ... }` (for await...of)</summary>

  Itera sobre os valores de um iterável assíncrono ou promessas.
</details>

<details>
  <summary>`function* gen() { yield 1; yield 2; }` (Gerador (function*))</summary>

  Cria uma função geradora que pode ser pausada (`yield`) e retomada.
</details>

<details>
  <summary>`gen.next(value?)`, `gen.return(val)`, `gen.throw(err)` (Métodos de Generator)</summary>

  Controla a execução da função geradora e consome seus valores.
</details>

<details>
  <summary>Exemplo: Generator Function e Iterador Customizado</summary>

  ```js title="Exemplo: Generator Function e Iterador Customizado"
  function* countUp(max) {
    for (let i = 1; i <= max; i++) {
      yield i;
    }
  }

  const counter = countUp(3);
  console.log(counter.next()); // { value: 1, done: false }
  console.log(counter.next()); // { value: 2, done: false }
  console.log(counter.next()); // { value: 3, done: false }
  console.log(counter.next()); // { value: undefined, done: true }
  ```
</details>
