O **Guia de ECMAScript** é um material de referência técnica para a linguagem JavaScript moderna, centrado na especificação internacional **ECMA-262**. Ele cobre desde a sintaxe base e a manipulação de dados até recursos avançados de assincronismo, orientação a objetos por protótipos, módulos ES e o processo formal de evolução do comitê TC39.

Diferente de uma disciplina acadêmica vinculada ao calendário letivo, este guia funciona como manual de consulta contínua e trilha progressiva de aprendizado para estudantes e desenvolvedores que buscam dominar os fundamentos reais da linguagem, sem atalhos ou abstrações desnecessárias.

Materiais: [slides do tópico](../../slides/courses/ecmascript/) e [mapa mental](../../mindmaps/courses/ecmascript/).

## Como o guia está organizado?

A progressão sugerida a seguir conduz o estudante pelos conceitos essenciais da linguagem, estabelecendo uma base conceitual e prática sólida antes de avançar para cenários complexos:

<Steps>

1. **Compreender o ecossistema e a especificação**: [Introdução e Ecossistema](basics/introduction/) detalha o papel do padrão ECMA-262, a arquitetura dos motores de execução (V8, SpiderMonkey, JavaScriptCore) e a criação do primeiro script executável.

2. **Identificar a natureza dos valores**: [Tipos de Dados e Coerção](basics/types/) apresenta a distinção fundamental entre valores primitivos e referências a objetos, verificações com `typeof` e regras de igualdade estrita (`===`).

3. **Declarar identificadores com segurança**: [Variáveis e Escopo](basics/variables/) estabelece a adoção padrão de `const` e `let`, o escopo léxico de bloco, os mecanismos de *hoisting* e a Zona Morta Temporal (TDZ).

4. **Operar sobre dados e controlar o fluxo**: [Expressões e Operadores](basics/operators/) e [Estruturas de Controle](basics/control-flow/) cobrem a precedência de operadores, curto-circuito lógico, estruturas condicionais e laços de repetição.

5. **Modularizar e proteger o código**: [Funções e Closures](structure/functions/), [Módulos ES (ESM)](structure/modules/) e [Tratamento de Erros](structure/errors/) ensinam funções de primeira classe, escopo léxico preservado por *closures*, exportações modulares e controle de exceções com blocos `try/catch`.

6. **Manipular dados e coleções**: [Strings](data/strings/), [Numbers](data/numbers/), [Arrays](data/arrays/), [Objetos](data/objects/), [Date](stdlib/date/), [Coleções](data/collections/), [RegExp](stdlib/regex/) e [Objetos Globais](stdlib/built-ins/) aprofundam a biblioteca padrão por meio de métodos funcionais imutáveis, template literals, classes ES6, manipulação de datas, estruturas dedicadas como `Map` e `Set`, padrões textuais e metaprogramação com `Proxy` e `Reflect`.

7. **Orquestrar operações assíncronas**: [Promises](async/promises/) e [Async/Await](async/async-await/) exploram o modelo de concorrência não bloqueante baseado em *Event Loop*, encadeamento de promessas e sintaxe linear para fluxos assíncronos.

8. **Acompanhar a evolução e consultar assinaturas**: [Evolução e TC39](evolution/tc39/), [Guia de Referência](reference/cheat-sheet/), [JavaScript vs Python](reference/python-vs-javascript/) e [Casos "Bizarros"](reference/weird-cases/) explicam o ciclo formal de propostas do TC39 e oferecem resumos rápidos de sintaxe e armadilhas históricas.

9. **Trabalhar com assistentes de código**: [Desenvolvimento com IA](reference/ai-assisted-development/) reúne o método de especificar, gerar, verificar e revisar JavaScript escrito com auxílio de inteligência artificial, com catálogo de *prompts* por tarefa e índice das armadilhas por tópico.

</Steps>

<Aside type="note" title="Versão de referência e compatibilidade">
  O guia adota o padrão **ECMAScript moderno** (ES2015 a ES2024+) como base de código executável. Ambientes modernos de execução, como o **Node.js 22+** e navegadores atuais (Chrome, Firefox, Safari, Edge), suportam nativamente mais de 99% das especificações atuais. Dessa forma, todos os exemplos deste guia rodam diretamente sem necessidade de ferramentas de transpilação (como Babel) ou etapas de empacotamento.
</Aside>

## ECMAScript e Ambientes de Execução

Uma distinção fundamental para qualquer desenvolvedor é separar o que pertence à especificação ECMAScript do que é fornecido pelo ambiente hospedeiro (*host environment*). A especificação padroniza a gramática, os tipos primitivos e os algoritmos internos da linguagem, enquanto cada plataforma injeta interfaces globais específicas para interação com o sistema ou com a tela.

A tabela a seguir compara o padrão internacional com as capacidades oferecidas em navegadores web e no ambiente de servidor:

| Recurso / Camada | ECMAScript Padrão (ECMA-262) | Navegadores Web (W3C / WHATWG) | Node.js (Servidor) |
| :--- | :--- | :--- | :--- |
| **Escopo Global** | `globalThis` | `window`, `self`, `globalThis` | `global`, `globalThis` |
| **Manipulação de I/O** | Não especificado na norma base | Manipulação visual via DOM e eventos | Sistema de arquivos com `node:fs` e *streams* |
| **Rede e Requisições** | Não especificado na norma base | `fetch`, `XMLHttpRequest`, `WebSocket` | Módulo `node:http` e `fetch` nativo |
| **Sistema de Módulos** | Sintaxe formal `import` e `export` | `<script type="module">` nativo | Módulos ES nativos e suporte a CommonJS |
| **Temporizadores** | Não faz parte do núcleo formal | `setTimeout`, `requestAnimationFrame` | `setTimeout`, `setImmediate`, `process.nextTick` |
| **Foco de Aplicação** | Lógica de negócio, algoritmos e dados | Interfaces de usuário e interatividade | APIs HTTP, serviços de back-end e scripts |

Ao escrever código JavaScript, priorize sempre que possível as construções padronizadas pelo ECMAScript. Dessa forma, suas funções de cálculo, manipulação de coleções, lógica de validação e classes de modelo permanecem 100% portáveis entre o cliente (navegador) e o servidor (Node.js).

## Ferramentas de Prática

Para consolidar os conceitos deste guia, a prática ativa com ferramentas simples e imediatas é essencial:

| Ferramenta | Tipo | Como utilizar |
| :--- | :--- | :--- |
| [Node.js](https://nodejs.org/) | Runtime local | Executar scripts pelo terminal (`$ node script.js`) ou abrir o console interativo com `$ node` |
| **Console DevTools** | Inspetor do navegador | Pressionar <kbd>F12</kbd> em qualquer navegador para avaliar expressões e pequenos trechos imediatamente |
| [Visual Studio Code](https://code.visualstudio.com/) | Editor de código | Escrever arquivos `.js` com realce sintático, autocompletar e terminal integrado |
| [TypeScript Playground](https://www.typescriptlang.org/play) | Playground online | Experimentar código no navegador configurando o modo JavaScript para inspeção de comportamento |
| [MDN Web Docs Playground](https://developer.mozilla.org/) | Ambiente de testes | Testar exemplos interativos diretamente na documentação oficial |

<Aside type="tip" title="Prática imediata no REPL">
  O interpretador interativo do Node.js (REPL) é a maneira mais rápida de testar métodos e operadores. Abra o seu terminal, digite `node` e pressione <kbd>Enter</kbd>. Para sair da sessão, basta digitar `.exit` ou pressionar <kbd>Ctrl+D</kbd>.
</Aside>
