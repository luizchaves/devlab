O **Guia de ECMAScript** é um material de referência técnica para a linguagem JavaScript (ECMA-262), cobrindo desde a sintaxe base até recursos avançados de assincronismo, orientação a objetos por protótipos, módulos ES e o processo de evolução do comitê TC39.

Diferente de uma disciplina acadêmica ligada ao calendário, este guia funciona como manual de consulta contínua para estudantes e desenvolvedores.
