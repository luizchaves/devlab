O **ECMAScript (ES)** é a especificação técnica padronizada da linguagem **JavaScript**, mantida pelo comitê internacional **TC39** (*Technical Committee 39*). Desde a publicação histórica do **ES6 (ES2015)**, a linguagem evolui através de um ciclo de publicações anuais, incorporando novos operadores, estruturas sintáticas, recursos de assincronismo e métodos nativos de coleções.

Materiais: [slides do tópico](../../../../slides/courses/ecmascript/evolution/tc39/) e [mapa mental](../../../../mindmaps/courses/ecmascript/evolution/tc39/)

## Objetivo

Compreender o papel do comitê TC39, o funcionamento dos 5 estágios de maturação de propostas (*Stage 0 a 4*) e a linha do tempo cronológica das principais adições ao padrão ECMAScript desde 2015 até as especificações mais recentes.

## O Comitê TC39 e o Processo de Padronização

O **TC39** (*Technical Committee 39*) da Ecma International é o comitê responsável por manter e evoluir a especificação **ECMA-262**. Composto por representantes de motores JS (Google V8, Mozilla SpiderMonkey, Apple JavaScriptCore, Microsoft), empresas de tecnologia e pesquisadores independentes, o comitê avalia e amadurece propostas de evolução através de cinco estágios rigorosos:

- **Stage 0 (Strawperson)**: Ideia inicial ou rascunho submetido por um membro do comitê para abrir a discussão.
- **Stage 1 (Proposal)**: Proposta formal aprovada para investigação. O comitê define o problema a ser resolvido, a forma da API e casos de uso concretos.
- **Stage 2 (Draft)**: Especificação formal e completa da sintaxe e da semântica na linguagem da especificação ECMA-262.
- **Stage 3 (Candidate)**: Especificação assinada e estável. Motores de navegadores e runtimes iniciam implementações experimentais para colher feedback de desenvolvedores.
- **Stage 4 (Finished)**: A funcionalidade possui testes completos na suíte oficial (*test262*), foi implementada em pelo menos dois motores incompatíveis e é incorporada à próxima versão anual do ECMAScript.

| **ES10** | ECMAScript 2019 | 2019 | `Array.prototype.flat()`, `flatMap()`, `Object.fromEntries()`, Optional Catch Binding. |
| **ES11** | ECMAScript 2020 | 2020 | Optional Chaining (`?.`), Nullish Coalescing (`??`), `BigInt`, `Promise.allSettled()`, `globalThis`. |

## ES6 / ES2015 — A Grande Renovação da Linguagem

O **ES6 (ECMAScript 2015)** representou a maior atualização da história do JavaScript, transformando-o em uma linguagem robusta para o desenvolvimento de sistemas complexos.

### Declaração de Variáveis com Escopo de Bloco (`let` e `const`)

Substituem o escopo de função do `var`, prevenindo vazamentos de escopo e introduzindo a *Temporal Dead Zone* (TDZ):

```js title="Exemplo: let e const"
const API_URL = "https://api.exemplo.com";
let counter = 0;
counter += 1;

console.log(counter); // 1
```

### Funções Seta (*Arrow Functions*)

Oferecem sintaxe concisa para funções anônimas com contexto `this` léxico:

```js title="Exemplo: Arrow Functions"
const double = (n) => n * 2;
const sum = (a, b) => a + b;

console.log(double(5)); // 10
console.log(sum(2, 3));  // 5
```

### Classes e Herança Orientada a Objetos

Fornecem uma sintaxe declarativa e clara sobre o modelo tradicional de protótipos:

```js title="Exemplo: Classes em ES6"
class User {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return `Olá, ${this.name}!`;
  }
}

const user = new User("Ana");
console.log(user.greet()); // "Olá, Ana!"
```

### Desestruturação (*Destructuring Assignment*)

Permite extrair dados de arrays e propriedades de objetos diretamente em variáveis:

```js title="Exemplo: Destructuring"
const person = { name: "Maria", age: 25 };
const { name, age } = person;

const colors = ["vermelho", "azul"];
const [primary, secondary] = colors;

console.log(name, age);       // "Maria" 25
console.log(primary, secondary); // "vermelho" "azul"
```

### Template Literals (Interpolação de Strings)

Strings delimitadas por crases (`` ` ``) com suporte a interpolação de variáveis `${val}` e texto multilinha:

```js title="Exemplo: Template Literals"
const framework = "DevLab";
const banner = `Bem-vindo ao ${framework}!
Ambiente de aprendizado interativo.`;

console.log(banner);
```

### Parâmetros Rest (`...args`) e Operador Spread (`...iterable`)

As reticências desempenham papéis complementares conforme o local de uso:

```js title="Exemplo: Rest e Spread"
// Rest: agrupa argumentos em um array real
function sumAll(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

// Spread: espalha elementos em um novo array
const base = [1, 2];
const expanded = [...base, 3, 4];

console.log(sumAll(1, 2, 3)); // 6
console.log(expanded);        // [1, 2, 3, 4]
```

### Módulos Nativos (`import` e `export`)

O ES2015 unificou a modularização de código na especificação, eliminando a dependência de bibliotecas externas:

```js title="Exemplo: Módulos ESM"
// math.js
export const add = (a, b) => a + b;

// app.js
import { add } from "./math.js";
console.log(add(10, 20)); // 30
```

## ES7 / ES2016

Uma atualização pontual focada em melhorias funcionais imediatas:

### Operador de Exponenciação (`**`)

Substitui a necessidade de invocar `Math.pow(base, exp)`:

```js title="Exemplo: Operador de Exponenciação"
const square = 2 ** 3; // 8 (equivalente a Math.pow(2, 3))
let x = 3;
x **= 2; // 9

console.log(square, x); // 8 9
```

### `Array.prototype.includes()`

Permite verificar a presença de um elemento diretamente com retorno booleano:

```js title="Exemplo: Array.prototype.includes"
const fruits = ["maçã", "banana", "laranja"];
console.log(fruits.includes("banana")); // true
console.log(fruits.includes("uva"));    // false
```

## ES8 / ES2017

Introduziu recursos cruciais para programação assíncrona e inspeção de estruturas:

### Funções Assíncronas (`async` / `await`)

Açúcar sintático sobre Promises que torna o fluxo assíncrono legível e sequencial:

```js title="Exemplo: async/await"
async function fetchUser(id) {
  const response = await fetch(`/api/users/${id}`);
  return await response.json();
}
```

### `Object.values()` e `Object.entries()`

Completam o trio de reflexão iniciado por `Object.keys()`:

```js title="Exemplo: Object.values e Object.entries"
const user = { name: "Ana", age: 30 };

console.log(Object.values(user));  // ["Ana", 30]
console.log(Object.entries(user)); // [["name", "Ana"], ["age", 30]]
```

### Preenchimento de Strings (`padStart` e `padEnd`)

Facilitam a formatação de números de série, datas e colunas alinhadas:

```js title="Exemplo: padStart e padEnd"
console.log("5".padStart(3, "0")); // "005"
console.log("5".padEnd(3, "0"));   // "500"
```

## ES9 / ES2018

### Rest e Spread em Objetos

Estende a sintaxe de desestruturação e clonagem para objetos literais:

```js title="Exemplo: Rest e Spread em Objetos"
const user = { id: 1, name: "Carlos", role: "admin" };
const { id, ...userData } = user;

const updatedUser = { ...user, active: true };
console.log(userData);    // { name: "Carlos", role: "admin" }
console.log(updatedUser); // { id: 1, name: "Carlos", role: "admin", active: true }
```

### Iteração Assíncrona (`for await...of`)

Permite percorrer fluxos assíncronos e coleções de Promises sob demanda:

```js title="Exemplo: for await...of"
async function processStreams(promises) {
  for await (const result of promises) {
    console.log(result);
  }
}
```

### `Promise.prototype.finally()`

Executa ações de limpeza (*cleanup*) após o término da Promise, independentemente do desfecho:

```js title="Exemplo: Promise.finally"
fetchData()
  .then((res) => console.log(res))
  .catch((err) => console.error(err))
  .finally(() => hideSpinner());
```

## ES10 / ES2019

### Aplainamento de Arrays (`flat` e `flatMap`)

Simplificam o tratamento de arrays aninhados sem a necessidade de loops recursivos:

```js title="Exemplo: flat e flatMap"
const matrix = [1, [2, [3, 4]]];
console.log(matrix.flat(2)); // [1, 2, 3, 4]

const phrases = ["Olá mundo", "DevLab Web"];
const words = phrases.flatMap((p) => p.split(" "));
console.log(words); // ["Olá", "mundo", "DevLab", "Web"]
```

### `Object.fromEntries()`

Reconstrói um objeto literal a partir de uma lista de pares chave-valor:

```js title="Exemplo: Object.fromEntries"
const entries = [["a", 1], ["b", 2]];
const obj = Object.fromEntries(entries);

console.log(obj); // { a: 1, b: 2 }
```

### `trimStart()` e `trimEnd()`

Remove espaços em branco direcionados nas extremidades de strings:

```js title="Exemplo: trimStart e trimEnd"
const raw = "   texto   ";
console.log(raw.trimStart()); // "texto   "
console.log(raw.trimEnd());   // "   texto"
```

## ES11 / ES2020

### Encadeamento Opcional (`?.`) e Coalescência Nula (`??`)

Simplificam a leitura de propriedades aninhadas e definem valores de contingência contra `null` e `undefined`:

```js title="Exemplo: Optional Chaining e Nullish Coalescing"
const user = { profile: { email: null } };

console.log(user?.profile?.email ?? "email-padrao@devlab.com");
// "email-padrao@devlab.com"
```

### `BigInt`

Permite representar inteiros com precisão arbitrária além do limite de $2^{53} - 1$:

```js title="Exemplo: BigInt"
const bigNumber = 9007199254740991n + 2n;
console.log(bigNumber); // 9007199254740993n
```

### `Promise.allSettled()`

Aguarda a conclusão de todas as Promises fornecidas, sem interromper a execução caso uma delas falhe:

```js title="Exemplo: Promise.allSettled"
const results = await Promise.allSettled([
  Promise.resolve(10),
  Promise.reject("Falha")
]);
console.log(results);
// [{ status: 'fulfilled', value: 10 }, { status: 'rejected', reason: 'Falha' }]
```

## ES12 / ES2021

### Operadores Lógicos de Atribuição (`??=`, `||=`, `&&=`)

Combinam operadores lógicos com atribuição direta:

```js title="Exemplo: Logical Assignment"
const config = { timeout: 0 };
config.timeout ??= 3000; // Mantém 0 (pois 0 não é nullish)
config.retries ||= 3;     // Atribui 3 se retries for falsy

console.log(config); // { timeout: 0, retries: 3 }
```

### `String.prototype.replaceAll()`

Substitui todas as ocorrências de uma substring sem a necessidade de Expressões Regulares globais:

```js title="Exemplo: replaceAll"
const sentence = "gato preto, gato branco";
console.log(sentence.replaceAll("gato", "cão"));
// "cão preto, cão branco"
```

### Separadores Numéricos (`_`)

Aumentam a legibilidade de literais numéricos extensos:

```js title="Exemplo: Separadores Numéricos"
const bytes = 1_000_000_000;
const hexMask = 0xFF_EC_DE;
console.log(bytes); // 1000000000
```

## ES13 / ES2022

### Campos Privados em Classes (`#field`)

Garantem encapsulamento estrito direto na sintaxe de classes:

```js title="Exemplo: Campos Privados"
class BankAccount {
  #balance = 0;

  deposit(amount) {
    this.#balance += amount;
  }

  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount();
account.deposit(100);
console.log(account.getBalance()); // 100
// console.log(account.#balance);  // SyntaxError: Private field '#balance' must be declared in an enclosing class
```

### Método `.at()` em Arrays e Strings

Permite indexação posicional direta com suporte a índices negativos:

```js title="Exemplo: Método .at()"
const list = [10, 20, 30, 40];
console.log(list.at(-1)); // 40 (último elemento)
console.log("DevLab".at(-1)); // "b"
```

### `Object.hasOwn()` e Opção `{ cause }` em Erros

Substitui `hasOwnProperty` com segurança e permite encadear causas de exceções:

```js title="Exemplo: Object.hasOwn e Error Cause"
const item = { id: 42 };
console.log(Object.hasOwn(item, "id")); // true

try {
  throw new Error("Erro no banco", { cause: "Timeout de conexão" });
} catch (err) {
  console.log(err.cause); // "Timeout de conexão"
}
```

## ES14 / ES2023

### Métodos Imutáveis em Array (`toSorted`, `toReversed`, `with`)

Permitem ordenar, inverter e substituir posições produzindo novos arrays sem alterar o original:

```js title="Exemplo: Métodos Imutáveis em Array"
const numbers = [3, 1, 4, 2];

const sorted = numbers.toSorted();   // [1, 2, 3, 4]
const reversed = numbers.toReversed(); // [2, 4, 1, 3]
const updated = numbers.with(0, 99);  // [99, 1, 4, 2]

console.log(numbers); // [3, 1, 4, 2] (original intacto!)
```

### `findLast()` e `findLastIndex()`

Localizam elementos a partir do final do array de forma direta:

```js title="Exemplo: findLast"
const values = [5, 12, 50, 130, 44];
const lastHigh = values.findLast((x) => x > 40);

console.log(lastHigh); // 44
```

## ES15 / ES2024

### Agrupamento de Dados (`Object.groupBy` e `Map.groupBy`)

Agrupam iteráveis de forma nativa a partir de uma função seletora:

```js title="Exemplo: Object.groupBy"
const inventory = [
  { name: "Maçã", type: "fruta" },
  { name: "Cenoura", type: "legume" },
  { name: "Banana", type: "fruta" },
];

const grouped = Object.groupBy(inventory, (item) => item.type);
console.log(grouped);
// { fruta: [ { name: "Maçã", ... }, { name: "Banana", ... } ], legume: [ ... ] }
```

### `Promise.withResolvers()`

Desacopla a Promise de suas funções de resolução e rejeição:

```js title="Exemplo: Promise.withResolvers"
const { promise, resolve, reject } = Promise.withResolvers();

setTimeout(() => resolve("Operação concluída!"), 100);
const message = await promise;
console.log(message); // "Operação concluída!"
```

### Novos Métodos de `Set`

Adicionam suporte nativo a operações matemáticas clássicas entre conjuntos:

```js title="Exemplo: Novos métodos de Set"
const setA = new Set([1, 2, 3]);
const setB = new Set([2, 3, 4]);

console.log(setA.union(setB));        // Set { 1, 2, 3, 4 }
console.log(setA.intersection(setB)); // Set { 2, 3 }
console.log(setA.difference(setB));   // Set { 1 }
```

## ES16 / ES2025 (Recursos em Finalização)

Recursos que atingiram o Estágio 4 (*Stage 4*) no TC39 e estão sendo integrados aos motores modernos:

- **Métodos Auxiliares para Iteradores (*Iterator Helpers*)**: `.map()`, `.filter()`, `.take()`, `.drop()` e `.flatMap()` aplicáveis diretamente em iteradores gerados por generators.
- **Import Attributes (`with { type: 'json' }`)**: possibilita importar arquivos JSON e módulos estáticos de forma nativa e padronizada.

## Adoção e Suporte nos Runtimes Modernos

Graças à velocidade de atualização dos motores modernos (Node.js v20+, Deno, Bun e navegadores modernos), os recursos do **ES2015 ao ES2024** estão disponíveis nativamente sem necessidade de transpiladores para a grande maioria dos projetos.
