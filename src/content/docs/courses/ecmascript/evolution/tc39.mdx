## O Comitê TC39 e o Processo de Padronização

O **TC39** (Technical Committee 39) é o comitê responsável por manter e fazer evoluir a especificação do ECMAScript (ECMA-262). O processo de adição de novos recursos à linguagem segue 5 estágios rigorosos:

1. **Stage 0 (Strawperson)**: Ideia ou rascunho inicial apresentado por um membro do TC39.
2. **Stage 1 (Proposal)**: Proposta formal aprovada para investigação. O comitê define o problema e soluções potenciais.
3. **Stage 2 (Draft)**: Especificação formal da sintaxe e semântica inicial.
4. **Stage 3 (Candidate)**: Especificação completa e assinada. Implementações experimentais iniciam em navegadores e motores JS.
5. **Stage 4 (Finished)**: A proposta está pronta para ser inclusa na próxima edição anual do padrão ECMAScript.

---

O **ECMAScript (ES)** é o padrão oficial que especifica a linguagem **JavaScript**. Desde o lançamento do **ES6 (ES2015)**, o comitê responsável (TC39) adota um ciclo de lançamentos anuais, introduzindo continuamente novos recursos de sintaxe, operadores, APIs e utilitários nativos.

Esta página apresenta um panorama completo da evolução do ECMAScript ano a ano, destacando os principais recursos introduzidos em cada versão.

## ES6 / ES2015 — A Grande Revolução

O **ES6 (ECMAScript 2015)** foi a maior atualização na história do JavaScript, transformando a linguagem com sintaxe moderna para desenvolvimento em grande escala.

### 1. Declaração de Variáveis de Escopo de Bloco (`let` e `const`)
Substituem o escopo de função do `var`, evitando vazamento de escopo e introduzindo a *Temporal Dead Zone (TDZ)*.

```js
const API_URL = "https://api.exemplo.com";
let count = 0;
count += 1;
```

### 2. Funções Seta (*Arrow Functions*)
Sintaxe enxuta para funções anônimas com vínculo léxico do contexto `this`.

```js
const double = (n) => n * 2;
const sum = (a, b) => a + b;
```

### 3. Classes e Herança Orientada a Objetos
Açúcar sintático sobre a herança baseada em protótipos.

```js
class User {
  constructor(name) {
    this.name = name;
  }
  greet() {
    return `Olá, ${this.name}`;
  }
}
```

### 4. Desestruturação (*Destructuring Assignment*)
Extração simplificada de valores em arrays e propriedades em objetos.

```js
const person = { name: "Maria", age: 25 };
const { name, age } = person;

const colors = ["vermelho", "azul"];
const [primary, secondary] = colors;
```

### 5. Template Literals (Interpolação de Strings)
Strings delimitadas por crases (`` ` ``) com suporte a expressões `${val}` e múltiplas linhas.

```js
const title = "DevLab";
const message = `Bem-vindo ao ${title}!
Ambiente de aprendizado.`;
```

### 6. Parâmetros Rest (`...args`) e Operador Spread (`...iterable`)

As reticências têm dois papéis opostos conforme a posição: agrupar argumentos na declaração e espalhar valores na chamada.
```js
// Rest: agrupa argumentos restantes
function sumAll(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

// Spread: espalha elementos
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]
```

### 7. Módulos Nativos (`import` e `export`)

O ES2015 trouxe para a linguagem o sistema de módulos que antes dependia de bibliotecas como RequireJS e CommonJS:
```js
// math.js
export const add = (a, b) => a + b;

// app.js
import { add } from './math.js';
```

### 8. Outros Recursos Importantes do ES6
- **Promises Nativas**: tratamento padronizado de assincronismo.
- **Coleções `Map`, `Set`, `WeakMap`, `WeakSet`**: estruturas de dados especializadas.
- **Iteradores e Geradores**: protocolos de iteração (`for...of` e `function*`).
- **Valores Padrão de Parâmetros**: `function greet(name = "Visitante")`.

## ES7 / ES2016

Uma atualização menor focada em aperfeiçoamentos pontuais da linguagem.

### 1. Operador de Exponenciação (`**`)
Substitui a necessidade de invocar `Math.pow(base, exp)`.

```js
const square = 2 ** 3; // 8 (equivalente a Math.pow(2, 3))
let x = 3;
x **= 2; // 9
```

### 2. `Array.prototype.includes()`
Verifica de forma direta se um elemento existe no array, retornando um booleano.

```js
const fruits = ["maçã", "banana", "laranja"];
console.log(fruits.includes("banana")); // true
```

---

## ES8 / ES2017

Introduziu construções essenciais para simplificar a programação assíncrona e a manipulação de objetos.

### 1. Funções Assíncronas (`async` / `await`)
Açúcar sintático sobre Promises que permite escrever código assíncrono com aparência síncrona.

```js
async function fetchUser(id) {
  try {
    const response = await fetch(`/api/users/${id}`);
    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Erro na requisição:", error);
  }
}
```

### 2. `Object.values()` e `Object.entries()`

Os dois métodos completam o trio iniciado por `Object.keys()`, permitindo percorrer objetos como se fossem coleções:
```js
const user = { name: "Ana", age: 30 };

console.log(Object.values(user));  // ["Ana", 30]
console.log(Object.entries(user)); // [["name", "Ana"], ["age", 30]]
```

### 3. Preenchimento de Strings (`padStart` e `padEnd`)

O preenchimento resolve a formatação de códigos, horários e colunas alinhadas sem laços manuais:
```js
console.log("5".padStart(3, "0")); // "005"
console.log("5".padEnd(3, "0"));   // "500"
```

### 4. `Object.getOwnPropertyDescriptors()`
Retorna todos os descritores de propriedades próprias de um objeto, facilitando a clonagem precisa de seletores *getters* e *setters*.

---

## ES9 / ES2018

### 1. Rest e Spread em Objetos
Expande a sintaxe de desestruturação e espalhamento para objetos literais.

```js
const user = { id: 1, name: "Carlos", role: "admin" };
const { id, ...userData } = user; // userData = { name: "Carlos", role: "admin" }

const updatedUser = { ...user, active: true };
```

### 2. Iteração Assíncrona (`for await...of`)
Permite iterar sobre iteráveis assíncronos ou coleções de Promises.

```js
async function processStreams(promises) {
  for await (const result of promises) {
    console.log(result);
  }
}
```

### 3. `Promise.prototype.finally()`
Executa um callback após a conclusão da Promise, independentemente de ter sido resolvida ou rejeitada.

```js
fetchData()
  .then(res => console.log(res))
  .catch(err => console.error(err))
  .finally(() => hideLoadingSpinner());
```

### 4. Melhorias em RegExp
- **Grupos de Captura Nomeados**: `/(?<year>\d{4})-(?<month>\d{2})/`
- **Lookbehind Assertions**: `(?<=%)` e `(?<!%)`
- **Flag `/s` (dotAll)**: faz o caractere `.` corresponder também a quebras de linha.

---

## ES10 / ES2019

### 1. `Array.prototype.flat()` e `flatMap()`

Os dois métodos tratam arrays aninhados, que antes exigiam recursão ou `reduce` com concatenação:
```js
const nested = [1, [2, [3]]];
console.log(nested.flat(2)); // [1, 2, 3]

const numbers = [1, 2, 3];
console.log(numbers.flatMap(x => [x, x * 2])); // [1, 2, 2, 4, 3, 6]
```

### 2. `Object.fromEntries()`
Converte uma lista de pares chave-valor (como um `Map` ou resultado de `Object.entries()`) de volta em um objeto.

```js
const entries = [["name", "Pedro"], ["age", 22]];
const obj = Object.fromEntries(entries); // { name: "Pedro", age: 22 }
```

### 3. `trimStart()` e `trimEnd()`
Remoção de espaços em branco apenas no início ou no fim de uma string.

### 4. Binding Opcional no `catch`
Permite omitir a variável de erro no bloco `catch` quando ela não for necessária.

```js
try {
  JSON.parse(data);
} catch {
  console.log("JSON inválido");
}
```

## ES11 / ES2020

### 1. Encadear Opcional (*Optional Chaining*: `?.`)
Evita erros de `TypeError: Cannot read properties of undefined` ao acessar propriedades aninhadas.

```js
const street = user?.address?.street;
const firstItem = items?.[0];
const result = customMethod?.();
```

### 2. Operador de Coalescência Nula (*Nullish Coalescing*: `??`)
Retorna o valor da direita somente se o lado esquerdo for `null` ou `undefined` (diferente do `||`, que considera `0`, `""` e `false` como falsy).

```js
const timeout = config.timeout ?? 3000;
```

### 3. `BigInt` (Inteiros de Precisão Arbitrária)
Permite representar números inteiros maiores que `2^53 - 1`.

```js
const hugeNumber = 9007199254740991n + 2n; // 9007199254740993n
```

### 4. `Promise.allSettled()`
Retorna o estado final de todas as Promises passadas, sem abortar caso uma seja rejeitada.

```js
const results = await Promise.allSettled([p1, p2, p3]);
// Retorna array com { status: "fulfilled" | "rejected", value | reason }
```

### 5. Outros Destaques do ES2020
- **`globalThis`**: referência padronizada para o objeto global em qualquer ambiente (Browser, Node.js, Web Workers).
- **Dynamic `import()`**: carregamento sob demanda de módulos JS via `await import('./module.js')`.

## ES12 / ES2021

### 1. Atribuição Lógica (`??=`, `||=`, `&&=`)
Combina operadores lógicos com atribuição de variável.

```js
opts.speed ??= 50; // Atribui 50 se opts.speed for null/undefined
opts.title ||= "Sem título"; // Atribui se for falsy
opts.active &&= validate(opts); // Atribui se for truthy
```

### 2. `String.prototype.replaceAll()`
Substitui todas as ocorrências de uma substring sem a necessidade de usar expressões regulares globais.

```js
const text = "123-456-789";
console.log(text.replaceAll("-", ".")); // "123.456.789"
```

### 3. `Promise.any()` e `AggregateError`
Retorna a primeira Promise resolvida com **sucesso**. Caso todas falhem, lança um `AggregateError`.

### 4. Separadores Numéricos (`_`)
Melhora a legibilidade de grandes valores numéricos.

```js
const billion = 1_000_000_000;
const bytes = 0b1010_0001;
```

---

## ES13 / ES2022

### 1. Membros Privados em Classes (`#field`)
Propriedades e métodos privados nativos prefixados com `#`.

```js
class BankAccount {
  #balance = 0;

  deposit(amount) {
    this.#balance += amount;
  }

  getBalance() {
    return this.#balance;
  }
}
```

### 2. Método `.at()` em Arrays e Strings
Aceita índices negativos para buscar elementos a partir do final.

```js
const numbers = [10, 20, 30, 40];
console.log(numbers.at(-1)); // 40 (último elemento)
```

### 3. `Object.hasOwn()`
Substituto mais seguro e direto para `Object.prototype.hasOwnProperty.call()`.

```js
const item = { id: 42 };
console.log(Object.hasOwn(item, "id")); // true
```

### 4. Opção `{ cause }` em Construtores de Erro
Permite encadear exceções mantendo a causa raiz do erro original.

```js
try {
  connectDB();
} catch (err) {
  throw new Error("Falha ao inicializar serviço", { cause: err });
}
```

---

## ES14 / ES2023

### 1. Métodos Imutáveis em Array
Permitem transformar arrays sem alterar o original (*non-mutating array methods*).

```js
const numbers = [3, 1, 4, 2];

const sorted = numbers.toSorted(); // [1, 2, 3, 4]
const reversed = numbers.toReversed(); // [2, 4, 1, 3]
const updated = numbers.with(0, 99); // [99, 1, 4, 2]

console.log(numbers); // [3, 1, 4, 2] (original intacto!)
```

### 2. `findLast()` e `findLastIndex()`
Busca elementos no array no sentido inverso (do fim para o início).

```js
const values = [5, 12, 50, 130, 44];
const lastHigh = values.findLast(x => x > 40); // 44
```

## ES15 / ES2024

### 1. Agrupamento de Dados (`Object.groupBy` e `Map.groupBy`)
Agrupa elementos de um iterável de acordo com uma função seletora.

```js
const inventory = [
  { name: "Maçã", type: "fruta" },
  { name: "Cenoura", type: "legume" },
  { name: "Banana", type: "fruta" }
];

const grouped = Object.groupBy(inventory, item => item.type);
/*
{
  fruta: [{ name: "Maçã", ... }, { name: "Banana", ... }],
  legume: [{ name: "Cenoura", ... }]
}
*/
```

### 2. `Promise.withResolvers()`
Facilita a criação de Promises ao expor os gatilhos `resolve` e `reject` separadamente.

```js
const { promise, resolve, reject } = Promise.withResolvers();

setTimeout(() => resolve("Concluído!"), 1000);
const result = await promise;
```

### 3. Novos Métodos Nativos de `Set`
Permitem realizar operações matemáticas clássicas entre conjuntos:

```js
const setA = new Set([1, 2, 3]);
const setB = new Set([2, 3, 4]);

console.log(setA.intersection(setB)); // Set { 2, 3 }
console.log(setA.union(setB));        // Set { 1, 2, 3, 4 }
console.log(setA.difference(setB));   // Set { 1 }
```

### 4. `Array.fromAsync()`
Cria um `Array` a partir de um iterável assíncrono ou coleção de Promises.

---

## ES16 / ES2025 (Recursos em Finalização)

Recursos que atingiram o Estágio 4 (Stage 4) no TC39 e estão em fase de adoção pelos navegadores:

- **Métodos Auxiliares para Iteradores (*Iterator Helpers*)**: `.map()`, `.filter()`, `.take()`, `.drop()`, `.flatMap()` diretamente em iteradores nativos.
- **Import Attributes (`with { type: 'json' }`)**: possibilita importar arquivos JSON e módulos estáticos de forma nativa e segura.
