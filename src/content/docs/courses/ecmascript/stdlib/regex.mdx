Expressões Regulares são padrões para validação e extração de texto.

```javascript
// Validação simples de email
const regexEmail = /^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$/;
console.log(regexEmail.test("dev@devlab.com")); // true
```

## Resumo e Boas Práticas

- Teste suas expressões em ferramentas como RegExr antes do deploy.
- Evite expressões excessivamente complexas mantendo a legibilidade.
