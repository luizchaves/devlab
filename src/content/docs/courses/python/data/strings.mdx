Texto é o tipo de dado mais manipulado em qualquer programa: nomes, mensagens, respostas de
API, linhas de arquivo, comandos de terminal. Em Python, texto é representado pelo tipo `str`
— uma **sequência imutável de caracteres Unicode**.

Esta aula percorre as formas de criar strings, o acesso por índice e fatiamento, o catálogo
de métodos do tipo e a formatação com f-strings, que substituiu praticamente todas as
alternativas anteriores.

## Objetivo

Criar strings com diferentes delimitadores, explicar a imutabilidade e suas consequências,
acessar caracteres por índice e produzir fatias, aplicar os métodos de busca, transformação,
divisão e junção, formatar valores com f-strings e a mini-linguagem de formato, e diferenciar
`str` de `bytes`.

## Criação e Delimitadores

Aspas simples e duplas são equivalentes; a escolha costuma ser guiada pelo conteúdo do texto.
Os exemplos abaixo mostram as quatro formas de escrever literais:

```python title="Formas de criar strings"
single = 'Python'
double = "Python"
with_quote = "Ela disse 'olá'"
with_double = 'Ela disse "olá"'

multiline = """Primeira linha
Segunda linha
Terceira linha"""

print(single == double)
print(with_quote)
print(multiline)
print(str(42), str([1, 2]))   # conversão para texto
```

```txt title="Output"
True
Ela disse 'olá'
Primeira linha
Segunda linha
Terceira linha
42 [1, 2]
```

### Escapes e strings cruas

A barra invertida introduz sequências de escape; o prefixo `r` desativa esse tratamento:

| Escape | Significado |
| :--- | :--- |
| `\n` | Quebra de linha |
| `\t` | Tabulação |
| `\\` | Barra invertida literal |
| `\"` / `\'` | Aspas dentro do mesmo delimitador |
| `\u00e9` | Caractere Unicode pelo código |

```python title="Escapes e prefixo r"
print("Nome:\tAna\nCidade:\tJoão Pessoa")
print("Caminho: C:\\Users\\ana")
print(r"Caminho: C:\Users\ana")     # string crua: nada é interpretado
print("Caf\u00e9 \u2615")
```

```txt title="Output"
Nome:	Ana
Cidade:	João Pessoa
Caminho: C:\Users\ana
Caminho: C:\Users\ana
Café ☕
```

<Aside type="tip" title="Strings cruas em expressões regulares">
  Padrões de regex são cheios de barras invertidas (`\d`, `\s`, `\b`). Escrevê-los como
  string crua (`r"\d+"`) evita escapes duplicados — é a convenção adotada em
  [Expressões Regulares](../../stdlib/regex/).
</Aside>

### Concatenação e repetição

Strings se combinam com `+` e se repetem com `*`, mas juntar muitos pedaços em laço é
ineficiente:

```python title="Combinando textos"
first, last = "Ada", "Lovelace"

print(first + " " + last)
print("=" * 30)
print("Py" "thon")              # literais adjacentes se juntam

parts = ["nome", "email", "idade"]
print(", ".join(parts))          # forma eficiente de concatenar muitos itens
```

<Aside type="caution" title="Concatenar em laço cria N objetos">
  Como `str` é imutável, `text += item` dentro de um laço cria uma nova string a cada
  iteração. Para muitos pedaços, acumule em uma lista e finalize com `"".join(lista)`.
</Aside>

## Imutabilidade

Nenhum método de `str` altera o objeto original: todos devolvem uma **nova** string.

```python title="Métodos devolvem cópias"
text = "python"

upper = text.upper()
print(text, upper)        # python PYTHON

# text[0] = "P"           # TypeError: 'str' object does not support item assignment
changed = "P" + text[1:]
print(changed)            # Python

print(id(text) == id(text.upper()))  # False — objeto novo
```

<Aside type="note" title="Imutável não é constante">
  A variável pode ser reatribuída livremente (`text = "outro"`); o que não muda é o objeto
  string em si. Isso torna strings seguras como chaves de dicionário e elementos de conjunto.
</Aside>

## Índices e Fatiamento

Cada caractere ocupa uma posição, contada a partir de `0`. Índices negativos contam do fim
para o começo:

```python title="Acesso por índice"
language = "Python"

print(language[0], language[5])     # P n
print(language[-1], language[-6])   # n P
print(len(language))                # 6
# print(language[6])                # IndexError
```

O **fatiamento** usa a forma `texto[início:fim:passo]`, com `fim` sempre exclusivo:

```python title="Fatias"
text = "Guia de Python"

print(text[0:4])      # 'Guia'
print(text[:4])       # 'Guia'   — início implícito
print(text[8:])       # 'Python' — fim implícito
print(text[-6:])      # 'Python'
print(text[::2])      # 'ud ePto' — de dois em dois
print(text[::-1])     # 'nohtyP ed aiuG' — invertido
print(text[100:])     # ''       — fatia fora do limite não gera erro
```

| Fatia | Resultado | Uso típico |
| :--- | :--- | :--- |
| `s[:n]` | Primeiros `n` caracteres | Prefixo, truncar texto |
| `s[n:]` | Do índice `n` até o fim | Remover prefixo |
| `s[-n:]` | Últimos `n` caracteres | Extensão de arquivo, sufixo |
| `s[::-1]` | String invertida | Palíndromos |
| `s[::n]` | A cada `n` caracteres | Amostragem |

<Aside type="caution" title="Índice inválido dá erro, fatia não">
  `"abc"[10]` levanta `IndexError`, mas `"abc"[10:20]` devolve `""` silenciosamente. Ao
  fatiar entrada do usuário, valide o tamanho antes de assumir que o resultado tem conteúdo.
</Aside>

## Métodos de Texto

O tipo `str` traz dezenas de métodos. Os grupos abaixo cobrem o uso diário.

### Caixa e limpeza

Normalizar a entrada antes de comparar evita a maioria dos bugs de validação:

```python title="Normalização"
raw = "   Guia DE Python   "

print(raw.strip())          # 'Guia DE Python'
print(raw.lstrip(), "|")    # remove só à esquerda
print(raw.strip().lower())  # 'guia de python'
print(raw.strip().upper())  # 'GUIA DE PYTHON'
print(raw.strip().title())  # 'Guia De Python'
print("PYTHON".capitalize())  # 'Python'
print("Straße".casefold())    # 'strasse' — comparação sem caixa, ciente de Unicode
```

### Busca e verificação

Os métodos de busca devolvem posição, contagem ou booleano:

| Método | Devolve | Observação |
| :--- | :--- | :--- |
| `in` | `bool` | Forma idiomática de testar substring |
| `find(sub)` | Índice ou `-1` | Não levanta erro quando não encontra |
| `index(sub)` | Índice | Levanta `ValueError` se não encontrar |
| `count(sub)` | Quantidade | Ocorrências sem sobreposição |
| `startswith` / `endswith` | `bool` | Aceita tupla de opções |
| `isdigit` / `isalpha` / `isalnum` | `bool` | Validação de conteúdo |

```python title="Buscando dentro do texto"
path = "relatorio_2026.csv"

print("2026" in path)                 # True
print(path.find("2026"))              # 10
print(path.find("xml"))               # -1
print(path.endswith((".csv", ".tsv")))  # True
print("guia de python".count("i"))    # 2
print("42".isdigit(), "4a".isdigit())  # True False
```

### Divisão e junção

`split()` quebra texto em lista; `join()` faz o caminho inverso:

```python title="split e join"
line = "ana;bia;caio"

print(line.split(";"))               # ['ana', 'bia', 'caio']
print("um dois  três".split())       # ['um', 'dois', 'três'] — colapsa espaços
print("a:b:c".split(":", 1))         # ['a', 'b:c'] — limite de divisões
print("chave=valor".partition("="))  # ('chave', '=', 'valor')

lines = "linha 1\nlinha 2\nlinha 3"
print(lines.splitlines())

print(" | ".join(["ana", "bia"]))    # 'ana | bia'
print("".join(reversed("Python")))   # 'nohtyP'
```

<Aside type="tip" title="split() sem argumento é diferente">
  `"a  b".split()` (sem argumento) trata qualquer sequência de espaços, tabs e quebras como
  um único separador e descarta vazios. Já `"a  b".split(" ")` devolve `['a', '', 'b']`.
</Aside>

### Substituição e preenchimento

Para trocar trechos e alinhar saída em colunas:

```python title="replace, zfill e center"
text = "Guia de Java"

print(text.replace("Java", "Python"))
print("a-b-c-d".replace("-", "", 2))   # limite de substituições

print("7".zfill(3))                    # '007'
print("total".ljust(12, "."), "R$ 10")
print("total".rjust(12), "|")
print(" menu ".center(20, "="))

print("prefixo_arquivo.txt".removeprefix("prefixo_"))
print("arquivo.txt".removesuffix(".txt"))
```

```txt title="Output"
Guia de Python
abc-d
007
total....... R$ 10
       total |
=======" menu "=======
arquivo.txt
arquivo
```

## Formatação com f-strings

A f-string (PEP 498) avalia expressões dentro do próprio literal e é a forma recomendada
desde o Python 3.6:

```python title="Interpolação"
name = "Ana"
items = 3
price = 1234.5

print(f"{name} levou {items} itens")
print(f"Total: R$ {price:.2f}")
print(f"Dobro: {items * 2}")
print(f"Maiúsculas: {name.upper()}")
print(f"{'centralizado':^24}|")
```

```txt title="Output"
Ana levou 3 itens
Total: R$ 1234.50
Dobro: 6
Maiúsculas: ANA
      centralizado      |
```

### Mini-linguagem de formato

O trecho após `:` controla alinhamento, largura, precisão e notação:

| Formato | Efeito | Exemplo |
| :--- | :--- | :--- |
| `:.2f` | Duas casas decimais | `1234.50` |
| `:,.2f` | Separador de milhar | `1,234.50` |
| `:>10` `:<10` `:^10` | Alinha à direita, esquerda, centro | — |
| `:08.2f` | Preenche com zeros | `01234.50` |
| `:%` / `:.1%` | Percentual | `0.156` → `15.6%` |
| `:e` | Notação científica | `1.234500e+03` |
| `:b` `:o` `:x` | Binário, octal, hexadecimal | `255` → `ff` |
| `:+` | Sinal explícito | `+42` |

```python title="Relatório alinhado"
products = [("Teclado", 349.9, 3), ("Mouse", 89.9, 12), ("Monitor", 1899.0, 1)]

print(f"{'Produto':<12}{'Preço':>12}{'Qtd':>6}{'Total':>14}")
print("-" * 44)

for name, price, quantity in products:
    print(f"{name:<12}{price:>12,.2f}{quantity:>6}{price * quantity:>14,.2f}")

print(f"\n{255:b} {255:o} {255:x} {0.1567:.1%}")
```

```txt title="Output"
Produto            Preço   Qtd         Total
--------------------------------------------
Teclado         349.90     3      1,049.70
Mouse            89.90    12      1,078.80
Monitor       1,899.00     1      1,899.00

11111111 377 ff 15.7%
```

### Depuração com `=`

O sufixo `=` dentro da chave imprime a expressão e o valor, útil em depuração rápida:

```python title="f-string de depuração"
width, height = 3, 4

print(f"{width=}")
print(f"{width * height=}")
print(f"{'python'.upper()=}")
```

```txt title="Output"
width=3
width * height=12
'python'.upper()='PYTHON'
```

<Aside type="note" title="Alternativas mais antigas">
  `"%s" % nome` (estilo C) e `"{}".format(nome)` ainda funcionam e aparecem em código legado.
  Em código novo, prefira f-string: é mais rápida, mais curta e avalia a expressão no lugar.
  Para textos com marcadores preenchidos depois, existe `string.Template`.
</Aside>

## Texto, Unicode e Bytes

Em Python 3, `str` é uma sequência de **pontos de código Unicode**, e `bytes` é uma sequência
de octetos. A conversão entre os dois é explícita:

```python title="Codificação e decodificação"
text = "Café"

encoded = text.encode("utf-8")
print(encoded)              # b'Caf\xc3\xa9'
print(len(text), len(encoded))   # 4 5 — 'é' ocupa 2 bytes em UTF-8

print(encoded.decode("utf-8"))   # 'Café'
print(ord("é"), chr(233))        # 233 é
print("é".encode("latin-1"))     # b'\xe9'
```

<Aside type="caution" title="UnicodeDecodeError quase sempre é codificação errada">
  Ler um arquivo salvo em Latin-1 assumindo UTF-8 levanta `UnicodeDecodeError`. Informe a
  codificação explicitamente ao abrir arquivos — o assunto volta em
  [Arquivos, JSON e CSV](../../stdlib/files/).
</Aside>

## Exercício

Crie um arquivo `slug.py` que transforme títulos em identificadores de URL.

1. Leia um título com `input()`;
2. Normalize: remova espaços das bordas e converta para minúsculas;
3. Substitua espaços por hífens e remova pontuação (`.`, `,`, `!`, `?`, `:`);
4. Troque caracteres acentuados pelos equivalentes sem acento usando um dicionário de mapeamento;
5. Garanta que não existam hífens duplicados nem hífens nas bordas;
6. Mostre o título original, o slug e o comprimento de ambos, alinhados em colunas.

<details>
  <summary>Possível resposta</summary>

  ```python title="slug.py"
  ACCENTS = str.maketrans("áàâãéêíóôõúüç", "aaaaeeiooouuc")
  PUNCTUATION = ".,!?:;"

  title = input("Título: ").strip()

  slug = title.lower().translate(ACCENTS)

  for character in PUNCTUATION:
      slug = slug.replace(character, "")

  slug = "-".join(slug.split())

  while "--" in slug:
      slug = slug.replace("--", "-")

  slug = slug.strip("-")

  print(f"{'Original:':<12}{title:<40}{len(title):>4}")
  print(f"{'Slug:':<12}{slug:<40}{len(slug):>4}")
  ```

  `str.maketrans` cria a tabela de tradução usada por `translate()`, que substitui vários
  caracteres em uma única passada.
</details>

## Perguntas de revisão

### Criação e imutabilidade

**1. O que significa dizer que strings são imutáveis?**

<details>
  <summary>Possível resposta</summary>

  Que o objeto não pode ser alterado depois de criado. Métodos como `upper()` ou `replace()`
  devolvem uma **nova** string, e a atribuição por índice (`s[0] = "P"`) levanta `TypeError`.
</details>

**2. Por que concatenar strings dentro de um laço é ineficiente?**

<details>
  <summary>Possível resposta</summary>

  Porque cada `+=` cria um novo objeto e copia todo o conteúdo anterior. Para muitos pedaços,
  o custo cresce rapidamente; acumular em lista e finalizar com `"".join(lista)` faz uma
  única alocação.
</details>

**3. Para que serve o prefixo `r` em `r"\d+"`?**

<details>
  <summary>Possível resposta</summary>

  Ele cria uma *raw string*: a barra invertida deixa de iniciar sequências de escape e é
  tratada como caractere literal. É a forma padrão de escrever expressões regulares e
  caminhos do Windows.
</details>

### Índices e fatiamento

**4. Qual a diferença entre `texto[10]` e `texto[10:20]` quando o texto tem 5 caracteres?**

<details>
  <summary>Possível resposta</summary>

  O índice direto levanta `IndexError`, porque a posição não existe. O fatiamento devolve
  string vazia `""`, ajustando silenciosamente os limites.
</details>

**5. Como inverter uma string?**

<details>
  <summary>Possível resposta</summary>

  Com a fatia de passo negativo `texto[::-1]`, ou com `"".join(reversed(texto))`. A primeira
  forma é a idiomática.
</details>

### Métodos e formatação

**6. Qual a diferença entre `find()` e `index()`?**

<details>
  <summary>Possível resposta</summary>

  Ambos devolvem a posição da primeira ocorrência, mas `find()` devolve `-1` quando não
  encontra, enquanto `index()` levanta `ValueError`. Use `find()` em fluxo normal e `index()`
  quando a ausência for realmente excepcional.
</details>

**7. O que muda entre `split()` e `split(" ")`?**

<details>
  <summary>Possível resposta</summary>

  `split()` sem argumento trata qualquer sequência de espaços em branco como um único
  separador e ignora vazios. `split(" ")` divide em cada espaço, produzindo strings vazias
  quando há espaços consecutivos.
</details>

**8. Como formatar `1234.5` como `R$ 1.234,50`?**

<details>
  <summary>Possível resposta</summary>

  A f-string produz o formato inglês com `f"R$ {valor:,.2f}"` → `R$ 1,234.50`. Para o padrão
  brasileiro, troque os separadores depois
  (`f"{valor:,.2f}".replace(",", "X").replace(".", ",").replace("X", ".")`) ou use o módulo
  `locale`.
</details>

**9. O que faz `f"{valor=}"`?**

<details>
  <summary>Possível resposta</summary>

  Imprime a expressão literal seguida de `=` e do valor avaliado — por exemplo `valor=42`. É
  um atalho de depuração introduzido no Python 3.8.
</details>

### Unicode

**10. Qual a diferença entre `str` e `bytes`?**

<details>
  <summary>Possível resposta</summary>

  `str` é uma sequência de caracteres Unicode, usada para texto. `bytes` é uma sequência de
  octetos, usada em arquivos binários e comunicação de rede. A conversão é explícita, com
  `encode()` e `decode()`, e sempre exige uma codificação (normalmente UTF-8).
</details>
