Este guia apresenta a linguagem **Python** de forma progressiva, do primeiro `print()`
até módulos, classes, exceções e biblioteca padrão. Ele serve tanto para quem está
começando a programar quanto para quem já domina outra linguagem e quer mapear os
equivalentes em Python.

Python é uma linguagem interpretada, de tipagem dinâmica e forte, multiparadigma e com
uma biblioteca padrão extensa. É usada em automação de tarefas, análise de dados,
aprendizado de máquina, APIs web, scripts de infraestrutura e ensino de programação.
A referência oficial da linguagem é mantida pela **Python Software Foundation** e a
evolução acontece pelo processo de **PEPs** (*Python Enhancement Proposals*).

Todos os exemplos deste guia são executáveis: rodam no interpretador oficial (CPython)
a partir do terminal ou do REPL, sem dependências externas — exceto na aula de ambiente
virtual, que trata justamente da instalação de pacotes.

## Como o guia está organizado

<Steps>

1. **Preparar o ambiente** — [Introdução](basics/introduction/): instalar o interpretador, usar o REPL e executar o primeiro script.

2. **Dominar os tipos básicos** — [Variáveis e Tipos](basics/variables/) e [Expressões e Operadores](basics/operators/): como Python guarda e combina valores.

3. **Controlar o fluxo** — [Decisão e Repetição](basics/statements/): `if`, `match`, `for`, `while` e a indentação como sintaxe.

4. **Escrever funções** — [Funções](basics/functions/): parâmetros, valores padrão, `*args`, `**kwargs` e escopo.

5. **Manipular dados** — [Strings](data/strings/), [Coleções](data/collections/) e [Compreensões e Geradores](data/comprehensions/).

6. **Organizar o projeto** — [Módulos e Pacotes](structure/modules/), [Classes e Objetos](structure/classes/) e [Erros e Exceções](structure/errors/).

7. **Usar a biblioteca padrão** — [Arquivos, JSON e CSV](stdlib/files/), [Data e Hora](stdlib/datetime/) e [Expressões Regulares](stdlib/regex/).

8. **Isolar dependências** — [Ambiente e Pacotes com uv](tools/uv/): o passo obrigatório antes de instalar qualquer pacote, e [venv e pip](tools/venv/) para entender o que acontece por baixo.

</Steps>

<Aside type="note" title="Versão de referência e ferramenta padrão">
  O guia usa **Python 3.14** como versão de referência e sinaliza recursos que exigem
  versões específicas (`match` chegou no 3.10, f-strings ganharam sintaxe mais livre no
  3.12). Os comandos de terminal usam **uv** como caminho principal — ele instala o
  interpretador, cria o ambiente e executa o script com um comando só. As equivalências com
  `python3`, `venv` e `pip` aparecem sempre ao lado, para quem já tem o ambiente pronto.
</Aside>

## Ferramentas

As ferramentas abaixo cobrem todo o ciclo de trabalho com Python, da instalação do interpretador à formatação do código:

| Categoria | Ferramenta | Uso principal |
| --------- | ---------- | ------------- |
| Gerenciador | [uv](https://docs.astral.sh/uv/) | Instalar o Python, criar ambientes, resolver dependências e executar scripts |
| Interpretador | [CPython](https://www.python.org/downloads/) | Executar scripts e abrir o REPL |
| Editor | [Visual Studio Code](https://code.visualstudio.com/) | Escrever código com realce, depuração e terminal integrado |
| Extensão | [Python (Microsoft)](https://marketplace.visualstudio.com/items?itemName=ms-python.python) | IntelliSense, depurador e seleção de interpretador |
| Ambiente | [venv](https://docs.python.org/3/library/venv.html) | Alternativa da biblioteca padrão para isolar dependências |
| Pacotes | [pip](https://pip.pypa.io/) e [PyPI](https://pypi.org/) | Registro público de bibliotecas e instalador tradicional |
| Formatação e lint | [Ruff](https://docs.astral.sh/ruff/) | Formatar e analisar o código seguindo a PEP 8 |
| Notebooks | [Jupyter](https://jupyter.org/) | Explorar dados de forma interativa |

<Aside type="tip" title="Sem instalar nada">
  Para testar trechos rápidos sem instalar o interpretador, use o
  [Python Tutor](https://pythontutor.com/) (que também mostra a memória passo a passo)
  ou o console oficial em [python.org](https://www.python.org/shell/).
</Aside>
