Uma **expressão** é qualquer trecho de código que produz um valor: `2 + 3`, `len(name)`,
`price > 100 and stock > 0`. Uma **instrução** (*statement*) executa uma ação: uma
atribuição, um `if`, um `for`. Programas são feitos de instruções que combinam expressões.

Este tópico percorre os operadores de Python, a ordem em que eles são avaliados e alguns
comportamentos que surpreendem quem vem de outras linguagens — a divisão que sempre devolve
`float`, a comparação encadeada e os operadores lógicos que devolvem operandos em vez de
booleanos.

## Objetivo

Aplicar operadores aritméticos, de comparação, lógicos, de identidade, de associação e bit
a bit, prever o resultado de expressões pela tabela de precedência, usar comparação
encadeada e expressões condicionais, e reconhecer a avaliação em curto-circuito.

## Operadores Aritméticos

Python oferece sete operadores aritméticos, dois deles ausentes em boa parte das linguagens: a divisão inteira e a potência.

| Operador | Nome | Exemplo | Resultado |
| :--- | :--- | :--- | :--- |
| `+` | Adição | `7 + 2` | `9` |
| `-` | Subtração | `7 - 2` | `5` |
| `*` | Multiplicação | `7 * 2` | `14` |
| `/` | Divisão real | `7 / 2` | `3.5` |
| `//` | Divisão inteira (piso) | `7 // 2` | `3` |
| `%` | Resto (módulo) | `7 % 2` | `1` |
| `**` | Potência | `7 ** 2` | `49` |

```python title="Divisão real e divisão inteira"
print(7 / 2)     # 3.5  — sempre float, mesmo com divisão exata
print(6 / 2)     # 3.0
print(7 // 2)    # 3    — piso da divisão
print(-7 // 2)   # -4   — arredonda para baixo, não em direção a zero
print(7 % 2)     # 1
print(-7 % 2)    # 1    — o sinal do resto segue o divisor
print(2 ** 10)   # 1024
print(divmod(7, 2))  # (3, 1) — quociente e resto de uma vez
```

<Aside type="caution" title="/ nunca devolve int">
  Em Python 3, `/` é sempre divisão real: `6 / 2` resulta em `3.0`, não `3`. Para índices,
  contadores e paginação, use `//`. Essa foi uma das mudanças incompatíveis entre Python 2
  e 3.
</Aside>

### Aplicações do resto

O operador `%` vai além do teste de paridade: ele resolve ciclos, conversões de tempo e distribuição em faixas. Os exemplos abaixo mostram os usos mais frequentes:

```python title="Usos clássicos de %"
number = 17

print(number % 2 == 0)      # False — teste de paridade
print(number % 5)           # 2     — posição em ciclo de 5
print(f"{number % 12}h")    # 5h    — relógio de 12 horas

# Formatação de tempo
seconds = 3725
hours, rest = divmod(seconds, 3600)
minutes, secs = divmod(rest, 60)
print(f"{hours:02d}:{minutes:02d}:{secs:02d}")
```

```txt title="Output" frame="terminal"
False
2
5h
01:02:05
```

### Operadores em outros tipos

`+` e `*` também operam sobre sequências, com significado de concatenação e repetição.

```python title="Sobrecarga em sequências"
print("Dev" + "Lab")      # 'DevLab'
print("ab" * 3)           # 'ababab'
print([1, 2] + [3])       # [1, 2, 3]
print([0] * 4)            # [0, 0, 0, 0]
print("-" * 30)           # separador visual

# Tipagem forte: sem mistura implícita
# print("Total: " + 10)   # TypeError
print("Total: " + str(10))
```

## Atribuição Aumentada

Os operadores compostos aplicam a operação e reatribuem o resultado ao mesmo nome, encurtando expressões repetitivas:

| Operador | Equivale a |
| :--- | :--- |
| `x += 1` | `x = x + 1` |
| `x -= 1` | `x = x - 1` |
| `x *= 2` | `x = x * 2` |
| `x /= 2` | `x = x / 2` |
| `x //= 2` | `x = x // 2` |
| `x %= 3` | `x = x % 3` |
| `x **= 2` | `x = x ** 2` |

```python title="Incremento e mutabilidade"
total = 10
total += 5
print(total)   # 15

# Não existe ++ nem -- em Python
# total++     # SyntaxError

items = [1, 2]
items += [3]        # altera a lista no lugar (como extend)
print(items)        # [1, 2, 3]

text = "ab"
text += "c"         # str é imutável: cria um novo objeto
print(text)         # 'abc'
```

<Aside type="note" title="Não existe ++ em Python">
  Incremento e decremento unários não fazem parte da linguagem. `++x` é interpretado como
  dois sinais de "mais unário" (`+(+x)`) e não altera nada; `x--` é erro de sintaxe. Use
  `x += 1`.
</Aside>

## Operadores de Comparação

Operadores de comparação produzem sempre `True` ou `False` e funcionam com números, strings e sequências:

| Operador | Significado |
| :--- | :--- |
| `==` | Igual a (compara valores) |
| `!=` | Diferente de |
| `>` `<` | Maior que, menor que |
| `>=` `<=` | Maior ou igual, menor ou igual |

```python title="Comparações"
print(10 == 10.0)       # True  — valores numéricos iguais
print("a" < "b")        # True  — ordem lexicográfica por code point
print("Z" < "a")        # True  — maiúsculas vêm antes na tabela Unicode
print([1, 2] < [1, 3])  # True  — compara elemento a elemento
print(len("dev") >= 3)  # True
```

## Comparação Encadeada

Python permite encadear comparações como na notação matemática — algo raro entre linguagens.

```python title="Encadeamento"
age = 25

print(18 <= age < 65)          # True — avalia idade uma única vez
print(0 < age < 18)            # False

# Em outras linguagens seria necessário:
print(age >= 18 and age < 65)  # equivalente, porém mais verboso
```

<Aside type="tip" title="Encadeamento avalia uma vez só">
  Em `18 <= idade() < 65`, a função `idade()` é chamada **uma** vez. O encadeamento também
  aplica curto-circuito: se a primeira comparação falhar, a segunda nem é avaliada.
</Aside>

## Operadores Lógicos

Os operadores lógicos combinam condições — mas, diferente de outras linguagens, `and` e `or` devolvem um dos **operandos**, e não necessariamente um booleano:

| Operador | Devolve |
| :--- | :--- |
| `and` | O primeiro operando *falsy*, ou o último valor |
| `or` | O primeiro operando *truthy*, ou o último valor |
| `not` | O booleano invertido (`True` ou `False`) |

```python title="and e or devolvem operandos"
print(True and "texto")    # 'texto'
print(0 and "texto")       # 0        — curto-circuito no falsy
print("" or "padrão")      # 'padrão' — idioma de valor padrão
print(None or 0 or "fim")  # 'fim'
print(not "")              # True
```

## Curto-circuito

A avaliação para assim que o resultado já é conhecido, de modo que o segundo operando pode nunca ser executado:

```python title="Avaliação preguiçosa"
def expensive():
    print("função chamada")
    return True


user = None

# expensive() NÃO é chamada: o primeiro operando já é falsy
if user is not None and expensive():
    print("nunca chega aqui")

# Protege contra erro de atributo em None
name = user.name if user is not None else "visitante"
print(name)
```

```txt title="Output" frame="terminal"
visitante
```

<Aside type="caution" title="or para valor padrão engole zero">
  `quantity = informed or 10` substitui `0` por `10`, porque `0` é *falsy*. Quando `0` é um
  valor legítimo, teste explicitamente:
  `quantity = informed if informed is not None else 10`.
</Aside>

## Identidade e Associação

Dois grupos de operadores respondem a perguntas distintas: um sobre o objeto na memória, outro sobre pertencimento a um iterável.

| Operador | Pergunta |
| :--- | :--- |
| `is` / `is not` | É (não é) o mesmo objeto na memória? |
| `in` / `not in` | Está (não está) contido no iterável? |

```python title="in e is"
languages = ["python", "javascript", "go"]

print("python" in languages)       # True
print("rust" not in languages)     # True
print("py" in "python")            # True — substring
print("id" in {"id": 1, "n": 2})   # True — procura nas CHAVES

value = None
print(value is None)               # True — teste idiomático
print(value is not None)           # False
```

<Aside type="note" title="in em dicionário olha as chaves">
  `"id" in user` verifica as **chaves** do dicionário, não os valores. Para procurar entre
  valores, use `in user.values()`.
</Aside>

## Operadores Bit a Bit

Operadores bit a bit trabalham sobre a representação binária dos inteiros e aparecem em máscaras, flags de configuração e otimizações:

| Operador | Nome | Exemplo (`a = 12`, `b = 10`) |
| :--- | :--- | :--- |
| `&` | AND | `a & b` → `8` |
| `\|` | OR | `a \| b` → `14` |
| `^` | XOR | `a ^ b` → `6` |
| `~` | NOT | `~a` → `-13` |
| `<<` | Deslocamento à esquerda | `a << 1` → `24` |
| `>>` | Deslocamento à direita | `a >> 1` → `6` |

```python title="Bits e máscaras"
a, b = 0b1100, 0b1010

print(bin(a & b))   # 0b1000
print(bin(a | b))   # 0b1110
print(bin(a ^ b))   # 0b110
print(a << 1)       # 24 — equivale a a * 2
print(a >> 2)       # 3  — equivale a a // 4

# | e & também operam sobre conjuntos e dicionários (3.9+)
print({1, 2} | {2, 3})              # {1, 2, 3}
print({"a": 1} | {"b": 2})          # {'a': 1, 'b': 2}
```

## Precedência e Associatividade

Da maior para a menor precedência:

| Nível | Operadores |
| :--- | :--- |
| 1 | `()` — agrupamento |
| 2 | `**` (associativo à direita) |
| 3 | `+x`, `-x`, `~x` — unários |
| 4 | `*`, `/`, `//`, `%` |
| 5 | `+`, `-` |
| 6 | `<<`, `>>` |
| 7 | `&` → `^` → `\|` |
| 8 | `in`, `not in`, `is`, `is not`, `<`, `<=`, `>`, `>=`, `!=`, `==` |
| 9 | `not` |
| 10 | `and` |
| 11 | `or` |
| 12 | `if ... else` (expressão condicional) |
| 13 | `:=` (walrus) |

```python title="Precedência na prática"
print(2 + 3 * 4)        # 14 — multiplicação primeiro
print((2 + 3) * 4)      # 20 — parênteses mudam a ordem
print(2 ** 3 ** 2)      # 512 — ** associa à direita: 2 ** (3 ** 2)
print(-2 ** 2)          # -4  — ** tem precedência sobre o menos unário
print((-2) ** 2)        # 4

print(True or False and False)    # True — and antes de or
print((True or False) and False)  # False
```

<Aside type="tip" title="Parênteses valem mais que memorizar a tabela">
  A PEP 8 e a prática recomendam parênteses explícitos em expressões compostas. Eles custam
  dois caracteres e eliminam a dúvida de quem lê o código depois.
</Aside>

## Expressões Condicionais e Walrus

Duas construções permitem decidir e atribuir dentro de uma expressão, sem abrir um bloco indentado:

```python title="Ternário e operador morsa"
age = 20

# Expressão condicional (ternário)
status = "adulto" if age >= 18 else "menor"
print(status)

# Encadeamento (use com moderação)
size = 42
label = "pequeno" if size < 10 else "médio" if size < 100 else "grande"
print(label)

# Operador morsa: atribui e usa no mesmo lugar
text = "DevLab Python"
if (words := text.split()) and len(words) > 1:
    print(f"{len(words)} palavras: {words}")
```

```txt title="Output" frame="terminal"
adulto
médio
2 palavras: ['DevLab', 'Python']
```

## Desafio

Escreva `precedence.py`, uma tabela que prova a ordem de avaliação.

1. Monte uma lista de expressões como strings, por exemplo `"2 + 3 * 4"`;
2. Avalie cada uma com `eval()` e mostre o resultado ao lado da versão com parênteses;
3. Inclua ao menos um caso de `**` à direita, um de menos unário e um de `and`/`or`;
4. Marque com um símbolo as expressões cujo resultado difere da leitura da esquerda para a direita;
5. Formate a saída em colunas alinhadas.

<details>
  <summary>Possível resposta</summary>

  ```python title="precedence.py"
  CASES = [
      ("2 + 3 * 4", "(2 + 3) * 4"),
      ("2 ** 3 ** 2", "(2 ** 3) ** 2"),
      ("-2 ** 2", "(-2) ** 2"),
      ("True or False and False", "(True or False) and False"),
      ("10 - 4 - 3", "10 - (4 - 3)"),
  ]

  print(f"{'Expressão':<28}{'Python':>10}{'Agrupada':>12}   Difere?")
  print("-" * 62)

  for expression, grouped in CASES:
      natural = eval(expression)
      forced = eval(grouped)
      flag = "  <-- sim" if natural != forced else ""
      print(f"{expression:<28}{str(natural):>10}{str(forced):>12}{flag}")
  ```

  `eval()` aqui é seguro porque as expressões são literais escritos no próprio arquivo.
  Nunca aplique `eval()` sobre texto vindo do usuário.
</details>

## Perguntas de revisão

### Aritmética

**1. Qual a diferença entre `/` e `//`?**

<details>
  <summary>Possível resposta</summary>

  `/` é a divisão real e devolve sempre `float` (`6 / 2` é `3.0`). `//` é a divisão inteira
  (piso): descarta a parte fracionária arredondando para baixo, devolvendo `int` quando os
  dois operandos são inteiros.
</details>

**2. Por que `-7 // 2` é `-4` e não `-3`?**

<details>
  <summary>Possível resposta</summary>

  Porque `//` arredonda em direção a menos infinito (piso), e não em direção a zero.
  `-7 / 2` é `-3.5`, e o piso de `-3.5` é `-4`.
</details>

**3. Como obter quociente e resto em uma única operação?**

<details>
  <summary>Possível resposta</summary>

  Com `divmod(a, b)`, que devolve a tupla `(a // b, a % b)`. É útil para converter segundos
  em horas/minutos ou dividir itens em páginas.
</details>

### Lógica e comparação

**4. O que `"" or "padrão"` devolve, e por quê?**

<details>
  <summary>Possível resposta</summary>

  Devolve `"padrão"`. O operador `or` avalia o primeiro operando; como `""` é *falsy*, ele
  devolve o segundo operando — o valor em si, não um booleano.
</details>

**5. O que significa avaliação em curto-circuito?**

<details>
  <summary>Possível resposta</summary>

  Significa que o segundo operando de `and`/`or` só é avaliado se necessário. Em
  `user is not None and user.name`, o acesso a `.name` nunca acontece quando `user` é
  `None`, o que evita `AttributeError`.
</details>

**6. Qual a vantagem de `18 <= age < 65` sobre `age >= 18 and age < 65`?**

<details>
  <summary>Possível resposta</summary>

  É mais legível e avalia `age` apenas uma vez — relevante quando o operando é uma chamada
  de função ou uma expressão custosa.
</details>

### Identidade, associação e precedência

**7. Quando usar `is` em vez de `==`?**

<details>
  <summary>Possível resposta</summary>

  Apenas para comparar com os *singletons* `None`, `True` e `False`, ou quando a pergunta é
  realmente sobre identidade de objeto. Para comparar valores, `==`.
</details>

**8. O que `in` verifica em um dicionário?**

<details>
  <summary>Possível resposta</summary>

  As chaves. `"id" in user` é `True` se existir a chave `"id"`. Para buscar entre os valores
  é preciso escrever `valor in user.values()`.
</details>

**9. Por que `-2 ** 2` resulta em `-4`?**

<details>
  <summary>Possível resposta</summary>

  Porque `**` tem precedência maior que o menos unário: a expressão é lida como `-(2 ** 2)`.
  Para elevar o número negativo, escreva `(-2) ** 2`, que resulta em `4`.
</details>

**10. Por que `2 ** 3 ** 2` é `512`?**

<details>
  <summary>Possível resposta</summary>

  Porque `**` é associativo à direita: a expressão equivale a `2 ** (3 ** 2)`, ou seja
  `2 ** 9`. Todos os outros operadores aritméticos associam à esquerda.
</details>
