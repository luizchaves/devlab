Um programa que só executa de cima para baixo resolve pouco. **Estruturas de controle**
permitem escolher caminhos conforme uma condição e repetir trabalho enquanto fizer sentido.
Em Python, esses blocos são delimitados por **indentação**, o que torna o recuo parte da
sintaxe, e não apenas do estilo.

Este tópico cobre decisão (`if`, `elif`, `else`, `match`) e repetição (`for`, `while`), além
dos comandos que alteram o fluxo de um laço.

## Objetivo

Escrever blocos corretamente indentados, encadear decisões com `if`/`elif`/`else`, aplicar
casamento de padrões com `match`/`case`, percorrer sequências com `for` e `range`,
`enumerate` e `zip`, repetir por condição com `while`, e controlar o fluxo com `break`,
`continue`, `else` de laço e `pass`.

## Blocos e Indentação

Toda estrutura de controle termina com dois-pontos e abre um bloco indentado.

```python title="Anatomia de um bloco"
temperature = 32

if temperature > 30:
    print("Está quente")       # dentro do bloco
    print("Beba água")         # ainda no bloco
print("Fim da checagem")       # fora do bloco
```

| Regra | Detalhe |
| :--- | :--- |
| Recuo padrão | **4 espaços** por nível (PEP 8) |
| Consistência | Todas as linhas do mesmo bloco com o mesmo recuo |
| Tabs e espaços | Não misture: gera `TabError` |
| Bloco vazio | Use `pass` como marcador |

```python title="Erros comuns de indentação"
# IndentationError: expected an indented block
# if True:
# print("faltou recuo")

# Bloco vazio precisa de pass
def todo_later():
    pass


for _ in range(3):
    pass
```

<Aside type="caution" title="Configure o editor uma vez">
  No VS Code, ative `"editor.insertSpaces": true` e `"editor.tabSize": 4` para arquivos
  Python. Isso elimina a maior fonte de `TabError` em código copiado da internet.
</Aside>

## `if`, `elif` e `else`

A decisão mais comum encadeia condições avaliadas em ordem, da mais restritiva para a mais ampla:

```python title="Encadeamento de decisões"
score = 78

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"

print(f"Nota {score} -> conceito {grade}")
```

```txt title="Output"
Nota 78 -> conceito C
```

Apenas o **primeiro** bloco cuja condição seja verdadeira é executado. Como as condições são
avaliadas em ordem, a sequência importa: começar por `score >= 70` classificaria `95` como
`"C"`.

## Condições e Valores *Truthy*

Como qualquer objeto pode ser avaliado em contexto booleano, os testes idiomáticos dispensam comparações explícitas com zero, string vazia ou lista vazia:

```python title="Testes idiomáticos"
items = []
name = ""
user = None

if not items:
    print("lista vazia")

if not name:
    print("nome não informado")

if user is None:            # explícito para None
    print("sem usuário")

# Combinações
age, has_ticket = 20, True
if 18 <= age < 65 and has_ticket:
    print("entrada liberada")
```

<Aside type="tip" title="Cláusula de guarda">
  Em vez de aninhar `if` dentro de `if`, trate primeiro os casos de saída e retorne cedo.
  O corpo principal fica no nível mais externo, e a leitura melhora:

  ```python
  def discount(user):
      if user is None:
          return 0
      if not user["active"]:
          return 0
      return 0.1
  ```
</Aside>

## `match` e `case`

O casamento de padrões estruturais chegou no **Python 3.10** (PEP 634). Ele vai além do
`switch` de outras linguagens: além de comparar valores, desestrutura listas, dicionários e
objetos.

```python title="Casamento de padrões"
def describe(command):
    match command.split():
        case ["sair"] | ["quit"]:
            return "encerrando"
        case ["abrir", filename]:
            return f"abrindo {filename}"
        case ["mover", x, y]:
            return f"movendo para ({x}, {y})"
        case ["ajuda", *topics] if topics:
            return f"ajuda sobre: {', '.join(topics)}"
        case _:
            return "comando desconhecido"


for text in ["sair", "abrir dados.csv", "mover 3 7", "ajuda for while", "xyz"]:
    print(f"{text:<18} -> {describe(text)}")
```

```txt title="Output"
sair               -> encerrando
abrir dados.csv    -> abrindo dados.csv
mover 3 7          -> movendo para (3, 7)
ajuda for while    -> ajuda sobre: for, while
xyz                -> comando desconhecido
```

| Padrão | Sintaxe | Casa com |
| :--- | :--- | :--- |
| Literal | `case 404:` | Valor exato |
| Alternativa | `case "a" \| "b":` | Qualquer uma das opções |
| Captura | `case value:` | Qualquer coisa, guardando em `value` |
| Sequência | `case [x, y]:` | Lista/tupla com dois itens |
| Resto | `case [first, *rest]:` | Primeiro item e o restante |
| Mapeamento | `case {"id": id}:` | Dicionário com a chave `"id"` |
| Classe | `case Point(x=0):` | Instância com atributo específico |
| Guarda | `case x if x > 10:` | Padrão + condição adicional |
| Curinga | `case _:` | Qualquer valor (caso padrão) |

```python title="Padrões de mapeamento"
def handle(event):
    match event:
        case {"type": "click", "x": x, "y": y}:
            return f"clique em ({x}, {y})"
        case {"type": "key", "key": key}:
            return f"tecla {key}"
        case {"type": type_}:
            return f"evento não tratado: {type_}"
        case _:
            return "formato inválido"


print(handle({"type": "click", "x": 10, "y": 42}))
print(handle({"type": "key", "key": "Enter"}))
print(handle({"type": "scroll"}))
```

<Aside type="caution" title="case NOME captura, não compara">
  `case status:` não compara com uma variável chamada `status` — ele **captura** o valor em
  `status` e sempre casa. Para comparar com uma constante, use um nome qualificado, como
  `case Status.OK:`, ou uma guarda: `case value if value == status:`.
</Aside>

## Laço `for`

O `for` de Python percorre **iteráveis** — não existe a forma `for (i = 0; i < n; i++)`.

```python title="Percorrendo iteráveis"
for language in ["Python", "JavaScript", "Go"]:
    print(language)

for char in "Py":
    print(char)

for key, value in {"id": 1, "name": "Ana"}.items():
    print(f"{key} = {value}")
```

### `range`

`range` gera sequências numéricas sob demanda e aceita início, fim e passo:

```python title="range(início, fim, passo)"
print(list(range(5)))          # [0, 1, 2, 3, 4]
print(list(range(2, 6)))       # [2, 3, 4, 5]
print(list(range(0, 10, 3)))   # [0, 3, 6, 9]
print(list(range(5, 0, -1)))   # [5, 4, 3, 2, 1]

for i in range(3):
    print(f"tentativa {i + 1}")
```

<Aside type="note" title="O fim é exclusivo">
  `range(1, 5)` produz `1, 2, 3, 4`. O limite superior nunca entra — a mesma convenção do
  fatiamento de listas e strings. `range` também não cria a lista inteira na memória: ele
  gera os valores sob demanda.
</Aside>

### `enumerate` e `zip`

Duas funções embutidas eliminam o controle manual de índices e o percurso paralelo de duas listas:

```python title="Índice e pares"
languages = ["Python", "Rust", "Go"]
years = [1991, 2010, 2009]

for index, language in enumerate(languages, start=1):
    print(f"{index}. {language}")

for language, year in zip(languages, years):
    print(f"{language} surgiu em {year}")

print(list(zip(languages, years)))
```

```txt title="Output"
1. Python
2. Rust
3. Go
Python surgiu em 1991
Rust surgiu em 2010
Go surgiu em 2009
[('Python', 1991), ('Rust', 2010), ('Go', 2009)]
```

<Aside type="caution" title="Não itere por índice sem necessidade">
  `for i in range(len(items)): print(items[i])` funciona, mas é contra o idioma. Prefira
  `for item in items:` e, quando o índice for realmente necessário,
  `for i, item in enumerate(items):`.
</Aside>

## Laço `while`

Usado quando o número de repetições não é conhecido antecipadamente.

```python title="Repetição por condição"
total = 0
number = 1

while number <= 5:
    total += number
    number += 1

print(total)   # 15

# Laço controlado por sentinela
command = ""
while command != "sair":
    command = input("Comando (sair para encerrar): ")
    print(f"recebido: {command}")
```

<Aside type="caution" title="Laço infinito">
  Todo `while` precisa de algo que faça a condição virar falsa — normalmente uma variável
  atualizada dentro do corpo. Esquecer o `number += 1` produz um laço infinito; interrompa
  com <kbd>Ctrl</kbd>+<kbd>C</kbd>.
</Aside>

## `break`, `continue`, `else` e `pass`

Quatro comandos ajustam o fluxo dentro de um laço — ou logo ao redor dele:

| Comando | Efeito |
| :--- | :--- |
| `break` | Encerra o laço imediatamente |
| `continue` | Pula para a próxima iteração |
| `else` (de laço) | Executa **se o laço terminou sem `break`** |
| `pass` | Não faz nada; preenche um bloco vazio |

```python title="Controle de fluxo dentro do laço"
for number in range(1, 10):
    if number % 2 == 0:
        continue          # ignora pares
    if number > 7:
        break             # encerra o laço
    print(number, end=" ")

print()

# else de laço: útil em buscas
target = 42
for value in [1, 7, 13]:
    if value == target:
        print("encontrado")
        break
else:
    print("não encontrado no conjunto")
```

```txt title="Output"
1 3 5 7 
não encontrado no conjunto
```

<Aside type="tip" title="for...else é uma busca sem flag">
  O `else` do laço substitui o padrão de criar uma variável `found = False`. Ele só executa
  quando **nenhum** `break` aconteceu — ou seja, quando a busca terminou sem sucesso.
</Aside>

## Laços Aninhados

Um laço dentro de outro percorre combinações: o laço interno completa todas as suas iterações a cada passo do externo.

```python title="Tabuada"
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i * j:<3}", end="")
    print()
```

```txt title="Output"
1 x 1 = 1  1 x 2 = 2  1 x 3 = 3  
2 x 1 = 2  2 x 2 = 4  2 x 3 = 6  
3 x 1 = 3  3 x 2 = 6  3 x 3 = 9  
```

`break` interrompe apenas o laço mais interno. Para sair dos dois, extraia o trecho para uma
função e use `return`, ou controle com uma flag.

## Exercício

Crie um arquivo `menu.py` com um menu de terminal que roda até o usuário sair.

1. Mostre um menu com quatro opções: somar, listar, contar e sair;
2. Use `while True` com `break` na opção de saída;
3. Valide a entrada: se a opção não existir, avise e continue;
4. Na opção "somar", leia números até o usuário digitar vazio e mostre o total;
5. Na opção "listar", percorra uma lista com `enumerate` mostrando a posição;
6. Na opção "contar", use `range` para imprimir uma contagem regressiva;
7. Trate a opção de saída com `match` em vez de `if` encadeado.

<details>
  <summary>Possível resposta</summary>

  ```python title="menu.py"
  ITEMS = ["Python", "JavaScript", "Go", "Rust"]


  def sum_numbers():
      total = 0
      while True:
          raw = input("Número (vazio encerra): ")
          if not raw:
              break
          total += float(raw)
      print(f"Total: {total}")


  def list_items():
      for index, item in enumerate(ITEMS, start=1):
          print(f"{index}. {item}")


  def countdown():
      for value in range(5, 0, -1):
          print(value, end=" ")
      print("fim!")


  while True:
      print("\n[1] Somar  [2] Listar  [3] Contar  [4] Sair")
      option = input("Opção: ").strip()

      match option:
          case "1":
              sum_numbers()
          case "2":
              list_items()
          case "3":
              countdown()
          case "4":
              print("Até logo!")
              break
          case _:
              print("Opção inválida.")
  ```
</details>

## Desafio

Escreva `primes.py`, que analisa números com laços aninhados e `for...else`.

1. Peça um limite `n` ao usuário;
2. Para cada número de 2 até `n`, verifique se é primo dividindo pelos anteriores;
3. Use `for...else` para decidir se o número é primo, sem variável de flag;
4. Interrompa a checagem com `break` no primeiro divisor encontrado;
5. Ao final, imprima os primos em linhas de 10 números e o total encontrado;
6. Otimize testando divisores apenas até a raiz quadrada do número.

<details>
  <summary>Possível resposta</summary>

  ```python title="primes.py"
  limit = int(input("Limite: "))
  primes = []

  for number in range(2, limit + 1):
      for divisor in range(2, int(number ** 0.5) + 1):
          if number % divisor == 0:
              break
      else:
          primes.append(number)

  for index, prime in enumerate(primes, start=1):
      end = "\n" if index % 10 == 0 else " "
      print(f"{prime:>5}", end=end)

  print(f"\n\n{len(primes)} primos até {limit}.")
  ```

  O `else` do laço interno executa apenas quando nenhum divisor causou `break` — exatamente
  a definição de número primo.
</details>

## Perguntas de revisão

### Blocos e decisão

**1. Por que a indentação é obrigatória em Python?**

<details>
  <summary>Possível resposta</summary>

  Porque ela delimita blocos, papel que em outras linguagens cabe às chaves. Um recuo errado
  muda o bloco ao qual a linha pertence ou levanta `IndentationError`. A PEP 8 padroniza 4
  espaços por nível.
</details>

**2. Em um encadeamento `if`/`elif`/`else`, quantos blocos executam?**

<details>
  <summary>Possível resposta</summary>

  No máximo um: o primeiro cuja condição seja verdadeira. Por isso a ordem das condições
  importa, e faixas devem ser testadas da mais restritiva para a mais ampla.
</details>

**3. Como escrever um bloco que ainda não faz nada?**

<details>
  <summary>Possível resposta</summary>

  Com `pass`, que é uma instrução nula usada como marcador. Sem ela, o bloco vazio gera
  `IndentationError`.
</details>

### `match`/`case`

**4. Em que versão o `match` foi introduzido e o que ele faz além de comparar valores?**

<details>
  <summary>Possível resposta</summary>

  Python 3.10 (PEP 634). Além de comparar literais, ele desestrutura sequências, mapeamentos
  e objetos, capturando partes do valor em variáveis, e aceita guardas (`case x if x > 10:`).
</details>

**5. O que acontece em `case status:` quando existe uma variável `status` no escopo?**

<details>
  <summary>Possível resposta</summary>

  O padrão captura o valor testado e o atribui a `status`, casando com qualquer coisa — a
  variável existente é sobrescrita, não comparada. Para comparar, use um nome qualificado
  (`Status.OK`) ou uma guarda.
</details>

### Repetição

**6. Qual a diferença entre `for` e `while`?**

<details>
  <summary>Possível resposta</summary>

  `for` percorre os elementos de um iterável, com número de iterações determinado pelo
  próprio iterável. `while` repete enquanto uma condição for verdadeira, e é indicado quando
  o número de repetições não é conhecido de antemão.
</details>

**7. O que `range(5, 0, -1)` produz?**

<details>
  <summary>Possível resposta</summary>

  A sequência `5, 4, 3, 2, 1`. O terceiro argumento é o passo; negativo, faz a contagem
  regressiva. O limite `0` é exclusivo e não aparece.
</details>

**8. Qual a diferença entre `break` e `continue`?**

<details>
  <summary>Possível resposta</summary>

  `break` encerra o laço inteiro imediatamente; `continue` abandona apenas a iteração atual e
  segue para a próxima.
</details>

**9. Quando o bloco `else` de um laço executa?**

<details>
  <summary>Possível resposta</summary>

  Quando o laço termina naturalmente, sem que nenhum `break` tenha sido executado. É o
  idioma para "busca não encontrou nada", dispensando uma variável de flag.
</details>

**10. Por que `for i in range(len(items))` é considerado não idiomático?**

<details>
  <summary>Possível resposta</summary>

  Porque Python itera diretamente sobre os elementos: `for item in items:`. Quando o índice
  é necessário, `enumerate(items)` fornece índice e valor ao mesmo tempo, com menos chance de
  erro de limite.
</details>
