Python é uma linguagem de tipagem dinâmica e forte. Isso significa que nomes não têm tipo
fixo, mas os objetos têm; e operações incompatíveis costumam falhar em vez de converter tudo
silenciosamente.

Esta aula separa o estudo dos valores da aula de variáveis: aqui o foco é reconhecer os tipos
embutidos, saber quais são mutáveis, converter entradas explicitamente e evitar armadilhas
com `float`, `None` e valores *truthy* ou *falsy*.

## Objetivo

Reconhecer os principais tipos embutidos (`int`, `float`, `complex`, `bool`, `str`,
`NoneType`, `list`, `tuple`, `range`, `dict`, `set`, `frozenset`, `bytes`, `bytearray`),
diferenciar tipos mutáveis e imutáveis, converter valores de forma explícita e escolher
representações adequadas para números, texto, coleções e ausência de valor.

| :--- | :--- | :--- |
| Escalares | `int`, `float`, `complex`, `bool`, `NoneType` | Números, lógica e ausência de valor |

<Aside type="note" title="O tipo pertence ao objeto">
  Em Python, a variável é um nome. O tipo pertence ao objeto referenciado por esse nome.
  Por isso um mesmo nome pode primeiro apontar para uma string e depois para um número.
</Aside>

## Tipos Numéricos

Python embute três tipos numéricos principais. Todos são imutáveis: operações aritméticas
produzem novos objetos.

| Tipo | Descrição | Literal |
| :--- | :--- | :--- |
| `int` | Inteiro de precisão arbitrária | `42`, `-7`, `1_000_000` |
| `float` | Ponto flutuante de dupla precisão (IEEE 754) | `3.14`, `2e-3` |
| `complex` | Número complexo | `3 + 4j` |

```python title="Inteiros sem limite fixo"
big = 2 ** 200
print(big)
print(len(str(big)), "dígitos")

population = 8_100_000_000
print(population)
```

```txt title="Output"
1606938044258990275541962092341162602522202993782792835301376
61 dígitos
8100000000
```

<Aside type="tip" title="int não estoura">
  Diferente de linguagens com inteiros de tamanho fixo, `int` em Python cresce conforme
  necessário, limitado pela memória disponível.
</Aside>

## Precisão de Ponto Flutuante

Como `float` segue o padrão IEEE 754, frações decimais simples não têm representação exata
em binário. Esse comportamento também aparece em JavaScript e em várias outras linguagens.

```python title="IEEE 754 em ação"
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False
print(round(0.1 + 0.2, 2))    # 0.3

from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2")) # 0.3
print(Decimal("0.1") + Decimal("0.2") == Decimal("0.3")) # True
```

<Aside type="caution" title="Nunca use float para dinheiro">
  Valores monetários exigem `Decimal` com literais em string ou aritmética em centavos usando
  `int`. `float` acumula erro de arredondamento em somas repetidas.
</Aside>

## Texto, Sequências e Coleções

`str`, `list`, `tuple` e `range` são sequências: podem ser percorridas, têm tamanho e podem
ser acessadas por posição. A mutabilidade, porém, muda bastante entre elas.

| Tipo | Mutável? | Exemplo | Uso comum |
| :--- | :--- | :--- | :--- |
| `str` | Não | `"python"` | Texto |
| `list` | Sim | `[1, 2, 3]` | Lista ordenada alterável |
| `tuple` | Não | `("Ana", 21)` | Registro posicional ou retorno múltiplo |
| `range` | Não | `range(1, 5)` | Intervalo usado em repetição |

```python title="Sequências"
text = "python"
numbers = [1, 2, 3]
point = (10, 20)
interval = range(1, 4)

print(text[0], text.upper()) # p PYTHON
numbers.append(4)
print(numbers) # [1, 2, 3, 4]
print(point[1]) # 20
print(list(interval)) # [1, 2, 3]
```

<Aside type="tip" title="String é sequência imutável">
  Métodos como `upper()`, `strip()` e `replace()` devolvem novas strings. A string original
  não é alterada.
</Aside>

## Dicionários e Conjuntos

`dict` representa pares chave-valor. `set` representa valores únicos, sem ordem lógica para
indexação. `frozenset` é a versão imutável de `set`.

| Tipo | Mutável? | Exemplo | Uso comum |
| :--- | :--- | :--- | :--- |
| `dict` | Sim | `{"name": "Ana"}` | Registro chave-valor |
| `set` | Sim | `{"python", "js"}` | Remover duplicatas e testar presença |
| `frozenset` | Não | `frozenset(["a", "b"])` | Conjunto que pode ser chave de dicionário |

```python title="dict e set"
user = {"name": "Ana", "active": True}
user["email"] = "ana@example.com"

tags = {"python", "web", "python"}
tags.add("types")

print(user["name"]) # Ana
print(tags) # {'types', 'web', 'python'} em alguma ordem
print("python" in tags) # True
```

<Aside type="caution" title="Set não é lista sem repetição">
  `set` não preserva uma API de acesso por índice. Use para presença, unicidade e operações
  de conjunto; use `list` quando a posição dos elementos importa.
</Aside>

## Mutáveis e Imutáveis

A mutabilidade define se uma operação pode alterar o próprio objeto ou se precisa produzir
um novo objeto.

| Categoria | Tipos | Efeito |
| :--- | :--- | :--- |
| **Imutáveis** | `int`, `float`, `complex`, `bool`, `str`, `tuple`, `frozenset`, `bytes` | Qualquer "alteração" cria um novo objeto |
| **Mutáveis** | `list`, `dict`, `set`, `bytearray`, objetos de classes | Podem ser alterados no lugar |

```python title="Mutabilidade na prática"
text = "python"
upper = text.upper()

print(text)  # python
print(upper) # PYTHON

numbers = [1, 2, 3]
numbers.append(4)
print(numbers) # [1, 2, 3, 4]
```

<Aside type="note" title="Mutabilidade afeta compartilhamento">
  Se dois nomes apontam para a mesma lista, mutar a lista é visível pelos dois nomes. Esse
  modelo foi estudado na aula de [Variáveis](../variables/).
</Aside>

## Booleanos, `None` e valores *truthy*

`bool` é subtipo de `int`: `True` vale `1` e `False` vale `0` em contexto numérico.

```python title="Booleanos são inteiros"
print(True + True) # 2
print(isinstance(True, int)) # True
```

Qualquer objeto pode ser avaliado em contexto booleano. São **falsy**:

| Falsy | Exemplo |
| :--- | :--- |
| Zero numérico | `0`, `0.0`, `Decimal("0")` |
| Sequências e coleções vazias | `""`, `[]`, `()`, `{}`, `set()` |
| Ausência de valor | `None` |
| `False` | `False` |

```python title="Truthy e falsy"
values = [0, 1, "", "texto", [], [0], None, {}]

for value in values:
    print(f"{str(value):<8} -> {bool(value)}")
```

```txt title="Output"
0        -> False
1        -> True
         -> False
texto    -> True
[]       -> False
[0]      -> True
None     -> False
{}       -> False
```

<Aside type="caution" title="None não é zero, nem string vazia">
  `None` é o único valor do tipo `NoneType` e representa ausência de valor. Teste com
  `value is None` quando a diferença entre ausente, zero e string vazia importa.
</Aside>

## Conversão de Tipos

Como a tipagem é forte, a conversão precisa ser explícita. Isso deixa claro quando uma entrada
de texto vira número, lista ou booleano.

| Função | Converte para | Exemplo |
| :--- | :--- | :--- |
| `int(x)` | Inteiro, truncando floats | `int("42")`, `int(3.9)` → `3` |
| `float(x)` | Ponto flutuante | `float("3.14")` |
| `str(x)` | Texto | `str(42)` → `"42"` |
| `bool(x)` | Booleano | `bool("")` → `False` |
| `list(x)` | Lista a partir de iterável | `list("abc")` → `["a", "b", "c"]` |
| `tuple(x)` | Tupla a partir de iterável | `tuple([1, 2])` → `(1, 2)` |
| `set(x)` | Conjunto sem repetição | `set([1, 1, 2])` → `{1, 2}` |

```python title="Conversões e entrada do usuário"
raw = "3"
quantity = int(raw)

price = float("19.90")
total = quantity * price

print(f"Total: R$ {total:.2f}")
print(int(3.99))        # 3
print(round(3.99))      # 4
print(int("0b1010", 0)) # 10
```

<Aside type="caution" title="Conversão pode falhar">
  `int("abc")` levanta `ValueError`. Entradas vindas do usuário, de arquivos ou de APIs devem
  ser validadas antes de entrar no cálculo.
</Aside>

## Desafio

Escreva `money.py` demonstrando por que `float` não serve para dinheiro.

1. Some `0.1` dez vezes com `float` e compare o resultado com `1.0`;
2. Repita a soma usando `Decimal` com literais em string;
3. Repita usando aritmética em centavos com `int`;
4. Imprima uma tabela comparando os três resultados e a igualdade com o valor esperado;
5. Conclua em um comentário qual abordagem usar em um sistema de vendas.

<details>
  <summary>Possível resposta</summary>

  ```python title="money.py"
  from decimal import Decimal

  EXPECTED = 1.0

  float_total = 0.0
  for _ in range(10):
      float_total += 0.1

  decimal_total = Decimal("0")
  for _ in range(10):
      decimal_total += Decimal("0.1")

  cents_total = 0
  for _ in range(10):
      cents_total += 10

  print(f"{'Abordagem':<14} {'Resultado':<24} {'Igual a 1.0?'}")
  print(f"{'float':<14} {float_total!r:<24} {float_total == EXPECTED}")
  print(f"{'Decimal':<14} {str(decimal_total):<24} {decimal_total == Decimal('1.0')}")
  print(f"{'int centavos':<14} {cents_total / 100!r:<24} {cents_total == 100}")

  # Em sistemas de venda: Decimal para cálculo contábil ou int em centavos.
  ```
</details>

## Perguntas de revisão

### Tipos embutidos

**1. O tipo pertence à variável ou ao objeto?**

<details>
  <summary>Possível resposta</summary>

  Ao objeto. A variável é um nome que referencia objetos diferentes ao longo do tempo.
</details>

**2. Quais são os tipos numéricos principais de Python?**

<details>
  <summary>Possível resposta</summary>

  `int`, `float` e `complex`. `bool` também se comporta como subtipo de `int`.
</details>

**3. Qual é a diferença entre `list` e `tuple`?**

<details>
  <summary>Possível resposta</summary>

  `list` é mutável; `tuple` é imutável. Listas são usadas para coleções alteráveis, enquanto
  tuplas representam sequências fixas ou registros posicionais.
</details>

### Conversões e booleanos

**4. Por que `0.1 + 0.2 == 0.3` é `False`?**

<details>
  <summary>Possível resposta</summary>

  Porque `float` usa ponto flutuante binário IEEE 754, e frações como `0.1` não têm
  representação exata em base 2.
</details>

**5. Qual tipo `input()` devolve?**

<details>
  <summary>Possível resposta</summary>

  Sempre `str`. Para cálculos, o valor precisa ser convertido com `int()`, `float()` ou outra
  função apropriada.
</details>

**6. Quais valores são considerados *falsy* em Python?**

<details>
  <summary>Possível resposta</summary>

  `False`, `None`, zeros numéricos e coleções/sequências vazias, como `""`, `[]`, `{}` e
  `set()`.
</details>

**7. Quando testar `value is None` em vez de `if not value`?**

<details>
  <summary>Possível resposta</summary>

  Quando `None` precisa ser tratado de forma diferente de `0`, `""`, `False` ou coleção
  vazia.
</details>
