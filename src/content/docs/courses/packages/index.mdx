O **Guia de Pacotes** reúne as ferramentas que cercam o código de uma aplicação front-end:
servidor de desenvolvimento e build, API falsa para prototipagem e biblioteca de gráficos.
Frameworks CSS ficam no [Guia de CSS](../css/), e clientes HTTP no
[Guia de Web APIs](../web-api/).
