O **Cloud Firestore** é o banco de dados NoSQL orientado a documentos do **Google Firebase**. Projetado para armazenar e sincronizar dados entre aplicações cliente e servidor em tempo real, o Firestore organiza os dados em **coleções** que contêm **documentos**, com suporte a consultas ricas, transações e regras de segurança na nuvem.

## Objetivo

Compreender o modelo de dados do Cloud Firestore, instalar e inicializar o SDK do Firebase em uma aplicação front-end e implementar um repositório de dados completo com operações de escrita (`addDoc`), leitura com filtros (`getDocs`, `query`, `where`), atualização (`updateDoc`) e exclusão (`deleteDoc`).

---

## Modelo de Dados NoSQL do Firestore

Diferente dos bancos relacionais (SQL), o Firestore não utiliza tabelas ou linhas. Os dados são organizados em **Coleções** que abrigam **Documentos** em formato similar a JSON:

## 3. Implementando Operações CRUD (`js/services/storage.js`)

Importamos as funções utilitárias do módulo `firebase/firestore`:

```js title="js/services/storage.js (Módulo de serviço)"
import {
  addDoc,
  collection,
  deleteDoc,
  doc,
  getDocs,
  query,
  updateDoc,
  where,
} from 'firebase/firestore';
import { db } from './api.js';

async function create(resource, data) {}
async function read(resource, filter, value) {}
async function update(resource, data) {}
async function remove(resource, id) {}

export default { create, read, update, remove };
```

---

### Criar um Documento (`create`)

O método `addDoc` insere um novo documento em uma coleção e gera automaticamente uma chave `id` única:

```js title="Criando um documento com addDoc"
async function create(resource, data) {
  data.created_at = new Date(data.created_at);

  const colRef = collection(db, resource);
  const docRef = await addDoc(colRef, data);

  return { ...data, id: docRef.id };
}
```

```js title="Exemplo de chamada para criar investimento"
import API from './services/storage.js';

const investment = {
  name: "Tesouro Selic 2029",
  value: 10000,
  origin: "Tesouro Direto",
  category: "Pós",
  interest: "100% Selic",
  created_at: "2021-09-10T00:00:00-03:00",
};

await API.create('investments', investment);
```

---

### Ler e Filtrar Documentos (`read`)

O método `getDocs` retorna os documentos de uma coleção, podendo aplicar filtros de consulta com `query()` e `where()`:

```js title="Buscando e filtrando documentos com getDocs e query"
async function read(resource, filter, value) {
  const data = [];
  const colRef = collection(db, resource);
  let docs;

  if (filter && value) {
    const q = query(colRef, where(filter, '==', value));
    docs = await getDocs(q);
  } else {
    docs = await getDocs(colRef);
  }

  docs.forEach((docRef) => data.push({ ...docRef.data(), id: docRef.id }));

  return data;
}
```

```js title="Exemplo de busca de investimentos"
import API from './services/storage.js';

// Busca todos os investimentos
const todos = await API.read('investments');

// Busca investimentos filtrados pela categoria 'Pós'
const pos = await API.read('investments', 'category', 'Pós');
```

---

### Atualizar um Documento (`update`)

O método `updateDoc` altera os campos de um documento localizado pela função `doc(db, coleção, id)`:

```js title="Atualizando um documento com updateDoc"
async function update(resource, data) {
  data.created_at = new Date(data.created_at);

  const docRef = doc(db, resource, data.id);
  await updateDoc(docRef, data);

  return data;
}
```

```js title="Exemplo de atualização de investimento"
import API from './services/storage.js';

await API.update('investments', { id: 'ID_DO_DOCUMENTO', value: 15000 });
```

---

### Remover um Documento (`remove`)

O método `deleteDoc` remove o documento do banco de dados pelo seu `id`:

```js title="Excluindo um documento com deleteDoc"
async function remove(resource, id) {
  const docRef = doc(db, resource, id);
  return await deleteDoc(docRef);
}
```

```js title="Exemplo de remoção de investimento"
import API from './services/storage.js';

await API.remove('investments', 'ID_DO_DOCUMENTO');
```

## Exercício

1. Qual a diferença fundamental entre uma coleção (*Collection*) e um documento (*Document*) no Cloud Firestore?
2. Qual função do SDK do Firestore é utilizada para criar uma referência apontando para um documento específico através do seu `id`?

<details>
  <summary>Possível resposta</summary>

  1. Uma **Coleção** é um contêiner de documentos (similar a uma tabela). Um **Documento** é a unidade individual que armazena os dados em pares chave/valor (similar a um objeto JSON).

  2. A função `doc(db, nomeColecao, idDocumento)`.
</details>

## Perguntas de revisão

1. **O que acontece se usarmos `addDoc` em vez de `setDoc` para inserir dados no Firestore?**
   <details>
     <summary>Possível resposta</summary>
     O `addDoc` gera automaticamente um ID alfanumérico único para o novo documento, enquanto o `setDoc` exige que você forneça um ID manualmente.
   </details>

2. **Como obter atualizações em tempo real do banco de dados sempre que um documento for alterado por outro usuário?**
   <details>
     <summary>Possível resposta</summary>
     Utilizando a função `onSnapshot(docRef, (doc) => { ... })` em vez de `getDocs()`.
   </details>
