## O que muda nesta etapa

| Antes (etapa 2) | Agora (etapa 3) |
| --------------- | --------------- |
| Handlers escritos dentro do router | `src/controllers/task-controller.js` |
| Array declarado no router | `src/models/task-model.js` |
| Só `GET` e `POST` | CRUD completo, com `PUT` e `DELETE` |
| Erro respondido em cada handler | `HttpError` + `errorHandler` centralizados |
| Sem log | `src/middlewares/logger.js` |

## Quem conhece quem

A dependência só aponta para dentro: o router conhece o controller, o controller
conhece o model, e o model não conhece ninguém. É isso que permite trocar o array por
um banco na etapa 7 mexendo em um arquivo só.

<Mermaid title="Camadas da TaskAPI na etapa 3">
{`
flowchart LR
  A["Requisição HTTP"] --> B["task-router.js<br/>caminho e método"]
  B --> C["task-controller.js<br/>lê req, escolhe status"]
  C --> D["task-model.js<br/>guarda e busca dados"]
  C -.->|"throw HttpError"| E["error-handler.js<br/>traduz erro em JSON"]
  D --> C
  C --> F["Resposta HTTP"]
  E --> F
`}
</Mermaid>

## O erro tem um lugar só

`notFound` cria o erro quando nenhuma rota respondeu; `errorHandler` é reconhecido pelo
Express por ter **quatro** parâmetros e é o último da cadeia. Erros com status abaixo
de 500 mostram a mensagem real; de 500 para cima, a mensagem é genérica e o erro vai
para o log:

## Rotas

| Método | Caminho      | Sucesso | Erros   |
| ------ | ------------ | ------- | ------- |
| GET    | `/health`    | `200`   | —       |
| GET    | `/tasks`     | `200`   | —       |
| GET    | `/tasks/:id` | `200`   | `404`   |
| POST   | `/tasks`     | `201`   | `400`   |
| PUT    | `/tasks/:id` | `200`   | `404`   |
| DELETE | `/tasks/:id` | `204`   | `404`   |

Uma rota que não existe atravessa toda a cadeia sem ser atendida, cai no `notFound` e

    }
  }
`}
</ApiResponse>

## Conceitos abordados

- Separação em models, controllers, routes e middlewares
- Middleware de aplicação e a obrigação de chamar `next()`
- Erros com status HTTP (`HttpError`) e handler centralizado
- Middleware de erro com quatro parâmetros, registrado por último
- CRUD completo sobre um model em memória
