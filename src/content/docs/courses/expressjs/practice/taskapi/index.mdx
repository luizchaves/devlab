Nível **Iniciante → Avançado** · Node.js · Express.js · TypeScript · Zod · Prisma

A **TaskAPI** é o projeto modelo do guia. Quando uma aula mostra um bloco de código, ele
sai daqui — de um arquivo que existe, roda e é validado pelo CI. Não é uma aplicação
para usar: é a **referência executável** das páginas de conceito.

<ProjectLinks path="examples/courses/express/projects/task-api-typescript" devcontainer="task-api-typescript" />

## Por que ela existe

Um guia de referência tem um problema que um projeto passo a passo não tem: cada página
é lida sozinha. A tentação é escrever, em cada aula, um exemplo isolado — e o resultado
é um guia onde a mesma API aparece com seis domínios diferentes, e onde o código exibido
não roda em lugar nenhum.

A TaskAPI resolve isso sem transformar o guia num tutorial: as aulas continuam
independentes e continuam mostrando recortes de 5 a 15 linhas, mas todos os recortes vêm
da **mesma** aplicação, crescendo na mesma ordem em que o guia apresenta os assuntos.

<Aside type="note" title="Ela não é o InvestApp nem o MonitorApp">
  A TaskAPI é **só API** — sem front-end, sem Docker, sem testes E2E. O
  [InvestApp](../investapp/) e o [MonitorApp](../monitorapp/) são as aplicações
  completas, com interface, banco e infraestrutura, construídas passo a passo. A TaskAPI
  é o que as aulas de conceito recortam; eles são o que você constrói.
</Aside>

## O domínio

Uma tarefa tem título e estado. Nada além disso, na etapa 1 — o resto do modelo aparece
quando a aula que o justifica chega.

O `User` só aparece na etapa 9, junto com a autenticação — a mesma ordem do InvestApp e
do MonitorApp, e a mesma ordem das seções do guia, onde `Autenticação` vem depois de
`Persistência`.

## Convenções

O que vale em toda a trilha, e que você pode assumir sem reler:

| Decisão | Escolha |
| ------- | ------- |
| Framework | Express 5, sem `express-async-errors` — o Express 5 já encaminha rejeições |
| Linguagem | JavaScript nas etapas 1 a 3, TypeScript da 4 em diante |
| Execução do TypeScript | Nativa pelo Node, sem `tsx` e sem passo de build |
| Imports internos | *Subpath imports* (`#models/…`) declarados no `package.json` |
| Variáveis de ambiente | `--env-file` nativo, sem `dotenv` |
| Autenticação | `node:crypto` para hash e para assinar o JWT, sem `bcrypt` e sem `jsonwebtoken` |
| Validação | Zod, em `body`, `query` e `params` |
| Banco | `node:sqlite` na etapa 7, Prisma 7 com driver adapter da etapa 8 em diante |
