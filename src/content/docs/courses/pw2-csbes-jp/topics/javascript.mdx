A disciplina começa nivelando a linguagem. Programação para Web 2 pressupõe contato
prévio com JavaScript, mas a experiência mostra que as lacunas costumam estar
exatamente nos pontos que mais doem depois: coerção de tipos, escopo, funções de
ordem superior e o modelo assíncrono.

Este tópico existe para fechar essas lacunas antes de entrar em React, onde um
mal-entendido sobre closures ou sobre imutabilidade vira um bug difícil de enxergar.

## O que esperar deste tópico

Uma revisão que vai da declaração de variáveis ao tratamento de erros em código
assíncrono, com ênfase no que React e o consumo de APIs vão exigir: desestruturação,
spread, métodos funcionais de array, módulos ES e `async`/`await`.

</Aside>
