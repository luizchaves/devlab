Uma aplicação front-end moderna não vive só de HTML, CSS e JavaScript: ela depende de
um servidor de desenvolvimento, de um processo de build e — cada vez mais — de
serviços que entregam banco de dados e autenticação prontos.

Este tópico reúne essas duas famílias. Primeiro o ferramental de projeto; depois os
provedores **BaaS** (*Backend as a Service*), que permitem construir uma aplicação
com persistência real e login sem escrever um servidor.

## O que esperar deste tópico

Criar um projeto com Vite, prototipar com JSON Server, estilizar com Bootstrap ou
Tailwind, e então conectar a aplicação ao Supabase ou ao Firebase — via API REST,
via SDK e com autenticação.

<Aside type="caution" title="Chaves não vão para o repositório">
  Os serviços exigem chaves de acesso. Use variáveis de ambiente (`.env`) e mantenha
  o arquivo fora do controle de versão — cada exemplo traz um `.env.example` como
  modelo.
</Aside>
