Com a linguagem nivelada, o foco passa para o que o navegador oferece. É aqui que a
página deixa de ser estática: o JavaScript lê e altera o DOM, responde a eventos,
guarda dados no dispositivo e busca informação em servidores.

Este tópico também introduz o vocabulário de APIs HTTP — recursos, verbos, status
codes, CORS — que sustenta tudo o que vem depois, do Supabase ao React.

## O que esperar deste tópico

Dos objetos globais do navegador até um CRUD completo contra uma API REST. Pelo
caminho: manipulação do DOM, criação dinâmica de elementos, eventos, `localStorage`,
`fetch`, Axios e a comparação entre clientes HTTP.

<Aside type="note" title="O Invest App atravessa o tópico">
  A mesma aplicação de investimentos reaparece em vários tópicos, trocando só a camada
  de persistência: `localStorage`, depois `fetch`, depois Axios. Isso torna visível o
  que muda e o que permanece quando a fonte de dados muda.
</Aside>
