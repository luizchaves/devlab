A disciplina de [Programação para Web 2](../../pw2/docs/plano-de-ensino.pdf) (PW2)
faz parte do Curso Superior de Bacharelado em Engenharia de Software do IFPB. Ela
possui carga horária de 67 horas-aula e é ministrada pelos professores Luiz Carlos Chaves e Francisco Dantas.

O foco da disciplina é construir uma base sólida para o desenvolvimento front-end moderno e a integração com serviços de backend na nuvem. Ao longo do semestre, estudamos o ecossistema JavaScript moderno (ES6+), manipulação do DOM e objetos do navegador, armazenamento local com LocalStorage, consumo de APIs REST/BaaS com Supabase, e a construção de interfaces reativas e declarativas com React e React Hooks.

A trilha de aprendizagem é estruturada de forma incremental. Começamos nivelando os conceitos fundamentais de JavaScript moderno e APIs de navegador para construir aplicações vanilla; em seguida, integramos persistência e autenticação com Supabase e culminamos na reconstrução de aplicações completas utilizando o ecossistema React.

As aulas combinam exposição teórica, leitura de código, exercícios práticos e desenvolvimento de projetos. As avaliações envolvem entregas individuais de listas de exercícios e o desenvolvimento em equipe do projeto prático da disciplina.

Como pré-requisito, espera-se conhecimento prévio em Algoritmos, Estrutura de Dados e Programação para Web 1 (HTML e CSS).

## O que você vai aprender?

A disciplina se organiza em tópicos, na ordem em que são vistos ao longo do

que ficam nos guias por tecnologia.

## Ferramentas

Estas ferramentas serão usadas com frequência durante a disciplina:

| Categoria | Ferramenta | Uso principal |
| --------- | ---------- | ------------- |
| Ambiente de execução | [Node.js](https://nodejs.org/en/) | Executar JavaScript no servidor e gerenciar pacotes |
| Editor | [Visual Studio Code](http://code.visualstudio.com) | Escrever e organizar o código das aplicações |
| Tooling e Bundler | [Vite](https://vite.dev/) | Servidor de desenvolvimento rápido e bundler front-end |
| Backend & BaaS | [Supabase](https://supabase.com/) | Banco de dados PostgreSQL, autenticação e APIs em nuvem |
| Biblioteca Front-end | [React](https://react.dev/) | Construção de interfaces reativas baseadas em componentes |
| Design e prototipação | [Figma](https://www.figma.com/) | Planejar telas, protótipos e fluxos de interface |
| Navegador | [Chrome](https://www.google.com/chrome/browser/index.html) | Testar páginas, usar DevTools e depurar comportamento |
| Versionamento | [Git](https://git-scm.com/) | Controlar histórico, publicar código e submeter projetos |
