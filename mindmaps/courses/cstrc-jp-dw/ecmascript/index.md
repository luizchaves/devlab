# JavaScript: ECMAScript

## Ideia Central

- JavaScript é a linguagem da Web (navegador e servidor)
- ECMAScript é a especificação oficial mantida pela Ecma International (TC39)

## Origem e Padronização

- **Origem**: Criada em 1995 por Brendan Eich na Netscape
- **Padronização**: Padrão ECMA-262 (ECMAScript)
- **Evolução**: Gerenciada pelo comitê TC39 (Edição ECMAScript 2026)

## Ecossistema e APIs

### ECMAScript
- Sintaxe base da linguagem
- Variáveis, funções, objetos, arrays, classes, módulos, promises

### Web APIs (Navegador)
- Fornecidas pelos motores de navegação
- `document` (DOM), `window`, `fetch`, `localStorage`, eventos

### Node.js APIs (Servidor)
- Fornecidas pelos runtimes de servidor
- Módulos nativos (`node:fs`, `node:http`, `node:path`), `process`

### npm / Pacotes
- Ecossistema de bibliotecas e dependências (Express, Vite, Prisma)

## Ambientes de Execução

### Navegadores
- Manipulação da interface, eventos e consumo de APIs no cliente
- Execução via tag `<script>` ou Console do DevTools

### Runtimes de Servidor
- **Node.js**: Runtime consagrado
- **Deno**: Runtime moderno com TypeScript nativo e segurança
- **Bun**: Runtime e toolkit integrado de alta performance

## Características da Linguagem

- **Alto Nível**: Gerenciamento automático de memória (Garbage Collector)
- **Tipagem Dinâmica**: O tipo pertence ao valor
- **Tipagem Fraca**: Coerções automáticas de tipo
- **Multiparadigma**: Funcional, Orientado a Objetos (Protótipos), Imperativo
- **ASI**: Inserção automática de ponto e vírgula
