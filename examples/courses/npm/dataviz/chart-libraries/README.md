# D3 e ECharts

Exemplo comparando duas bibliotecas de visualização instaladas via npm:

- `d3`: controla SVG, escalas, eixos e ligação de dados em baixo nível.
- `echarts`: cria gráficos interativos a partir de uma configuração declarativa.

## Como executar

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
