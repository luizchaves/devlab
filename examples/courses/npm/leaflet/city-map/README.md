# Leaflet City Map

Exemplo mínimo de mapa interativo com Leaflet, Vite e tiles do OpenStreetMap.

## Rotas e arquivos principais

- `index.html`: estrutura da página e contêiner do mapa.
- `src/main.js`: inicialização do Leaflet, camada de tiles, marcador e rota.
- `src/style.css`: layout responsivo do exemplo.

## Como executar

```bash
npm install
npm run dev
```
