# express-basic

Primeiro servidor HTTP com Express.

```bash
pnpm install
pnpm dev
```

Rotas disponiveis:

- `GET /` — retorna `{ "message": "Hello World" }`
- `GET /hello/:name` — usa um parametro de rota
- `POST /echo` — devolve o corpo JSON recebido

Documentacao: `courses/cstrc-jp-dw/projects/hello-express`.
