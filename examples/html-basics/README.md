# html-basics

Página pessoal mínima usada na aula de introdução ao HTML. Não tem dependências:
abra os arquivos direto no navegador.

```bash
open index.html          # macOS
xdg-open index.html      # Linux
```

Arquivos:

| Arquivo               | Assunto                                       |
| --------------------- | --------------------------------------------- |
| `index.html`          | Estrutura básica e elementos semânticos       |
| `texto.html`          | Títulos, parágrafos, ênfase e entidades       |
| `listas.html`         | `<ul>`, `<ol>` e `<dl>`                       |
| `tabela.html`         | `<table>` com `<thead>`, `<tbody>` e `<th>`   |
| `imagens.html`        | `<img>`, `alt` e `<figure>`                   |
| `paginas/contato.html`| Links entre páginas e caminhos com `../`      |

Documentação: `courses/cstrc-jp-dw/html`.
