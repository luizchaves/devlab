# express-mvc

Aplicacao Express organizada em MVC.

```bash
pnpm install
pnpm dev
```

Rotas disponiveis:

| Metodo | Caminho      | Descricao              |
| ------ | ------------ | ---------------------- |
| GET    | `/users`     | Lista os usuarios      |
| GET    | `/users/:id` | Busca um usuario       |
| POST   | `/users`     | Cria um usuario        |
| PUT    | `/users/:id` | Atualiza um usuario    |
| DELETE | `/users/:id` | Remove um usuario      |

Documentacao: `courses/express/architecture/mvc`.
