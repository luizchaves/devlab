# HTML: Sintaxe e Estrutura do Documento

Página base: [HTML: Sintaxe e Estrutura do Documento](../../../../src/content/docs/courses/html/basics/syntax-structure.mdx)

Repositório pesquisado: [brain-check-questions](https://github.com/luizchaves/brain-check-questions/tree/main/questions)
