# HTML: Introdução

Página base: [HTML: Introdução](../../../../src/content/docs/courses/cstrc-jp-dw/html/index.mdx)

Repositório pesquisado: [ifpb/exercises](https://github.com/ifpb/exercises)

Este índice reúne exercícios que combinam com a aula de introdução ao HTML. A seleção prioriza atividades de marcação pura, estrutura do documento, texto, listas, links, imagens, entidades e tabelas.
