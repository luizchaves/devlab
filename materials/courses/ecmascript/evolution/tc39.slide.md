# JavaScript: Evolução e o Processo TC39

O comitê TC39, os 5 estágios de propostas (Stage 0 a 4) e o histórico completo de evoluções do ECMAScript do ES6/ES2015 até as edições recentes.

---

## Objetivo

- Reconhecer os conceitos centrais da página e aplicá-los em código JavaScript.
- Diferenciar sintaxes parecidas pelo comportamento em tempo de execução.
- Ler exemplos reais com atenção a entrada, saída e efeitos colaterais.
- Praticar o tema com exercícios progressivos.

## O Comitê TC39 e o Processo de Padronização

- Stage 0 (Strawperson): Ideia ou rascunho inicial apresentado por um membro do TC39.
- Stage 1 (Proposal): Proposta formal aprovada para investigação. O comitê define o problema e soluções potenciais.
- Stage 2 (Draft): Especificação formal da sintaxe e semântica inicial.
- Stage 3 (Candidate): Especificação completa e assinada. Implementações experimentais iniciam em navegadores e motores JS.
- Stage 4 (Finished): A proposta está pronta para ser inclusa na próxima edição anual do padrão ECMAScript.

- A tabela abaixo resume o que cada edição anual trouxe de mais significativo desde a virada do ES2015

---

## Visão Geral da Linha do Tempo (Comparação)

| Edição | Nome Oficial | Ano | Principais Destaques |
| :--- | :--- | :--- | :--- |
| **ES6** | ECMAScript 2015 | 2015 | `let`/`const`, Arrow Functions, Classes, Promises, Módulos, Destructuring, Spread/Rest. |
| **ES7** | ECMAScript 2016 | 2016 | Operador de Exponenciação (`**`), `Array.prototype.includes()`. |
| **ES8** | ECMAScript 2017 | 2017 | `async`/`await`, `Object.values()`, `Object.entries()`, String Padding. |
| **ES9** | ECMAScript 2018 | 2018 | Rest/Spread em Objetos, `for await...of`, `Promise.prototype.finally()`, Regex Lookbehind. |
| **ES10** | ECMAScript 2019 | 2019 | `Array.prototype.flat()`, `Object.fromEntries()`, Optional Catch Binding. |

## ES6 / ES2015 — A Grande Revolução

- O ES6 (ECMAScript 2015) foi a maior atualização na história do JavaScript.

---

## 1. Declaração de Variáveis de Escopo de Bloco (`let` e `const`)

- Substituem o escopo de função do `var`, evitando vazamento de escopo e introduzindo a Temporal Dead Zone (TDZ).

---

## 1. Declaração de Variáveis de Escopo de Bloco (`let` e `const`) (Exemplo)

```js
const API_URL = "https://api.exemplo.com";
let count = 0;
count += 1;
```

---

## 2. Funções Seta (*Arrow Functions*)

- Sintaxe enxuta para funções anônimas com vínculo léxico do contexto `this`.

---

## 2. Funções Seta (*Arrow Functions*) (Exemplo)

```js
const double = (n) => n * 2;
const sum = (a, b) => a + b;
```

---

## 3. Classes e Herança Orientada a Objetos

- Açúcar sintático sobre a herança baseada em protótipos.

---

## 3. Classes e Herança Orientada a Objetos (Exemplo)

```js
class User {
  constructor(name) {
    this.name = name;
  }
  greet() {
    return `Olá, ${this.name}`;
  }
}
```

---

## 4. Desestruturação (*Destructuring Assignment*)

- Extração simplificada de valores em arrays e propriedades em objetos.

---

## 4. Desestruturação (*Destructuring Assignment*) (Exemplo)

```js
const person = { name: "Maria", age: 25 };
const { name, age } = person;

const colors = ["vermelho", "azul"];
const [primary, secondary] = colors;
```

---

## 5. Template Literals (Interpolação de Strings)

- Strings delimitadas por crases (`` ` ``) com suporte a expressões `${val}` e múltiplas linhas.

---

## 5. Template Literals (Interpolação de Strings) (Exemplo)

```js
const title = "DevLab";
const message = `Bem-vindo ao ${title}!
Ambiente de aprendizado.`;
```

---

## 6. Parâmetros Rest (`...args`) e Operador Spread (`...iterable`)

- As reticências têm dois papéis opostos conforme a posição: agrupar argumentos na declaração e espalhar valores na chamada.

---

## 6. Parâmetros Rest (`...args`) e Operador Spread (`...iterable`) (Exemplo)

```js
// Rest: agrupa argumentos restantes
function sumAll(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}

// Spread: espalha elementos
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]
```

---

## 7. Módulos Nativos (`import` e `export`)

- O ES2015 trouxe para a linguagem o sistema de módulos que antes dependia de bibliotecas como RequireJS e CommonJS

---

## 7. Módulos Nativos (`import` e `export`) (Exemplo)

```js
// math.js
export const add = (a, b) => a + b;

// app.js
import { add } from './math.js';
```

---

## 8. Outros Recursos Importantes do ES6

- Promises Nativas: tratamento padronizado de assincronismo.
- Coleções `Map`, `Set`, `WeakMap`, `WeakSet`: estruturas de dados especializadas.
- Iteradores e Geradores: protocolos de iteração (`for...of` e `function*`).
- Valores Padrão de Parâmetros: `function greet(name = "Visitante")`.

---

## ES7 / ES2016

- Uma atualização menor focada em aperfeiçoamentos pontuais da linguagem.

---

## 1. Operador de Exponenciação (`**`)

- Substitui a necessidade de invocar `Math.pow(base, exp)`.

---

## 1. Operador de Exponenciação (`**`) (Exemplo)

```js
const square = 2 ** 3; // 8 (equivalente a Math.pow(2, 3))
let x = 3;
x **= 2; // 9
```

---

## 2. `Array.prototype.includes()`

- Verifica de forma direta se um elemento existe no array, retornando um booleano.

---

## 2. `Array.prototype.includes()` (Exemplo)

```js
const fruits = ["maçã", "banana", "laranja"];
console.log(fruits.includes("banana")); // true
```

---

## ES8 / ES2017

- Introduziu construções essenciais para simplificar a programação assíncrona e a manipulação de objetos.

---

## 1. Funções Assíncronas (`async` / `await`)

- Açúcar sintático sobre Promises que permite escrever código assíncrono com aparência síncrona.

---

## 1. Funções Assíncronas (`async` / `await`) (Exemplo)

```js
async function fetchUser(id) {
  try {
    const response = await fetch(`/api/users/${id}`);
    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Erro na requisição:", error);
  }
}
```

---

## 2. `Object.values()` e `Object.entries()`

- Os dois métodos completam o trio iniciado por `Object.keys()`, permitindo percorrer objetos como se fossem coleções

---

## 2. `Object.values()` e `Object.entries()` (Exemplo)

```js
const user = { name: "Ana", age: 30 };

console.log(Object.values(user));  // ["Ana", 30]
console.log(Object.entries(user)); // [["name", "Ana"], ["age", 30]]
```

---

## 3. Preenchimento de Strings (`padStart` e `padEnd`)

- O preenchimento resolve a formatação de códigos, horários e colunas alinhadas sem laços manuais

---

## 3. Preenchimento de Strings (`padStart` e `padEnd`) (Exemplo)

```js
console.log("5".padStart(3, "0")); // "005"
console.log("5".padEnd(3, "0"));   // "500"
```

---

## 4. `Object.getOwnPropertyDescriptors()`

- Retorna todos os descritores de propriedades próprias de um objeto, facilitando a clonagem precisa de seletores getters e setters.

---

## 1. Rest e Spread em Objetos

- Expande a sintaxe de desestruturação e espalhamento para objetos literais.

---

## 1. Rest e Spread em Objetos (Exemplo)

```js
const user = { id: 1, name: "Carlos", role: "admin" };
const { id, ...userData } = user; // userData = { name: "Carlos", role: "admin" }

const updatedUser = { ...user, active: true };
```

---

## 2. Iteração Assíncrona (`for await...of`)

- Permite iterar sobre iteráveis assíncronos ou coleções de Promises.

---

## 2. Iteração Assíncrona (`for await...of`) (Exemplo)

```js
async function processStreams(promises) {
  for await (const result of promises) {
    console.log(result);
  }
}
```

---

## 3. `Promise.prototype.finally()`

- Executa um callback após a conclusão da Promise, independentemente de ter sido resolvida ou rejeitada.

---

## 3. `Promise.prototype.finally()` (Exemplo)

```js
fetchData()
  .then(res => console.log(res))
  .catch(err => console.error(err))
  .finally(() => hideLoadingSpinner());
```

---

## 4. Melhorias em RegExp

- Grupos de Captura Nomeados: `/(?\d{4})-(?\d{2})/`
- Lookbehind Assertions: `(?<=%)` e `(?<!%)`
- Flag `/s` (dotAll): faz o caractere `.` corresponder também a quebras de linha.

---

## 1. `Array.prototype.flat()` e `flatMap()`

- Os dois métodos tratam arrays aninhados, que antes exigiam recursão ou `reduce` com concatenação

---

## 1. `Array.prototype.flat()` e `flatMap()` (Exemplo)

```js
const nested = [1, [2, [3]]];
console.log(nested.flat(2)); // [1, 2, 3]

const numbers = [1, 2, 3];
console.log(numbers.flatMap(x => [x, x * 2])); // [1, 2, 2, 4, 3, 6]
```

---

## 2. `Object.fromEntries()`

- Converte uma lista de pares chave-valor (como um `Map` ou resultado de `Object.entries()`) de volta em um objeto.

---

## 2. `Object.fromEntries()` (Exemplo)

```js
const entries = [["name", "Pedro"], ["age", 22]];
const obj = Object.fromEntries(entries); // { name: "Pedro", age: 22 }
```

---

## 3. `trimStart()` e `trimEnd()`

- Remoção de espaços em branco apenas no início ou no fim de uma string.

---

## 4. Binding Opcional no `catch`

- Permite omitir a variável de erro no bloco `catch` quando ela não for necessária.

---

## 4. Binding Opcional no `catch` (Exemplo)

```js
try {
  JSON.parse(data);
} catch {
  console.log("JSON inválido");
}
```

---

## 1. Encadear Opcional (*Optional Chaining*: `?.`)

- Evita erros de `TypeError: Cannot read properties of undefined` ao acessar propriedades aninhadas.

---

## 1. Encadear Opcional (*Optional Chaining*: `?.`) (Exemplo)

```js
const street = user?.address?.street;
const firstItem = items?.[0];
const result = customMethod?.();
```

---

## 2. Operador de Coalescência Nula (*Nullish Coalescing*: `??`)

- Retorna o valor da direita somente se o lado esquerdo for `null` ou `undefined` (diferente do `||`, que considera `0`.

---

## 2. Operador de Coalescência Nula (*Nullish Coalescing*: `??`) (Exemplo)

```js
const timeout = config.timeout ?? 3000;
```

---

## 3. `BigInt` (Inteiros de Precisão Arbitrária)

- Permite representar números inteiros maiores que `2^53 - 1`.

---

## 3. `BigInt` (Inteiros de Precisão Arbitrária) (Exemplo)

```js
const hugeNumber = 9007199254740991n + 2n; // 9007199254740993n
```

---

## 4. `Promise.allSettled()`

- Retorna o estado final de todas as Promises passadas, sem abortar caso uma seja rejeitada.

---

## 4. `Promise.allSettled()` (Exemplo)

```js
const results = await Promise.allSettled([p1, p2, p3]);
// Retorna array com { status: "fulfilled" | "rejected", value | reason }
```

## Resumo da Aula

- **Marcos Históricos**: ES1 (1997), ES3 (1999), ES5 (2009 com Strict Mode e JSON) e a revolução do ES6 / ES2015 (Classes, Módulos, Promises).
- **Ciclo Anual de Releases**: Lançamentos incrementais anuais (ES2016 até ES2026+) baseados em um padrão vivo (Living Standard).
- **Processo TC39 (5 Estágios)**: Stage 0 (Ideia), Stage 1 (Proposta), Stage 2 (Rascunho), Stage 3 (Candidato/Implementação), Stage 4 (Pronto/Padrão).
- **Recursos Modernos**: Optional Chaining, Nullish Coalescing, BigInt, Top-Level Await, Métodos Imutáveis de Array e Métodos de Set.
- **Ferramental & Babel**: Compilação e polyfills permitem testar propostas em Stage 3 de forma segura em projetos de produção.
