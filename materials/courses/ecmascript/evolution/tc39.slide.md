## O Comitê TC39 e o Processo de Padronização

O **TC39** (*Technical Committee 39*) da Ecma International gerencia o padrão **ECMA-262**:

- **Stage 0 (Strawperson)**: Ideia ou rascunho inicial proposto por membro do comitê.
- **Stage 1 (Proposal)**: Investigação formal, definição do problema e design da API.
- **Stage 2 (Draft)**: Especificação formal da sintaxe e semântica na especificação.
- **Stage 3 (Candidate)**: Especificação completa assinada; implementações experimentais.
- **Stage 4 (Finished)**: Testes aprovados no *test262*, 2+ motores compatíveis e inclusão no padrão.

## Linha do Tempo: Edições 2015 a 2019

| Edição | Nome Oficial | Ano | Principais Recursos |
| :--- | :--- | :--- | :--- |
| **ES6** | ECMAScript 2015 | 2015 | `let`/`const`, Arrow Functions, Classes, Promises, Módulos ESM |
| **ES7** | ECMAScript 2016 | 2016 | Exponenciação (`**`), `Array.prototype.includes()` |
| **ES8** | ECMAScript 2017 | 2017 | `async`/`await`, `Object.values()`, `Object.entries()`, `padStart` |
| **ES9** | ECMAScript 2018 | 2018 | Rest/Spread em Objetos, `for await...of`, `Promise.finally()` |
| **ES10** | ECMAScript 2019 | 2019 | `Array.prototype.flat()`, `flatMap()`, `Object.fromEntries()` |

| Edição | Nome Oficial | Ano | Principais Recursos |

## ES6 / ES2015: Blocos, Funções e Classes

A maior revolução da linguagem para desenvolvimento em larga escala:

```js
// 1. Escopo de bloco com let/const
const API_URL = "https://api.devlab.com";
let count = 0;

// 2. Arrow Functions com 'this' léxico
const double = (n) => n * 2;

// 3. Classes declarativas
class User {
  constructor(name) { this.name = name; }
  greet() { return `Olá, ${this.name}!`; }
}
```

const { name, age } = { name: "Maria", age: 25 };

## ES7 (2016) e ES8 (2017): Async/Await e Objetos

```js
// ES2016: Exponenciação e includes
const area = 2 ** 3; // 8
console.log(["a", "b"].includes("a")); // true

// ES2017: async/await e reflexão de objetos
async function fetchUser(id) {
  const res = await fetch(`/users/${id}`);
  return await res.json();
}

const user = { name: "Ana", age: 30 };
console.log(Object.values(user));  // ["Ana", 30]
console.log(Object.entries(user)); // [["name", "Ana"], ["age", 30]]
console.log("5".padStart(3, "0")); // "005"
```

## ES9 (2018) e ES10 (2019): Spread em Objetos e Flat

```js
// ES2018: Rest e Spread em Objetos literais
const user = { id: 1, name: "Carlos", role: "admin" };
const { id, ...data } = user; // data = { name: "Carlos", role: "admin" }
const updated = { ...user, active: true };

// ES2019: Aplainamento de arrays e reconstrução de objetos
const nested = [1, [2, [3, 4]]];
console.log(nested.flat(2)); // [1, 2, 3, 4]

const entries = [["a", 1], ["b", 2]];
console.log(Object.fromEntries(entries)); // { a: 1, b: 2 }
```

## ES11 (2020) e ES12 (2021): Coalescência e Operadores

```js
// ES2020: Encadeamento Opcional (?.) e Coalescência Nula (??)
const email = user?.profile?.email ?? "padrao@devlab.com";

// ES2020: BigInt para números gigantes
const big = 9007199254740991n + 2n;

// ES2021: Atribuição lógica e replaceAll
let timeout = 0;
timeout ??= 3000; // Mantém 0 (0 não é nullish)

const text = "gato preto, gato branco";
console.log(text.replaceAll("gato", "cão")); // "cão preto, cão branco"
```

## ES13 (2022) e ES14 (2023): Privacidade e Imutabilidade

```js
// ES2022: Campos privados (#) e método .at()
class Account {
  #balance = 0;
  deposit(v) { this.#balance += v; }
  get balance() { return this.#balance; }
}

const list = [10, 20, 30];
console.log(list.at(-1)); // 30 (último item)

// ES2023: Métodos imutáveis de Array (toSorted, toReversed, with)
const numbers = [3, 1, 2];
console.log(numbers.toSorted()); // [1, 2, 3]
console.log(numbers);            // [3, 1, 2] (original intacto!)
```

## ES15 (2024) e ES16 (2025): Recursos Modernos

```js
// ES2024: Agrupamento de dados nativo
const items = [{ cat: "fruta", name: "maçã" }, { cat: "fruta", name: "banana" }];
const grouped = Object.groupBy(items, (i) => i.cat);

// ES2024: Métodos de conjunto nativos em Set
const setA = new Set([1, 2, 3]);
const setB = new Set([2, 3, 4]);
console.log(setA.intersection(setB)); // Set { 2, 3 }
console.log(setA.difference(setB));   // Set { 1 }

// ES2024: Promise.withResolvers()
const { promise, resolve, reject } = Promise.withResolvers();
```

## Adoção e Runtimes Modernos

- Motores modernos (V8 no Node.js 20+ e Chrome, SpiderMonkey, JSC) implementam recursos do **ES2015 ao ES2024** nativamente.
- O ciclo anual do TC39 garante previsibilidade para a indústria de software.
- Recursos em **Stage 3/4** já podem ser testados com flags experimentais ou em runtimes recentes.
- Projetos modernos com ferramentas como Vite e TypeScript aproveitam sintaxes atuais sem dependência de polyfills legados.
