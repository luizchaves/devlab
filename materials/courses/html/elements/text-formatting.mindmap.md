# Texto, Listas e Links

## 1. Hierarquia de Títulos
- **`<h1>`**: Título principal (1 por página).
- **`<h2>`**: Seções principais.
- **`<h3>` a `<h6>`**: Subseções aninhadas.
- **Regra**: Não escolher tag pelo tamanho visual.

## 2. Marcação & Ênfase
- **`<strong>`**: Alta importância (negrito).
- **`<em>`**: Ênfase no texto (itálico).
- **`<code>`**: Código monoespaçado.
- **`<mark>`**: Destaque de contexto.

## 3. Listas
- **`<ul>` + `<li>`**: Lista não-ordenada (marcadores).
- **`<ol>` + `<li>`**: Lista ordenada (sequência 1, 2, 3).
- **`<dl>` + `<dt>` + `<dd>`**: Lista de definição (termo e significado).

## 4. Hiperlinks (`<a>`)
- **`href`**: URL de destino (relativa ou absoluta).
- **`target="_blank"`**: Abrir em nova aba.
- **`rel="noopener noreferrer"`**: Segurança para links externos.
