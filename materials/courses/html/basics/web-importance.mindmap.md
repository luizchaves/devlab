# A Importância da Web

## Ideia Central

- Arquitetura descentralizada para conectar e acessar recursos distribuídos
- Redução de barreiras de acesso e publicação
- Diferença entre **Internet** (infraestrutura) e **Web** (serviço de hipertexto)

## Origem no CERN

- Proposta por Tim Berners-Lee em 1989 (com Robert Cailliau em 1990)
- Resolução do problema de informação fragmentada entre pesquisadores
- Primeiro site e servidor: `info.cern.ch`
- Artigos e propostas fundacionais (1989-1994)

## O Tripé da Web

### URL (*Uniform Resource Locator*)
- Identifica e localiza recursos na rede
- Exemplo: `https://example.com/pagina`

### HTTP (*Hypertext Transfer Protocol*)
- Protocolo de comunicação por requisição e resposta (*request-response*)
- *Stateless*: requisições independentes
- Facilita escala, caches, CDNs e balanceamento de carga

### HTML (*Hypertext Markup Language*)
- Estruturação semântica do conteúdo do documento

## Clientes e Servidores HTTP

### Clientes
- Navegadores Web (Chrome, Firefox, Safari)
- Ferramentas CLI (`curl`, `wget`) e de teste (Postman, REST Client)

### Servidores
- Servidores de Produção (Apache, Nginx)
- Runtimes/Frameworks (Node.js/Express, Python `http.server`)
- Servidores Locais de Desenvolvimento (Live Server)

## Hipertexto e Padrões Abertos

### Hipertexto e Links
- Navegação entre documentos e domínios independentes
- Formação de uma rede global conectada

### W3C e Padrões Abertos
- Fundado em 1994 por Tim Berners-Lee
- Interoperabilidade, acessibilidade e longevidade dos documentos
