# Tipografia e Cores

## 1. Modelos de Cores
- **Hexadecimal**: `#2563eb`.
- **RGB / RGBA**: `rgb(37 99 235 / 80%)`.
- **HSL / HSLA**: `hsl(220 83% 53%)` (Matiz, Saturação, Luminosidade).
- **Color Mix**: Sintaxe CSS 4.

## 2. Unidades de Medida
- **`rem`**: Relativo à raiz (`html`). Padrão para acessibilidade.
- **`em`**: Relativo ao pai direto.
- **`px`**: Absoluto (evitar em fontes).

## 3. Propriedades de Texto
- **`font-family`**: Pilha de fontes com fallback.
- **`font-weight`**: 400 (normal), 700 (bold).
- **`line-height`**: Legibilidade (ex: 1.5 a 1.6).
- **`letter-spacing`**: Espaçamento entre letras.
