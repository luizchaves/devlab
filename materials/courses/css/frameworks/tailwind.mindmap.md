# Tailwind CSS

## 1. Conceito Utility-First
- **Classes Atômicas**: Classes de propósito único no HTML.
- **Vantagens**: Sem troca de arquivos CSS/HTML, naming zero.

## 2. Layout & Espaçamento
- **Flexbox**: `flex`, `flex-col`, `items-center`, `justify-between`.
- **Grid**: `grid`, `grid-cols-3`, `gap-4`.
- **Espaçamento**: `p-4`, `m-2`, `px-6`, `py-3`.

## 3. Variantes Modificadoras
- **Estados**: `hover:`, `focus:`, `disabled:`, `active:`.
- **Breakpoints**: `sm:` (640px), `md:` (768px), `lg:` (1024px).
- **Tema Escuro**: `dark:bg-slate-900`.
