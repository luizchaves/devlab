# Bootstrap 5

## 1. Instalação & Inclusão
- **CDN**: `<link rel="stylesheet" href="...">` no `<head>`.
- **JS Bundle**: Script JS antes do `</body>` (para modals/dropdowns).

## 2. Sistema de Grid (12 Colunas)
- **Contêineres**: `.container` | `.container-fluid`.
- **Linha**: `.row`.
- **Colunas**: `.col-12`, `.col-md-6`, `.col-lg-4`.
- **Breakpoints**: `sm` (576px), `md` (768px), `lg` (992px), `xl` (1200px).

## 3. Componentes Nativos
- **Botões**: `.btn`, `.btn-primary`, `.btn-outline-secondary`.
- **Cartões**: `.card`, `.card-body`, `.card-title`.
- **Alertas**: `.alert`, `.alert-success`, `.alert-danger`.

## 4. Utilitários
- **Espaçamento**: `m-3`, `p-2`, `mt-4`, `mb-2`.
- **Cores**: `.text-primary`, `.bg-dark`.
- **Flexbox**: `.d-flex`, `.justify-content-between`.
